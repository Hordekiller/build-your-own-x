مقدمه

هدف این مجموعه آموزش‌ها این است که با توسعه‌دادنِ یک بلاک‌چین، به شما در درک فناوری بلاک‌چین کمک کند. اگر می‌خواهید یک ارز دیجیتال واقعی بسازید، چیزی مانند coinmechanic.io جایگزین بسیار باهوش‌تری است!

در این آموزش ما:

  • اولین بلاک‌چین «بسیار» ابتدایی خود را می‌سازیم.
  • یک سیستم سادهٔ اثبات کار (proof of work / استخراج) را پیاده‌سازی می‌کنیم.
  • در برابر امکانات، شگفت‌زده می‌شویم.

(فرض می‌کنم درک پایه‌ای از برنامه‌نویسی شیءگرا (Object Oriented Programming) دارید.)

شایان ذکر است که این یک بلاک‌چین کاملاً کاربردی و آمادهٔ تولید نخواهد بود. در عوض، این یک پیاده‌سازیِ اثباتِ-مفهوم (proof of concept) است تا به شما کمک کند بفهمید بلاک‌چین برای آموزش‌های آینده چیست.

این بخشی از راهنمای بزرگ توسعه بلاک‌چین (The Blockchain Development Mega Guide) است.

راه‌اندازی (Setting Up)

ما از جاوا استفاده خواهیم کرد؛ اما شما باید بتوانید در هر زبان برنامه‌نویسی شیءگرای دیگری نیز همراه بیایید. من از Eclipse استفاده می‌کنم، اما شما می‌توانید از هر ویرایشگر متن مدرن و شیکی استفاده کنید (اگرچه بسیاری از مزخرفات خوب را از دست خواهید داد).

شما نیاز دارید:

  • جاوا و JDK نصب‌شده (معلوم است).
  • Eclipse (یا یک IDE/ویرایشگر متن دیگر).

اگر Eclipse شما با من فرق دارد نگران نباشید. من از تم تیره در Eclipse استفاده می‌کنم، چون ^

ساخت بلاک‌چین (Making the Blockchain)

بلاک‌چین فقط یک زنجیره/لیست از بلاک‌هاست. هر بلاک در بلاک‌چین اثر انگشت دیجیتال (digital fingerprint) خودش را دارد، اثر انگشت دیجیتال بلاک قبلی را در خود دارد و مقداری داده دارد (این داده می‌تواند مثلاً تراکنش‌ها باشد).

امیدوارم ناکاموتو (Nakamoto) هرگز این را نبیند.

هش (Hash) = اثر انگشت دیجیتال.

هر بلاک فقط هش بلاک قبل از خود را در خود ندارد؛ بلکه هش خودش نیز تا حدی از هش قبلی محاسبه می‌شود. اگر دادهٔ بلاک قبلی تغییر کند، هش بلاک قبلی تغییر خواهد کرد (زیرا تا حدی از روی داده محاسبه می‌شود) و به نوبهٔ خود همهٔ هش‌های بلاک‌های پس از آن را تحت تأثیر قرار می‌دهد. محاسبه و مقایسهٔ هش‌ها به ما امکان می‌دهد ببینیم آیا یک بلاک‌چین نامعتبر است.

این یعنی چه؟ …تغییر هر داده‌ای در این لیست، امضا را تغییر می‌دهد و زنجیره را می‌شکند.

پس اول بیایید کلاس Block را بسازیم که بلاک‌چین را تشکیل می‌دهد:

javaimport java.util.Date;

public class Block {

	public String hash;
	public String previousHash;
	private String data; //داده ما یک پیام ساده است.
	private long timeStamp; //به صورت تعداد میلی‌ثانیه از 1/1/1970.

	//سازنده بلاک.
	public Block(String data,String previousHash ) {
		this.data = data;
		this.previousHash = previousHash;
		this.timeStamp = new Date().getTime();
	}
}

همان‌طور که می‌بینید، Block ابتدایی ما شامل یک String hash است که امضای دیجیتال ما را نگه می‌دارد. متغیر previousHash برای نگه‌داشتن هش بلاک قبلی و String data برای نگه‌داشتن دادهٔ بلاک ماست.

در ادامه به راهی برای تولید یک اثر انگشت دیجیتال نیاز خواهیم داشت

الگوریتم‌های رمزنگاری زیادی وجود دارند که می‌توانید از میان آن‌ها انتخاب کنید؛ با این‌حال SHA256 برای این مثال کاملاً کافی است. ما می‌توانیم با import java.security.MessageDigest; به الگوریتم SHA256 دسترسی پیدا کنیم.

بعداً در ادامه به SHA256 نیاز خواهیم داشت، پس بیایید یک متد کمکیِ به‌دردبخور در یک کلاس «ابزار» (utility) جدید به نام StringUtil بسازیم:

javaimport java.security.MessageDigest;

public class StringUtil {
	//الگوریتم Sha256 را روی یک رشته اعمال می‌کند و نتیجه را برمی‌گرداند.
	public static String applySha256(String input){
		
		try {
			MessageDigest digest = MessageDigest.getInstance("SHA-256");	        
			//sha256 را روی ورودی ما اعمال می‌کند،
			byte[] hash = digest.digest(input.getBytes("UTF-8"));	        
			StringBuffer hexString = new StringBuffer(); // این رشته هش را به صورت هگزادسیمال نگه می‌دارد
			for (int i = 0; i<hash.length; i++) {
				String hex = Integer.toHexString(0xff&hash[i]);
				if(hex.length() == 1) hexString.append('0');
				hexString.append(hex);
			}
			return hexString.toString();
		}
		catch(Exception e) {
			throw new RuntimeException(e);
		}
	}	
}

این تا حد زیادی کپی از http://www.baeldung.com/sha-256-hashing-java است.

اگر محتوای این متد کمکی را متوجه نمی‌شوید خیلی نگران نباشید؛ تنها چیزی که باید بدانید این است که یک رشته می‌گیرد و الگوریتم SHA256 را روی آن اعمال می‌کند و امضای تولیدشده را به‌صورت یک رشته برمی‌گرداند.

حالا بیایید از متد کمکی applySha256 خود، در یک متد جدید در کلاس Block برای محاسبهٔ هش استفاده کنیم. ما باید هش را از تمام بخش‌های بلاکی که نمی‌خواهیم دستکاری شوند محاسبه کنیم. پس برای بلاک خود، previousHash، data و timeStamp را لحاظ می‌کنیم.

javapublic String calculateHash() {
	String calculatedhash = StringUtil.applySha256( 
			previousHash +
			Long.toString(timeStamp) +
			data 
			);
	return calculatedhash;
}

و بیایید این متد را به سازندهٔ Block نیز اضافه کنیم…

javapublic Block(String data,String previousHash ) {
	this.data = data;
	this.previousHash = previousHash;
	this.timeStamp = new Date().getTime();
	this.hash = calculateHash(); //مطمئن می‌شویم این کار را بعد از مقداردهی سایر مقادیر انجام می‌دهیم.
}

زمان کمی آزمایش…

در کلاس اصلی NoobChain بیایید چند بلاک بسازیم و هش‌ها را روی صفحه چاپ کنیم تا ببینیم همه‌چیز درست کار می‌کند یا نه.

بیایید این را آزمایش کنیم…

اولین بلاک، بلاک جنسیس (genesis block) نامیده می‌شود و چون بلاک قبلی وجود ندارد، فقط «0» را به‌عنوان هش قبلی وارد می‌کنیم.

javapublic class NoobChain {

	public static void main(String[] args) {

		Block genesisBlock = new Block("Hi im the first block", "0");
		System.out.println("Hash for block 1 : " + genesisBlock.hash);

		Block secondBlock = new Block("Yo im the second block",genesisBlock.hash);
		System.out.println("Hash for block 2 : " + secondBlock.hash);

		Block thirdBlock = new Block("Hey im the third block",secondBlock.hash);
		System.out.println("Hash for block 3 : " + thirdBlock.hash);

	}
}

خروجی باید چیزی شبیه به این باشد:

مقادیر شما متفاوت خواهند بود، زیرا برچسب زمانی (timestamp) شما متفاوت است.

هر بلاک اکنون امضای دیجیتال خودش را بر اساس اطلاعاتش و امضای بلاک قبلی دارد.

در حال حاضر این زیاد یک بلاک‌چین (blockchain) نیست، پس بیایید بلاک‌هایمان را در یک ArrayList ذخیره کنیم و برای مشاهده به‌صورت Json، gson را هم import کنیم. (برای یادگیری نحوهٔ import کردن کتابخانهٔ gson اینجا کلیک کنید)

javaimport java.util.ArrayList;
import com.google.gson.GsonBuilder;

public class NoobChain {

	public static ArrayList<Block>blockchain = new ArrayList<Block>();

	public static void main(String[] args) {
		//بلاک‌هایمان را به آرایه‌لیست بلاک‌چین اضافه می‌کنیم:
		blockchain.add(new Block("Hi im the first block", "0"));
		blockchain.add(new Block("Yo im the second block",blockchain.get(blockchain.size()-1).hash));
		blockchain.add(new Block("Hey im the third block",blockchain.get(blockchain.size()-1).hash));

		String blockchainJson = new GsonBuilder().setPrettyPrinting().create().toJson(blockchain);
		System.out.println(blockchainJson);
	}

}

حالا خروجی ما باید به چیزی نزدیک‌تر به آنچه انتظار داریم یک بلاک‌چین شبیه آن باشد، باشد.

حالا به راهی برای بررسی یکپارچگی بلاک‌چین خود نیاز داریم

بیایید یک متد Boolean به نام isChainValid() در کلاس NoobChain بسازیم که در تمام بلاک‌های زنجیره حلقه بزند و هش‌ها را مقایسه کند. این متد باید بررسی کند که متغیر hash واقعاً با هش محاسبه‌شده برابر است و هش بلاک قبلی با متغیر previousHash برابر است.

javapublic static Boolean isChainValid() {
	Block currentBlock;
	Block previousBlock;

	//حلقه روی بلاک‌چین برای بررسی هش‌ها:
	for(int i=1; i<blockchain.size(); i++) {
		currentBlock = blockchain.get(i);
		previousBlock = blockchain.get(i-1);
		//مقایسه هش ثبت‌شده و هش محاسبه‌شده:
		if(!currentBlock.hash.equals(currentBlock.calculateHash()) ){
			System.out.println("Current Hashes not equal");
			return false;
		}
		//مقایسه هش قبلی و هش قبلی ثبت‌شده
		if(!previousBlock.hash.equals(currentBlock.previousHash) ) {
			System.out.println("Previous Hashes not equal");
			return false;
		}
	}
	return true;
}

هر تغییری در بلاک‌های بلاک‌چین باعث می‌شود این متد false برگرداند.

در شبکهٔ بیت‌کوین، نودها (nodes) بلاک‌چین‌های خود را به اشتراک می‌گذارند و طولانی‌ترین زنجیرهٔ معتبر توسط شبکه پذیرفته می‌شود. چه چیزی جلوی کسی را می‌گیرد که داده‌ها را در یک بلاک قدیمی دستکاری کند و سپس یک بلاک‌چین کاملاً جدید و طولانی‌تر بسازد و آن را به شبکه ارائه دهد؟ اثبات کار (Proof of work). سیستم اثبات کارِ هش‌کش (hashcash) به این معناست که ساخت بلاک‌های جدید زمان و توان محاسباتی قابل‌توجهی می‌برد. از این رو، مهاجم به توان محاسباتی بیشتری نسبت به مجموع بقیهٔ همتاها نیاز خواهد داشت.

hashcash، بسیار عالی.

بیایید استخراج بلاک‌ها را شروع کنیم!!!

ما از استخراج‌کننده‌ها (miners) می‌خواهیم اثبات کار را با امتحان‌کردن مقادیر متغیر مختلف در بلاک انجام دهند، تا زمانی که هش آن با تعداد مشخصی 0 شروع شود.

بیایید یک int به نام nonce اضافه کنیم تا در متد calculateHash() ما لحاظ شود، و متدِ به‌شدت موردنیازِ mineBlock():

javaimport java.util.Date;

public class Block {

	public String hash;
	public String previousHash;
	private String data; //داده ما یک پیام ساده است.
	private long timeStamp; //به صورت تعداد میلی‌ثانیه از 1/1/1970.
	private int nonce;

	//سازنده بلاک.
	public Block(String data,String previousHash ) {
		this.data = data;
		this.previousHash = previousHash;
		this.timeStamp = new Date().getTime();

		this.hash = calculateHash(); //مطمئن می‌شویم این کار را بعد از مقداردهی سایر مقادیر انجام می‌دهیم.
	}

	//محاسبه هش جدید بر اساس محتوای بلاک
	public String calculateHash() {
		String calculatedhash = StringUtil.applySha256(
				previousHash +
				Long.toString(timeStamp) +
				Integer.toString(nonce) +
				data
				);
		return calculatedhash;
	}

	public void mineBlock(int difficulty) {
		String target = new String(new char[difficulty]).replace('\0', '0'); //رشته‌ای با تعداد difficulty صفر بساز
		while(!hash.substring( 0, difficulty).equals(target)) {
			nonce ++;
			hash = calculateHash();
		}
		System.out.println("Block Mined!!! : " + hash);
	}
}

در واقعیت، هر استخراج‌کننده از یک نقطهٔ تصادفی شروع به تکرار (iterate) می‌کند. برخی استخراج‌کننده‌ها حتی ممکن است برای nonce اعداد تصادفی را امتحان کنند. همچنین شایان ذکر است که در سختی‌های بالاتر، راه‌حل‌ها ممکن است به بیشتر از integer.MAX_VALUE نیاز داشته باشند؛ در این صورت استخراج‌کننده‌ها می‌توانند تغییر برچسب زمانی را امتحان کنند.

متد mineBlock() یک int به نام difficulty می‌گیرد؛ این تعداد صفرهایی است که باید حل کنند. سختیِ پایین مانند ۱ یا ۲ تقریباً فوراً در بیشتر رایانه‌ها حل می‌شود؛ من چیزی در حدود ۴ تا ۶ را برای آزمایش پیشنهاد می‌کنم. در زمان نوشتن این مقاله، سختی لایت‌کوین (Litecoin) حدود 442,592 است.

بیایید difficulty را به‌عنوان یک متغیر استاتیک (static) به کلاس NoobChain اضافه کنیم:

javapublic static int difficulty = 5;

ما باید کلاس NoobChain را به‌روزرسانی کنیم تا برای هر بلاک جدید متد mineBlock() را فعال کند. متد Boolean یِ isChainValid() نیز باید بررسی کند که آیا هر بلاک هشِ حل‌شده (با استخراج) دارد یا نه.

javaimport java.util.ArrayList;
import com.google.gson.GsonBuilder;

public class NoobChain {

	public static ArrayList<Block>blockchain = new ArrayList<Block>();
	public static int difficulty = 5;

	public static void main(String[] args) {	
		//بلاک‌هایمان را به آرایه‌لیست بلاک‌چین اضافه می‌کنیم:

		blockchain.add(new Block("Hi im the first block", "0"));
		System.out.println("Trying to Mine block 1... ");
		blockchain.get(0).mineBlock(difficulty);

		blockchain.add(new Block("Yo im the second block",blockchain.get(blockchain.size()-1).hash));
		System.out.println("Trying to Mine block 2... ");
		blockchain.get(1).mineBlock(difficulty);

		blockchain.add(new Block("Hey im the third block",blockchain.get(blockchain.size()-1).hash));
		System.out.println("Trying to Mine block 3... ");
		blockchain.get(2).mineBlock(difficulty);	
		
		System.out.println("\n Blockchain is Valid: " + isChainValid());

		String blockchainJson = new GsonBuilder().setPrettyPrinting().create().toJson(blockchain);
		System.out.println("\n The block chain: ");
		System.out.println(blockchainJson);
	}

	public static Boolean isChainValid() {
		Block currentBlock; 
		Block previousBlock;
		String hashTarget = new String(new char[difficulty]).replace('\0', '0');

		//حلقه روی بلاک‌چین برای بررسی هش‌ها:
		for(int i=1; i<blockchain.size(); i++) {
			currentBlock = blockchain.get(i);
			previousBlock = blockchain.get(i-1);
			//مقایسه هش ثبت‌شده و هش محاسبه‌شده:
			if(!currentBlock.hash.equals(currentBlock.calculateHash()) ){
				System.out.println("Current Hashes not equal");			
				return false;
			}
			//مقایسه هش قبلی و هش قبلی ثبت‌شده
			if(!previousBlock.hash.equals(currentBlock.previousHash) ) {
				System.out.println("Previous Hashes not equal");
				return false;
			}
			//بررسی اینکه آیا هش حل شده است
			if(!currentBlock.hash.substring( 0, difficulty).equals(hashTarget)) {
				System.out.println("This block hasn't been mined");
				return false;
			}
		}
		return true;
	}
}

توجه کنید که اینجا isChainValid را نیز بررسی و چاپ می‌کنیم.

  • آن‌ها قادر نخواهند بود بلاک‌چین طولانی‌تری بسازند.
  • بلاک‌چین‌های صادق در شبکهٔ شما در زنجیرهٔ طولانی‌تر مزیت زمانی خواهند داشت.

یک بلاک‌چین دستکاری‌شده قادر نخواهد بود به یک زنجیرهٔ طولانی‌تر و معتبر برسد.*

*مگر اینکه سرعت محاسباتی آن‌ها بسیار بیشتر از مجموع سرعت محاسباتی تمام نودهای دیگر شبکهٔ شما باشد. یک رایانهٔ کوانتومیِ آینده یا چیزی شبیه به آن.

شما با بلاک‌چین ابتدایی خود کارتان تمام شد!

برو به پشت خودت بزن.

بلاک‌چین شما:

  • از بلاک‌هایی تشکیل شده است که داده ذخیره می‌کنند.
  • امضای دیجیتالی دارد که بلاک‌های شما را به هم زنجیر می‌کند.
  • برای اعتبارسنجی بلاک‌های جدید به استخراجِ اثباتِ کار نیاز دارد.
  • قابل بررسی است که داده‌های درون آن معتبر و تغییرناپذیرند.
