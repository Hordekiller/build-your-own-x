کدک چیست و چرا از صفر؟

کدک (Codec = Compressor-Decompressor) الگوریتمی است که ویدیو را برای ذخیره/انتقال فشرده می‌کند و دوباره بازیابی می‌کند. H.264 استاندارد محبوبی است که در اکثر پخش‌کننده‌ها و دوربین‌ها استفاده می‌شود. پروژهٔ «codec-from-scratch» زیرمجموعهٔ کاربردی آن را پیاده می‌کند که برای یادگیری، بسیار ارزشمندتر از مطالعهٔ سند ۶۰۰ صفحه‌ای است.

ساختار فایل و NAL units

در H.264، داده به «واحدهای NAL» (Network Abstraction Layer) تقسیم می‌شود که هرکدام یک «header» و بدنه دارند. پارس‌کردن این واحدها، اولین قدم است:

Go// پارس یک NAL unit: بایت آغازین + header + داده
type NAL struct {
    Header   byte
    Type     int
    Payload  []byte
}

func parseNAL(data []byte) (*NAL, error) {
    start := 0
    // فرمت 00 00 01 یا 00 00 00 01
    if len(data) > 4 && data[0]==0 && data[1]==0 && data[2]==0 && data[3]==1 {
        start = 4
    } else if len(data) > 3 && data[0]==0 && data[1]==0 && data[2]==1 {
        start = 3
    } else {
        return nil, errors.New("فرمت NAL نامعتبر")
    }
    header := data[start]
    return &NAL{
        Header:  header,
        Type:    int(header & 0x1F),   // 5 بیت میانی: نوع NAL
        Payload: data[start+1:],
    }, nil
}

نوع‌های مهم: `1` برای slice غیرIDR، `5` برای IDR (کلید فریم) و `7` برای SPS (پارامترهای متادیتا).

رمزگشایی ماکروبلوک‌ها

فریم‌ها به «ماکروبلوک‌های» ۱۶×۱۶ تقسیم می‌شوند. هر ماکروبلوک می‌تواند با جبران حرکت (motion) از فریم قبلی پیش‌بینی شود یا مستقیم رمزگشایی شود. برای هر ماکروبلوک، ضرایب DCT و رویدادهای CAVLC خوانده می‌شود:

Go// خواندن یک ماکروبلوک از استریم بیتی
func (d *Decoder) decodeMacroblock() (mb, error) {
    mbType := d.readUE()   // ازمپ جووینت شمارهٔ نوع
    res := mb{}

    if mbType > 0 {        // نوع غیر «ترقی»
        // خواندن تفاوت‌های جبران حرکت
        res.mvDX = d.readSE()
        res.mvDY = d.readSE()
    }

    // خواندن ضرایب تبدیل (جزئیات)
    for i := 0; i < 256; i++ {
        c, more := d.readCoeff()
        if !more { break }
        res.coeffs = append(res.coeffs, c)
    }
    return res, nil
}

توابع `readUE`/`readSE` (Exp-Golomb) اجزای پایهٔ فشرده‌سازی هستند که اعداد کوچک را با بیت‌های کمتری نشان می‌دهند.

جمع‌بندی

این پروژه نشان می‌دهد که پیاده‌سازی یک کدک، ترکیبی از ساختار بیتی، پیش‌بینی تصویری و ریاضیات تحویل است. بعد از ساختن decoder ساده، مسیر به سمت encoder و استانداردهای جدیدتر (HEVC/AV1) باز می‌شود.
