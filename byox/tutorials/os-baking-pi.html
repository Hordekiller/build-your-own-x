Baking Pi — توسعه سیستم‌عامل با اسمبلی ARM روی Raspberry Pi

⚙ زبان: ARM Assembly 🍓 Raspberry Pi ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور دورهٔ «Baking Pi — Operating Systems Development» از الکس چادویک (Alex Chadwick) در گروه علوم کامپیوتر دانشگاه کمبریج است که سیستم‌عامل را روی Raspberry Pi با اسمبلی ARMv6 آموزش می‌دهد.
↗ مشاهده منبع اصلی

۱. دربارهٔ دوره

Baking Pi یک دورهٔ رایگان دانشگاه کمبریج است که پایه‌های توسعهٔ سیستم‌عامل را روی Raspberry Pi و تقریباً به‌طور کامل با اسمبلی ARMv6 آموزش می‌دهد. رویکرد دوره متفاوت است: به‌جای ساخت یک سیستم‌عامل کامل، هر درس یک «کار کوچک» را کامل انجام می‌دهد — از روشن کردن یک LED تا خط فرمان — و هر درس نظریهٔ لازم و تمرین عملی کامل دارد. هیچ دانش قبلی از اسمبلی یا سیستم‌عامل فرض نمی‌شود.

۲. ابزارها و محیط

نیازمندی‌ها: یک Raspberry Pi (با کارت SD و منبع تغذیه) و یک کامپیوتر جدا برای توسعه که کامپایلر متقاطع ARMv6 (کراس‌کامپایلر) روی آن نصب باشد. نتیجهٔ کامپایل، فایل kernel.img است که روی کارت SD جایگزین کرنل لینوکس می‌شود (یک کپی از کرنل اصلی همیشه نگه دارید!). نصب کراس‌کامپایلر در لینوکس ساده است:

bash# نصب کراس‌کامپایلر ARM برای Raspberry Pi (نسخه‌ی قدیمی ARMv6)
sudo apt install gcc-arm-none-eabi binutils-arm-none-eabi

# ساخت پروژه با Makefile قالب OS Template
make        # خروجی: kernel.img، kernel.list، kernel.map

۳. درس‌ها: از LED تا خط فرمان

دوره به سه سری تقسیم می‌شود که هر درس روی درس قبل بنا می‌شود:

  • سری OK LED (مبتدی): OK01: روشن کردن LED برد با پیکربندی GPIO؛ OK02: چشمک‌زدن؛ OK03: توابع اسمبلی؛ OK04: تایمر برای چشمک‌زدن دقیق؛ OK05: الگوی مورس SOS.
  • سری Screen (پیشرفته): Screen01: گرادیان رنگی روی صفحه؛ Screen02: رسم خط و اعداد تصادفی؛ Screen03: چاپ متن و آشنایی با kernel command line؛ Screen04: چاپ مقادیر محاسبه‌شده.
  • سری Input (پیشرفته): Input01: تئوری درایورها، لینک‌کردن و صفحه‌کلید — استفاده از درایور USB آماده و چاپ حروف؛ Input02: یک خط فرمان کامل که دستورهای کاربر را اجرا می‌کند.

۴. نمونه‌ی کد: روشن کردن LED (OK01)

اولین سیستم‌عامل، پیامی به کنترل‌کنندهٔ GPIO می‌فرستد تا پین ۱۶ (LED برد) فعال شود. نکتهٔ جالب: سخت‌افزار به‌گونه‌ای طراحی شده که LED با خاموش کردن پین روشن می‌شود! و چون پردازنده هرگز متوقف نمی‌شود، باید یک حلقهٔ بی‌پایان در انتها بگذاریم:

arm// main.s — روشن کردن OK/ACT LED روی Raspberry Pi (ARMv6)
.section .init          // این بخش اول اجرا می‌شود
.global _start

_start:
    ldr r0, =0x20200000  // آدرس پایه‌ی کنترل‌کننده‌ی GPIO
    mov r1, #1           // تنظیم بیت‌های خروجی برای پین ۱۶
    lsl r1, #18          // (پین ۱۶ هر ۳ بیت، یعنی بیت ۱۸)
    str r1, [r0, #4]     // نوشتن در GPFSEL1: پین ۱۶ خروجی شود

    mov r1, #1
    lsl r1, #16
    str r1, [r0, #40]    // GPCLR0: «خاموش» کردن پین ۱۶ ← LED روشن!

loop$:
    b loop$              // حلقه‌ی بی‌پایان

کامپایل با make سه فایل تولید می‌کند: kernel.img (تصویر بوت)، kernel.list (نمایش اسمبلی واقعی) و kernel.map (نقشهٔ آدرس برچسب‌ها). بعد از کپی روی کارت SD و روشن کردن Pi، LED سبز روشن می‌شود — اولین سیستم‌عامل شما!

۵. چرا این دوره ارزش دنبال کردن دارد؟

  • سخت‌افزار واقعی: روی برد واقعی اجرا می‌کنید، نه فقط شبیه‌ساز.
  • اسمبلی خالص: هیچ کامپایلر C وسط کار نیست؛ رابط بین کد و سخت‌افزار کاملاً شفاف است.
  • نظریه + عمل در هر درس: هر مفهوم (درایور، لینک، تایمر، جدول جست‌وجو) قبل از کد، توضیح داده می‌شود.
  • پاسخ کامل درس‌ها: پاسخ مدل هر درس در صفحهٔ دانلود دوره هست.
نکتهٔ تکمیلی: این دوره نقطهٔ شروع عالی برای کسانی است که می‌خواهند بعداً سراغ آموزش‌های پیشرفته‌تر ARM مثل mini-arm-os بروند — در همین مجموعه ترجمه شده است.
کپیرایت: دورهٔ «Baking Pi — Operating Systems Development» اثر الکس چادویک (Alex Chadwick) و گروه علوم کامپیوتر دانشگاه کمبریج است. این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
