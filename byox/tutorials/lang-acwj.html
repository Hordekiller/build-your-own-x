واقعی‌ترین سری ساخت کامپایلر C

بیشتر آموزش‌ها یا یک زبان ساختگی می‌سازند یا به یک زیرمجموعهٔ کوچک می‌رسند. اما جلسهٔ وارن تومی (که سال‌ها روی کامپایلرهای واقعی کار کرده) یک کامپایلر SubC می‌سازد که بخش بزرگی از زبان C واقعی را پشتیبانی می‌کند: تمام عملگرها، انواع پایه، struct، union، enum، typedef، توابع با آرگومان‌های متغیر (varargs)، حتی یک پیش‌پردازندهٔ ساده.

معماری پایه: Pratts پارسر

بخش‌های ابتدایی به سرعت پایه‌ها را می‌سازند: lexer با کلاس‌های token، سپس پارسری که از «قدرت باندینگ» (binding power) و روش Pratt parsing استفاده می‌کند — روشی مدرن که پردازش عملگرهای با اولویت‌های مختلف را بسیار تمیز می‌کند:

C// جدول اولویت عملگرها
static struct {
  int token;
  int precedence;
} binop_prec[] = {
  { T_PLUS, 10 }, { T_MINUS, 10 },   // جمع/تفریق
  { T_STAR, 20 }, { T_SLASH, 20 },   // ضرب/تقسیم
  { T_EQ,   40 }, { T_NE, 40 },      // برابری
  ...
};

// پارسر عملگرهای دودویی (Pratt)
static struct ASTnode *binexpr(int ptp) {
  struct ASTnode *left = unary();
  while (op_precedence(Token.token) > ptp) {
    int tok = Token.token;
    left = mkastnode(A_BINOP, left, NULL, tok, ...);
  }
  return left;
}

گام‌های اصلی سفر

سفر در ۳۴ بخش: ۱-۵) مبانی lexer/parser و تولید اسمبلی؛ ۶-۸) مقادیر و عملگرهای منطقی؛ ۹-۱۲) شرط‌ها و حلقه‌ها؛ ۱۳-۱۵) تابع‌ها و فراخوانی‌ها (callq)؛ ۱۶-۲۲) پوینترها و dereference (کلاس موقعیت‌های پرتنش!)؛ ۲۳-۲۸) struct/union/enum و typedef؛ ۲۹-۳۱) varargs و پیش‌پردازنده؛ ۳۲-۳۴) مقادیر منطقی، لانداها و …

نکتهٔ مهم: هر بخش شامل تست‌های (tests) است که رگرسیون را تضمین می‌کند — مثل یک پروژهٔ واقعی.

نمونهٔ کد: تولید اسمبلی برای ضرب

Assembly# a = b * 3  →  کد تولیدی برای x86-64
        movq    %rbx, %rax    # b را در rax بگذار
        imulq   $3, %rax, %rax   # ضرب در 3
        movq    %rax, a(%rip) # ذخیره در a

جمع‌بندی

اگر می‌خواهید بفهمید «کامپایلر C واقعی چطور کار می‌کند»، acwj بهترین منبع موجود است: عمق کامل، تست‌های منظم، و در پایان شما یک کامپایلر دارید که می‌تواند فایل‌های C واقعی را به اسمبلی تبدیل کند.
