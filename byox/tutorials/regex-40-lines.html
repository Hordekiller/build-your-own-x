یک موتور Regex در کمتر از ۴۰ خط کد بساز

⚙ زبان: JavaScript ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمه فارسی مقاله «Build a Regex Engine in Less than 40 Lines of Code» از نیک درین (نوامبر ۲۰۱۷) است. کد مقاله، تبدیل کد ۳۰ خطی راب پایک به جاوااسکریپت است.
↗ مشاهده منبع اصلی

مقدمه

چند روز پیش به مقاله‌ای برخوردم که در آن راب پایک یک موتور عبارت باقاعده ابتدایی در C پیاده می‌کند. کد او را به جاوااسکریپت تبدیل کردم و مشخصات آزمون اضافه کردم تا کسی بتواند خودش را در ساخت موتور regex راهنمایی کند. مشخصات و راه‌حل در این مخزن گیت‌هاب موجود است. این پست وبلاگ راهنمای راه‌حل من است.

مسئله

موتور regex ما از نحو زیر پشتیبانی می‌کند:

نحونحو      معنی                          مثال     مطابقت با
a        کاراکتر تحت‌اللفظی مشخص        q        q
*        صفر یا بیشتر از کاراکتر قبلی   a*       "", a, aa, aaa
?        صفر یا یک از کاراکتر قبلی      a?       "", a
.        هر کاراکتر                     .        a, b, c, d, e ...
^        شروع رشته                      ^c       c, ca, caa, cbb ...
$        پایان رشته                     a$       ba, baaa, qwerta ...

هدف ارائه نحو مستحکمی است که با حداقل کد، بخش بزرگی از موارد استفاده regex را پوشش دهد.

مطابقت یک کاراکتر

اولین گام نوشتن تابعی است که یک الگوی تک‌کاراکتری و یک متن تک‌کاراکتری می‌گیرد و بولی برمی‌گرداند که نشان می‌دهد مطابقت دارند یا نه. الگوی . جانشین در نظر گرفته می‌شود و با هر کاراکتری مطابقت می‌خورد.

چند مثال:

jsmatchOne('a', 'a') -> true
matchOne('.', 'z') -> true
matchOne('', 'h') -> true
matchOne('a', 'b') -> false
matchOne('p', '') -> false
jsfunction matchOne(pattern, text) {
  if (!pattern) return true; // هر متنی با الگوی خالی مطابقت دارد
  if (!text) return false; // اگر الگو تعریف شده اما متن خالی باشد، مطابقت ممکن نیست
  if (pattern === ".") return true; // هر متن ورودی با جانشین مطابقت دارد
  return pattern === text;
}

مطابقت رشته‌های هم‌طول

حالا پشتیبانی از الگوها و متن‌های بلندتر را اضافه می‌کنیم. فعلاً فقط جفت الگو/متن هم‌طول را در نظر بگیرید. می‌دانم راه‌حل خودش را به بازگشت می‌سپارد، پس اینجا از بازگشت استفاده می‌کنیم. می‌خواهیم به‌طور مکرر matchOne را روی جفت‌های متوالی کاراکتر از ترکیب الگو/متن صدا بزنیم.

jsfunction match(pattern, text) {
  if (pattern === "") return true;
  // حالت پایه - اگر الگو خالی باشد، هر متن ورودی مطابقت است
  else
    return (
      matchOne(pattern[0], text[0]) && match(pattern.slice(1), text.slice(1))
    );
}

کد بالا کاراکتربه‌کاراکتر روی جفت الگو/متن پیش می‌رود. اول pattern[0] را با text[0] مقایسه می‌کند، بعد pattern[1] را با text[1] و تا i === pattern.length - 1 ادامه می‌دهد. اگر در هر نقطه مطابقت ندادند، می‌دانیم الگو نمی‌تواند با متن مطابقت کند.

مثالی بزنیم. فرض کنید match('a.c', 'abc') را صدا می‌زنیم که به matchOne('a', 'a') && match('.c', 'bc') تبدیل می‌شود. با ادامه ارزیابی این توابع به matchOne('a', 'a') && matchOne('.', 'b') && matchOne('c', 'c') && match("", "") می‌رسیم که برابر true && true && true && true است. پس مطابقت داریم!

کاراکتر $

پشتیبانی از کاراکتر ویژه الگو $ را اضافه می‌کنیم که به ما اجازه می‌دهد پایان رشته را مطابقت دهیم. راه‌حل فقط به افزودن یک حالت پایه به تابع match نیاز دارد:

jsfunction match(pattern, text) {
  if (pattern === "") return true;
  if (pattern === "$" && text === "") return true;
  else
    return (
      matchOne(pattern[0], text[0]) && match(pattern.slice(1), text.slice(1))
    );
}

کاراکتر ^

پشتیبانی از کاراکتر ویژه الگو ^ را اضافه می‌کنیم که به ما اجازه می‌دهد شروع رشته را مطابقت دهیم. یک تابع جدید به نام search معرفی می‌کنم:

jsfunction search(pattern, text) {
  if (pattern[0] === "^") {
    return match(pattern.slice(1), text);
  }
}

این تابع نقطه ورود جدید کد ما خواهد بود. تا اینجا فقط الگوهایی را مطابقت می‌دادیم که از آغاز متن شروع می‌شدند. حالا با الزام کاربر به پیشوند ^ آن را واضح‌تر می‌کنیم. اما الگوهایی که در هر جای متن ظاهر می‌شوند چطور؟

مطابقت‌هایی که از هرجا شروع می‌شوند

در حال حاضر موارد زیر true برمی‌گردانند:

jssearch("^abc", "abc")
search("^abcd", "abcd")

اما search("bc", "abcd") مقدار undefined برمی‌گرداند. می‌خواهیم true برگرداند.

اگر کاربر مشخص نکند الگو با آغاز متن مطابقت دارد، می‌خواهیم الگو را در هر نقطه شروع ممکن داخل متن جست‌وجو کنیم. اگر الگو با ^ شروع نشود، به این رفتار پیش‌فرض می‌رویم:

jsfunction search(pattern, text) {
  if (pattern[0] === "^") {
    return match(pattern.slice(1), text);
  } else {
    // این کد match(pattern, text.slice(index)) را روی هر اندیس متن اجرا می‌کند.
    // یعنی الگو را روی هر نقطه شروع متن می‌آزماییم.
    return text.split("").some((_, index) => {
      return match(pattern, text.slice(index));
    });
  }
}

کاراکتر ?

می‌خواهیم صفر تا یک از کاراکتر قبل از ? را مطابقت دهیم.

چند مثال:

jssearch("ab?c", "ac") -> true
search("ab?c", "abc") -> true
search("a?b?c?", "abc") -> true
search("a?b?c?", "") -> true

اولین گام اصلاح match برای تشخیص حضور کاراکتر ? و واگذاری کار به تابع matchQuestion است که به‌زودی تعریف می‌کنیم:

jsfunction match(pattern, text) {
  if (pattern === "") {
    return true;
  } else if (pattern === "$" && text === "") {
    return true;
    // توجه کنید به pattern[1] نگاه می‌کنیم نه pattern[0].
    // pattern[0] کاراکتری است که باید صفر یا یک بار مطابقت کند.
  } else if (pattern[1] === "?") {
    return matchQuestion(pattern, text);
  } else {
    return (
      matchOne(pattern[0], text[0]) && match(pattern.slice(1), text.slice(1))
    );
  }
}

matchQuestion باید دو حالت را مدیریت کند:

  1. جایی که کاراکتر قبل از ? مطابقت نمی‌کند اما متن با بقیه الگو (همه‌چیز بعد از ?) مطابقت دارد.
  2. جایی که کاراکتر قبل از ? مطابقت می‌کند و بقیه متن (منهای یک کاراکتر مطابقت‌شده) با بقیه الگو مطابقت دارد.

اگر هرکدام از این حالت‌ها truthy بود، matchQuestion می‌تواند true برگرداند.

حالت اول را در نظر بگیریم. چگونه بررسی کنیم متن با همه‌چیزِ الگو جز نحو _? مطابقت دارد؟ به عبارت دیگر، چگونه بررسی کنیم کاراکتر قبل از ? صفر بار ظاهر شده؟ دو کاراکتر از الگو جدا می‌کنیم (اولی کاراکتر قبل از ? و دومی خود ?) و تابع match را صدا می‌زنیم:

jsfunction matchQuestion(pattern, text) {
  return match(pattern.slice(2), text);
}

حالت دوم کمی چالش‌برانگیزتر است، اما مثل قبل از توابعی که قبلاً نوشته‌ایم دوباره استفاده می‌کند:

jsfunction matchQuestion(pattern, text) {
  if (matchOne(pattern[0], text[0]) && match(pattern.slice(2), text.slice(1))) {
    return true;
  } else {
    return match(pattern.slice(2), text);
  }
}

اگر text[0] با pattern[0] مطابقت کند و بقیه متن (منهای بخشی که matchOne مطابقت داده) با بقیه الگو مطابقت داشته باشد، موفقیم. می‌توانیم کد را این‌گونه بازنویسی کنیم:

jsfunction matchQuestion(pattern, text) {
  return (
    (matchOne(pattern[0], text[0]) && match(pattern.slice(2), text.slice(1))) ||
    match(pattern.slice(2), text)
  );
}

نکته‌ای که از این رویکرد دوم دوست دارم این است که OR بولی صریحاً روشن می‌کند دو حالت وجود دارد که هرکدام می‌تواند درست باشد.

کاراکتر *

می‌خواهیم کاراکتر قبل از * را صفر یا بیشتر بار مطابقت دهیم.

همه این‌ها باید true برگردانند:

jssearch("a*", "")
search("a*", "aaaaaaa")
search("a*b", "aaaaaaab")

مثل کاری که برای پشتیبانی از ? کردیم، کار را در تابع match به تابع matchStar واگذار می‌کنیم:

jsfunction match(pattern, text) {
  if (pattern === "") {
    return true;
  } else if (pattern === "$" && text === "") {
    return true;
  } else if (pattern[1] === "?") {
    return matchQuestion(pattern, text);
  } else if (pattern[1] === "*") {
    return matchStar(pattern, text);
  } else {
    return (
      matchOne(pattern[0], text[0]) && match(pattern.slice(1), text.slice(1))
    );
  }
}

matchStar مثل matchQuestion باید دو حالت را مدیریت کند:

  1. جایی که کاراکتر قبل از * مطابقت نمی‌کند اما متن با بقیه الگو (همه‌چیز بعد از *) مطابقت دارد.
  2. جایی که کاراکتر قبل از * یک یا بیشتر بار مطابقت می‌کند و بقیه متن با بقیه الگو مطابقت دارد.

چون دو حالت هست که هر دو به مطابقت می‌انجامند، می‌دانیم matchStar را می‌توان با OR بولی پیاده کرد. علاوه بر این، حالت ۱ برای matchStar دقیقاً همان حالت ۱ برای matchQuestion است و می‌توان آن را یکسان پیاده کرد: match(pattern.slice(2), text). یعنی فقط باید عبارتی بسازیم که حالت ۲ را برآورده کند:

jsfunction matchStar(pattern, text) {
  return (
    (matchOne(pattern[0], text[0]) && match(pattern, text.slice(1))) ||
    match(pattern.slice(2), text)
  );
}

بازآرایی

حالا می‌توانیم برگردیم و search را با یک ترفند که از کلاس پیتر نورویگ یاد گرفتم هوشمندانه ساده کنیم:

jsfunction search(pattern, text) {
  if (pattern[0] === "^") {
    return match(pattern.slice(1), text);
  } else {
    return match(".*" + pattern, text);
  }
}

از خود کاراکتر * برای اجازه دادن به الگو استفاده می‌کنیم تا در هر جای رشته ظاهر شود. .* پیش‌نشان‌دهنده می‌گوید هر تعداد از هر کاراکتر می‌تواند قبل از الگوی مورد نظر ما بیاید.
