یک اپ درخواست سفر (ride hailing) با React Native بساز

اپ تاکسی اینترنتی چه بخش‌هایی دارد؟

اپ‌های مثل Uber از سه بخش اصلی تشکیل شده‌اند: نمایش نقشه و موقعیت کاربر، تعیین مسیر و محاسبهٔ قیمت، و ارتباط بلادرنگ بین راننده و مسافر. در این آموزش، هر سه با ابزارهای رایگان پیاده می‌شوند: React Native برای رابط کاربری، react-native-maps برای نقشه و Pusher Channels برای پیام بلادرنگ.

مرحلهٔ ۱: نقشه و موقعیت

اولین صفحه، یک MapView با موقعیت فعلی کاربر است. با `react-native-maps` این کار بسیار ساده است:

JavaScriptimport MapView, { Marker, Polyline } from 'react-native-maps';

export default function MapScreen({ route }) {
  const { start, destination } = route.params;

  return (
    <MapView
      style={{ flex: 1 }}
      initialRegion={{
        latitude: start.latitude,
        longitude: start.longitude,
        latitudeDelta: 0.05,
        longitudeDelta: 0.05,
      }}
    >
      <Marker coordinate={start} title="مبدأ" pinColor="green" />
      <Marker coordinate={destination} title="مقصد" pinColor="red" />
      <Polyline coordinates={[start, destination]}
                 strokeColor="#00a" strokeWidth={4} />
    </MapView>
  );
}

با این کامپوننت، نقشه و مسیر مستقیم بین دو نقطه دیده می‌شود.

مرحلهٔ ۲: مسیر واقعی و قیمت

مسیر مستقیم واقعی نیست؛ برای مسیر جاده‌ای باید از یک سرویس مسیر (مثل Google Directions API) استفاده کنید. پاسخ API شامل polyline و فاصله است؛ با فاصله و تعرفه، قیمت تخمینی محاسبه می‌شود و روی صفحهٔ بعد نمایش داده می‌شود.

تماس با API باید در سرور واسطه انجام شود تا کلید API لو نرود — الگوی رایج اپ‌های واقعی.

مرحلهٔ ۳: بلادرنگ با Pusher

وقتی مسافر درخواست می‌دهد، یک رویداد در کانال Pusher فرستاده می‌شود که راننده‌ای (در اپ دوم) آن را دریافت کند. سادگی عالی کانال‌ها:

JavaScriptimport Pusher from 'pusher-js/react-native';

// ساختار کلاینت
const pusher = new Pusher('APP_KEY', { cluster: 'eu' });

export function subscribeToRides(onRide) {
  const channel = pusher.subscribe('rides');
  channel.bind('new-ride', onRide);
  return () => pusher.unsubscribe('rides');
}

// سمت سرور: انتشار رویداد جدید
// pusher.trigger('rides', 'new-ride', { start, destination });

با این‌حال، فریم‌ورک‌های جدیدتر (WebSockets خودتان + فایربیس) هم گزینه‌های جایگزینی هستند که در پایان آموزش بحث می‌شود.

جمع‌بندی

این پروژه تمام اجزای یک اپ موبایل واقعی (نقشه، شبکه، بلادرنگ) را پوشش می‌دهد و با React Native قابل اجرا روی Android/iOS است. بعد از آن، می‌توانید تشخیص خودکار مسیر با Google Places را هم اضافه کنید.

کپیرایت: Pusher. این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
