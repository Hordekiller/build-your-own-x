۱. چرا CNN برای تصاویر؟

برای طبقه‌بندی یک تصویر، «هلو، دنیای بینایی» یعنی مسئلهٔ MNIST: تشخیص رقم دست‌نویس از تصویر ۲۸×۲۸. شبکهٔ تمام‌متصل معمولی ضعف بزرگی دارد: یک تصویر ۲۸×۲۸ = ۷۸۴ پیکسل؛ با لایهٔ پنهانِ ۷۸۴ نوری، وزن‌ها به ۶۰۰ هزار می‌رسند و ساختار فضایی تصویر (نزدیکی پیکسل‌ها) نادیده گرفته می‌شود. CNN با دو ایدهٔ کلیدی این مشکل را حل می‌کند: کانولوشن (جابه‌جایی یک فیلتر روی تصویر) و هم‌ساخت بودن — یک الگو هر کجای تصویر باشد، با همان فیلتر پیدا می‌شود.

۲. کانولوشن: آشکارساز ویژگی

یک فیلتر (مثلاً ۳×۳) روی ناحیه‌های کوچک تصویر سُر می‌خورد و برای هر ناحیه، حاصل‌ضرب نقطه‌ای با پیکسل‌ها را می‌دهد. نتیجه یک «نقشهٔ ویژگی» است که شدت حضور آن الگو را در هر نقطه نشان می‌دهد. مثلاً یک فیلتر می‌تواند لبهٔ افقی را تشخیص دهد: اعدادِ ۱- در یک سطر و ۱ در سطر دیگر:

pythonimport numpy as np

class Conv3x3:
    # لایه‌ی کانولوشن با فیلترهای ۳×۳

    def __init__(self, num_filters):
        self.num_filters = num_filters
        # فیلترها: آرایه‌ی ۳بعدی (تعداد فیلتر، ۳، ۳)؛ تقسیم بر ۹ برای واریانس کم
        self.filters = np.random.randn(num_filters, 3, 3) / 9

    def forward(self, input):
        # خروجی: نقشه‌ی ویژگی با ابعاد (h−2, w−2, num_filters)
        h, w = input.shape
        output = np.zeros((h - 2, w - 2, self.num_filters))
        for i in range(h - 2):
            for j in range(w - 2):
                im_region = input[i:(i + 3), j:(j + 3)]  # ناحیه‌ی ۳×۳
                output[i, j] = np.sum(im_region * self.filters, axis=(1, 2))
        return output

در شبکهٔ نمونه، اولین لایه ۸ فیلتر دارد و تصویر ۲۸×۲۸ را به حجم 26×26×8 تبدیل می‌کند.

۳. لایهٔ Pooling: کوچک‌کردن هوشمندانه

نقشه‌های ویژگی هنوز بزرگ‌اند. لایهٔ Max Pooling هر بلوک ۲×۲ را به یک مقدار (بیشترین مقدار) کاهش می‌دهد — ابعاد نصف می‌شود، مهم‌ترین اطلاعات حفظ می‌شود، و کمی مقاومت به جابه‌جایی می‌دهد. در نمونه: 26×26×8 ← 13×13×8:

pythonclass MaxPool2:
    # لایه‌ی بیشینه‌گیری با پنجره‌ی ۲×۲ (بدون هم‌پوشانی)

    def forward(self, input):
        h, w, num_filters = input.shape
        output = np.zeros((h // 2, w // 2, num_filters))
        for i in range(h // 2):
            for j in range(w // 2):
                im_region = input[(i * 2):(i * 2 + 2), (j * 2):(j * 2 + 2)]
                output[i, j] = np.amax(im_region, axis=(0, 1))  # بیشینه روی h و w
        return output

۴. لایهٔ Softmax: تصمیم نهایی

برای طبقه‌بندی ۱۰ رقم، خروجی باید ۱۰ احتمال باشد. لایهٔ Softmax (تمام‌متصل) خروجی حجم‌ها را صاف می‌کند، با وزن‌ها و بایاس‌ها ترکیب می‌کند و با تابع softmax به توزیع احتمال تبدیل می‌کند. پیش‌بینی شبکه = رقمی با بیشترین احتمال:

pythonclass Softmax:
    # لایه‌ی تمام‌متصل با فعال‌سازی softmax

    def __init__(self, input_len, nodes):
        self.weights = np.random.randn(input_len, nodes) / input_len
        self.biases = np.zeros(nodes)

    def forward(self, input):
        input = input.flatten()
        totals = np.dot(input, self.weights) + self.biases
        exp = np.exp(totals)
        return exp / np.sum(exp, axis=0)   # توزیع احتمال

۵. چیدمان کامل و Forward

سه قطعه کنار هم شبکه را می‌سازند. برای هر تصویر، مقداردهی اولیه و Forward انجام و هزینهٔ cross-entropy و دقت محاسبه می‌شود. نرمال‌سازی تصاویر از [۰,۲۵۵] به [۰/۵- ، ۰/۵+] کار را برای شبکه آسان می‌کند:

pythonconv = Conv3x3(8)                    # 28×28×1 ← 26×26×8
pool = MaxPool2()                    # 26×26×8 ← 13×13×8
softmax = Softmax(13 * 13 * 8, 10)   # 13×13×8 ← 10

def forward(image, label):
    out = conv.forward((image / 255) - 0.5)   # نرمال‌سازی
    out = pool.forward(out)
    out = softmax.forward(out)

    loss = -np.log(out[label])                # هزینه‌ی cross-entropy
    acc = 1 if np.argmax(out) == label else 0
    return out, loss, acc

در این مقاله فقط Forward (پیش‌بینی) پیاده شد — هیچ یادگیری‌ای رخ نداد و وزن‌ها تصادفی‌اند (دقت ~۱۰٪، یعنی حدس تصادفی). آموزش CNN یعنی مشتق‌گیری از خطا در لایهٔ softmax، pooling و فیلترهای کانولوشن — مضمون مقالهٔ «بخش ۲: آموزش یک شبکهٔ عصبی کانولوشنی» از همین نویسنده.
