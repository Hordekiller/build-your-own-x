متدهای call()، apply() و bind() را خودت در جاوااسکریپت پیاده‌سازی کن

↗ مشاهده منبع اصلی

این سه متد چه کار می‌کنند؟

هر سه، «this» تابع را عوض می‌کنند: call با آرگومان‌های جدا، apply با آرایه، و bind یک تابع جدید برمی‌گرداند که this به آن گره خورده است. درک عمیق آن‌ها به شما نشان می‌دهد که this در جاوااسکریپت چطور کار می‌کند.

پیاده‌سازی myCall

ایدهٔ اصلی ساده است: تابع را به‌عنوان متدِ `context` صدا بزنیم. با اینکه این‌روش را می‌توان با `Reflect` و `Function` هم انجام داد، درخت ساده با property موقت واضح است:

JavaScript// myCall: فراخوانی تابع با this دلخواه و آرگومان‌های جدا
Function.prototype.myCall = function (context = globalThis, ...args) {
  // یک کلید یکتا برای جلوگیری از collision
  const fnKey = Symbol('fn');

  context[fnKey] = this;        // تابع را به context وصل کن
  const result = context[fnKey](...args);  // با آرگومان‌ها صدا بزن
  delete context[fnKey];        // ردِّ پا را پاک کن
  return result;
};

// استفاده: قطعه =
const person = { name: 'سارا' };
function greet(greeting) {
  return `${greeting}, ${this.name}`;
}
console.log(greet.myCall(person, 'سلام')); // سلام, سارا

نکات: اگر context null بود، `globalThis` را بگیریم و با Symbol کلید یکتا بسازیم.

myApply و myBind

myApply با یک آرایهٔ آرگومان کار می‌کند (یا `arguments`)، و myBind باید یک تابع جدید برگرداند که آرگومان‌های اولیه را ادغام کند:

JavaScript// myApply: مثل call ولی با آرایهٔ آرگومان
Function.prototype.myApply = function (context = globalThis, argsArray = []) {
  const fnKey = Symbol('fn');
  context[fnKey] = this;
  const result = context[fnKey](...argsArray);
  delete context[fnKey];
  return result;
};

// myBind: تابعِ گره‌خورده به this برمی‌گرداند
Function.prototype.myBind = function (context = globalThis, ...initialArgs) {
  const original = this;
  return function (...laterArgs) {
    return original.myCall(context, ...initialArgs, ...laterArgs);
  };
};

// استفاده از bind
const boundGreet = greet.myBind(person);
console.log(boundGreet('درود'));  // درود, سارا

`myBind` بستار (closure) می‌سازد: original و context و initialArgs حفظ می‌شوند و با هر فراخوانی با هم ترکیب می‌شوند.

چرا پیاده‌سازی آن‌ها مهم است؟

بازسازی این متدها، سازوکار this و بستارها را از «ماژیک» به «مفهوم» تبدیل می‌کند. روش‌های جایگزین (مثل `Reflect.apply` و `WeakMap` برای context) هم بحث می‌شوند؛ و در پایان می‌فهمید که bind/getcomrature میان receive untracked توسط V8 چطور کار می‌کند.

جمع‌بندی
