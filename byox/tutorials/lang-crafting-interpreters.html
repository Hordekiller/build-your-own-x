معرفی کتاب

Crafting Interpreters نوشتهٔ رابرت نیستروم نیست؟ بله! همان کسی که مقالهٔ «زباله‌روب نوزاد» را نوشته و در Google روی زبان Dart کار کرده است. این کتاب زبان Lox را دو بار پیاده می‌کند: بار اول یک مفسر درختی (tree-walker) در Java، بار دوم یک ماشین مجازی بایت‌کد در C. چیزی که هیچ کتاب دیگری نمی‌دهد: مقایسهٔ مستقیم دو معماری.

پارت اول: jlox — مفسر درختی در Java

بخش اول (فصل‌های ۴ تا ۱۳) scanner، parser (با تولیدکنندهٔ AST)، evaluator، محیط، توابع (closures)، کلاس‌ها (inheritance و polymorphism) را می‌سازد. یاد می‌گیرید که چطور ارزیابی گام‌به‌گام روی درخت نحو انجام می‌شود. نمونه:

Java// ارزیابی یک گره با visitor pattern
@Override
public Object visitBinaryExpr(Expr.Binary expr) {
  Object left = evaluate(expr.left);
  Object right = evaluate(expr.right);

  switch (expr.operator.type) {
    case PLUS:
      // عدد یا رشته: + هر دو را حذف می‌کند
      if (left instanceof Double && right instanceof Double)
        return (double) left + (double) right;
      if (left instanceof String && right instanceof String)
        return (String) left + (String) right;
      throw new RuntimeError(expr.operator, "مقادیر باید عدد یا رشته باشند");
    case MINUS:
      checkNumberOperands(expr.operator, left, right);
      return (double) left - (double) right;
    case STAR:
      checkNumberOperands(expr.operator, left, right);
      return (double) left * (double) right;
    case SLASH:
      checkNumberOperands(expr.operator, left, right);
      return (double) left / (double) right;
    default:
      throw new RuntimeError(expr.operator, "عملگر ناشناخته");
  }
}

پارت دوم: clox — ماشین مجازی در C

در پارت دوم (فصل‌های ۱۴ تا ۳۰) همه‌چیز از نو و با سرعت ساخته می‌شود: بایت‌کد (فصل ۱۵)، اجرای VM با حلقهٔ dispatch (فصل ۱۶)، جدول‌های هش برای متغیرهای سراسری (فصل ۱۸)، closures با upvalue (فصل ۲۵)، جمع‌کنندهٔ زباله با mark-and-sweep (فصل ۲۶)، کلاس‌ها و ارث‌بری (فصل ۲۷-۲۸)، و governor (فصل ۳۰). این بخش، عمق واقعی اجرای بایت‌کد را نشان می‌دهد:

C// حلقهٔ اصلی VM
static InterpretResult run() {
  for (;;) {
    uint8_t instruction;
    switch (instruction = READ_BYTE()) {
      case OP_CONSTANT: {
        Value constant = READ_CONSTANT();
        push(constant);
        break;
      }
      case OP_ADD: {
        Value b = pop();
        Value a = pop();
        push(NUMBER_VAL(AS_NUMBER(a) + AS_NUMBER(b)));
        break;
      }
      case OP_RETURN: {
        return INTERPRET_OK;
      }
    }
  }
}

۱) ترتیب منطقی: هر فصل یک قابلیت کوچک و قابل‌کامپایل؛ ۲) توضیح «چرایی» هر تصمیم (مثلاً چرا closureها upvalue دارند)؛ ۳) داستان پردازی و شوخ‌طبعی نویسنده که خواندن را دلچسب می‌کند؛ ۴) کد کامل هر فصل (فایل‌های lox و c در GitHub). مثل یک استاد راهنما، قدم‌به‌قدم همراه شماست.

پیش‌نیازها و جمع‌بندی

نیاز به آشنایی متوسط با برنامه‌نویسی دارید (Java یا C به‌ترتیب برای هر پارت)، ولی خود کتاب همهٔ مفاهیم را توضیح می‌دهد. اگر فقط وقت یک کتاب را دارید، این را انتخاب کنید: پس از اتمام، هم مفسر دارید هم درک عمیق VM — و پروندهٔ «ساخت زبان برنامه‌نویسی» را بسته‌اید.
