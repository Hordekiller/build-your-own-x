معرفی آموزش

این مجموعه یک زبان برنامه‌نویسی کوچک به نام «PL» را در جاوااسکریپت پیاده می‌کند؛ زبانی تابعی با توکن‌ها، متغیرها، توابع و آرایه‌ها. متمایز بودنش در سبک توضیح است: هر بخش با مثال‌های کد کوتاه و توضیح مختصر جلو می‌رود بدون حاشیه‌روی.

بخش‌های آموزش

۱) توکن‌ها: ساختن lexer ساده با regex؛ ۲) تجزیه: پارسری که گرامر را به تابع‌های recursive descent تبدیل می‌کند؛ ۳) ارزیابی: پیمایش و اجرای AST؛ ۴) توابع: lambda و closures؛ ۵) محیط و scope: متغیرهای محلی و global. زبان حاصل می‌تواند مثال‌هایی مثل sum(1,2,3) و برنامه‌های واقعی‌تر را اجرا کند.

نمونهٔ کد: پارسر عبارات

JavaScript// پارسر کمینه برای گویش ریاضی (با اولویت)
function parse_atom() {
  return function() {
    if (is_punc("(")) {            // لیست یا گروه‌بندی
      skip_punc("(");
      var exp = parse_expression();
      skip_punc(")");
      return exp;
    }
    if (is_num()) return make_number(parse_num());
    ...
  };
}

// expr := atom (("+"|"-") atom)*
function parse_expression() {
  var left = parse_atom();
  while (is_op("+") || is_op("-")) {
    var op = parse_op();
    var right = parse_atom();
    left = { type: "binary", operator: op, left: left, right: right };
  }
  return left;
}

بخش ارزیابی

ارزیاب با یک جدول env و تابع‌های evaluate/apply پیاده می‌شود. این مجموعه مخصوصاً برای یادگیری «execution model» — اینکه متغیرها کجا ذخیره می‌شوند و فراخوانی تابع چطور اتفاق می‌افتد — عالی است؛ همه چیز با کد کم و تمیز JavaScript.

جمع‌بندی

کمتر از چند ساعت مطالعه، یک زبان تابعی با توابع، متغیر و آرایه دارید. برای ادامهٔ عمق، «mal» و «Crafting Interpreters» پیشنهاد می‌شوند؛ ولی به‌عنوان دسر سریع و شیرین، این آموزش عالی است.
