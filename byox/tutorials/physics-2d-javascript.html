یک موتور فیزیک دو بعدی ساده برای بازی‌های جاوااسکریپت بساز

⚙ زبان: JavaScript ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمه فارسی آموزش «Build a basic 2D physics engine for JavaScript games» از Adam Ranfelt (IBM developerWorks، نوامبر ۲۰۱۲) است — ساخت گام‌به‌گام یک موتور فیزیک دوبعدی در جاوااسکریپت با جداسازی MVC، حلقه گیم با requestAnimationFrame و مقایسه با Box2D.

۱. درباره آموزش

این آموزش IBM (منتشرشده در ۱۹ نوامبر ۲۰۱۲) به‌صورت عملی نشان می‌دهد که یک موتور فیزیک دوبعدی ساده برای بازی‌های مرورگری چگونه ساخته می‌شود. هدف آموزش ساخت از صفر و بدون کتابخانه فیزیک آماده است: تشخیص برخورد، پاسخ برخورد و مفاهیم پایه توسعه بازی. پیشنهاد خود آموزش این است که پیاده‌سازی را با موتورهای موجود (مثل Box2D و نسخه جاوااسکریپت آن box2d-js) مقایسه کنید تا تفاوت پیاده‌سازی ساده و حرفه‌ای را ببینید.

پیش‌نیازها: آشنایی با جاوااسکریپت و رندر با canvas. مفاهیم مقدماتی سینماتیک (مکان، سرعت، شتاب) هم در متن همراه آموزش مرور می‌شود.

۲. معماری MVC

نکته شاخص آموزش، جداسازی مدل از دید است (الگوی MVC):

  • مدل (فیزیک): دنیای فیزیکی با اجسام، برخوردها و قوانین حرکت — مستقل از رندر.
  • دید (Canvas): رسم اجسام روی بوم — فقط از وضعیت مدل می‌خواند.
  • کنترلر/حلقه بازی: پل زدن بین مدل و دید در هر فریم با requestAnimationFrame.
javascript// حلقه بازی: هر فریم، مدل را گام بده و بعد رسم کن
function gameLoop() {
    physics.step(dt);   // فیزیک: مدل
    renderer.draw();    // رسم: دید
    requestAnimationFrame(gameLoop);
}

این جداسازی باعث می‌شود موتور فیزیک همان‌طور که هست قابل استفاده مجدد و تست باشد.

۳. مدل فیزیکی پایه

مدل از اجسام ساده (مثل توپ/دایره و مستطیل) ساخته می‌شود؛ هر جسم مکان، سرعت و جرم دارد و در هر گام با قوانین حرکت به‌روز می‌شود. قوانین پایه همان انتگرال‌گیری اویلر است:

javascript// به‌روزرسانی سینماتیک یک جسم
function integrate(body, dt) {
    body.velocityY += GRAVITY * dt;      // شتاب گرانش
    body.x += body.velocityX * dt;       // جابه‌جایی
    body.y += body.velocityY * dt;
}

گرانش به‌عنوان شتاب ثابت اعمال می‌شود و اجسام با سرعت تابع زمان به سمت پایین شتاب می‌گیرند.

۴. برخوردها

سپس تشخیص برخورد اضافه می‌شود: ابتدا برخورد با مرزهای صحنه (زمین/دیوار) و سپس برخورد جسم با جسم. برای هر برخورد یک پاسخ لازم است تا اجسام در هم فرو نروند — مثلاً معکوس‌کردن سرعت با ضریب بازگشت، یا اتصال مستقیم مکان به مرز:

javascript// برخورد با زمین: برگشت به بالا با اتلاف انرژی
function collideWithGround(body) {
    if (body.y + body.radius > floorY) {
        body.y = floorY - body.radius;
        body.velocityY *= -RESTITUTION;
    }
}

برای برخورد جسم-جسم، فاصله مرکزها با مجموع شعاع‌ها مقایسه می‌شود و سرعت‌ها مطابق قانون بقای تکانه تغییر می‌کنند.

۵. مقایسه با Box2D و ادامه راه

در بخش منابع، آموزش به Box2D و پورت جاوااسکریپت آن (box2d-js) ارجاع می‌دهد و پیشنهاد می‌کند خروجی موتور ساده خودتان را از نظر ثبات، دقت و پایداری با یک موتور حرفه‌ای مقایسه کنید — تفاوتی که مفاهیمی مثل حل‌کننده تکراری، منیفولدها و اصلاح موقعیت را ملموس می‌کند. منابع تکمیلی آموزش شامل آموزش رسمی Canvas و مطالب سینماتیک است.
