چرا یک هدست VR خانگی؟

هدست‌های تجاری گران‌اند و درونشان جعبهٔ سیاه است. پروژهٔ Relativ نشان می‌دهد که با یک نمایشگر (در اصل دو پنل)، یک سنسور اینرسی (IMU) و قطعات چاپ سه‌بعدی، می‌توان یک هدست واقعیت مجازی ساخت که با SteamVR کار کند و تمام سورس آن باز است.

این پروژه برای علاقه‌مندان به سخت‌افزار، الکترونیک و توسعهٔ نرم‌افزار دسکتاپ، یک تجربهٔ ترکیبی کامل است.

اجزای اصلی

قلب نرم‌افزار، یک «درایور» است که از طریق SteamVR-OpenVR با بازی‌ها صحبت می‌کند. اجزای کلیدی عبارتند از: نمایشگر با رفرش‌ریت بالا، IMU که دادهٔ شتاب و ژیروسکوپ را می‌دهد، میکروکنترلر برای پردازش و ارسال، و لنز برای فوکوس.

نکتهٔ مهندسی مهم: تأخیر (latency) در VR کشنده است. برای کاهش آن باید داده‌های حسگر را سریع خواند و با نسبت اینرسی درست نمایش داد.

نمونهٔ کد: خواندن و ترکیب دادهٔ IMU

ترکیب دادهٔ ژیروسکوپ و شتاب‌سنج (سنسور fusion) کاری است که با فیلتر مکمل (complementary filter) ساده انجام می‌شود:

C++// ترکیب سادهٔ دادهٔ شتاب و ژیروسکوپ با فیلتر مکمل
struct Orientation {
    float pitch, roll;
    double last_time;
};

void update_orientation(Orientation* o, float gx, float gy,
                        float ax, float ay, double dt) {
    const float alpha = 0.98f;   // وزن ژیروسکوپ

    // زاویه از شتاب‌سنج (gravitational vector)
    float acc_pitch = atan2f(ay, sqrtf(ax*ax + 1.0f));
    float acc_roll  = atan2f(ax, sqrtf(ay*ay + 1.0f));

    // ترکیب: ژیروسکوپ بلندمدت + شتاب‌سنج کوتاه‌مدت
    o->pitch = alpha * (o->pitch + gy * dt) + (1.0f - alpha) * acc_pitch;
    o->roll  = alpha * (o->roll  + gx * dt) + (1.0f - alpha) * acc_roll;
}

این فیلتر ساده، زاویهٔ سر را با دقت خوبی بین دو نمونه محاسبه می‌کند؛ در نسخهٔ پیشرفته از Madgwick یا Kalman filter استفاده می‌شود.

اتصال به SteamVR

برای اینکه بازی هدست شما را ببیند، باید یک درایور OpenVR بنویسید که موقعیت (pose) و display را معرفی کند. پروژهٔ Relativ این بخش را با یک سرور UDP ساده و یک رندرر گلوبال پیاده می‌کند. پس از نصب، بازی‌های VR عادی بدون کد اضافه کار می‌کنند.

جمع‌بندی

این پروژه نشان می‌دهد که VR فقط برای شرکت‌های بزرگ نیست: با ۲۰۰ دلار و کمی صبر می‌توانید تجربهٔ واقعیت مجازی را از صفر بسازید و در میانهٔ راه دربارهٔ IMU، پروتکل‌ها و درایورهای سیستم عاملی بسیار یاد بگیرید.

کپیرایت: تیم پروژهٔ Relativ. این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
