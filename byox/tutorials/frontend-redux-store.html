در این درس از سری «آشنایی با Redux»، دن آبراموف (نویسندهٔ خود Redux) نشان می‌دهد که createStore چطور کار می‌کند: یک پیاده‌سازی کوچک و کامل از store را با دست می‌نویسد و مفاهیم getState، dispatch و subscribe را عملاً توضیح می‌دهد. پیام اصلی درس: Redux هیچ جادویی ندارد؛ خودتان می‌توانید بنویسیدش.

▶ مشاهدهٔ درس «Implementing Store from Scratch»

۳. هستهٔ درس: پیاده‌سازی createStore

محتوا و کد این درس همان رویکرد کلاسیک است که در ادامه خلاصه شده — با اجرای دستی همان چهار روش اصلی:

jsconst createStore = (reducer) => {
  let state;
  let listeners = [];

  // فقط reducer می‌تواند state را عوض کند
  const getState = () => state;

  const dispatch = (action) => {
    state = reducer(state, action);
    listeners.forEach((listener) => listener());
  };

  const subscribe = (listener) => {
    listeners.push(listener);
    return () => {
      listeners = listeners.filter((l) => l !== listener);
    };
  };

  // مقداردهی اولیه: reducer را با state نامشخص صدا می‌زنیم
  dispatch({});

  return { getState, dispatch, subscribe };
};

نکتهٔ مهم: فراخوانی dispatch({}) در انتها — چون action خالی است و reducer معمولاً با default همان state را برمی‌گرداند، اما state به مقدار پیش‌فرض reducer (مثلاً آرایهٔ خالی) مقداردهی می‌شود.

۴. استفادهٔ عملی

js// یک reducer ساده برای شمارنده
const counter = (state = 0, action) => {
  switch (action.type) {
    case 'INCREMENT': return state + 1;
    case 'DECREMENT': return state - 1;
    default: return state;
  }
};

const store = createStore(counter);

store.subscribe(() => {
  console.log('state فعلی:', store.getState());
});

store.dispatch({ type: 'INCREMENT' }); // 1
store.dispatch({ type: 'INCREMENT' }); // 2
store.dispatch({ type: 'DECREMENT' }); // 1

نکتهٔ طراحی که در درس تأکید می‌شود: action باید صراحتاً «چه اتفاقی افتاد» را بگوید، نه «چطور state عوض شود» — یعنی فقط { type: 'INCREMENT' } می‌فرستیم و این reducer است که می‌داند یعنی چه. این جدایی، همان فلسفهٔ Redux است.

۵. چرا این درس مهم است؟

  • از زبان خالق کتابخانه؛ همهٔ تصمیم‌ها با دلیل واقعی توضیح داده می‌شوند.
  • پیاده‌سازی دستی نشان می‌دهد store فقط یک closure ساده است.
  • سری کامل «Getting Started with Redux» بعد از این درس، اجزای دیگر (combineReducers، connect، middleware) را با همان روش دستی توضیح می‌دهد.
