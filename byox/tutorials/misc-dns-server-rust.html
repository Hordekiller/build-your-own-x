ساخت یک سرور DNS در Rust

⚙ زبان: Rust ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور «DNS guide» از امیل هرنوال است که یک سرور DNS کامل را از صفر در Rust می‌سازد.
↗ مشاهده منبع اصلی

قلمرو: بایت به بایت

DNS یک پروتکل باینری ساده است: درخواست UDP روی پورت ۵۳ فرستاده می‌شود. اگر پیام را بایت‌به‌بایت تشریح کنید (header، سوال، پاسخ)، مفاهیم تمام سیستم‌های باینری را یاد گرفته‌اید. این راهنما با Rust — زبانی که برای کار بایت‌محور عالی است — انجامش می‌دهد.

خواندن بایت‌ها با ساختارهای Rust

اولین قدم: ارسال یک درخواست ساده و چاپ بایت‌های خام پاسخ. بعد ساختار `Packet` تعریف می‌شود که از `BytePacketBuffer` می‌خواند؛ هر فیلد (ID، پرچم‌ها، شماره‌ها) با متدهایی مثل `read_u16` بیرون کشیده می‌شود:

Rustpub struct BytePacketBuffer {
    pub buf: [u8; 512],
    pub pos: usize,
}

impl BytePacketBuffer {
    pub fn read_u16(&mut self) -> Result<u16> {
        let hi = self.buf[self.pos] as u16;
        let lo = self.buf[self.pos + 1] as u16;
        self.pos += 2;
        Ok((hi << 8) | lo)      // big-endian در DNS
    }

    pub fn read_string(&mut self) -> Result<String> {
        // فرمت label: هر بخش طول + حروف
        let len = self.buf[self.pos]; self.pos += 1;
        let mut s = String::with_capacity(len as usize);
        for _ in 0..len {
            s.push(self.buf[self.pos] as char); self.pos += 1;
        }
        Ok(s)
    }
}

نکتهٔ مهم پروتکل: بایت‌ها big-endian هستند و نام‌ها به شکل متوالی label ذخیره می‌شوند — بدون null-terminator مثل C.

قدرت: forwarder و پاسخ‌گویی

بعد از پارس کردن درخواست، سرور به یک سرور DNS بالادست (مثل 8.8.8.8) فوروارد می‌کند، جواب را می‌گیرد و برای کاربر برمی‌گرداند — این یعنی یک «سرور DNS رله» واقعی (glue). جواب را هم که باز کنید و ایمن بفرستید، کار تمام است:

Rustfn handle_query(socket: &UdpSocket, buf: &mut [u8]) -> Result<()> {
    let query = Packet::from_buffer(&mut BytePacketBuffer::new(buf))?;

    // فوروارد به سرور بالادست
    let mut resolver = UdpSocket::bind("0.0.0.0:0")?;
    resolver.send_to(buf, "8.8.8.8:53")?;
    let mut response = [0u8; 512];
    let (n, _) = resolver.recv_from(&mut response)?;

    // ارسال پاسخ به کاربر
    socket.send_to(&response[..n], ...)?;
    Ok(())
}

با `SocketAddr` مشتری از `recv_from`، پاسخ دقیقاً همانجا برمی‌گردد که باید.

ارتقاها: recursive و DoT

راهنما در فصل‌های بعد چیزهای بیشتری اضافه می‌کند: کش کردن (Cache) پاسخ‌ها، حلقهٔ بازگشتی خودکار (بدون اتکا به 8.8.8.8)، DNS-over-TCP و حتی DNS-over-TLS. هر کدام با همین واحدهای کوچک بایت‌خوانی ساخته می‌شوند.
