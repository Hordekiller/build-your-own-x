پلاگین گیت خودت را با پایتون بساز

⚙ زبان: Python ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور «Build your own git plugin» از جاش برنز است که اکستنشن git را با پایتون می‌سازد.
↗ مشاهده منبع اصلی

git با هر زبانی قابل توسعه است

چیزی که خیلی‌ها نمی‌دانند: هر برنامه‌ای که اسمش `git-XXX` باشد و در PATH باشد، با `git XXX` صدا زده می‌شود! همین مکانیزم ساده، همهٔ «افزونه‌های گیت» از git-flow تا ابزارهای شخصی را می‌سازد. با پایتون هم می‌توانیم — فقط باید executable باشد و با stdin/stdout رفتار درستی داشته باشد.

قرارداد نام‌گذاری

قانون اصلی: `git-` در PATH → فرمان `git `. پس فایل `git-brag` یا `git-stats` را در `/usr/local/bin` یا پوشهٔ scripts پروژه بگذارید:

Bash# git-brag — بدون هیچ پیکربندی گیت کار می‌کند
code git-brag
chmod +x git-brag          # قابل اجرا شدن لازم است!
sudo cp git-brag /usr/local/bin/

git brag                   # ← پلاگین اجرا می‌شود
git brag --help            # ← آرگومان هم می‌گیرد

مهم‌ترین نکته: Shedoller `git` هیچ برنامه‌ای را با این نام نمی‌شناسد؛ فقط پیدا می‌کند و می‌دودش.

پلاگین ساده: آمار امروز شما

Python#!/usr/bin/env python3
import subprocess, sys

# همهٔ کامیت‌های امروز را بشمار
cmd = ["git", "log", "--since=midnight", "--oneline"]
result = subprocess.run(cmd, capture_output=True, text=True)

commits = result.stdout.strip().splitlines()
print(f"امروز {len(commits)} کامیت زدی:")
for c in commits[:10]:
    print(" ", c)

با `subprocess` به خود گیت تکیه می‌کنید (نه بازسازی منطق گیت!) — این پیمان‌بار استاندارد همهٔ پلاگین‌هاست.

چک هوک‌ها با پلاگین

پلاگین‌ها فقط برای سرگرمی نیستند؛ می‌توانید قبل از کامیت، پلاگین `git pre-push` را روی CI اجرا کنید، یا پلاگینی بسازید که از `git status --porcelain` بخواند و خطای کد سبک را گزارش دهد. فرق پلاگین با hook: پلاگین را کاربر خودش صدا می‌زند، hook خودکار اجرا می‌شود.
