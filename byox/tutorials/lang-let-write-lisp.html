بیا یک Lisp بنویسیم (Let's Go Write a Lisp)

دربارهٔ مقاله

این مقالهٔ قدیمی اما طلایی، با روش «بازگشت به بالا» (bottom-up) مفسر Lisp را می‌سازد: اول نمایش داده‌ها و توابع اولیه، بعد parser و بعد closures و محیط. سبک آن شبیه مقالهٔ «Little Lisp» ماری روز کوک است اما با جزئیات بیشتر دربارهٔ محیط و closures.

ساختار قدم‌به‌قدم

۱) تعریف ساختارهای داده‌ای (Number، Lambda، Symbol و… )؛ ۲) توابع اولیه محیط global (تعریف با define)؛ ۳) parser با دو تابع tokenize/parse؛ ۴) eval اصلی که هم support number/name و هم تعریف lambda می‌کند؛ ۵) apply برای فراخوانی تابع و ساختن محیط محلی.

JavaScript// ساخت محیط محلی برای فراخوانی تابع
function callLispFunction(closure, args) {
  var localEnv = cloneEnvironment(closure.env);   // فرزند محیط تعریف
  closure.params.forEach(function (param, i) {
    localEnv[param] = args[i];                    // اتصال پارامترها
  });
  // بدنهٔ تابع در محیط محلی ارزیابی می‌شود
  return evalLisp(closure.body, localEnv);
}

مفاهیم کلیدی که یاد می‌گیرید

۱) closure: تابع باید محیط تعریف‌شدهٔ خودش را نگه دارد (Env in closure) — این چیزی است که به Lispها معنا می‌دهد؛ ۲) ارزیابی ترتیبی (begin) و ارزیابی شرطی (if)؛ ۳) بازگشت در تابع‌ها؛ ۴) تفاوت eval و apply. مثال‌های مقاله شامل فاکتوریل و تابع map هستند.

مقایسه با آموزش‌های دیگر

در مقایسه با «Little Lisp»، این مقاله محیط تعریف‌شدهٔ «فرزند» (nested scope) را صریح‌تر نشان می‌دهد — یعنی درک بهتری از scope زنجیره‌ای به شما می‌دهد که پایهٔ درک هر زبان دیگر است.

جمع‌بندی

یک بعدازظهر سرگرم‌کننده و آموزنده: ساخت مفسر Lisp از صفر در جاوااسکریپت، با تاکید بر محیط و closures. بعداً می‌توانید با افزودن quote، ماکروها و GC این مفسر را به سمت «mal» ببرید.
