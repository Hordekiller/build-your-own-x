توسعه بازی با Ruby — کتاب آنلاین «Developing Games with Ruby»

⚙ زبان: Ruby ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه معرفی و مرور فارسی کتاب «Developing Games With Ruby» از توماس وارانکاس (Tomas Varaneckas) است — یک کتاب کامل (۲۳ فصل) که یک بازی دو‌بعدی دونمای شوتر (top-down) را با Ruby می‌سازد و در Leanpub به‌صورت آنلاین و رایگان قابل خواندن است.

۱. دربارهٔ کتاب

این کتاب چند جلدی، بهترین منبع بازی‌سازی با Ruby است: یک بازی شوتر بال‌به‌بالا (مانند آنچه در دههٔ ۹۰ مرسوم بود) از صفر ساخته می‌شود — با گیم‌پلی سریع، دوربین خودکار، هوش مصنوعی دشمنان، مپ‌های تصادفی و سیستم‌های امتیاز. ابزار اصلی کتاب: کتابخانهٔ Gosu (معروف‌ترین کتابخانهٔ بازی Ruby). نسخهٔ آنلاین در Leanpub رایگان خواندنی است و نسخهٔ خرید کتاب، پشتیبانی از نویسنده را فراهم می‌کند.

نکته: نویسنده، بنیان‌گذار انجمن «Game Hero» (بازی‌سازی با Ruby) است و در همین کتاب تجربه‌های عملی از شهرسازی و مفاهیم پیشرفتهٔ گیم‌دِو را هم می‌گنجاند.

۲. فصل‌های کلیدی

  • راه‌اندازی Gosu و ساخت پنجره
  • حلقهٔ بازی، حالت‌ها و مدیریت ورودی
  • اسپرایت و انیمیشن با bmfont ها
  • دوربین و دنیای بزرگ‌تر از صفحه
  • هوش مصنوعی: تعقیب، شلیک و الگوها
  • مپ‌های تصادفی و فیزیک ساده
  • سیستم ذخیرهٔ رکورد و چالش‌های بعد

۳. نمونهٔ کد

ruby# ساختار بازی با Gosu
require 'gosu'

class Game < Gosu::Window
  def initialize(width = 800, height = 600)
    super(width, height)
    self.caption = 'بازی من با Ruby'
    @player_x = 400
    @player_y = 300
  end

  # به‌روزرسانی منطق هر فریم
  def update
    # حرکت با کلیدها
    @player_x -= 5 if Gosu.button_down?(Gosu::KB_LEFT)
    @player_x += 5 if Gosu.button_down?(Gosu::KB_RIGHT)
    @player_y -= 5 if Gosu.button_down?(Gosu::KB_UP)
    @player_y += 5 if Gosu.button_down?(Gosu::KB_DOWN)
  end

  # رندر هر فریم
  def draw
    # (رسم با Gosu::Image یا شکل‌های ساده)
  end
end

Game.new.show
