هدف و جریان داده

پخش‌کردن ویدیو یعنی تبدیل یک فایل فشرده‌شده به فریم‌هایی که روی صفحه نمایش داده شوند. این آموزش با کتابخانهٔ FFmpeg کار می‌کند و سه مرحله دارد: باز کردن فایل و یافتن استریم‌ها (video/audio)، رمزگشایی فریم‌ها با کدک مناسب، و نمایش با SDL. تمام این‌ها با API قدیمی و تا حدی ساده‌شدهٔ FFmpeg انجام می‌شود.

جریان اصلی (pipeline) چنین است: فایل → بسته‌های encoded → فریم‌های decoded → تبدیل به RGB → نمایش.

کدک‌ها و ساختار API

کلید این کار، درک دو ساختار است: AVFormatContext (که فایل و استریم‌هایش را دارد) و AVCodecContext (که کدک فعال را نگه می‌دارد). برای نمایش، بافر قاب را با `av_frame_alloc` می‌سازیم.

در ادامه، حلقهٔ پخش برای هر فریم، آن را رمزگشایی و به فرمت RGB (برای SDL) تبدیل می‌کند. تابعی که «frame را برای SDL آماده می‌کند» هستهٔ کار است:

C// تبدیل یک فریم رمزگشایی‌شده بهRGB و نمایش
void displayFrame(AVFrame *frame, AVPicture *pict, SwsContext *sws,
                  SDL_Surface *screen) {
    int w = frame->width, h = frame->height;

    // تبدیل YUV به RGB با استفاده از swscale
    sws_scale(sws, frame->data, frame->linesize, 0, h,
              pict->data, pict->linesize);

    // کپی پیکسل‌ها به سطح SDL
    SDL_LockSurface(screen);
    memcpy(screen->pixels, pict->data[0],
           pict->linesize[0] * h);
    SDL_UnlockSurface(screen);
    SDL_UpdateRect(screen, 0, 0, w, h);
}

در این‌جا `sws_scale` کار تبدیل فرمت (YUV → RGB) را انجام می‌دهد و سپس پیکسل‌ها مستقیماً به بافر سطح SDL کپی می‌شوند.

مدیریت زمان‌بندی (Timing)

بخش سخت اما مهم، همگام‌سازی صدا و تصویر است. برای اینکه فریم‌ها با سرعت درست پخش شوند، باید «زمان نمایش» (PTS) را محاسبه و بین فریم‌ها `usleep` کنیم. اگر این مرحله را درست انجام ندهید، ویدیو یا تند یا کند پخش می‌شود.

در نسخهٔ پیشرفته، تفاوت زمانی با «audio clock» محاسبه می‌شود؛ اما در آموزش ابتدایی یک فرمول ساده بر اساس duration هر فریم کافی است: `delay = (frame->pts - last_pts) * (1000 / fps)`.

جمع‌بندی

این آموزش نشان می‌دهد که با چند صد خط C و FFmpeg، می‌توان یک پخش‌کنندهٔ ویدیوی واقعی ساخت. مفاهیم کدک، تبدیل رنگ و همگام‌سازی، مهارت‌هایی هستند که در هر کار چندرسانه‌ای به کار می‌آیند و این مسیر بهترین شروع است.

کپیرایت: استیون دکترانگر (Dranger). این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
