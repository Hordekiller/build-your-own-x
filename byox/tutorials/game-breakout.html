۱. پیش‌نیاز و جایگاه فصل

این فصل بخش «In Practice → 2D Game» از کتاب LearnOpenGL است؛ یک پروژهٔ کاربردی که همهٔ مطالب قبلی کتاب را در قالب یک بازی واقعی به کار می‌گیرد. پیش‌نیاز: آشنایی با فصل‌های «Getting Started» و «Lighting» (مخصوصاً شیدرها، بافت و ریاضیات ماتریسی).

بازی Breakout (از آتاری ۱۹۷۶): یک راکت در پایین، توپی که به دیوارها و بلوک‌ها برخورد می‌کند و بلوک‌ها نابود می‌شوند. آنچه این پیاده‌سازی خاص می‌کند، فناوری‌های گرافیکی آن است: particles (ذرات)، rendering text، power-ups و postprocessing — همه در OpenGL خالص.

۳. منطق برخورد: AABB و دایره

قلب بازی، برخورد توپ (دایره) با بلوک‌ها و راکت (مستطیل‌های AABB) است. تکنیک bounce-off — تشخیص اینکه توپ از کدام سمت برخورد کرده و بازتاب بر اساس آن: 

cpp// تشخیص برخورد دایره (توپ) با مستطیل (بلوک/راکت)
Collision CheckCollision(BallObject &ball, GameObject &box) {
  // نزدیک‌ترین نقطهٔ مستطیل به مرکز دایره
  glm::vec2 closest = glm::clamp(ball.Position, box.Position,
                                 box.Position + box.Size);
  // فاصلهٔ مرکز دایره تا آن نقطه
  glm::vec2 diff = ball.Position - closest;
  float distance = glm::length(diff);

  // اگر فاصله کمتر از شعاع باشد، برخورد رخ داده
  if (distance <= ball.Radius) {
    // تعیین جهت برخورد با مقایسهٔ diff با ابعاد
    glm::vec2 overlap = glm::abs(diff);
    if (overlap.x < overlap.y) {
      ball.Velocity.x = -ball.Velocity.x;  // از کنار
    } else {
      ball.Velocity.y = -ball.Velocity.y;  // از بالا/پایین
    }
    return { true, ball.Position - closest };
  }
  return { false, glm::vec2(0.0f) };
}

۴. جلوه‌های بصری

  • Particles: دنبالهٔ ذرات پشت توپ و بلوک‌های در حال نابودی؛ هر ذره یک چهارضلعی کوچک با شیدر GLSL است که می‌میرد و دوباره ساخته می‌شود.
  • Postprocessing: با یک FrameBuffer، صحنه روی بافت رندر می‌شود و بعد افکت shake با جابه‌جایی تصادفی نمونه‌برداری اعمال می‌شود.
  • Text rendering: نمایش امتیاز و پیام‌ها با FreeType روی یک شیدر.
  • Power-ups: «گلدان‌های» افتادنی با افکت‌هایی مثل راکت بزرگ، توپ چسبنده، توپ‌های عبوری (پاس‌کنندهٔ بلوک‌ها) و توپ‌های متعدد.
