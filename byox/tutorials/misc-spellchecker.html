غلط‌یاب چگونه کار می‌کند؟

یک غلط‌یاب املایی دو گام دارد: تشخیص — تشخیص اینکه کلمه در دیکشنری نیست؛ و پیشنهاد — پیدا کردن نزدیک‌ترین کلمهٔ معتبر. ساده‌ترین روش برای پیشنهاد، تولید «ویرایش‌های یک فاصله» (deletion، insertion، substitution، transposition) و جست‌وجوی آن‌ها در دیکشنری است.

پروژهٔ این آموزش با Clojure ساخته می‌شود؛ زبانی که به‌خاطر ساختار دادهٔ ناپذیر و تابع‌های pure، نوشتن این الگوریتم را تمیز و خواناتر می‌کند.

تولید کاندیدها با ویرایش یک فاصله

برای هر کلمه، تمام تغییرات یک‌حرفی تولید می‌شود: حذف، جایگزینی، درج و جابه‌جایی حروف مجاور:

Clojure; تولید همهٔ کلماتی که با یک ویرایش بدست می‌آیند
(defn edits1 [word]
  (let [letters "abcdefghijklmnopqrstuvwxyz"
        splits (for [i (range (inc (count word)))]
                 [(subs word 0 i) (subs word i)])]
    (concat
      ; حذف یک حرف
      (for [[a b] splits :when (pos? (count b))]
        (str a (subs b 1)))
      ; جابه‌جایی دو حرف مجاور
      (for [[a b] splits :when (pos? (count (subs b 1)))]
        (str a (subs b 1 2) (subs b 0 1) (subs b 2)))
      ; جایگزینی
      (for [[a b] splits :when (pos? (count b)) c letters]
        (str a c (subs b 1)))
      ; درج
      (for [[a b] splits c letters]
        (str a c b))))

حالا کاندیدها را با دیکشنری مقایسه می‌کنیم و اگر هیچ‌کدام معتبر نبود، یک ویرایش دوم هم می‌زنیم (edits2).

انتخاب بهترین پیشنهاد

برای انتخاب بین چند کاندید معتبر، از فرکانس کلمات در یک corpus استفاده می‌شود: کلمه‌ای با بیشترین فراوانی برنده است. این مدل «بيز» ساده، پایهٔ غلط‌یاب‌های واقعی است:

Clojure; بهترین کاندید با بالاترین فراوانی در دیکشنری
(defn best-candidate [freqs candidates]
  (when (seq candidates)
    (reduce (fn [best c]
              (if (> (get freqs c 0) (get freqs best 0))
                c best))
            (first candidates)
            (rest candidates))))

; غلط‌یاب کامل: ویرایش ۱، سپس ۲
(defn correct [word freqs known-words]
  (cond
    (contains? known-words word) word
    (seq (filter known-words (edits1 word)))
      (best-candidate freqs (filter known-words (edits1 word)))
    :else (best-candidate freqs
            (filter known-words (edits2 word)))))

این ساختار نشان می‌دهد که الگوریتم‌های «هوشمندانه» گاهی از چند صد خط ساده تشکیل شده‌اند.

گام‌های پیاده‌سازی و تست

مراحل: ۱) ساخت دیکشنری از یک corpus متنی با یک تابع `frequencies`، ۲) پیاده‌سازی edits1/edits2، ۳) تابع correct و ۴) ساخت یک REPL کوچک که کلمهٔ کاربر را درست می‌کند + مجموعهٔ تست که صحت را بررسی می‌کند.

جمع‌بندی

این پروژهٔ کوچک، مفاهیم بزرگ مدل‌های زبانی (فرکانس، فاصلهٔ ویرایش) را نشان می‌دهد و با Clojure هم‌خوانی زیبایی دارد. بعد از آن می‌توانید سراغ الگوریتم‌های پیشرفته‌تر (مثل BK-tree یا Soundex) بروید.

کپیرایت: برنهارد ونزل (Bernhard Wenzel). این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
