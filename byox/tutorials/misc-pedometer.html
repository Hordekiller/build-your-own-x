مسئله: شمارش قدم از روی شتاب سنج

گوشی شما شتاب‌سنج دارد؛ هر قدم، یک نوسان کوچک در سیگنال شتاب می‌سازد. اما سیگنال خام پر از نویز است: دست‌تکان دادن گوشی، جادهٔ ناهموار و سوار شدن در اتوبوس هم الگوهای مشابهی می‌دهند. تبدیل «سیگنال نویزی» به «عدد قدم» یک کار مهندسی واقعی است — و این فصل از کتاب 500 Lines آن را با Ruby انجام می‌دهد.

فیلتر کردن سیگنال

اولین گام: نرم‌تر کردن (smoothing) سیگنال تا نویز لحظه‌ای حذف شود ولی شکل کلی نوسان بماند. یک «میانگین وزنی» مثل فیلتر پایین‌گذر کار می‌کند — یعنی ساده‌ترین و مهم‌ترین ابزار پردازش سیگنال:

Rubyclass Pedometer
  def initialize
    @window = []                 # پنجرهٔ آخرین نمونه‌ها
    @sum = 0.0
    @stepCount = 0
  end

  # فیلتر پایین‌گذر: میانگین پنجرهٔ ۲۰ نمونه
  def filter(value)
    @window << value
    @sum += value
    if @window.size > 20
      @sum -= @window.shift
    end
    @sum / @window.size
  end
end

اندازهٔ پنجره با «سرعت قدم زدن» (حدود ۲ قدم در ثانیه) هماهنگ تنظیم می‌شود؛ خیلی کوچک = نویز می‌ماند، خیلی بزرگ = قدم‌ها محو می‌شوند.

تشخیص قدم: عبور از آستانه

پس از نرم‌سازی، هر قدم یک «قله» است. الگوریتم: سیگنال از یک آستانه رو به بالا عبور کند → یک قدم. برای جلوگیری از شمارش توأمان همان قله، بعد از هر قدم، حالت «خنک شدن» (cooldown) بگیرید:

Rubydef process(sample)
  smoothed = filter(sample.acceleration_magnitude)
  return unless smoothed > @threshold   # زیر آستانه: رد کن

  # آستانه از خود دادهٔ چند روز آموزش/کالیبراسیون به دست آمد
  unless @last_step_at && now - @last_step_at < 0.3
    @stepCount += 1
    @last_step_at = now
  end
end

مقدار دامنه (magnitude سه‌بعدی شتاب) به دست جهت گوشی وابسته نیست — انتخاب هوشمندانه‌ای برای تنوع حمل گوشی است.

درس‌های فصل

نکتهٔ آموزشی فصل فقط الگوریتم نیست: دادهٔ خام باید جمع شود، کالیبره شود و روی دستگاه واقعی تست شود. شماره‌گذاری قدم‌ها در جیب شلوار با دست‌تکان دادن کاملاً فرق می‌کند. این همان تفاوت «کد نمونه» با «سیستم دنیای واقعی» است — درسی که در کل کتاب 500 Lines تکرار می‌شود.

کپیرایت: هامبرتو فورتس؟ — این فصل از کتاب «500 Lines or Less» است. این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
