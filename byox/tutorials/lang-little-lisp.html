داستان: یک مفسر در کمتر از ۱۵۰ خط

ماری روز کوک با این مقاله ثابت کرد که ساخت مفسر Lisp با جاوااسکریپت (زبان browsers) خیلی ساده است: کل پروژه ۴ تابع دارد — tokenize، parse، evaluate و apply. خروجی: یک زبان با توابع، متغیر، شرط و recursion.

گام اول: tokenize

تبدیل رشتهٔ ورودی به آرایه‌ای از توکن‌ها — برای مثال (begin (define r 10) (* pi (* r r))) تبدیل می‌شود به: ['(', 'begin', '(', 'define', 'r', '10', ')', '(', '*', 'pi', ...]. از استریم‌ها با memory ساده استفاده می‌شود.

گام دوم: parse

توکن‌ها را به درخت (لیست‌های تو در تو) تبدیل می‌کند. اگر توکن «(» باشد، بازگشتی لیست داخلی را می‌سازد تا «)» برسد:

JavaScriptfunction parse(tokens, memory) {
  if (typeof memory === 'undefined') {
    memory = { index: 0 };
  }

  if (tokens[memory.index] === '(') {           // شروع لیست
    memory.index++;
    let list = [];
    while (tokens[memory.index] !== ')') {
      list.push(parse(tokens, memory));         // بازگشت برای عنصر بعد
    }
    memory.index++;                             // رد شدن از ')'
    return list;
  } else if (tokens[memory.index] === ')') {
    throw new Error('پرانتز اضافی!');
  } else {
    const atomicToken = tokens[memory.index];
    memory.index++;
    return atomicToken;                         // اتم: نام یا عدد
  }
}

گام سوم: evaluate

حالا درخت را ارزیابی می‌کند: اگر اتم «عدد» بود مقدارش؛ اگر «نام» بود مقدار متغیر از محیط؛ و اگر «لیست» بود، عنصر اول تابع و بقیه آرگومان هستند (apply). مفاهیم closure و محیط تودرتو هم در همین‌جا نوشته می‌شوند:

JavaScriptfunction evaluate(ast, environment) {
  if (typeof environment === 'undefined') {
    environment = globalEnvironment;
  }

  // اتم‌ها
  if (typeof ast === 'string') {
    if (parseInt(ast) === NaN) {
      return lookupVariable(ast, environment);   // نام متغیر
    } else {
      return parseInt(ast);                       // عدد
    }
  }

  // لیست: عملگر و آرگومان‌ها
  const operator = ast[0];
  const operands = ast.slice(1);

  if (operator === 'define') {
    const variable = operands[0];
    const value = evaluate(operands[1], environment);
    environment[variable] = value;                // تعریف متغیر
    return value;
  }

  if (operator === 'begin') {
    // اجرای ترتیبی همهٔ عبارت‌ها
    return operands.reduce((last, exp) => evaluate(exp, environment), undefined);
  }

  const closure = evaluate(operator, environment);
  const args = operands.map(o => evaluate(o, environment));
  return closure.apply(null, args);
}

چه یاد می‌گیرید؟

۱) مفهوم AST و بازگشت؛ ۲) محیط (environment) به‌عنوان جدول نام→مقدار؛ ۳) closure با apply؛ ۴) اینکه Lisp = «قواعد بازگشتی» است نه چیز جادویی. برای تعریف تابع lambda هم همان patternها کافی است.

جمع‌بندی

بهترین نقطهٔ شروع برای ساخت مفسر در جاوااسکریپت: کوتاه، خوانا و کامل (متغیر + تابع). اگر می‌خواهید بعداً متغیرهای محلی، closures و GC را ببینید، «Crafting Interpreters» یا «mal» را دنبال کنید.
