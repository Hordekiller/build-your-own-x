ایدهٔ پروژه

جیمز کایل با این پروژه می‌خواست «اسکلت» کامپایلرها را در کمترین کد ممکن نشان دهد. ورودی زبانی شبیه Lisp است: (add 2 (subtract 4 2)) و خروجی شبیه C: add(2, subtract(4, 2)). همهٔ مفاهیم کلیدی کامپایلر در این ۲۰۰ خط وجود دارد.

مراحل: ۴ تابع

۱) tokenizer — رشته را به توکن‌ها تبدیل می‌کند؛ ۲) parser — توکن‌ها را به AST تبدیل می‌کند؛ ۳) transformer — با کمک traverser (پیمایش enter/exit) AST ورودی را به AST خروجی تبدیل می‌کند؛ ۴) codeGenerator — از AST خروجی، کد نهایی را می‌سازد.

JavaScriptfunction tokenizer(input) {
  let current = 0;      // نشان‌گر موقعیت
  let tokens = [];

  while (current < input.length) {
    let char = input[current];

    // پرانتزها
    if (char === '(') {
      tokens.push({ type: 'paren', value: '(' });
      current++;
      continue;
    }

    // اعداد: چند رقم پشت سر هم
    const NUMBERS = /[0-9]/;
    if (NUMBERS.test(char)) {
      let value = '';
      while (NUMBERS.test(char)) {
        value += char;
        char = input[++current];
      }
      tokens.push({ type: 'number', value });
      continue;
    }

    // نام‌ها (add, subtract, ...)
    const LETTERS = /[a-z]/i;
    if (LETTERS.test(char)) {
      let value = '';
      while (LETTERS.test(char)) {
        value += char;
        char = input[++current];
      }
      tokens.push({ type: 'name', value });
      continue;
    }

    // فاصله‌ها را رد کن
    const WHITESPACE = /\s/;
    if (WHITESPACE.test(char)) {
      current++;
      continue;
    }

    throw new TypeError('کاراکتر ناشناخته: ' + char);
  }

  return tokens;
}

چرا باید بخوانید؟

اگر قبلاً هیچ کدی از کامپایلر ندیده‌اید، این پروژه یک ورود نرم است: مستندات کامنت‌دار و دقیق، هر تابع را توضیح می‌دهد و می‌توانید گام‌به‌گام با node اجرا کنید. همچنین نسخه‌های Go، Rust و… از همین پروژه گرفته شده‌اند؛ خواندن نسخهٔ اصلی دید کامل‌تری از معماری می‌دهد.

بعد از این پروژه کجا برویم؟

برای ادامه: نسخهٔ مرکزش را در ذهن داشته باشید — tokenizer، parser، AST، traverser، codegen. سپس به سراغ «Little Lisp» یا «Crafting Interpreters» بروید تا ارزیابی و محیط را هم به آن اضافه کنید — یا اگر قدرت کامپایل را می‌خواهید، آموزش Kaleidoscope با LLVM.

کپیرایت: جیمز کایل (jamiebuilds). این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
