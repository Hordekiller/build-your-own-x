یک ویرایشگر متن ساده پایتون بساز! (Create a Simple Python Text Editor!)

⚙ زبان: Python ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور آموزش «Create a Simple Python Text Editor!» از سایت Instructables (منتشرشده: ژانویه ۲۰۱۶) است که در ۴ قدم، یک ویرایشگر متن کاربردی با tkinter می‌سازد. نسخه کامل و به‌روز را از سایت اصلی بخوانید.
↗ مشاهده منبع اصلی

۱. مقدمه

این آموزش در ۴ قدم، یک ویرایشگر متن ساده و در عین حال کاربردی را با پایتون می‌سازد. خبر خوب این است که به هیچ نصب خارجی نیاز نیست: tkinter همراه پایتون می‌آید و کدِ نهایی هم کوتاه است. نتیجه: برنامه‌ای که می‌تواند فایل متنی را باز کند، متن‌تان را در خودش نگه دارد و به فایل ذخیره کند — یک Notepad مینیاتوریِ خودساخته که پایهٔ هر ویرایشگر بزرگ‌تری است.

۲. نقشهٔ راه ۴ قدم

  1. قدم ۱ — مقدمات: ایمپورت tkinter و ساخت پنجرهٔ اصلی برنامه (root window)؛ تعریف ویدجت Text به‌عنوان ناحیهٔ ویرایش متن؛ تنظیم تایتل و ابعاد پنجره.
  2. قدم ۲ — ساخت ویجت‌ها: اضافه‌کردن نوار منو با منوی File (New/Open/Save) و منوی Edit (Cut/Copy/Paste)؛ هر آیتم به یک تابع تابعِ رویداد وصل می‌شود.
  3. قدم ۳ — توابع: نوشتن توابع اصلی — برداشتن متن انتخاب‌شده، کپی و چسباندنِ محتوا در ناحیهٔ متن، بازکردن یک فایل با filedialog و خواندن محتویاتش در ویجت Text، و ذخیره‌کردن محتویاتِ ویجت در یک فایل.
  4. قدم ۴ — اجرا: صدا زدنِ mainloop() تا پنجره نمایش داده شود و برنامه اجرا شود; + نکاتی دربارهٔ اجرا و اشکال‌زدایی.

ساختار کد به این شکل است (نمونهٔ خلاصه‌شده برای درک نقشه):

python# قدم ۱: پنجره و ناحیهٔ متن
from tkinter import *
from tkinter import filedialog

root = Tk()
root.title("Simple Text Editor")
text_area = Text(root)
text_area.pack(expand=True, fill=BOTH)

# قدم ۲: منوهای File و Edit
menu_bar = Menu(root)
file_menu = Menu(menu_bar, tearoff=0)
file_menu.add_command(label="New", command=new_file)
file_menu.add_command(label="Open", command=open_file)
file_menu.add_command(label="Save", command=save_file)
menu_bar.add_cascade(label="File", menu=file_menu)
root.config(menu=menu_bar)

# قدم ۳: توابع فایل
def open_file():
    path = filedialog.askopenfilename()
    if path:
        text_area.delete("1.0", END)
        with open(path, "r") as f:
            text_area.insert(END, f.read())

def save_file():
    path = filedialog.asksaveasfilename(defaultextension=".txt")
    if path:
        with open(path, "w") as f:
            f.write(text_area.get("1.0", END))

# قدم ۴: اجرا
root.mainloop()

۳. چه چیزهایی یاد می‌گیرید

  • GUI اولیه با tkinter: پنجره، ویجت ناحیهٔ متن، منوها و اتصال رویدادها.
  • مدیریت فایل: دیالوگ‌های باز و ذخیره با filedialog.
  • ساختار برنامه: جداسازیِ «ساخت رابط» از «منطق عملیات» — همان الگویی که در ویرایشگرهای واقعی می‌بینید.
قدم بعدی: بعد از ساخت این ویرایشگر، می‌توانید آن را ارتقا دهید: برچسبِ «تغییرنخورده/تغییرکرده» در عنوان پنجره، میان‌برهای صفحه‌کلید (Ctrl+S و…) و حتی های‌لایت نحوی — مسیرِ الهام از برنامه‌های واقعی.

در ۴ قدم کوتاه، یک ویرایشگر متن کار می‌کنیم دارید: بازکردن، ویرایش و ذخیرهٔ فایل‌های متنی با کمترین وابستگی. این آموزشِ دلچسبی برای شروعِ برنامه‌نویسی رابط گرافیکی و ساخت ابزارهای کاربردی است.
