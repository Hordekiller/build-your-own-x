چگونه یک موتور فیزیک سفارشی بسازیم — سری آموزشی Randy Gaul

۱. معرفی سری

این سری به شما یاد می‌دهد که موتور فیزیک ماه‌مربوط خودتان را از صفر بسازید — بدون استفاده از کتابخانه فیزیک آماده. تمرکز سری روی فیزیک دوبعدی با اجسام صلب است و در چند مقاله دنبال می‌شود:

  1. مبانی و حل ایمپالس — ساختار موتور، انتگرال‌گیری و پاسخ برخورد پایه.
  2. تشخیص و پاسخ برخورد بهبودیافته — مدل‌سازی بهتر و مدیریت چند نقطه تماس.
  3. تشخیص برخورد دوبعدی با منیفولدها — تولید داده تماس کامل برای چندضلعی‌ها.

کد مثال سری در C++ نوشته شده و برای نمایش، یک حلقه رندر ساده (SFML) به کار می‌رود، اما منطق موتور کاملاً مستقل از کتابخانه گرافیکی است.

۲. مبانی: ساختار موتور

مقاله اول با ساختار کلی موتور شروع می‌کند. هر جسم صلب این داده‌ها را دارد:

cppstruct Body {
    Vec2 position;    // مکان
    Vec2 velocity;    // سرعت
    float mass;       // جرم
    float invMass;    // وارون جرم (برای جرم بی‌نهایت = ۰)
    float restitution;// ضریب بازگشت
    Shape* shape;     // شکل هندسی
};

حلقه موتور در هر فریم سه کار انجام می‌دهد:

  1. انتگرال‌گیری: به‌روزرسانی مکان و سرعت با گام زمانی.
  2. تشخیص برخورد: یافتن برخوردهای بین اجسام.
  3. پاسخ برخورد: اعمال ایمپالس تا اجسام همدیگر را هل دهند و از هم جدا شوند.
cppvoid PhysicsEngine::Step(float dt) {
    // ۱) انتگرال‌گیری
    for (Body* b : bodies) {
        b->velocity += gravity * dt;
        b->position += b->velocity * dt;
    }

    // ۲) تشخیص برخورد
    std::vector contacts;
    BroadPhase(contacts);
    NarrowPhase(contacts);

    // ۳) پاسخ برخورد
    for (Manifold& m : contacts) {
        ResolveCollision(m);
        PositionalCorrection(m);
    }
}

۳. حل ایمپالس

برای حل برخورد از فرمول استاندارد ایمپالس استفاده می‌شود. سرعت نسبی در جهت نرمال برخورد محاسبه و با وارون جرم‌ها نرمال‌سازی می‌شود:

cppvoid ResolveCollision(Manifold& m) {
    Body* A = m.bodyA;
    Body* B = m.bodyB;
    Vec2 n = m.normal;             // نرمال برخورد (یکه)
    Vec2 relV = B->velocity - A->velocity;
    float velAlongNormal = Dot(relV, n);

    // اگر اجسام در حال جداشدن هستند برخورد نکن
    if (velAlongNormal > 0)
        return;

    float e = std::min(A->restitution, B->restitution);
    float j = -(1.0f + e) * velAlongNormal;
    j /= A->invMass + B->invMass;

    Vec2 impulse = j * n;
    A->velocity -= A->invMass * impulse;
    B->velocity += B->invMass * impulse;
}

۴. تشخیص و پاسخ برخورد بهبودیافته

مقاله دوم وارد جزئیات تشخیص برخورد می‌شود. ابتدا فاز گسترده (broad phase) که سریع اجسام نامزد را پیدا می‌کند (مثلاً با جعبه‌های مرزی AABB)، سپس فاز محدود (narrow phase) که برای هر جفت شکل، برخورد دقیق را حل می‌کند. در این مرحله به‌جای نقطه‌ای ساده، منیفولد تماس ساخته می‌شود: مجموعه‌ای از نقاط تماس به‌همراه نرمال و عمق نفوذ که ثبات شبیه‌سازی را به‌شدت بالا می‌برد.

cppstruct Manifold {
    Body* bodyA;
    Body* bodyB;
    Vec2  normal;       // نرمال برخورد
    float penetration;  // عمق نفوذ
    Vec2  contact;      // نقطه تماس (یا چند نقطه)
};

همچنین «اصلاح موقعیت» (positional correction) مطرح می‌شود: بعد از حل ایمپالس، اجسامی که کمی نفوذ کرده‌اند با یک ضریب نرم (مثلاً ٨۰٪ عمق نفوذ) در جهت نرمال از هم جدا می‌شوند تا به هم نچسبند.

۵. منیفولدها برای چندضلعی‌ها

مقاله پایانی سری به سراغ عمومی‌ترین حالت می‌رود: برخورد دو مستطیل/چندضلعی محدب. در این‌جا الگوریتم SAT (Separating Axis Theorem) استفاده می‌شود: اگر محوری پیدا کنیم که پیش‌بینی دو شکل روی آن همپوشانی نداشته باشد، اجسام جدا هستند؛ در غیر این صورت کمترین همپوشانی، نرمال و عمق برخورد را می‌دهد.

cpp// ایده SAT: برای هر محور (نرمال هر ضلع) پیش‌بینی هر دو شکل را مقایسه کن
float OverlapAlongAxis(Box a, Box b, Vec2 axis) {
    // پیش‌بینی گوشه‌های هر جعبه روی محور
    float minA = FLT_MAX, maxA = -FLT_MAX;
    for (Vec2 v : a.corners) {
        float p = Dot(v, axis);
        minA = std::min(minA, p);
        maxA = std::max(maxA, p);
    }
    // همین‌طور برای b ...
    return IntervalOverlap(minA, maxA, minB, maxB);
}

با داشتن منیفولد کامل (نرمال + عمق + نقاط تماس)، حل ایمپالس و اصلاح موقعیت همین‌قسمت قبل دقیقاً به کار می‌آید و در پایان سری، موتوری دارید که چندضلعی‌های دوبعدی را به‌شکل پایدار شبیه‌سازی می‌کند.

نکته: چرخش و اصطکاک در قسمت‌های پیشرفته‌تر مطرح می‌شوند؛ این سری پایه‌ای استوار برای ادامه یادگیری می‌سازد.
