ساخت یک شبکه مولد تخاصمی (GAN) ساده با TensorFlow

⚙ زبان: Python + TensorFlow ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور آموزش Paperspace است که یک GAN ساده (نویز → تصویر MNIST) را با TensorFlow می‌سازد.
↗ مشاهده منبع اصلی

GAN چیست؟

شبکهٔ مولد تخاصمی از دو شبکه ساخته می‌شود: مولد (Generator) که از نویز تصادفی، تصویر جعلی می‌سازد، و متمایزکننده (Discriminator) که می‌خواهد جعلی/واقعی را تشخیص دهد. این دو با هم «بازی» می‌کنند: جاعل بهتر می‌شود تا تشخیص‌دهنده گول بخورد، و تشخیص‌دهنده دقیق‌تر می‌شود — تعادل این رقابت، تصاویر واقعی‌نمای نهایی است.

معماری

در این آموزش ساده فقط لایه‌های Dense و LeakyReLU استفاده می‌شود، نه کانولوشن. مولد: ورودی ۱۰۰ نویز → چند لایه → تصویر ۲۸×۲۸. متمایزکننده: تصویر → چند لایه → احتمال «واقعی بودن»:

Pythondef generator(z_dim):
    model = Sequential([
        Dense(256, input_dim=z_dim),
        LeakyReLU(alpha=0.2),
        Dense(512), LeakyReLU(alpha=0.2),
        Dense(784, activation='tanh')   # 28*28 پیکسل
    ])
    return model

def discriminator():
    model = Sequential([
        Dense(256, input_dim=784),
        LeakyReLU(alpha=0.2),
        Dense(128), LeakyReLU(alpha=0.2),
        Dense(1, activation='sigmoid')  # احتمال واقعی بودن
    ])
    return model

`tanh` در خروجی مولد تصویر را بین ۱- و ۱ نگه می‌دارد: باید دادهٔ ورودی (MNIST) هم پیش‌تر به همین بازه مقیاس شده باشد.

آموزش رقابتی

در هر دونه آموزش اول متمایزکننده روی دادهٔ واقعی+جعلی، بعد مولد کل شبکهٔ ترکیبی را به‌دست می‌آورد. برای اینکه مولد در ابتدای کار گرفتار نشود، متمایزکننده را گاهی «قوی‌تر» نگه می‌دارند و labelهای جعلی برای مولد، به ۰.۹ نزدیک می‌شود (label smoothing):

مشاهدهٔ پیشرفت

هر چند دونه، از مولد عکس بگیرید و ذخیره کنید: می‌بینید که از نویز کامل به ارقام خوانا می‌رسد. همین «مشاهدهٔ یادگیری» یکی از لذت‌بخش‌ترین تجربه‌های یادگیری ماشین است.
