یک پرسپترون چندلایه (MLP) با Golang بساز

⚙ زبان: Go 🧠 MLP از صفر ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور نوشتهٔ «Build a Multilayer Perceptron with Golang» از ماتئو پاگلیزی (Matteo Pagliuzzi / made2591) است که با یک فایل Go ساده یک MLP آموزش‌پذیر می‌سازد. کد کامل در go-perceptron-go موجود است.
↗ مشاهده منبع اصلی

۱. ایده: یادگیری تقلیدی (imitation learning)

نویسنده با یک آزمایش ساده شروع می‌کند: شبکه را به‌جای کدگذاری دستی رفتار، با «مثال» آموزش می‌دهد — همان تقلید از نمایش. معماری انتخاب‌شده پرسپترون چندلایه (MLP) است: لایهٔ ورودی، یک یا چند لایهٔ پنهان و لایهٔ خروجی که هر نورون با یک تابع فعال‌سازی غیرخطی کار می‌کند.

۲. ساختار کد: NeuralLayer و MultiLayerNetwork

کد در یک فایل Go (network.go) با سه قطعهٔ کلیدی سازماندهی شده: ساختار NeuralLayer که نورون‌ها، بایاس و فعال‌سازی را نگه می‌دارد؛ ساختار MultiLayerNetwork که لایه‌ها و ماتریس وزن‌ها را نگه می‌دارد؛ و تابع اصلی که شبکه را با آرایه‌ای مثل [4, 3, 3] می‌سازد — یعنی ۴ نورون ورودی، لایهٔ پنهان ۳ نوری و خروجی ۳ نوری:

go// یک لایهٔ عصبی: نورون‌ها، بایاس‌ها و تابع فعال‌سازی
type NeuralLayer struct {
    neurons    int
    activation ActivationFunction
    bias       float64
}

// شبکهٔ چندلایه: لایه‌ها + ماتریس وزن‌ها + نرخ یادگیری
type MultiLayerNetwork struct {
    layers      []NeuralLayer
    weights     []*matrix.Matrix
    lr          float64
}

// ساخت شبکه با ابعاد داده‌شده: ورودی ۴، پنهان ۳، خروجی ۳
network, err := NewMultiLayerNetwork([]int{4, 3, 3}, 0.1)

۳. انتشار پیشرو با ضرب ماتریسی

خروجی هر لایه حاصل ضرب ماتریس وزن در خروجی لایهٔ قبل است که از تابع فعال‌سازی (در این پیاده‌سازی sigmoid) می‌گذرد. مزیت نمایش ماتریسی: همهٔ محاسبات به‌صورت برداری و با کتابخانهٔ gonum/matrix انجام می‌شود:

go// محاسبهٔ خروجی شبکه برای یک ورودی (انتشار پیشرو)
func (nn *MultiLayerNetwork) Predict(input []float64) []float64 {
    activation := matrix.NewDenseMatrix(len(input), 1, input)
    for i := 0; i < len(nn.layers); i++ {
        activation = nn.weights[i].Times(activation)
        activation = activation.Apply(nn.layers[i].activation)
    }
    return activation.Array()
}

۴. آموزش: انتشار بازگشتی و اصلاح وزن‌ها

در هر تکرار، خروجی با پاسخ درست مقایسه می‌شود و خطا از لایهٔ خروجی به عقب پخش می‌شود (backpropagation). وزن‌ها به‌اندازهٔ lr × گرادیان اصلاح می‌شوند تا خطا در تکرار بعد کمتر شود:

go// آموزش روی یک نمونه: backprop + به‌روزرسانی وزن
func (nn *MultiLayerNetwork) BackPropagation(input, target []float64) error {
    // محاسبهٔ خروجی هر لایه و نگه‌داشتن میانی‌ها (برای مشتق‌ها)
    outputs := nn.feedForward(input)

    // خطای لایهٔ خروجی، سپس پخش به عقب لایه‌به‌لایه
    // delta = error × مشتق فعال‌سازی؛ سپس وزن‌ها به‌روز می‌شوند
    error := matrix.NewDenseMatrix(len(target), 1, target)
    error.MinusEquals(outputs[len(outputs)-1])

    for i := len(nn.layers) - 1; i >= 0; i-- {
        delta := error.Apply(nn.layers[i].activationPrime).Times(nn.lr)
        gradient := outputs[i].Times(delta.Transpose())
        nn.weights[i].MinusEquals(gradient)
        error = nn.weights[i].Transpose().Times(delta)
    }
    return nil
}

۵. آزمایش: یادگیری از مثال

نویسنده شبکه را با یک مثال ساده آموزش می‌دهد و مشاهده می‌کند که خطا به‌مرور کاهش می‌یابد و پیش‌بینی‌ها به پاسخ درست نزدیک می‌شوند. این آزمایش نشان می‌دهد همان ساختار بدون هیچ دانش دامنه‌ای، الگو را از داده یاد می‌گیرد:

go// اجرای یک دور آموزش روی چند مثال و چاپ خطای میانگین
for epoch := 0; epoch < 5000; epoch++ {
    for i := range trainingInputs {
        err := network.BackPropagation(trainingInputs[i], trainingTargets[i])
        if err != nil {
            panic(err)
        }
    }
    if epoch%1000 == 0 {
        fmt.Printf("Epoch %d — خطای میانگین: %.6f\n", epoch, network.ComputeError(...))
    }
}

۶. جمع‌بندی

  • MLP = لایهٔ ورودی + لایه‌های پنهان + لایهٔ خروجی، با فعال‌سازی غیرخطی.
  • نمایش ماتریسی کد را کوتاه و محاسبات را برداری می‌کند (gonum).
  • backpropagation با نگه‌داشتن میانی‌های هر لایه، ساده و قابل ردیابی است.
  • آموزش با مثال (تقلید)، جایگزین قاعده‌های دستی برای رفتارهای پیچیده است.
