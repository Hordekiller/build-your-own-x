cache-lite: کش خودت را در کاتلین بساز

⚙ زبان: Kotlin ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور «cache-lite» از کژیژن خو است که یک کش LRU را در کاتلین با کد تمیز و کوچک پیاده می‌کند.
↗ مشاهده منبع اصلی

کش LRU چیست؟

کش (Cache) داده‌های پرتکرار را نزدیک برنامه نگه می‌دارد تا دفعهٔ بعد سریع‌تر پاسخ دهد. LRU (کم‌استفاده‌ترین اخیر) سیاستی است که وقتی ظرفیت پر شد، عنصری که «مدت بیشتری استفاده نشده» را حذف می‌کند. این سیاست در سیستم‌عامل‌ها، دیتابیس‌ها و مرورگرها استفاده می‌شود.

پیاده‌سازی درست LRU نیاز به ترکیب HashMap (برای جست‌وجوی سریع) و Doubly Linked List (برای دانستن ترتیب استفاده) دارد.

ساختار داده

ایدهٔ اصلی: هر عنصر یک «گره» در لیست دوطرفه است و HashMap کلیدها را به گره‌ها نگاشت می‌کند. وقتی عنصری استفاده شد، گره به آخر لیست (جوان‌ترین) منتقل می‌شود؛ و وقتی ظرفیت پر شد، گرهٔ اول لیست حذف می‌شود:

Kotlinclass CacheLite<K, V>(private val capacity: Int) {

    private class Node<K, V>(val key: K, var value: V) {
        var prev: Node<K, V>? = null
        var next: Node<K, V>? = null
    }

    private val map = HashMap<K, Node<K, V>>()
    private var head: Node<K, V>? = null   // قدیمی‌ترین
    private var tail: Node<K, V>? = null   // جوان‌ترین

    operator fun get(key: K): V? =
        map[key]?.also { node -> moveToTail(node) }?.value

    operator fun set(key: K, value: V) {
        val existing = map[key]
        if (existing != null) {
            existing.value = value              // به‌روزرسانی
            moveToTail(existing)
        } else {
            val node = Node(key, value)
            map[key] = node
            appendTail(node)                    // به انتها اضافه کن
            if (map.size > capacity) evictHead()  // حذف قدیمی
        }
    }
}

عملگرهای `get`/`set`، استفاده از کش را شبیه HashMap طبیعی می‌کنند — همان تجربهٔ کاربردی که نویسندهٔ اصلی هدف گرفته.

مدیریت لیست

عملکردهای کمکی (moveToTail، evictHead) قلب ترتیب‌سنجی هستند:

Kotlin    private fun moveToTail(node: Node<K, V>) {
        if (node === tail) return
        if (node === head) {
            head = node.next
            head?.prev = null
        } else {
            node.prev?.next = node.next
            node.next?.prev = node.prev
        }
        appendTail(node)
    }

    private fun appendTail(node: Node<K, V>) {
        node.prev = tail
        node.next = null
        tail = node
        node.prev?.next = node
        if (head == null) head = node
    }

    private fun evictHead() {
        head?.let {
            map.remove(it.key)
            head = it.next
            head?.prev = null
        }
    }

توجه کنید که `evictHead` باید کلید را از HashMap هم حذف کند — وگرنه ردپای منقضی می‌ماند.

جمع‌بندی

با حدود ۷۰ خط، یک کش LRU کامل در کاتلین ساخته‌اید که هم خواناتر و هم ایمن‌تر از اجراهای C است. مفاهیم این‌جا (لیست + هش‌مپ) را در LruCache اندروید و Redis هم می‌بینید و همین بار دیگر درک آن‌ها عمیق می‌شود.
