Gooact: ساخت React در ۱۶۰ خط جاوااسکریپت

⚙ زبان: JavaScript ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور مقالهٔ «Gooact: React in 160 lines of JavaScript» از میکووای پالکیویچ (Mikołaj Palkiewicz) در Medium است. او «هستهٔ React» را — کلاس کامپوننت، render، و به‌روزرسانی — در ۱۶۰ خط می‌نویسد تا نشان دهد فناوری‌های پیشرفته جادو نیستند.

۱. مقدمه: هدف و محدودیت‌ها

هدف این مقاله پیاده‌سازی یک «React مینیمال» است که بتواند برنامه‌های واقعی ساده را اجرا کند؛ شامل React.createElement، کلاس React.Component با setState و مکانیزم diffing برای به‌روزرسانی کارآمد. نویسنده صراحتاً از پیاده‌سازی برخی قابلیت‌ها (مانند کامپوننت‌های تابعی، portals و بهینه‌سازی ‌های پیشرفته) صرف‌نظر می‌کند تا کد کوچک بماند.

نکته: مزیت این آموزش، کوتاهی آن است؛ می‌توانید کل کد را یک‌باره بخوانید و بعد سراغ نسخهٔ کامل‌تر (مانند Didact با Fiber و Hook) بروید.

۲. createElement: ساخت گره‌های درخت مجازی

مانند همهٔ نسخه‌ها، اولین قطعه، تولیدکنندهٔ گره است. نکتهٔ ویژهٔ پیاده‌سازی Gooact: نودها مستقیم با نام کلاس‌های CSS مسیر می‌شوند و رویدادها با پیشوند on تشخیص داده می‌شوند:

jsconst TEXT_ELEMENT = "TEXT ELEMENT";

function createElement(type, config, ...args) {
  const props = Object.assign({}, config);
  // بچه‌ها: نودهای متنی به TEXT_ELEMENT تبدیل می‌شوند
  const hasChildren = args.length > 0;
  const rawChildren = hasChildren ? [].concat(...args) : [];
  props.children = rawChildren
    .filter(c => c != null && c !== false)
    .map(c => (c instanceof Object ? c : createTextElement(c)));
  return { type, props };
}

function createTextElement(value) {
  return createElement(TEXT_ELEMENT, { nodeValue: value });
}

۳. render: تبدیل درخت مجازی به DOM

تابع render به‌صورت بازگشتی نودهای DOM می‌سازد و صفات را روی آن‌ها می‌نشاند؛ رویدادها (با پیشوند on) با addEventListener متصل می‌شوند و بقیهٔ کلیدها صفت می‌شوند:

jsfunction render(element, parentDom) {
  const dom =
    element.type === TEXT_ELEMENT
      ? document.createTextNode("")
      : document.createElement(element.type);

  const isListener = (name) => name.startsWith("on");
  const isAttribute = (name) => !isListener(name) && name !== "children";

  // اتصال رویدادها
  Object.keys(element.props || {})
    .filter(isListener)
    .forEach((name) => {
      const eventType = name.toLowerCase().substring(2);
      dom.addEventListener(eventType, element.props[name]);
    });

  // تنظیم صفات
  Object.keys(element.props || {})
    .filter(isAttribute)
    .forEach((name) = => {
      dom[name] = element.props[name];
    });

  // رندر بچه‌ها به‌صورت بازگشتی
  const childElements = element.props.children || [];
  childElements.forEach((childElement) => render(childElement, dom));

  parentDom.appendChild(dom);
  return dom;
}

توجه کنید چگونه فقط با یک قاعدهٔ نام‌گذاری (پیشوند on) هم رویدادها و هم صفات از هم جدا می‌شوند — همین سادگی، خوانایی کد را بالا می‌برد.

۴. کلاس Component و setState

قلب React، کلاس Component است: هر نمونه، props و state و یک __internalInstance دارد که به نود DOM خودش اشاره می‌کند. هنگام setState فقط خود نود و فرزندانش دوباره رندر می‌شوند (نه کل صفحه):

jsclass Component {
  constructor(props) {
    this.props = props || {};
    this.state = null;
  }

  setState(nextState) {
    // ادغام state جدید با قبلی
    this.state = Object.assign({}, this.state, nextState);
    // رندر دوبارهٔ فقط همین کامپوننت
    updateInstance(this.__internalInstance);
  }
}

function updateInstance(internalInstance) {
  const parentDom = internalInstance.dom.parentNode;
  const element = internalInstance.element;
  const newElement = getElement(internalInstance);
  const newInstance = instantiate(newElement);
  // مقایسهٔ درخت‌ها و اعمال diff بین DOM قبلی و جدید
  diff(parentDom, internalInstance.dom, newInstance.dom, internalInstance.dom);
  internalInstance.dom = newInstance.dom;
}

function instantiate(element) {
  const { type, props } = element;
  // کامپوننت‌ها: نمونه می‌سازیم و با متد render مقدار می‌دهیم
  const isDomElement = typeof type === "string";
  if (isDomElement) {
    const isTextElement = type === TEXT_ELEMENT;
    const dom = isTextElement ? document.createTextNode("") : document.createElement(type);
    updateDomProperties(dom, [], props);
    const childElements = props.children || [];
    const childInstances = childElements.map(instantiate);
    const childDoms = childInstances.map((ci) => ci.dom);
    childDoms.forEach((childDom) => dom.appendChild(childDom));
    return { dom, element, childInstances };
  } else {
    // کلاس کامپوننت: نمونه ساخته و رندر می‌شود
    const instance = new type(props);
    const childElement = instance.render();
    const childInstance = instantiate(childElement);
    const dom = childInstance.dom;
    // اتصال نمونهٔ داخلی برای به‌روزرسانی‌های بعدی
    Object.assign(instance, { __internalInstance: { dom, element, childInstance } });
    return { dom, element, childInstance, instance };
  }
}

۵. diffing: به‌روزرسانی هوشمند نودها

تابع diff چهار حالت را پوشش می‌دهد: جابه‌جایی نود (با insertBefore)، حذف، جایگزینی با نود جدید و «همان نود» — در این حالت فقط صفات و بچه‌ها مقایسه و در صورت تغییر اعمال می‌شوند:

jsfunction diff(parentDom, instance, newInstance, referenceDom) {
  const oldDom = instance.dom;
  const newDom = newInstance.dom;

  if (instance.element.type === newInstance.element.type) {
    // همان نوع: فقط props را به‌روز کن
    updateDomProperties(oldDom, instance.element.props, newInstance.element.props);
    const oldChildInstances = instance.childInstances;
    const newChildElements = newInstance.element.props.children || [];
    // بچه‌های جدید را بر اساس تعداد قبلی diff کن
    const newChildInstances = [];
    const count = Math.max(oldChildInstances.length, newChildElements.length);
    for (let i = 0; i < count; i++) {
      const newChildElement = newChildElements[i];
      const oldChildInstance = oldChildInstances[i];
      if (oldChildInstance && newChildElement) {
        // هر دو موجود: diff بازگشتی
        newChildInstances.push(diff(parentDom, oldChildInstance, instantiate(newChildElement), oldChildInstance.dom));
      } else if (oldChildInstance) {
        // قبلی بود و الان نیست: حذف
        parentDom.removeChild(oldChildInstance.dom);
      } else {
        // جدید است: اضافه کن
        parentDom.appendChild(instantiate(newChildElement).dom);
      }
    }
    instance.childInstances = newChildInstances;
    return instance;
  }
  // نوع عوض شده: جایگزین کامل
  parentDom.replaceChild(newDom, oldDom);
  return newInstance;
}

توجه: چون بچه‌ها با «شاخص» مقایسه می‌شوند، این نسخه از کلیدها (key) پشتیبانی نمی‌کند — یکی از بهینه‌سازی‌هایی که React واقعی با key اضافه می‌کند.

۶. جمع‌بندی

  • هستهٔ React (element ← render ← setState ← diff) بدون هیچ سرباری در ۱۶۰ خط جاوااسکریپت خالص پیاده‌شدنی است.
  • جداسازی «نود DOM» از «نمونهٔ داخلی» همان چیزی است که به‌روزرسانی بخشی از درخت را بدون رندر کامل صفحه ممکن می‌کند.
  • diff بر اساس «نوع نود» و «شاخص بچه» کار می‌کند؛ key ها راهی برای بهترکردن همین مقایسه در React واقعی‌اند.
