دربارهٔ ویدیو

این ویدیو با پایتون یک زبان مفسری ساده می‌سازد: از تعریف دستورهای اولیه (اتصالات، حلقه، شرط) تا اجرای آن روی نمونه‌ها. مناسب کسی که می‌خواهد نتیجهٔ کار را سریع ببیند.

▶ تماشای ویدیو

ساختار مورد انتظار

مانند هر مفسر، سه مؤلفهٔ اصلی ساخته می‌شود: lexer (تبدیل متن به توکن)، parser (ساخت درخت/توالی)، و evaluator (اجرای دستورها). در ویدیو معمولاً این سه در یک کلاس یا فایل ساده با تمرکز روی خوانایی نوشته می‌شوند.

نمونهٔ کد: اجرای یک دستور

برای اینکه از قبل با جوهرهٔ کار آشنا باشید، نمونهٔ یک حلقهٔ eval ساده:

Pythondef execute(node, env):
    if node['type'] == 'assign':          # a = 5
        env[node['name']] = eval_expr(node['value'], env)
    elif node['type'] == 'print':         # print expr
        print(eval_expr(node['value'], env))
    elif node['type'] == 'if':            # if cond: ...
        if eval_expr(node['cond'], env):
            for stmt in node['body']:
                execute(stmt, env)
    elif node['type'] == 'while':         # while cond: ...
        while eval_expr(node['cond'], env):
            for stmt in node['body']:
                execute(stmt, env)

نکته‌ها

۱) با یک زبان کوچک شروع کنید و قابلیت اضافه کنید؛ ۲) محیط (env) را ساده با dict نگه دارید؛ ۳) روی خطاها (خط syntactical) تمرکز کنید تا مفسرتان مفید باشد؛ ۴) بعد از دیدن ویدیو، سری «lsbasi» رسلان اسپیواک را بخوانید تا مفاهیم عمیق‌تر شوند.

جمع‌بندی

سریع‌ترین راه دیدن «مفسر چکار می‌کند»: ویدیو را ببینید، همان‌جا در حالت live کدنویسی را دنبال کنید، و بعد سعی کنید خودتان زبان کوچکی بسازید. یادگیری مفسرنویسی با دیدن کد در حال شکل‌گیری، ساده‌تر از هر متن خشک است.
