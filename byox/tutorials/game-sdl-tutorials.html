شروع برنامه‌نویسی بازی نسخه ۲.۰ — آموزش‌های SDL لزیفو (Lazy Foo)

⚙ زبان: C++ ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه معرفی و مرور فارسی مجموعه‌آموزش‌های «Beginning Game Programming v2.0» از سایت Lazy Foo' Productions است — کامل‌ترین منبع یادگیری SDL 2 برای برنامه‌نویسان C++ که از مقدمات تا مفاهیم پیشرفته (رندر، صدا، ورودی و پلتفرم) را پوشش می‌دهد.

۱. SDL چیست و چرا لزیفو؟

SDL (Simple DirectMedia Layer) یک کتابخانهٔ متن‌باز C/C++ برای دسترسی سطح پایین به گرافیک، صدا، ورودی و پنجره است — همان چیزی که بازی‌ها و موتورهای زیادی (حتی Emulators) روی آن ساخته می‌شوند. آموزش‌های لزیفو معروف‌ترین منبع شروع SDL 2 هستند: درس‌های شماره‌دار، کد کامل قابل دانلود و توضیح دقیق هر مفهوم.

نکته: این سری «از کنسول به رندر زمان‌واقعی» حرکت می‌کند: اول با اولین پنجره و رندر بافت آشنا می‌شوید و به‌تدریج به سیستم‌های کامل‌تر (مثل tiling، ورودی موش/کیبورد/گیم‌پد، صدا و ویدیو) می‌رسید.

۲. نقشهٔ درس‌ها

  • درس ۱–۵: نصب، اولین پنجره، رندر کردن تصویر و event loop
  • درس ۶–۱۰: بافت‌سازی، بارگذاری تصویر (PNG با libpng)، نرم‌افزار و سخت‌افزار rendering
  • درس ۱۱–۱۵: حرکت کلیدی و mouse، کنترل‌کننده‌ها، کلیپ‌برد
  • درس ۱۶–۲۰: صوت (WAV و پخش جریان‌ها)، tiling با sprite sheet، برخورد، font ها (TTF)
  • درس ۲۱–۲۵: پیشرفت‌ها: تفاوت نمایشگر (vsync)، فرمت پیکسل، نمونه‌های متحرک (animated sprites)
  • بیشتر: گیم‌پد، ضبط صفحه، کامپوزینگ و حتی مقدمهٔ Vulkan/SDL3

۳. نمونهٔ اولین برنامه

cpp// درس ۰۱: اولین پنجره
#include <SDL.h>
#include <cstdio>

int main(int argc, char *argv[]) {
  if (SDL_Init(SDL_INIT_VIDEO) < 0) {
    printf("SDL نتوانست مقداردهی شود! خطا: %s\n", SDL_GetError());
    return 1;
  }

  SDL_Window *window = SDL_CreateWindow(
    "اولین پنجره",            // عنوان
    SDL_WINDOWPOS_UNDEFINED,   // موقعیت x
    SDL_WINDOWPOS_UNDEFINED,   // موقعیت y
    SCREEN_WIDTH, SCREEN_HEIGHT,
    SDL_WINDOW_SHOWN
  );
  if (window == NULL) { printf("پنجره ساخته نشد: %s\n", SDL_GetError()); return 1; }

  SDL_Surface *screen = SDL_GetWindowSurface(window);
  // رنگ‌آمیزی سطح پنجره
  SDL_FillRect(screen, NULL, SDL_MapRGB(screen->format, 0xFF, 0xFF, 0xFF));
  SDL_UpdateWindowSurface(window);

  // حلقهٔ رویداد: تا بسته‌شدن پنجره
  bool quit = false;
  SDL_Event e;
  while (!quit) {
    while (SDL_PollEvent(&e) != 0) {
      if (e.type == SDL_QUIT) quit = true;
    }
  }

  SDL_DestroyWindow(window);
  SDL_Quit();
  return 0;
}

روند هر درس همین است: راه‌اندازی ← حلقهٔ رویداد ← رندر ← تمیزکردن. با تکرار این الگو در درس‌های بعدی، لایه‌های بیشتری (بافت، ورودی، صدا) اضافه می‌شود.

۴. جمع‌بندی

  • لزیفو بهترین نقطهٔ شروع SDL 2 است: درس‌ها خودکفا و کدها کامل‌اند.
  • هر درس یک لایهٔ جدید از توسعهٔ بازی (گرافیک، ورودی، صوت، برخورد) را آموزش می‌دهد.
  • برای اجرای کدها، کتابخانهٔ SDL2 و کامپایلر C++ کافی است؛ مثال‌ها روی Windows، Linux و Mac کار می‌کنند.
