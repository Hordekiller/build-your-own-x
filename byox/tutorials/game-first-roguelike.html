۱. دربارهٔ آموزش

این یک سری ۸ قسطی (مثلاً در نسخهٔ اصلی ۴ بخش اصلی) است که اولین بازی roguelike شما را از پایه می‌سازد. نویسنده (فارن بریسی، سازندهٔ RogueSharp) از نمایش یک «@» روی صفحه شروع می‌کند تا مبارزهٔ کامل با هیولاها، سیاه‌چاه تصادفی، میدان دید، آیتم‌ها و … — با RogueSharp برای منطق و RLNET/MonoGame برای نمایش.

نکته: اگر سری وبلاگ رسمی RogueSharp را هم دیده‌اید، این مقاله‌ها نسخهٔ ساختارمندتر همان آموزش‌اند — انتخاب با شماست؛ محتوا یکی است.

۲. درس‌ها

  • مقدمه و اصول بازی‌های roguelike
  • ساخت سیاه‌چاه با تولید تصادفی اتاق‌ها
  • حرکت بازیکن و تشخیص ورودی
  • میدان دید (FOV) و محیط‌های تاریک
  • هوش مصنوعی دشمن و مسیریابی
  • مبارزه، آیتم‌ها و مدیریت امتیاز/سلامت

۳. نمونهٔ کد

csharp// ساخت سیاه‌چاه با RogueSharp
using RogueSharp;
using RogueSharp.MapCreation;

IMapCreationStrategy<Map> strategy =
    new RandomRoomsMapCreationStrategy<Map>(80, 50, 30, 12, 6);
Map map = Map.Create(strategy);

// قرار دادن بازیکن در اولین اتاق
foreach (Cell cell in map.GetAllCells())
{
    if (cell.IsWalkable) {
        playerX = cell.X;
        playerY = cell.Y;
        break;
    }
}

// حرکت بازیکن با امنیت: فقط به سلول‌های قابل عبور
if (map.IsWalkable(newX, newY))
{
    playerX = newX;
    playerY = newY;
    map.SetIsWalkable(playerX, playerY, false); // بازیکن محل را اشغال می‌کند
}
