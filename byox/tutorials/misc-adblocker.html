افزونهٔ مسدودکردن تبلیغات چطور کار می‌کند؟

تبلیغات معمولاً از دامنه‌های خاصی (مثل adserver.com) بارگذاری می‌شوند. یک AdBlocker درخواست‌های مرورگر را به این دامنه‌ها می‌بیند و آن‌ها را مسدود می‌کند. در Chrome، این کار با API `webRequest` و رویداد `onBeforeRequest` انجام می‌شود.

مزیت این روش: مسدودسازی در سطح شبکه است، پس تبلیغ حتی بارگذاری هم نمی‌شود (سریع‌تر از پنهان‌کردن با CSS).

manifest.json

اولین قدم در هر افزونه، فایل manifest است که دسترسی‌ها را اعلام می‌کند. برای AdBlocker باید `webRequest` و `webRequestBlocking` را داشته باشیم:

JSON{
  "manifest_version": 2,
  "name": "AdBlocker ساده",
  "version": "1.0",
  "description": "مسدودکنندهٔ سادهٔ تبلیغات",
  "permissions": [
    "webRequest",
    "webRequestBlocking",
    "<all_urls>"
  ],
  "background": {
    "scripts": ["blocker.js"],
    "persistent": true
  }
}

نسخهٔ ۳ افزونه‌ها (MV3) روش دیگری دارد (declarativeNetRequest)؛ اما این ساختار ساده برای یادگیری عالی است.

منطق مسدودسازی

قلب افزونه، اسکریپت background است که قبل از هر درخواست، URL را با لیست دامنه‌های تبلیغاتی مقایسه می‌کند:

JavaScript// لیست سادهٔ دامنه‌های تبلیغاتی
const AD_DOMAINS = [
  'doubleclick.net',
  'googleadservices.com',
  'adservice.google.com',
  'adsense.com',
  'googlesyndication.com'
];

// مسدودکردن درخواست‌هایی که به دامنهٔ تبلیغاتی می‌روند
chrome.webRequest.onBeforeRequest.addListener(
  function (details) {
    const url = new URL(details.url);
    const host = url.hostname;

    if (AD_DOMAINS.some(domain => host === domain || host.endsWith('.' + domain))) {
      console.log('مسدود شد:', details.url);
      return { cancel: true };   // قطع درخواست
    }
    return {};                   // اجازهٔ ادامه
  },
  { urls: ['<all_urls>'] },
  ['blocking']
);

مقایسهٔ hostname به‌صورت دقیق (برابری یا پسوند) باعث می‌شود زیردامنه‌ها هم مسدود شوند و دامنه‌های مشابه اشتباهاً بلاک نشوند.

گزینه‌های پیشرفته

برای یک AdBlocker واقعی، موارد بیشتری لازم است: filter لیست‌های عظیم (EasyList)، مسدودسازی بر اساس الگوی URL (pattern) نه فقط دامنه، و UI برای مدیریت استثناها. اما همین ۲۰ خط، رفتار پایه را دارد و می‌تواند در سایت‌های شلوغ تفاوت محسوس ایجاد کند.

جمع‌بندی

ساختن AdBlocker اولین قدم عالی برای درک اکوسیستم افزونه‌های مرورگر است: manifest، background script و APIهای قدرتمند. با همین دانش می‌توانید افزونه‌های مفید دیگری هم بسازید.
