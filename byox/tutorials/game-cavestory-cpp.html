۱. دربارهٔ پروژه

Cave Story یک بازی اکشن-پلتفرمر فوق‌محبوب است که توسط یک نفر (Daisuke "Pixel" Amaya) و در ۵ سال ساخته شد و به‌عنوان پدر «indie games» شناخته می‌شود. در این سری ویدیویی، بازی با C++ بازسازی می‌شود: حرکت شخصیت، فیزیک پرش و گرانش، سلاح‌ها، دشمنان، موتور صحنه و اسکرول — همه از صفر.

نکته: این سری یکی از کامل‌ترین آموزش‌های «بازسازی بازی» است؛ چون Cave Story پیچیدگی‌های واقعی (اسکرول دوربین، انیمیشن، برخورد دقیق) را دارد.

۳. آنچه در ویدیوی اول یاد می‌گیرید

  • راه‌اندازی پروژه و مدیریت پنجره (معمولاً با SDL)
  • بارگذاری اسپرایت‌ها و تایل‌ها
  • حلقهٔ اصلی بازی و مدیریت ورودی
  • حرکت بازیکن و فیزیک پایه (گرانش و پرش)

نمونهٔ ساختار کلاس‌ها در این سری:

cpp// ساختار پایهٔ بازی در سری Cavestory
class Entity {
public:
  Vector2 position;
  Vector2 velocity;
  bool grounded;

  virtual void update(float dt) = 0;   // منطق هر موجود
  virtual void render() = 0;           // رسم هر موجود
};

class Player : public Entity {
public:
  void update(float dt) override {
    // ورودی → حرکت افقی
    velocity.x = input * MOVE_SPEED;
    // گرانش
    velocity.y += GRAVITY * dt;
    // پرش
    if (jump_pressed && grounded) velocity.y = -JUMP_SPEED;
    // اعمال حرکت با برخورد
    position += velocity * dt;
    resolve_collisions();
  }
};

۴. جمع‌بندی

با دنبال‌کردن این سری، یک پلتفرمر کامل با ویژگی‌های Cave Story می‌سازید: سلاح با ارتقا، دشمنان هوشمند، پورتال‌ها و نبردهای باس. برای کسانی که با C++ راحت‌اند و به دنبال پروژهٔ چالش‌برانگیز هستند، عالی است.

کپیرایت: ویدیوی «Cavestory Part 1» اثر سازندهٔ کانال یوتیوب است و بازی Cave Story متعلق به Daisuke "Pixel" Amaya است. این صفحه فقط ترجمهٔ فارسی و مرور آن است. برای مشاهدهٔ اصل ویدیو به یوتیوب مراجعه کنید.
