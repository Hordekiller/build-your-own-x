۱. دربارهٔ آموزش

بازی‌های roguelike — با کاراکترهای ASCII، سیاه‌چاه‌های تولیدشدهٔ تصادفی و مرگ همیشگی — یکی از بهترین ژانرها برای یادگیری برنامه‌نویسی بازی هستند؛ چون همهٔ منطق در ترمینال اجرا می‌شود و نیازی به گرافیک نیست. در این پلی‌لیست، یک بازی کامل به سبک Rogue/Nethack ساخته می‌شود: تولید نقشهٔ تصادفی، شخصیت و آمار، مبارزهٔ نوبتی، آیتم‌ها و بالا رفتن از طبقه‌های سیاه‌چاه.

▶ مشاهدهٔ پلی‌لیست «Programming an RPG in C»

۳. مفاهیم کلیدی

ساختار بازی‌های roguelike — نمایش دنیا به‌صورت شبکهٔ کاراکتری و حلقهٔ نوبتی:

c// نقشهٔ سیاه‌چاه: شبکه‌ای از کاراکترها
#define WALL '#'
#define FLOOR '.'
#define PLAYER '@'
#define MONSTER 'M'
#define ITEM '$'

char map[MAP_H][MAP_W];

// تولید تصادفی نقشه با «اتاق‌ها و راهروها»
void generate_map(void) {
  // اتاق‌های تصادفی بچین و با راهرو به هم وصل کن
  for (int i = 0; i < NUM_ROOMS; i++) {
    make_room(x, y, w, h);
    connect_rooms(prev_x, prev_y, x, y);
  }
}

// حلقهٔ اصلی: نوبت بازیکن → نوبت دشمنان
void game_loop(void) {
  while (player_alive) {
    render_map();          // نمایش ترمینال
    int key = get_input(); // خواندن یک کلید (حرکت/اکشن)
    move_player(key);
    // مبارزهٔ نوبتی: هر دشمن یک نوبت
    for (int i = 0; i < num_monsters; i++) {
      move_monster(&monsters[i]);  // دنبال کردن بازیکن
      check_fight(&monsters[i]);   // حمله در برخورد
    }
    check_items();  // برداشتن آیتم‌ها
    check_descent(); // پایین رفتن به طبقهٔ بعد
  }
}

این سری از کتابخانهٔ ncurses برای ترمینال استفاده می‌کند تا صفحه‌نمایش تمام‌صفحه و خواندن کلید بدون Enter را ممکن کند.

۴. جمع‌بندی

ساخت یک roguelike همهٔ مهارت‌های اساسی بازی‌سازی را پوشش می‌دهد: حلقهٔ بازی، مدیریت state، تولید تصادفی و طراحی سیستم‌ها — بدون سردرگمی گرافیک. ویدیوهای این سری با کد کامل، بهترین همراه برای شروع هستند.
