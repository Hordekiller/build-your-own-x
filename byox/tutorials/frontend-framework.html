ساخت یک فریم‌ورک فرانت‌اند از صفر (قالب‌سازی، state و VDOM)

۱. دربارهٔ کتاب

این کتاب آموزشی به‌صورت گام‌به‌گام نشان می‌دهد یک فریم‌ورک فرانت‌اند (شبیه Vue یا React) چطور ساخته می‌شود. در پایان کتاب، فریم‌ورکی به نام «کدومینار» داریم که سه قابلیت اصلی را دارد:

  • قالب‌سازی (Templating): جذب HTML اعلانی به‌همراه دستورها؛
  • مدیریت state: به‌روزرسانی خودکار رابط با تغییر مدل؛
  • Virtual DOM: به‌روزرسانی کارآمد DOM با diff.

نکتهٔ جالب: هر فصل از کتاب، توضیح مفهومی + کد کامل + تمرین تعاملی دارد و در انتها می‌توانید کد نهایی را از مخزن GitHub بردارید.

۲. گام اول: طراحی موتور قالب (Templating)

فریم‌ورک ما باید HTML را «کامپایل» کند. ابتدا مفهوم «کامپوننت» را تعریف می‌کنیم: تابعی که props می‌گیرد و درخت مجازی برمی‌گرداند؛ سپس کار موتور قالب، تبدیل این درخت به DOM است:

js// کامپوننت: تابعی که props می‌گیرد و درخت مجازی برمی‌گرداند
function HelloWorld({ name }) {
  return {
    type: 'h1',
    props: { class: 'title' },
    children: ['سلام ' + name + '!'],
  };
}

// کامپایل درخت مجازی به DOM
function compileTree(vnode) {
  if (typeof vnode === 'string') {
    return document.createTextNode(vnode);
  }

  const el = document.createElement(vnode.type);

  for (const key in vnode.props) {
    // دستورهای ما (رویدادها) با پیشوند on شروع می‌شوند
    if (key.startsWith('on')) {
      el.addEventListener(key.slice(2).toLowerCase(), vnode.props[key]);
    } else {
      el.setAttribute(key, vnode.props[key]);
    }
  }

  vnode.children.forEach((child) => el.appendChild(compileTree(child)));
  return el;
}

const root = document.getElementById('app');
root.appendChild(compileTree(HelloWorld({ name: 'دنیا' })));

این موتور قالب می‌تواند دستورهای سادهٔ HTML (مثل حلقه و شرط) را هم پشتیبانی کند: در کتاب با «دستورهای قالب» آشنا می‌شوید که به HTML خام اضافه می‌شوند.

۳. گام دوم: مدیریت state و رندر دوباره

برای اینکه رابط با تغییر state به‌روز شود، به یک «حالت مرکزی» و مکانیزم اشتراک نیاز داریم. کتاب رویکردی ساده و شبیه به Vue انتخاب می‌کند — یک شیء reactive:

jsfunction createReactiveState(initialState, listeners = []) {
  return new Proxy(initialState, {
    set(target, key, value) {
      target[key] = value;
      // هر تغییری = خبر دادن همهٔ شنونده‌ها (رندر دوباره)
      listeners.forEach((listener) => listener());
      return true;
    },
  });
}

// نمونه: هر تغییر state باعث رندر دوبارهٔ درخت می‌شود
const state = createReactiveState({ count: 0 }, () => renderApp());

function renderApp() {
  const vnode = Counter();
  diff(previousVnode, vnode, root); // diff و patch (گام بعد)
}

توجه کنید: استفاده از Proxy باعث می‌شود هر دسترسی به state ردیابی شود و فریم‌ورک بداند کدام کامپوننت‌ها به چه بخشی از state وابسته‌اند — همان ایدهٔ reactivity در Vue 3.

۴. گام سوم: Virtual DOM و diff

بخش نهایی کتاب الگوریتم diff را پیاده می‌کند تا بین رندرها فقط تغییرات واقعی اعمال شوند. کتاب سه تابع اصلی را معرفی می‌کند:

js// ۱) ساخت درخت مجازی قبلی و جدید
// ۲) مقایسهٔ آنها (diff) — نتیجه: لیستی از تغییرات
// ۳) اعمال تغییرات روی DOM (patch)

function diff(oldVnode, newVnode, parentDom) {
  if (oldVnode === undefined) {
    // نود جدید — ساخت و افزودن
    parentDom.appendChild(compileTree(newVnode));
  } else if (oldVnode.type === newVnode.type) {
    // همان نوع — به‌روزرسانی صفات و بچه‌ها (بازگشتی)
    updateProps(parentDom.childNodes[0], oldVnode, newVnode);
    const max = Math.max(oldVnode.children.length, newVnode.children.length);
    for (let i = 0; i < max; i++) {
      diff(oldVnode.children[i], newVnode.children[i], parentDom.childNodes[0]);
    }
  } else {
    // نوع متفاوت — جایگزینی کل نود
    parentDom.replaceChild(compileTree(newVnode), parentDom.childNodes[0]);
  }
}

۵. جمع‌بندی کتاب

  • یک فریم‌ورک از سه لایهٔ مستقل ساخته می‌شود: موتور قالب، سیستم state و Virtual DOM.
  • reactivity با Proxy ساده‌تر و دقیق‌تر از dirty checking است؛ دلیل اصلی این که فریم‌ورک‌های جدید (Vue 3، MobX) سراغ آن رفتند.
  • در پایان کتاب می‌توانید فریم‌ورک خودتان را گسترش دهید: اضافه‌کردن رویدادها، کامپوننت‌های محلی و رندر سمت سرور.
