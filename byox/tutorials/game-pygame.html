۱. دربارهٔ دوره

این سری ویدیویی، بازی «A bit Racey» را می‌سازد: یک ماشین مسابقه‌ای که با کلید ها حرکت می‌کند و باید موانع در حال آمدن را دور بزند. درس اول راه‌اندازی کامل را نشان می‌دهد: نصب PyGame، ساخت پنجره، حلقهٔ بازی و کنترل فریم‌ریت با Clock.

نکته: این یک آموزش ویدیویی-متنتی است؛ درس‌ها هم ویدیو دارند هم متن — برای دنبال‌کردن گام‌به‌گام عالی است.

۲. کد مقدماتی

pythonimport pygame

# راه‌اندازی همهٔ ماژول‌های pygame
pygame.init()

# ساخت پنجره: عرض ۸۰۰، ارتفاع ۶۰۰
win = pygame.display.set_mode((800, 600))

# عنوان پنجره
pygame.display.set_caption("A bit Racey")

# ساعت: کنترل فریم‌ریت
clock = pygame.time.Clock()

# مقداردهی اولیهٔ ماشین بازی
x, y = 400, 500      # موقعیت ماشین
width, height = 40, 60
vel = 5              # سرعت حرکت

run = True
while run:
    clock.tick(60)   # حداکثر ۶۰ فریم در ثانیه

    # مدیریت رویدادها: بستن پنجره
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            run = False

    # ورودی: حرکت با کلیدهای جهت‌نما
    keys = pygame.key.get_pressed()
    if keys[pygame.K_LEFT] and x > 0:
        x -= vel
    if keys[pygame.K_RIGHT] and x < 800 - width:
        x += vel

    # رندر: پاک کردن صفحه و رسم ماشین
    win.fill((0, 0, 0))
    pygame.draw.rect(win, (255, 0, 0), (x, y, width, height))

    pygame.display.update()

pygame.quit()

با همین حدود ۳۰ خط، اولین بازی قابل اجرای شما آماده است؛ درس‌های بعدی موانع، برخورد، امتیاز و صفحهٔ شروع/پایان را اضافه می‌کنند.
