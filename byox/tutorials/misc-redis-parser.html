پروتکل RESP چیست؟

RESP (REdis Serialization Protocol) یک پروتکل متنی-باینری ساده است که کلاینت و سرور Redis برای ارتباط از آن استفاده می‌کنند. هر نوع داده با یک حرف پیشوند مشخص می‌شود: `+` برای رشتهٔ ساده، `-` برای خطا، `:` برای عدد صحیح، `$` برای رشتهٔ باینری و `*` برای آرایه.

ساختن پارسر این پروتکل، گام عالی برای یادگیری «پروتکل‌های باینری-متنی» است و با Nim که سینتکس پایتون‌مانند ولی کارایی C دارد، لذت‌بخش می‌شود.

ساختار پیام‌ها

مثال پیام‌ها: `:1000\r\n` یعنی عدد ۱۰۰۰؛ `$5\r\nhello\r\n` یعنی رشتهٔ binری با طول ۵؛ و `*2\r\n$3\r\nfoo\r\n$3\r\nbar\r\n` یعنی آرایه‌ای از دو رشته. CRLF جداکنندهٔ استاندارد است.

پارسر ساده در Nim

پیاده‌سازی با یک نوع «بافر خواندن» و توابع کوچک برای هر نوع انجام می‌شود:

Nimimport strutils, sequtils

# نوع دادهٔ مشترک برای هر پاسخ RESP
type RespValue = object
  case kind: enum
    of rSimple: s: string
    of rError:  e: string
    of rInt:    i: int
    of rBulk:   b: string
    of rArray:  items: seq[RespValue]

# پارس رشتهٔ ساده: +OK\r\n
proc parseSimple(line: string): RespValue =
  result = RespValue(kind: rSimple, s: line)

# پارس bulk string: $len\r\n<payload>\r\n
proc parseBulk(data: seq[string], idx: var int): RespValue =
  let len = parseBiggestInt(data[idx]); inc idx
  if len == -1:
    return RespValue(kind: rBulk, b: "")
  result = RespValue(kind: rBulk, b: data[idx])
  inc idx

در حلقهٔ اصلی، خط اول خوانده می‌شود و بر اساس حرف اول (پیشوند) به تابع مناسب واگذار می‌شود.

حلقهٔ اصلی پارس

با یک ساختار داده که پیام‌ها را خط‌به‌خط می‌شکند، کل پارسر به‌صورت بازگشتی پیش می‌رود:

Nim# پارس ارس: آرایه را متناوب پارس می‌کند
proc parseArray(data: seq[string], idx: var int): RespValue =
  let count = parseBiggestInt(data[idx]); inc idx
  var items: seq[RespValue]
  for i in 0..<count:
    items.add(parseMessage(data, idx))
  RespValue(kind: rArray, items: items)

proc parseMessage(data: seq[string], idx: var int): RespValue =
  let first = data[idx][0]
  case first
  of '+': result = parseSimple(data[idx][1..^1]); inc idx
  of ':': result = RespValue(kind: rInt, i: parseBiggestInt(data[idx][1..^1])); inc idx
  of '$': result = parseBulk(data, idx)
  of '*': result = parseArray(data, idx)
  of '-': result = RespValue(kind: rError, e: data[idx][1..^1]); inc idx
  else: raise newException(ValueError, "غیرقابل شناسایی: " & first)

با ۳۰ خط پارسر، هم‌صحبت با Redis امکان‌پذیر است (برای کوئری‌های GET/SET).

جمع‌بندی

RESP یکی از ساده‌ترین پروتکل‌های واقعی برای یادگیری است و این آموزش Nim، آن را با کدی کوچک و تمیز آموزش می‌دهد. بعد از این، می‌توانید کلاینت Redis خودتان را کامل کنید یا سراغ پروتکل‌های باینری پیچیده‌تر بروید.
