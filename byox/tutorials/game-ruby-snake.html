۱. دربارهٔ آموزش

این مقاله نشان می‌دهد بازی‌سازی با Ruby کاملاً شدنی و لذت‌بخش است؛ یک بازی مار در ترمینال ساخته می‌شود و شیوهٔ تفکر ساختارمند (کلاس‌های Board، Snake، Food و Game) آموزش داده می‌شود — بدون نیاز به گرافیک، با کاراکترهای ترمینال.

نکته: خواندن این مقاله همدانش با بازی‌سازی و هم با «ساختار تمیز مفاهیم بازی» را نشان می‌دهد؛ کلاس‌بندی خوبی دارد.

۲. ساختار کلاس‌ها

مجموعهٔ کلاس‌ها و مسئولیت‌هایشان:

ruby# صفحهٔ بازی: شبکه و مرزها
class Board
  attr_accessor :grid_size, :x_limit, :y_limit

  def initialize(grid_size)
    @grid_size = grid_size
    @x_limit = @grid_size / 2   # مختصات از -limit تا +limit
    @y_limit = @grid_size / 2
  end

  def random_position
    [rand(-@x_limit..@x_limit), rand(-@y_limit..@y_limit)]
  end

  def within?(x, y)
    x.between?(-@x_limit, @x_limit) && y.between?(-@y_limit, @y_limit)
  end
end

# غذا: یک نقطهٔ تصادفی
class Food
  attr_accessor :x, :y

  def initialize(board)
    @board = board
    spawn
  end

  def spawn
    @x, @y = @board.random_position
  end
end

# مار: دنباله‌ای از بخش‌ها (segmentها)
class Snake
  attr_accessor :body, :direction_head, :poisoning

  def initialize(length)
    @direction_head = [1, 0]
    @body = Array.new(length) { |i| [0, i] }
    @poisoning = false
  end

  def head
    @body.first
  end

  # گام: سر جدید به جلو، دم حذف می‌شود مگر اینکه تغذیه شده باشیم
  def move(food_eaten = false)
    new_head = [head[0] + @direction_head[0], head[1] + @direction_head[1]]
    @body.unshift(new_head)
    @body.pop unless food_eaten
  end
end

۳. حلقهٔ اصلی بازی

rubyclass Game
  def initialize
    @board = Board.new(32)
    @snake = Snake.new(3)
    @food = Food.new(@board)
  end

  def run
    loop do
      input          # تغییر جهت با کلیدها
      moved          # گام مار
      break if collision   # دیوار یا خودش
      eat            # خوردن غذا و رشد
      render         # رسم صفحه در ترمینال
      sleep(0.1)
    end
  end
end

نکتهٔ الگوریتمی جالب مقاله: طراحی مار با body.unshift(new_head) و شرطی شدن pop — یعنی رشد طبیعی با خوردن غذا بدون هیچ کد اضافه‌ای.

۴. جمع‌بندی

  • بازی‌سازی با Ruby به‌سادگی هر زبان دیگر ممکن است.
  • ساختار کلاس‌ی تمیز (Board/Snake/Food/Game) — الگوی خوبی برای هر بازی.
  • ترمینال پایهٔ عالی برای شروع است؛ بعداً می‌توانید UI گرافیکی اضافه کنید.
