سری کلاسیک کِرنشاو

در دههٔ ۱۹۸۰، جک کرنشاو مجموعهٔ آموزشی «Let's Build a Compiler» را منتشر کرد که با یک ماشین‌حساب ساده شروع می‌شد و به یک کامپایلر کامل با توابع می‌رسید. این مجموعه پایهٔ صدها آموزش بعدی شد. پورت lotabout آن را از Pascal/68k به C و اسمبلی x86 منتقل کرده تا روی ماشین‌های امروزی قابل اجرا باشد.

روش «تک‌مرحله‌ای» (Single-Pass)

فلسفهٔ اصلی سری: کامپایلر هم‌زمان با خواندن ورودی، کد خروجی تولید می‌کند — بدون AST، بدون lexer جدا. کافیست سه تابع پایه را تعریف کنیم: GetChar() (خواندن شخصیت بعدی)، Look() (شخصیت فعلی) و Match() (بررسی شخصیت) — سپس همهٔ قواعد با همین سه تابع ساخته می‌شوند:

Cvoid Expression() {   // قاعدهٔ عبارت: +1+2 → mov eax,1; add eax,2
  Term();
  while (Look == '+' || Look == '-') {
    EmitLn("push eax");
    switch (Look) {
      case '+': Add(); break;
      case '-': Subtract(); break;
    }
  }
}

void Add() {
  Match('+');
  Term();
  EmitLn("pop ebx");     // عملوند دوم را بازیابی کن
  EmitLn("add eax, ebx");
}

هر قاعدهٔ گرامری یک تابع است و هر تابع مستقیماً اسمبلی x86 (دستورهای mov/add/sub و پشته) تولید می‌کند — این درک شهودی‌ای از رابطهٔ گرامر و کد ماشین می‌دهد.

مسیر آموزشی

این مجموعه گام‌به‌گام جلو می‌رود: (۱) ماشین‌حساب جمع/تفریق، (۲) ضرب و تقسیم با اولویت‌ها، (۳) متغیرها و انتساب، (۴) شرط‌های if و پرش‌های اسمبلی، (۵) حلقه‌های while/loop، (۶) توابع و پارامترها، (۷) انواع داده‌ٔ بیشتر. در پایان یک کامپایلر کوچک ولی کامل دارید.

چرا این نسخهٔ C مفید است؟
