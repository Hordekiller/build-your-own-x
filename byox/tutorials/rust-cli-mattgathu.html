نوشتن یک ابزار خط فرمان در Rust

⚙ زبان: Rust 📁 دسته: ابزار خط فرمان ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمه فارسی مقاله «Writing a Command Line Tool in Rust» نوشته «مت گاتو (Matt Gathu)» است. نسخه کامل و به‌روز را از سایت اصلی بخوانید.
↗ مشاهده منبع اصلی

چیست؟ (What)

راست (Rust) یک زبان برنامه‌نویسی سیستمی (systems programming language) است که به شما امکان می‌دهد کدهایی سریع، ایمن و هم‌زمان بنویسید. این زبان همان جایگاهی را پر می‌کند که C و ++C دارند؛ اما با مجموعه‌ای تازه از قابلیت‌ها و آسودگی‌ها عرضه شده است که نوشتن برنامه در آن را لذت‌بخش می‌کند.

ابزارهای خط فرمان (Command Line Tools) برنامه‌هایی هستند که برای اجرا در یک واسط ترمینال (خط فرمان) طراحی شده‌اند. آن‌ها با برنامه‌نویسی یونیکس هم‌معنا هستند و در آن‌جا اغلب «ابزارهای شل» (shell tools) نامیده می‌شوند. برای نمونه فرمان ls که برای فهرست‌کردن دایرکتوری‌ها به کار می‌رود.

قصد داریم نشان دهیم که چگونه با استفاده از راست یک ابزار خط فرمان بنویسیم؛ این کار را با ساختن یک کلون (clone) ساده از ابزار پرکاربرد wget انجام می‌دهیم که برای دانلود فایل به کار می‌رود.

چرا؟ (Why)

هدف در این‌جا شروع نوشتن ابزارهای خط فرمان در زبان برنامه‌نویسی راست است و نیز استفاده از برخی کریت‌های (crates) فوقالعاده — کتابخانه‌های ساخته‌شده توسط جامعه — که نوشتن برنامه‌های CLI را بسیار آسان می‌کنند.

چگونه؟ (How)

کلون ساده‌مان از wget ویژگی‌های زیر را خواهد داشت — ویژگی‌هایی که در یک ابزار خط فرمان مطلوب‌اند:

  • تجزیهٔ آرگومان‌ها (Argument parsing)
  • خروجی رنگی (Colored Output)
  • نوار پیشرفت (Progress bar)

راه‌اندازی پروژه (Project Setup)

برای برپاکردن اسکلت پروژه‌مان از ابزار ساخت (و مدیر بسته) راست یعنی کargo (Cargo) استفاده می‌کنیم:

shellcargo new rget --bin

این دستور پروژهٔ جدیدی به نام rget می‌سازد و گزینهٔ --bin به کargo می‌گوید که ما در حال ساخت یک برنامهٔ اجرایی (executable) هستیم، نه یک کتابخانه. پوشه‌ای با ساختار زیر تولید می‌شود:

shell$ cd rget
$ tree .
.
├── Cargo.toml
└── src
    └── main.rs

1 directory, 2 files

Cargo.toml یک فایل مانیفست (manifest) است و کد ما در پوشهٔ src و در فایل main.rs قرار خواهد گرفت.

تجزیهٔ آرگومان‌ها (Argument Parsing)

برای تجزیهٔ آرگومان‌های خط فرمان از کریت clap استفاده خواهیم کرد. برای افزودن آن به پروژه‌مان، بخش وابستگی‌ها (dependencies) فایل مانیفست کargo را به‌روزرسانی می‌کنیم:

toml[package]
name = "rget"
version = "0.1.0"
authors = ["Matt Gathu <mattgathu@gmail.com>"]

[dependencies]
clap = "2.26.0"

سپس تابع main را در main.rs به‌روزرسانی می‌کنیم تا تجزیهٔ آرگومان‌ها را انجام دهد:

rustextern crate clap;

use clap::{Arg, App};

fn main() {
    let matches = App::new("Rget")
        .version("0.1.0")
        .author("Matt Gathu <mattgathu@gmail.com>")
        .about("wget clone written in Rust")
        .arg(Arg::with_name("URL")
                 .required(true)
                 .takes_value(true)
                 .index(1)
                 .help("url to download"))
        .get_matches();
    let url = matches.value_of("URL").unwrap();
    println!("{}", url);
}

اکنون می‌توانیم تجزیه‌گر آرگومان خود را با استفاده از کargo آزمایش کنیم:

cargo run

     Running `target/debug/rget`
error: The following required arguments were not provided:
    <URL>

USAGE:
    rget <URL>

For more information try --help

برای ارسال آرگومان به برنامه‌مان می‌توانیم هنگام فراخوانی cargo run دو خط تیره (--) اضافه کنیم:

نوار پیشرفت و خروجی رنگی (Progress bar and colored output)

indicatif یک کتابخانهٔ راست برای نمایش پیشرفت در برنامه‌های خط فرمان است. ما از آن برای پیاده‌سازی یک نوار پیشرفت و یک اسپینر (spinner) — نشانگر چرخان — برای کلون wget خود استفاده می‌کنیم.

indicatif به کریت دیگری به نام console متکی است و از آن برای خروجی رنگی استفاده می‌کند. ما همواره از console بهره خواهیم گرفت و با آن متن‌های رنگی چاپ خواهیم کرد.

در ادامه تابع ساخت نوار پیشرفت آمده است:

rustfn create_progress_bar(quiet_mode: bool, msg: &str, length: Option<u64>) -> ProgressBar {
    let bar = match quiet_mode {
        true => ProgressBar::hidden(),
        false => {
            match length {
                Some(len) => ProgressBar::new(len),
                None => ProgressBar::new_spinner(),
            }
        }
    };

    bar.set_message(msg);
    match length.is_some() {
        true => bar
            .set_style(ProgressStyle::default_bar()
                .template("{msg} {spinner:.green} [{elapsed_precise}] [{wide_bar:.cyan/blue}] {bytes}/{total_bytes} eta: {eta}")
                .progress_chars("=> ")),
        false => bar.set_style(ProgressStyle::default_spinner()),
    };

    bar
}

این تابع چند آرگومان دارد و بر اساس مقدار آن‌ها یک نوار پیشرفت می‌سازد. ما از قابلیت تطبیق الگو (pattern matching) در راست استفاده کرده‌ایم تا آرگومان‌ها را با نوار پیشرفت موردنظر مطابقت دهیم.

شبیه‌سازی منطق wget (Cloning wget's logic)

برای پیاده‌سازی تابع دانلود فایل — که یک آدرس URL دریافت می‌کند و آن را در یک فایل محلی ذخیره می‌کند — از کریت reqwest استفاده می‌کنیم.

تابع دانلود همچنین پس از دریافت هر تکه (chunk) از فایل، نوار پیشرفت را به‌روزرسانی می‌کند و متن رنگی حاوی فراداده‌های (metadata) دانلود را نیز چاپ می‌کند؛ رفتاری مشابه رفتار خود wget.

در ادامه، قطعه‌کد نمایش‌دهندهٔ تابع دانلود آمده است:

rustfn download(target: &str, quiet_mode: bool) -> Result<(), Box<::std::error::Error>> {

    // تجزیهٔ آدرس URL
    let url = parse_url(target)?;
    let client = Client::new().unwrap();
    let mut resp = client.get(url)?
        .send()
        .unwrap();
    print(format!("HTTP request sent... {}",
                  style(format!("{}", resp.status())).green()),
          quiet_mode);
    if resp.status().is_success() {

        let headers = resp.headers().clone();
        let ct_len = headers.get::<ContentLength>().map(|ct_len| **ct_len);

        let ct_type = headers.get::<ContentType>().unwrap();

        match ct_len {
            Some(len) => {
                print(format!("Length: {} ({})",
                      style(len).green(),
                      style(format!("{}", HumanBytes(len))).red()),
                    quiet_mode);
            },
            None => {
                print(format!("Length: {}", style("unknown").red()), quiet_mode); 
            },
        }

        print(format!("Type: {}", style(ct_type).green()), quiet_mode);

        let fname = target.split("/").last().unwrap();

        print(format!("Saving to: {}", style(fname).green()), quiet_mode);

        let chunk_size = match ct_len {
            Some(x) => x as usize / 99,
            None => 1024usize, // اندازهٔ پیش‌فرض هر تکه
        };

        let mut buf = Vec::new();

        let bar = create_progress_bar(quiet_mode, fname, ct_len);

        loop {
            let mut buffer = vec![0; chunk_size];
            let bcount = resp.read(&mut buffer[..]).unwrap();
            buffer.truncate(bcount);
            if !buffer.is_empty() {
                buf.extend(buffer.into_boxed_slice()
                               .into_vec()
                               .iter()
                               .cloned());
                bar.inc(bcount as u64);
            } else {
                break;
            }
        }

        bar.finish();

        save_to_file(&mut buf, fname)?;
    }

    Ok(())

}

تابع download یک آدرس URL مقصد دریافت می‌کند، آن را تجزیه می‌کند تا نام فایل را به دست آورد و از هدر HTTP با نام Content-Length برای تعیین اندازهٔ فایل استفاده می‌کند. سپس یک نوار پیشرفت رنگی می‌سازد و فایل را به‌صورت تکه‌تکه دانلود می‌کند. پس از دریافت هر تکه، نوار پیشرفت برای نمایش میزان پیشرفت به‌روزرسانی می‌شود.

هنگامی که دانلود کامل شد، محتوای فایل روی دیسک ذخیره می‌شود.

جمع‌بندی (Recap)

نوشتن ابزارهای CLI در راست بسیار آسان است: تجزیهٔ آرگومان‌ها با کریت clap، ساخت نوارهای پیشرفت با کریت indicatif و خروجی رنگی با کریت console انجام می‌شود. ابزار ساخت کargo نیز ساخت و اجرای کد ما را بی‌نهایت ساده می‌کند.
