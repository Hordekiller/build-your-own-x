lisp.py — ساخت مفسر Lisp در پایتون

⚙ زبان: Python ✅ ترجمه شده 🔗 منبع اصلی

↗ مشاهده منبع اصلی

معرفی

lisp.py یک مفسر Lisp در چند ده خط پایتون است که درس‌های اصلی مفسرنویسی را در خودش جا داده: tokenizer، parser، evaluator با محیط، و پشتیبانی از تعریف تابع با lambda یا def، شرط if، و عملگرهای پایه.

ساختار کد

کد در سه بخش مرتب: tokenize (تبدیل متن به لیست)، parse (ساخت درخت با بازگشت)، و eval (اجرا با محیط). خود پروژه طوری نوشته شده که به‌عنوان «مفسر آموزشی» مستقیم خوانده شود — بدون وابستگی به خارج از پروژه فقط با پایتون استاندارد.

نمونهٔ کد: قلب مفسر

Pythondef eval(x, env):
    if type(x) is int:                    # عدد: مقدار خودش
        return x

    if type(x) is str:                    # نماد: از محیط بخوان
        return env[x]

    if x[0] == 'quote':
        return x[1]

    if x[0] == 'if':                      # شرط: فقط شاخهٔ درست
        (_, test, true, false) = x
        return eval(true, env) if eval(test, env) else eval(false, env)

    if x[0] == 'lambda':                  # lambda: ساخت closure
        (_, params, body) = x
        return Lambda(params, body, env)

    if x[0] == 'define':                  # تعریف متغیر
        (_, name, value) = x
        env[name] = eval(value, env)
        return None

    # فراخوانی تابع: eval عملگر و آرگومان‌ها
    op = eval(x[0], env)
    args = [eval(arg, env) for arg in x[1:]]
    return apply(op, args, env)

چه چیزهایی بیشتر می‌آموزید

با apply و ساختار Lambda که محیط تعریف را نگه می‌دارد، مفهوم closure را در عمل می‌بینید — همان چیزی که توابع Lisp را قدرتمند می‌کند. می‌توانید در ادامه let، begin و حتی GC ساده (با استفاده از مقالهٔ «Baby's First Garbage Collector») اضافه کنید.
