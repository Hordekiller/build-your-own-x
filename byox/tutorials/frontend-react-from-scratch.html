ساخت React از صفر — سخنرانی پال او شنسِی در React Rally 2016

⚙ زبان: JavaScript 🎥 ویدیو (۳۳:۵۶) ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه معرفی و مرور فارسی ویدیوی «Building React From Scratch» — سخنرانی پال او شنسِی (Paul O'Shannessy) در کنفرانس React Rally 2016 است. در این سخنرانی، React بدون هیچ وابستگی خارجی، با ابزارهای جاوااسکریپت خالص بازسازی می‌شود.
↗ مشاهده منبع اصلی

۱. دربارهٔ سخنرانی

پال او شنسِی — از مهندسان ارشد تیم React در فیسبوک — در این سخنرانی ۳۳ دقیقه‌ای نشان می‌دهد که هستهٔ React را می‌توان فقط با جاوااسکریپت خالص (بدون JSX و بدون هیچ کتابخانهٔ دیگری) ساخت. او با یک محیط توسعهٔ ساده که خودش ساخته، قدم‌به‌قدم اجزای داخلی React را پیاده‌سازی و با ابزارهایی مانند pretty و پارسر جاوااسکریپت، کد را مستقیم روی صفحه‌نمایش اجرا می‌کند.

نکته: این سخنرانی از بهترین منابع «پشت پردهٔ React» است؛ مخصوصاً برای کسانی که می‌خواهند بدانند در کد واقعی React چه خبر است — به‌جای نسخهٔ ساده‌شدهٔ آموزشی.

۲. ویدیو را تماشا کنید

این آموزش به‌صورت ویدیویی است و میزبانی محتوای آن در این صفحه ممکن نیست؛ لینک مستقیم ویدیو در یوتیوب (در کنفرانس React Rally 2016 ضبط شده):

▶ تماشای ویدیو «Building React From Scratch»

۳. آنچه در این ویدیو یاد می‌گیرید

  • Element ها و Instance ها: تفاوت مفهومی بین توصیف UI (عنصر) و شیء واقعی نگهدارندهٔ وضعیت (نمونه/instance) و چرایی این جداسازی در معماری React.
  • مکانیزم رندر: تبدیل درخت عناصر به DOM واقعی، مدیریت صفات، رویدادها و نودهای متنی بدون JSX.
  • بازنشانی و به‌روزرسانی (re-render): چطور React تصمیم می‌گیرد کدام بخش‌ها را دوباره بسازد و چه چیزی باید حفظ شود.
  • رویدادهای به‌هم‌پیوسته: مدیریت state داخلی کامپوننت و پاسخ به تعامل کاربر — هستهٔ واکنش‌گرایی React.
  • معماری diff: ایدهٔ مقایسهٔ دو درخت و اعمال حداقل تغییرات لازم.

۴. چرا این ویدیو مهم است؟

بیشتر آموزش‌های «React خودت را بساز» نسخهٔ ساده‌شدهٔ مفاهیم را ارائه می‌دهند؛ اما او شنسِی به‌عنوان عضو تیم اصلی، تصمیم‌های طراحی واقعی React (مثل چرایی وجود Instance جدا از Element) را از زبان کسی که آن‌ها را گرفته، توضیح می‌دهد. دیدن این ویدیو در کنار منابع متنی مانند Didact یا «Build Your Own React» مکمل عالی است.

تکمیل: اگر با فیبر و رندر همزمان آشنا نیستید، بعد از این ویدیو یادداشت‌های آرشیتکتوری تیم React (مثل توضیحات Andrew Clark دربارهٔ Fiber) را بخوانید تا تصویر کاملی از معماری امروز React داشته باشید.
کپیرایت: ویدیوی «Building React From Scratch» اثر پال او شنسِی (Paul O'Shannessy) است و در کنفرانس React Rally 2016 ضبط و در کانال یوتیوب React Rally منتشر شده. این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق ویدیو متعلق به خالقان آن است. برای مشاهدهٔ اصل ویدیو به یوتیوب مراجعه کنید.
