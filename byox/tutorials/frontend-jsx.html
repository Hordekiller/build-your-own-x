JSX چیست؟ — ساخت یک رندرکننده JSX

⚙ زبان: JavaScript ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور مقالهٔ «WTF is JSX» از جیسون میلر (Jason Miller) — نویسندهٔ فریم‌ورک Preact — است. او در این مقاله نشان می‌دهد JSX در حقیقت فقط «قند نحوی» برای تابع‌های جاوااسکریپت است و یک رندرکنندهٔ ساده را قدم‌به‌قدم می‌سازد.
↗ مشاهده منبع اصلی

۱. مقدمه: JSX یک جادو نیست

خیلی از توسعه‌دهنده‌ها JSX را یک «زبان جدید» می‌دانند، اما حقیقت این است که JSX فقط یک قند نحوی (syntax sugar) برای فراخوانی تابع است. وقتی می‌نویسید:

jsxconst el = <div className="foo">سلام دنیا!</div>;

مترجم (Babel یا TypeScript) دقیقاً همان را به این فراخوانی ساده تبدیل می‌کند:

jsconst el = createElement("div", { className: "foo" }, "سلام دنیا!");

تمام کار JSX همین است: یک تابع را با آرگومان‌های مرتب صدا زدن. پس برای «ساخت JSX» کافی است createElement خودمان را پیاده کنیم.

نکته: دلیل موفقیت این طراحی این است که JSX به DOM گره نخورده است؛ همین فرمت یکسان است که به React Native، Preact، Vue و ده‌ها فریم‌ورک دیگر اجازه می‌دهد از همان نحو استفاده کنند.

۲. ساخت createElement خودمان

نویسنده یک پیاده‌سازی کامل همراه با پروژهٔ تمرینی در GitHub منتشر کرده است. ابتدا یک تولیدکنندهٔ node (ساختار درختی) می‌سازیم که DOM نودها را با document.createElement بسازد؛ سپس props ها را روی آن ست کند و بچه‌ها (children) را به‌صورت بازگشتی اضافه کند:

jsfunction createElement(type, props, ...children) {
  // مقدار نهایی children می‌تواند آرایه‌ای از نودها و رشته‌ها باشد
  const el = document.createElement(type);

  // کپی کردن props روی عنصر
  for (const key in props) {
    if (key === "className") {
      el.setAttribute("class", props[key]);
    } else {
      el.setAttribute(key, props[key]);
    }
  }

  // افزودن بچه‌ها
  for (const child of children) {
    if (typeof child === "string") {
      el.appendChild(document.createTextNode(child));
    } else {
      el.appendChild(child);
    }
  }

  return el;
}

حالا با این تابع، هر کد JSX کار می‌کند؛ حتی کامپوننت‌ها! چون تابع createElement می‌تواند خودش تصمیم بگیرد که اگر نوع، یک تابع بود چه کند:

jsfunction createElement(type, props, ...children) {
  // اگر type یک تابع است (کامپوننت)، آن را با props صدا بزن
  if (typeof type === "function") {
    return type({ ...props, children });
  }
  // در غیر این صورت یک عنصر DOM بساز
  const el = document.createElement(type);
  /* ... ادامه پیاده‌سازی قبلی ... */
}

// استفاده: کامپوننت عادی
const Button = (props) => (
  <button className={"btn " + props.variant}>{props.children}</button>
);
// JSX خودش تشخیص می‌دهد Button یک تابع است
const app = <Button variant="primary">کلیک کن</Button>;

۳. به‌روزرسانی: مقایسه و patch

تا اینجا فقط یک‌بار رندر انجام می‌شود. برای به‌روزرسانی، ساده‌ترین راه این است که درخت قدیمی را حذف کنیم و درخت جدید بسازیم، اما این روش به‌صرفه نیست. راه بهتر، رندر دوباره و مقایسهٔ نودها (diff) است:

jsfunction update(oldNode, newNode) {
  if (!oldNode || oldNode.nodeName !== newNode.nodeName) {
    // نوع نود عوض شده: جایگزین کامل
    oldNode.replaceWith(newNode);
    return newNode;
  }
  // بچه‌های جدید را بساز و بازگشتی به‌روز کن
  while (oldNode.firstChild) oldNode.removeChild(oldNode.firstChild);
  for (const child of newNode.childNodes) {
    oldNode.appendChild(child);
  }
  return oldNode;
}

این همان ایدهٔ اصلی همهٔ فریم‌ورک‌هاست؛ React و Preact فقط الگوریتم diff را هوشمندتر (مثلاً استفاده از کلید/key و مقایسهٔ فقط صفات تغییرکرده) کرده‌اند.

۴. جمع‌بندی

  • JSX = قند نحوی: هر عبارت JSX به یک فراخوانی تابع تبدیل می‌شود؛ برای استفاده از آن فقط باید آن تابع را پیاده کنید.
  • کامپوننت = تابع: وقتی typeof type === "function" باشد، رندرکننده تابع را با props صدا می‌زند — همین سادگی، پایهٔ طراحی کامپوننت‌محور همهٔ فریم‌ورک‌های مدرن است.
  • به‌روزرسانی = diff: ساخت درخت مجازی و مقایسهٔ آن، قلب هر فریم‌ورک واکنش‌گراست؛ JSX تنها بخش «توضیح‌دادن UI» است.
نکتهٔ تکمیلی: جیسون میلر همان کسی است که Preact را با همین ایده (یک React سبک بدون گره خوردن به مشخصات) ساخته؛ مطالعهٔ کد منبع Preact هم در ادامهٔ همین مسیر عالی است.
کپیرایت: مقالهٔ «WTF is JSX» اثر جیسون میلر (Jason Miller) است و در وبلاگ jasonformat.com منتشر شده. این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
