ساخت شبکه‌های عصبی در F#: بخش ۲ — آموزش با انتشار بازگشتی و ارزیابی

⚙ زبان: F# 🧠 MathNet.Numerics ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور بخش دوم مجموعهٔ «Building Neural Networks in F#» نوشتهٔ حارس محمود (Haaris Mehmood) در Medium (۲۰۱۸) است. در این بخش، یادگیری با انتشار بازگشتی پیاده و شبکه روی دیتاست واقعی آموزش و ارزیابی می‌شود.
↗ مشاهده منبع اصلی

۱. ادامه از بخش ۱

در بخش ۱ زیرساخت کامل شد: تابع فعال‌سازی tanh، نوع‌های Layer و Node و انتشار پیشرو. مشکل این بود که وزن‌ها تصادفی‌اند و شبکه هیچ‌چیز نمی‌داند. در این بخش مکانیزم یادگیری می‌آید: انتشار بازگشتی (backpropagation) که خطای خروجی را لایه‌به‌لایه به عقب می‌فرستد و با گرادیان نزولی وزن‌ها را اصلاح می‌کند.

۲. گرادیان و قانون زنجیره‌ای

گرادیان تابع هزینه نسبت به هر وزن، «جهت و اندازهٔ تغییر لازم» را می‌گوید. برای محاسبهٔ آن در شبکه‌های عمیق از قانون زنجیره‌ای استفاده می‌شود: مشتق خطا نسبت به خروجی نهایی، ضرب در مشتقات محلی هر لایه، از عقب به جلو. برای هر وزن، مقدار جدید = مقدار قدیم − نرخ‌یادگیری × گرادیان:

fsharp// به‌روزرسانی وزن: w ← w − η × گرادیان خطا نسبت به w
let updateWeights (lr: double) (weights: Matrix<double>) (grad: Matrix<double>) =
    weights - (grad.Multiply(lr))

نرخ یادگیری (η) تعادل بین سرعت و ثبات را کنترل می‌کند: بزرگ = پرش از درهٔ کمینه، کوچک = همگرایی کند.

۳. انتشار خطا در لایه‌های پنهان

مشکل اصلی: خطا فقط در لایهٔ خروجی قابل محاسبهٔ مستقیم است. برای لایه‌های پنهان خطا «توزیع» می‌شود: خطای لایهٔ بعدی، با ترانهادهٔ ماتریس وزن‌ها ضرب می‌شود تا سهم هر نورون پنهان در خطا به‌دست آید، و سپس در مشتق tanh (یعنی 1 - tanh²) ضرب می‌شود تا خطای «مقیاس‌شده با اطمینان» ساخته شود:

fsharp// انتشار خطا به لایهٔ پنهان:
// خطای خروجی، وزن‌شده با ترانهادهٔ ماتریس وزن، سپس ضرب در مشتق tanh
let backpropagate (nextError: Vector<double>) (weights: Matrix<double>)
                 (hiddenOut: Vector<double>) =
    let weightedError = weights.Transpose() * nextError
    weightedError.PointwiseMultiply(hiddenOut.Map(tanhDerivative))

۴. یک چرخهٔ کامل آموزش

حالا همهٔ اجزا را کنار هم می‌گذاریم: انتشار پیشرو ← محاسبهٔ خطا ← انتشار بازگشتی ← به‌روزرسانی همهٔ وزن‌ها. تکرار این چرخه روی کل دیتاست، «عصر» (epoch) نام دارد؛ شبکه با هر عصر، خطای کمتری می‌گیرد:

fsharp// یک گام آموزشی کامل روی یک نمونه
let trainStep (network: Network) (input: Vector<double>) (expected: Vector<double>)
              (lr: double) =
    let output = feedForward network input          // ۱) پیش‌بینی
    let error = output - expected                   // ۲) خطا
    let grad = backpropagate error network.weights  // ۳) انتشار به عقب
    let newWeights = updateWeights lr network.weights grad // ۴) اصلاح وزن‌ها
    { network with weights = newWeights }

۵. آموزش و ارزیابی روی دادهٔ واقعی

نویسنده شبکه را روی یک دیتاست واقعی آموزش می‌دهد و پیشرفت را با تابع هزینه دنبال می‌کند: کاهش پیوستهٔ هزینه نشانهٔ سالم بودن آموزش است. برای ارزیابی منصفانه، داده به دو بخش آموزش و تست تقسیم می‌شود — شبکه فقط روی بخش آموزش دیده و روی بخش تست سنجیده می‌شود تا توانایی تعمیم (نه حفظ‌کردن) سنجیده شود. دقت (درصد پاسخ‌های درست) معیار اصلی گزارش است.

نکتهٔ تکمیلی: اگر هزینهٔ آموزش کم اما هزینهٔ تست زیاد باشد، نشانهٔ بیش‌برازش است؛ راه‌حل‌ها: نمونهٔ بیشتر، شبکهٔ کوچک‌تر یا توقف زودهنگام.

۶. جمع‌بندی

  • یادگیری = انتشار بازگشتی خطا + به‌روزرسانی وزن با گرادیان نزولی.
  • ترانهادهٔ ماتریس وزن، پل بین خطای لایهٔ بعدی و سهم لایهٔ پنهان است.
  • مشتق tanh ساده است (1−tanh²)؛ همین سادگی backprop را عملی می‌کند.
  • جداسازی آموزش/تست، معیار واقعی کیفیت مدل است.
