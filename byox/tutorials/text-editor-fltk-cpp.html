طراحی یک ویرایشگر متن ساده (Designing a Simple Text Editor — FLTK)

⚙ زبان: C++ ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی فصل «Designing a Simple Text Editor» از مستندات رسمی کتابخانهٔ GUI چارچوب C++ به نام FLTK (Fast Light Toolkit) است — اولین پروژهٔ بزرگِ آموزشِ FLTK. کد کامل در فایل test/editor.cxx خود FLTK است. نسخهٔ کامل را از سایت اصلی بخوانید.
↗ مشاهده منبع اصلی

۱. اهداف ویرایشگر

این فصل، طراحی یک ویرایشگر متن کامل با FLTK را گام‌به‌گام دنبال می‌کند. قبل از هر کدی، اهداف را روشن می‌کنیم — همان کاری که هر مهندس باید بکند:

  1. نوار منو (menubar) و منوهایی برای همهٔ عملیات.
  2. ویرایش یک فایل متنی، احتمالاً با چند نمای (view) هم‌زمان.
  3. بارگذاری از فایل.
  4. ذخیره در فایل.
  5. توابع Cut/Copy/Delete/Paste.
  6. توابع جست‌وجو و جایگزینی (Search and Replace).
  7. ردیابیِ تغییرِ فایل (علامت‌گذاری وقتی فایل تغییر کرده).

۲. پنجرهٔ اصلی: کلاس EditorWindow

ابتدا پنجرهٔ اصلی برنامه را در کلاسی به نام EditorWindow تعریف می‌کنیم که همهٔ کامپوننت‌های UI — دیالوگ جایگزینی، فیلدهای ورودی، دکمه‌ها و خودِ ویرایشگر — را نگه می‌دارد:

cppclass EditorWindow : public Fl_Double_Window {
  public:
    EditorWindow(int w, int h, const char* t);
    ~EditorWindow();

    Fl_Window          *replace_dlg;
    Fl_Input           *replace_find;
    Fl_Input           *replace_with;
    Fl_Button          *replace_all;
    Fl_Return_Button   *replace_next;
    Fl_Button          *replace_cancel;

    Fl_Text_Editor     *editor;
    char               search[256];
};

۳. منوها و نوار منو

برای هدف اول، منوها با ساختار Fl_Menu_Item تعریف می‌شوند — هر آیتم یک برچسب، یک میان‌بر و یک callback دارد. سپس با Fl_Menu_Bar نوار منو ساخته و منوها به آن اختصاص داده می‌شوند. مثلاً آیتم‌های Edit (Undo/Redo با FL_COMMAND+'z' و…) و Find/Replace.

۴. ویرایش متن: Fl_Text_Editor + Fl_Text_Buffer

قلب برنامه ویدجت Fl_Text_Editor است — FLTK یک ویرایشگر متن کامل (بازنویسی به‌اجازهٔ هستهٔ NEdit) دارد. اما یک نکتهٔ ظریف: Fl_Text_Editor برای کار به یک Fl_Text_Buffer نیاز دارد. این «قدمِ اضافه» در واقع یک قابلیت بزرگ است: می‌توان یک بافر متن را به چند ویرایشگر وصل کرد — همان‌که بعداً برای پنجرهٔ split استفاده می‌شود:

cpp#include <FL/Fl.H>
#include <FL/Fl_Double_Window.H>
#include <FL/Fl_Menu_Bar.H>
#include <FL/Fl_Text_Editor.H>

Fl_Text_Editor *app_editor = NULL;
Fl_Text_Buffer *app_text_buffer = NULL;

void tut3_build_main_editor() {
    app_window->begin();
    app_text_buffer = new Fl_Text_Buffer();
    app_text_buffer->add_modify_callback(text_changed_callback, NULL);

    app_editor = new Fl_Text_Editor(0, app_menu_bar->h(),
        app_window->w(), app_window->h() - app_menu_bar->h());
    app_editor->buffer(app_text_buffer);
    app_editor->textfont(FL_COURIER);          // فونت تک‌فاصله
    app_window->resizable(app_editor);         // فقط ویرایشگر کشیده شود
    app_window->end();
}

با قراردادنِ app_editor به‌عنوان resizable() پنجره، تغییر سایزِ پنجره فقط ویرایشگر را (به‌صورت عمودی) بزرگ می‌کند و نوار منو ثابت می‌ماند. برای ردیابیِ تغییرات، یک callback تغییرِ بافر اضافه می‌کنیم که با هر درج/حذفِ متن، پرچم text_changed را بالا می‌برد:

cppvoid text_changed_callback(int, int n_inserted, int n_deleted, int,
                           const char*, void*) {
    if (n_inserted || n_deleted)
        set_changed(true);
}

// و «File/New» که بافر را پاک و پرچم را خاموش می‌کند:
void menu_new_callback(Fl_Widget*, void*) {
    app_text_buffer->text("");
    set_changed(false);
}

۵. دیالوگ جایگزینی و callbackها

برای بیشتر دیالوگ‌ها می‌شود از توابع راحتی FLTK استفاده کرد، اما دیالوگِ Replace پنجرهٔ اختصاصی خودش را می‌خواهد: یک Fl_Input برای «Find» ، یکی برای «Replace» و دکمه‌های «Replace All» و «Replace Next» (که Fl_Return_Button است تا Enter کار کند) و «Cancel». سپس callbackهای اصلی تعریف می‌شوند: changed_cb()، copy_cb() (با Fl_Text_Editor::kf_copy())، cut_cb()، paste_cb()، find_cb()/find2_cb()، replace_cb()، replall_cb()، new_cb()، open_cb()، save_cb() و توابع کمکی load_file()/save_file(). جست‌وجو با search_forward() بافر انجام می‌شود:

cppbool find_next(const char *needle) {
    Fl_Text_Editor *editor = app_editor;
    int pos = editor->insert_position();
    int found = app_text_buffer->search_forward(pos, needle, &pos);
    if (found) {
        app_text_buffer->select(pos, pos + (int)strlen(needle));
        editor->insert_position(pos + (int)strlen(needle));
        editor->show_insert_position();
        return true;
    } else {
        fl_alert("No further occurrences of '%s' found!", needle);
        return false;
    }
}

۶. تابع main(): به هم دوختن همه‌چیز

بعد از تمام توابع پشتیبان، فقط ماندن main(): ساخت بافر متنی جدید، ساخت نمای (پنجره) جدید، نمایش پنجره، بارگذاری فایلِ آرگومانِ خط فرمان (اگر بود) و ورود به حلقهٔ رویداد FLTK:

cppint main(int argc, char **argv) {
    textbuf = new Fl_Text_Buffer;
    Fl_Window* window = new_view();
    window->show(1, argv);
    if (argc > 1) load_file(argv[1], -1);
    return Fl::run();          // حلقهٔ رویداد FLTK
}

۷. های‌لایت نحوی با Style Buffer

بخش آخر، ویژگی‌های پیشرفتهٔ Fl_Text_Editor را نشان می‌دهد: های‌لایت متن با فونت/رنگ/سایزهای مختلف. پیاده‌سازی بر پایهٔ هستهٔ ویرایشگر NEdit است که از یک «بافر سبک» موازی (parallel style buffer) استفاده می‌کند که فونت/رنگِ هر نویسه را نگه می‌دارد:

cppFl_Text_Buffer *stylebuf;

w->editor->highlight_data(stylebuf, styletable,
                          sizeof(styletable) / sizeof(styletable[0]),
                          'A', style_unfinished_cb, 0);

و callbackی که تغییراتِ بافر اصلی را در بافر سبک منعکس می‌کند (textbuf->add_modify_callback(style_update, w->editor))؛ تابع style_parse() کپیِ متن را اسکن و کاراکترهای سبک لازم (مثل «سبک کامنت») را تولید می‌کند. اینجاست که می‌بینید یک ویرایشگر «واقعی» چطور های‌لایت می‌کند.

۸. کامپایل و جمع‌بندی

کد کامل در test/editor.cxx و Makefile مربوطه هست؛ با یک کامپایلر استاندارد (fltk-config --compile editor.cxx) ساخته می‌شود. این فصل یک درس کامل «مهندسی GUI» است: تعریف اهداف، جداسازی داده (Text_Buffer) از نما (Text_Editor)، callbackمحوری، دیالوگ اختصاصی و بافرِ سبک موازی — و نشان می‌دهد که با ابزار درست (FLTK)، یک ویرایشگرِ کامل در یک فایل منبع جا می‌شود.

کپیرایت: فصل «Designing a Simple Text Editor» بخشی از مستندات رسمی کتابخانهٔ FLTK (GNU LGPL) است. این صفحه فقط ترجمهٔ فارسی و مرور آن است. برای مشاهده اصل مطلب به سایت اصلی مراجعه کنید.
