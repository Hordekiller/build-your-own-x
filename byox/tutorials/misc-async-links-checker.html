مشکل: چک‌کردن صدها لینک

چند صد لینک در یک صفحهٔ وب. اگر یکی‌یکی (سریال) بررسی شوند، هر درخواست چند صد میلی‌ثانیه منتظر می‌ماند و کل کار چند دقیقه طول می‌کشد. راه‌حل: ارسال همهٔ درخواست‌ها «هم‌زمان» و برخورد با نتایج وقتی رسیدند — همین ایدهٔ async I/O است.

async در Nim

Nim با کتابخانهٔ `asyncdispatch` مدل async/await را با event loop خودش دارد (بدون اپراتور سیستم‌عامل). هر تابع async چیزی شبیه یک کار است؛ `await` کار را تعلیق می‌کند تا I/O تمام شود:

Nimimport asyncdispatch, httpclient

# گرفتن HTML یک صفحه به‌صورت async
proc fetch(url: string): Future[string] {.async.} =
  let client = newAsyncHttpClient()
  result = await client.getContent(url)
  client.close()

# بررسی وضعیت یک لینک بدون مسدودکردن event loop
proc checkLink(url: string): Future[(string, bool)] {.async.} =
  try:
    let resp = await client.head(url)   # فقط سرصفحه
    result = (url, resp.status in {Http200, Http301, Http302})
  except:
    result = (url, false)

با `accept` (چک‌کردن دستی event loop) یا ترکیب futures می‌توان همهٔ لینک‌ها را leak-شده رها کرد تا موازی اجرا شوند.

اجرای هم‌زمان همهٔ لینک‌ها

کلید کار: ساخت آرایه‌ای از Future و `await` کردن همهٔ آن‌ها با هم. هر client جدا است، پس event loop همهٔ درخواست‌ها را هم‌زمان روی شبکه می‌فرستد:

Nimproc main() {.async.} =
  let html = await fetch("https://example.com")
  let links = extractLinks(html)   # استخراج href ها

  # ساخت Future برای همهٔ لینک‌ها
  var futures: seq[Future[(string, bool)]]
  for link in links:
    futures.add(checkLink(link))

  # منتظر رسیدن همه
  let results = await all(futures)

  for (url, ok) in results:
    echo (if ok: "✓ " else: "✗ "), url

نتایج همان ترتیب را دارند چون آرایهٔ Futureها ترتیب را حفظ می‌کند. نکته: `all` اگر یکی خطا بدهد کلش خطا می‌دهد؛ با `failOnError: false` میتوان partial result گرفت.

مقایسه با مدل‌های دیگر

async/await فقط یکی از سه مدل هم‌زمانی است. مدل threads (۱۰۰۰ Thread یا ThreadPool) برای CPU-heavy خوب است؛ model event loop (Node.js) برای I/O-heavy. همین ساختار فایل، اگر `--threads:on` کامپایل شود، می‌تواند با Threads هم اجرا شود. با تمرین این آموزش، مفهوم event loop را که در Node.js هم هست، عمیق می‌فهمید.
