ساخت یک سرور HTTP پایه از صفر در پایتون

مقدمه

در ذات خود، وب مدرن فقط متنی است که بین کلاینت‌ها و سرورها در رفت‌وآمد است. به‌عنوان توسعه‌دهنده، اغلب از فریم‌ورک‌های وب برای ساختن رشته‌هایی استفاده می‌کنیم که به کلاینت‌ها فرستاده می‌شوند. فریم‌ورک‌های وب ما را از «واقعیت متنی» زیربنایی دور می‌کنند: درخواست‌های http ورودی (که فقط یک رشته است) را پارس می‌کنند، تابع متناظر را صدا می‌زنند و یک پاسخ رشته‌ای می‌سازند (بیشتر با قالب‌ها). در نهایت، کلاینت‌ها آن رشته‌ها را پارس می‌کنند و هر کاری که خواسته‌اند با آن انجام می‌دهند.

این پست وبلاگ نشان می‌دهد چگونه یک سرور HTTP کاملاً ساده را از صفر بسازیم و بر اساس تمرینی است که نویسنده به دانشجویان کارشناسی‌ارشدش داده. تنها پیش‌نیاز، درک پایه‌ای پایتون ۳ است. اگر می‌خواهید همراه با آموزش پیاده‌سازی کنید، برنامهٔ شروع‌کننده را از این لینک بگیرید. سورس نهایی را در این gist می‌بینید.

HTTP فقط متن است

HTTP پروتکلی است که مرورگرها با آن اطلاعات را از سرورها می‌گیرند و به آن‌ها می‌فرستند. در ذات خود، HTTP فقط متنی است که از الگویی خاص پیروی می‌کند: در خط اول مشخص می‌کنید کدام منبع را می‌خواهید، بعد هدرها می‌آیند و بعد یک خط خالی دارید که هدرها را از بدنهٔ پیام (اگر هست) جدا می‌کند. این‌طور می‌توانید صفحهٔ «about» یک وب‌سایت را بگیرید:

HTTPGET /about.html HTTP/1.0
User-Agent: Mozilla/5.0

و این‌طور با متد POST دادهٔ فرم به یک وب سرور می‌فرستید:

HTTPPOST /form.php HTTP/1.0
Content-Type: application/x-www-form-urlencoded
Content-Length: 21

name=John&surname=Doe

برای اثبات اینکه این فقط متن است، می‌توانید متن بالا را کپی-پیست کنید و از چیزی استفاده کنید که به شما اجازه می‌دهد متن را روی شبکه بفرستید. بگذارید با telnet صفحهٔ about گوگل را بگیریم:

فرستادن پاسخ‌های HTTP با سوکت‌ها

اگر قصد پیاده‌سازی برنامه‌های شبکه از صفر را دارید، احتمالاً لازم است با سوکت‌های شبکه کار کنید. سوکت انتزاعی است که سیستم‌عامل‌تان فراهم کرده و به شما اجازه می‌دهد بایت‌ها را از طریق شبکه بفرستید و دریافت کنید. این‌جا یک پیاده‌سازی پایهٔ سرور HTTP است:

python"""
پیاده‌سازی یک سرور HTTP/1.0 ساده
"""

import socket

# تعریف میزبان و پورت سوکت
SERVER_HOST = '0.0.0.0'
SERVER_PORT = 8000

# ساخت سوکت
server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
server_socket.bind((SERVER_HOST, SERVER_PORT))
server_socket.listen(1)
print('Listening on port %s ...' % SERVER_PORT)

while True:
        # منتظر اتصال کلاینت باش
    client_connection, client_address = server_socket.accept()

    # درخواست کلاینت را بگیر
    request = client_connection.recv(1024).decode()
    print(request)

    # پاسخ HTTP بفرست
    response = 'HTTP/1.0 200 OK\n\nHello World'
    client_connection.sendall(response.encode())
    client_connection.close()

# بستن سوکت
server_socket.close()

با تعریف میزبان و پورت سوکت شروع می‌کنیم. بعد متغیر server_socket را می‌سازیم و روی AF_INET (خانوادهٔ آدرس IPv4) و SOCK_STREAM (در اصل TCP) تنظیم می‌کنیم. بقیهٔ کد برای این است که سوکت را برای گوش‌دادن به درخواست‌های (host, port) داده‌شده آماده کند. مستندات پایتون دربارهٔ سوکت‌ها اطلاعات بیشتری دارد.

بقیهٔ کد خودتوضیح است: منتظر اتصال کلاینت بمان، رشتهٔ درخواست را بخوان، یک رشتهٔ HTTP-formatted با Hello World در بدنهٔ پاسخ بفرست و اتصال کلاینت را ببند. این کار را برای همیشه انجام می‌دهیم (یا تا وقتی کسی Ctrl+C را نزند). مرورگرتان را روی http://localhost:8000/ باز کنید و باید پاسخ سرور را ببینید:

به‌عنوان تمرین، Hello World را به <h1>Hello World</h1> تغییر دهید و ببینید چه اتفاقی می‌افتد. و print(request) را در سورس سرور دیدید؟ این خروجی‌اش در کنسول است:

بله، مرورگر در حال درخواست صفحهٔ ریشه («/») سرور است.

index.html

به‌طور پیش‌فرض، وقتی مرورگر ریشهٔ یک سرور را درخواست می‌کند (با درخواستی مثل GET / HTTP/1.0)، باید صفحهٔ index.html را برگردانیم. بگذارید کد داخل while را تغییر دهیم تا همیشه محتویات فایل htdocs/index.html را برگرداند:

pythonwhile True:
    # منتظر اتصال کلاینت باش
    (...)

    # درخواست کلاینت را بگیر
    (...)

    # محتوای htdocs/index.html را بگیر
    fin = open('htdocs/index.html')
    content = fin.read()
    fin.close()

    # پاسخ HTTP بفرست
    response = 'HTTP/1.0 200 OK\n\n' + content
    client_connection.sendall(response.encode())
    (...)

در اصل، محتویات فایل را می‌خوانیم و به‌جای Hello World قبلی به‌عنوان بدنهٔ پیام به رشتهٔ response اضافه می‌کنیم. فایل index.html فقط یک فایل متنی است (داخل دایرکتوری htdocs) با محتوای html:

html<html>
<head>
    <title>Hello World</title>
</head>
<body>
    <h1>Hello World!</h1>
    <p>Welcome to the index.html web page..</p>
    <p>Here's a link to <a href="ipsum.html">Ipsum</a></p>
</body>
</html>

می‌توانید هر چند بار که می‌خواهید روی لینک کلیک کنید، اما سرور شما همیشه محتویات index.html را برمی‌گرداند؛ طوری برنامه‌ریزی شده!

برگرداندن صفحات دیگر

تا اینجا سرور ما صفحهٔ index.html را برمی‌گرداند، اما باید اجازه دهیم بقیهٔ صفحات را هم برگرداند. از نظر فنی یعنی باید خط اول درخواست HTTP (چیزی مثل GET /ipsum.html HTTP/1.0) را پارس کنیم، فایل مورد نظر را باز کنیم و محتویاتش را برگردانیم. تغییرات:

pythonwhile True:
    # منتظر اتصال کلاینت باش
    (...)

    # درخواست کلاینت را بگیر
    (...)

    # هدرهای HTTP را پارس کن
    headers = request.split('\n')
    filename = headers[0].split()[1]

    # محتوای فایل را بگیر
    if filename == '/':
        filename = '/index.html'

    fin = open('htdocs' + filename)
    content = fin.read()
    fin.close()

    # پاسخ HTTP بفرست
    response = 'HTTP/1.0 200 OK\n\n' + content
    client_connection.sendall(response.encode())
    (...)

در اصل، نام فایل را از رشتهٔ درخواست بیرون می‌کشیم، فایل را باز می‌کنیم (فرض می‌کنیم همهٔ فایل‌های html داخل پوشهٔ htdocs هستند) و محتوایش را برمی‌گردانیم. هم‌چنین می‌بینید که وقتی کلاینت‌ها منبع ریشه ('/') را می‌خواهند، فایل index.html را درست برمی‌گردانیم.

404 — پیدا نشد

تمام نشده! این اتفاقی است که اگر بخواهیم فایلی را درخواست کنیم که وجود ندارد — مثلاً http://localhost:8000/hello.html:

ConsoleGET /hello.html HTTP/1.1

Traceback (most recent call last):
  File "httpserver.py", line 36, in <module>
    fin = open('htdocs' + filename)
FileNotFoundError: [Errno 2] No such file or directory: 'htdocs/hello.html'

سرور کرش می‌کند و خارج می‌شود!

باید استثنا را بگیریم و پاسخ 404 بفرستیم:

pythonwhile True:
    # منتظر اتصال کلاینت باش
    (...)

    # درخواست کلاینت را بگیر
    (...)

    # هدرهای HTTP را پارس کن
    headers = request.split('\n')
    filename = headers[0].split()[1]

    # محتوای فایل را بگیر
    if filename == '/':
        filename = '/index.html'

    try:
        fin = open('htdocs' + filename)
        content = fin.read()
        fin.close()

        response = 'HTTP/1.0 200 OK\n\n' + content
    except FileNotFoundError:
        response = 'HTTP/1.0 404 NOT FOUND\n\nFile Not Found'

    # پاسخ HTTP بفرست
    client_connection.sendall(response.encode())
    client_connection.close()
