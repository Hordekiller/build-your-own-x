مهندسی مرورگر وب (Web Browser Engineering) — ساخت یک مرورگر واقعی با پایتون

⚙ زبان: Python ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور کتاب آزاد «Web Browser Engineering» از پاول پانچخا (Pavel Panchekha) و کریس هارلسون (Chris Harrelson) (مهندس Chrome گوگل) است که با همکاری No Starch Press منتشر شده و به‌صورت آنلاین رایگان در دسترس است: شما یک مرورگر کامل تدریجی با پایتون می‌سازید.
↗ مشاهده منبع اصلی

۱. ایدهٔ بزرگ: همهٔ مرورگر را بسازید

کتاب با یک وعده شروع می‌شود: «این کتاب نشان می‌دهد که می‌توانید در حدود ۲٬۰۰۰ خط پایتون، یک مرورگر وب ساده اما واقعی بسازید — که صفحات را دانلود می‌کند، HTML را تجزیه می‌کند، CSS را اعمال می‌کند، محتوا را چیدمان و رنگ‌آمیزی می‌کند، فرم‌هارا پردازش می‌کند و حتی جاوااسکریپت را اجرا می‌کند.»

در این مسیر همهٔ بازیگرهای کلیدی وب را یاد می‌گیرید، اما به‌جای حفظ کردن APIها، هرکدام را خودتان پیاده می‌کنید: از پروتکل HTTP که صفحه‌ها را می‌آورد، تا موتور رندر که آن‌ها را به پیکسل تبدیل می‌کند، و حتی مفسّر جاوااسکریپت کوچکی که صفحات را پویا می‌کند.

چهار ستون کتاب:

  • HTTP: درخواست‌ها و پاسخ‌ها، سربرگ‌ها، کوکی‌ها و رمزگذاری.
  • HTML و CSS: تجزیهٔ نرم‌افزار، درخت DOM، مدل جعبه‌ای، selector ها و cascade.
  • رندر: چیدمان بلوکی/خطی، painting، و مدیریت ورودی کاربر (کلیک، تایپ، فرم).
  • امنیت و عملکرد: اسکریپت‌های متقاطع (XSS)، مرور ایمن، کشینگ و بهینه‌سازی زمان اجرا.

۲. نقشهٔ فصل‌ها — و هر فصل چه می‌سازد

کتاب «تدریجی» نوشته شده: هر فصل یک تکهٔ تازه به مرورگر اضافه می‌کند:

  1. دانلود صفحات وب — کلاس HTTP و اولین پیکسل‌های رندر.
  2. رسم روی صفحه — اولین چیدمان: متن‌ها را خط‌خط بچین و رسم کن.
  3. ساختاردهی متن — پاراگراف، بر، و فونت‌ها.
  4. ساختن اسناد — تجزیهٔ کامل HTML به یک درخت.
  5. استایل‌دهی — CSS: selector، matching و cascade.
  6. CSS — جزئیات مدل چیدمان: block formatting context و margin collapse.
  7. فرم‌ها و دکمه‌ها — تعامل: ورودی متن، چک‌باکس، submit.
  8. ارسال داده به سرورها — درخواست‌های POST، کوکی‌ها و جلسه.
  9. اجرای جاوااسکریپت — یک مفسّر کوچک برای فایل‌های JS.
  10. URL ها و امنیت — XSS، هدرها و مرور ایمن‌تر.
  11. جاوااسکریپت و اتصال به جهان — DOM APIها و رویدادها.
  12. بهبود عملکرد — کشینگ، اجرای موازی، و محدودیت‌های زمان.
  13. بازیابی از خطا — buffer ها، شکسته‌شدن صفحه و بازیابی هوشمند.
  14. صوت و ویدئو — اشاره به چند رسانه‌ای (Audio/Video).
  15. مرورگر در آینده — تصاویر، شبکه‌های سریع‌تر و گام‌های بعدی.

این ساختار «یک تکه در هر فصل» همان چیزی است که کتاب را از یک مرجع خسته‌کننده به یک بازی ساخت‌وساز جذاب تبدیل می‌کند.

۳. نکته‌های طراحی کتاب

  • پایتون به‌عنوان «رستی» برای یادگیری — بدون وابستگی‌های سنگین؛ هر فصل روی چند فایل کوچک کار می‌کند که همگی در یک مخزن Git هستند.
  • تا حد ممکن «واقعی» — نه فقط یک نسخهٔ UI، بلکه همان اصطلاحات و ساختارهای مرورگرهای واقعی (DOM، layout tree، raster) را با اندازهٔ کوچک بازسازی می‌کند.
  • آزمون در هر فصل — هر بخش با سؤال‌هایی برای بررسی پیشرفت همراه است.
  • رایگان و به‌روز — متن کامل کتاب به‌صورت آنلاین در دسترس است و نسخهٔ به‌روزرسانی‌شدهٔ چاپی هر چند وقت منتشر می‌شود.

۴. سناریوی عملی

در پایان کتاب، شما یک مرورگر دارید که: یک URL را باز می‌کند، صفحه را تجزیه می‌کند، ظاهر آن را با CSS می‌سازد، فرم‌ها و کلیک‌ها را مدیریت می‌کند، جاوااسکریپت اجرا می‌کند و حتی امنیت پایه را رعایت می‌کند. مقایسهٔ رفتار آن با مرورگر واقعی، یکی از بهترین تمرین‌های درک «چرا مرورگرها این‌گونه‌اند» است.

برای چه کسی؟ اگر سری «Toy Layout Engine» بروبک را دوست داشتید، این کتاب ادامهٔ طبیعی است: همان فضای ساخت‌وساز، اما در عمق بسیار بیشتر — تا مفسّر JS و امنیت. هم برای دانشجویان علوم رایانه و هم مهندسان وب، یک سفر عالی است.

۵. چه چیزهایی یاد می‌گیرید

  • HTTP واقعی: درخواست، پاسخ، کوکی، redirect و امنیت حمل‌ونقل.
  • تجزیهٔ HTML و ساخت درخت DOM؛ پردازش CSS با cascade.
  • رندر: چیدمان بلوکی/خطی، painting و تعامل با کاربر.
  • مبانی امنیت وب: XSS، ایزوله‌سازی و header ها.
  • عملکرد: کشینگ، اجرای موازی و صبر‌های اینترنت.

۶. جمع‌بندی

«مهندسی مرورگر وب» احتمالاً نزدیک‌ترین‌ترجمه به «خودت بساز» در میان منابع مرورگر است: به جای خواندن دربارهٔ مرورگر، برای چند هفته هر روز یک تکهٔ مرورگر می‌سازید — در پایان نه فقط مرورگرِ خودتان، بلکه اعتماد به نفسی برای ورود به دنیای پیچیده‌ترین نرم‌افزارهای جهان دارید.

کپیرایت: کتاب «Web Browser Engineering» اثر پاول پانچخا و کریس هارلسون است (نشر No Starch Press) و متن کامل آن به‌صورت آنلاین و رایگان در browser.engineering منتشر می‌شود. این صفحه فقط ترجمهٔ فارسی و مرور کتاب است و تمام حقوق محتوا متعلق به نویسندگان است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
