Writing an OS in Rust — ساخت سیستم‌عامل با زبان راست (فیلیپ اوپنبرمن)

۱. دربارهٔ سری

این مجموعه، پرمخاطب‌ترین و کامل‌ترین آموزش ساخت سیستم‌عامل با Rust است. هر مقاله یک موضوع را با کد کامل و توضیح عمیق پوشش می‌دهد و همهٔ مقالات با یک زنجیرهٔ پیشروی روی هم ساخته می‌شوند. نسخهٔ فعلی (نسخهٔ دوم) از معماری مدرن استفاده می‌کند: کامپایل به صورت freestanding binary بدون هیچ وابستگی به سیستم‌عامل، و بوت با crate مخصوص به نام bootloader.

نکتهٔ جالب دربارهٔ نسخه‌ها: نسخهٔ اول (قدیمی) با GRUB و Multiboot استاندارد کار می‌کرد، اما نسخهٔ دوم به بوت‌لودر اختصاصی و استاندارد مخصوص Rust (بوت در حالت UEFI و BIOS) مهاجرت کرده و کدها با ابزار cargo کاملاً مدیریت می‌شوند.

۲. فهرست مقالات

  • Freestanding Rust Binary: ساخت یک باینری بدون سیستم‌عامل — تعیین #![no_std] و target مخصوص.
  • Minimal Rust Kernel: اولین هسته با تابع _start و چاپ پیام در حافظهٔ VGA؛ راه‌اندازی با crate bootloader و اجرا در QEMU.
  • VGA Text Mode: نوشتن در حافظهٔ ویدیویی با ماژول vga_buffer و مدیریت println.
  • Testing: زیرساخت تست واحد و تست یکپارچه برای کرنل.
  • CPU Exceptions: جدول IDT، وقفه‌های CPU و handlerها.
  • Double Faults: مدیریت خطای دوتایی و پشتهٔ آن.
  • Hardware Interrupts: وقفه‌های سخت‌افزاری، کنترل‌کنندهٔ PIC و تایمر — اولین بستر multitasking.
  • Introduction to Paging: صفحه‌بندی و مدیریت حافظهٔ مجازی با جدول صفحات ۴ سطحی (P4..P1).
  • Heap Allocation: تخصیص‌دهندهٔ هیپ درون کرنل.
  • Allocator Designs: مقایسهٔ طراحی تخصیص‌دهنده‌ها (آزادشونده‌های لیست-لینکی و…).
  • Async/Await: الگوی async در سطح سیستم‌عامل و ساخت رانتایم اجرایی.

۳. نمونهٔ کد: یک کرنل مینیمال

هستهٔ کوچک سری، یک باینری freestanding است که با کامپایلر راست ساخته می‌شود و چیزهای حذف‌شده (مثل std) با کرکرهٔ راست (panic handler) جایگزین می‌شوند:

rust//! کرنل مینیمال — freestanding Rust binary
#![no_std]          // بدون کتابخانه‌ی استاندارد
#![no_main]         // بدون main معمولی

use core::panic::PanicInfo;

static HELLO: &[u8] = b"Hello World!";

#[no_mangle]
pub extern "C" fn _start() -> ! {
    let vga_buffer = 0xb8000 as *mut u8;

    for (i, &byte) in HELLO.iter().enumerate() {
        unsafe {
            *vga_buffer.offset(i as isize * 2) = byte;
            *vga_buffer.offset(i as isize * 2 + 1) = 0xb;  // سبز
        }
    }

    loop {}         // سیستم «تمام شد»
}

#[panic_handler]
fn panic(_info: &PanicInfo) -> ! {
    loop {}
}

ساخت و اجرا با ابزارهای راست انجام می‌شود؛ بوت‌لودر اختصاصی (bootloader crate) تصویر بوت را می‌سازد:

bashcargo build
cargo run    # با پیکربندی QEMU داخلی، هسته را اجرا می‌کند

۴. نقاط قوت

  • دقت و عمق: هر مفهوم با جزئیات معماری x86_64 توضیح داده شده.
  • به‌روز بودن: مقالات به‌طور مداوم برای نسخه‌های جدید Rust و ابزارها به‌روز می‌شوند.
  • تست درون پروژه: زیرساخت تست کامل — یاد می‌گیرید کرنل‌تان را هم‌چون نرم‌افزار معمولی تست کنید.
  • سطح بالا: تا async/await پیش می‌رود — چیزی که در آموزش‌های C دیده نمی‌شود.
نکتهٔ تکمیلی: اگر با Rust آشنا هستید (یا می‌خواهید به بهانهٔ سیستم‌عامل Rust یاد بگیرید)، این سری بهترین انتخاب است؛ در غیر این صورت ابتدا مسیر C (مثل Little OS Book) را بروید و بعد برای دیدن تفاوت ایمنی Rust، به این سری برگردید.
