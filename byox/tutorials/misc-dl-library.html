چرا شبکه از صفر؟

بیشتر افراد فقط «کتابخانه را صدا می‌زنند»: `model.add(...)` و `model.fit(...)`. در این سری، شما همان چیز را با numpy می‌سازید و می‌فهمید forward pass، backpropagation و gradient descent واقعاً چه می‌کنند. این درک، تنها راه برای تشخیص اینکه چرا یک شبکه خوب یا بد کار می‌کند است.

نورون و لایه

یک لایهٔ Dense یعنی: ضرب ماتریس ورودی در وزن‌ها + بایاس. در numpy کل لایه با دو خط نوشته می‌شود:

Pythonimport numpy as np

class Layer_Dense:
    def __init__(self, n_inputs, n_neurons):
        # وزن‌های کوچک تصادفی + بایاس
        self.weights = np.random.randn(n_inputs, n_neurons) * 0.01
        self.biases = np.zeros((1, n_neurons))

    def forward(self, inputs):
        self.inputs = inputs
        self.output = np.dot(inputs, self.weights) + self.biases
        return self.output

ضرب ماتریسی یعنی همهٔ نورون‌ها و همهٔ نمونه‌های یک batch هم‌زمان محاسبه می‌شوند — قدرت numpy همین است.

همراه با فعال‌سازی و خطا

بعد از لایه، تابع فعال‌سازی (ReLU در لایه‌های میانی، Softmax در خروجی) و تابع خطا (Cross-Entropy) اضافه می‌شود. نکتهٔ مهم سری: همهٔ این‌ها یک کلاس جدا با forward و (بعدا) backward خواهند داشت:

Pythondef relu_forward(inputs):
    return np.maximum(0, inputs)

def softmax_forward(z):
    exp = np.exp(z - np.max(z, axis=1, keepdims=True))  # پایداری عددی
    return exp / np.sum(exp, axis=1, keepdims=True)

def cross_entropy(y_pred, y_true):
    return -np.log(y_pred[range(len(y_pred)), y_true] + 1e-9).mean()

کم‌کردن حداکثر (max) قبل از exp، از سرریز شدن لازم است — جزئیاتی که در کتابخانه‌های آماده دیده نمی‌شود.
