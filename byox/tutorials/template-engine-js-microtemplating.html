۱. مقدمه: تابعی که همه‌چیز را تغییر داد

در سال ۲۰۰۸، جان رسیگ — خالق jQuery — یک تابعِ ۳۳ خطی منتشر کرد به نام JavaScript Micro-Templating که در «استفاده از قالب در مرورگر» تحولی ایجاد کرد: یک tmpl(str, data) که قالب را می‌گیرد، آن را کامپایل (ترجمه به کدِ اجرایی) می‌کند و در حافظه کش می‌کند. در این آموزش می‌بینیم خط‌به‌خط چطور کار می‌کند.

روش استفاده:

html<script type="text/html" id="item_tmpl">
  <div id="<%=id%>" class="<%=klass%>">
    <div class="item"><%=name%></div>
  </div>
</script>

<script>
  var results = tmpl("item_tmpl", { id: 1, klass: "item", name: "جان" });
  document.getElementById("results").innerHTML = results;
</script>

۲. هستهٔ تابع

javascript// میکرو-قالب‌سازی جاوااسکریپت، اثر جان رسیگ (با مجوز MIT)
(function(){
  var cache = {};

  this.tmpl = function tmpl(str, data){
    // تشخیص: آیدی یک تگ است یا خودِ رشتهٔ قالب؟
    var fn = !/\W/.test(str) ?
      cache[str] = cache[str] ||
        tmpl(document.getElementById(str).innerHTML) :
      new Function("obj",
        "var p=[],print=function(){p.push.apply(p,arguments);};" +
        "with(obj){p.push('" +
        str
          .replace(/[\r\t\n]/g, " ")
          .split("<%").join("\t")
          .replace(/((^|%>)[^\t]*)'/g, "$1\r")
          .replace(/\t=(.*?)%>/g, "',$1,'")
          .split("\t").join("');")
          .split("%>").join("p.push('")
          .split("\r").join("\\'")
        + "');}return p.join('');");
    return data ? fn( data ) : fn;
  };
})();
ایدهٔ کلیدی: قالب «رشته» می‌ماند ولی به‌دستِ new Function به بدنهٔ یک تابع واقعی تبدیل می‌شود. یعنی خروجی، «اجرای کد» است نه تجزیهٔ متن — سریع، ساده و بسیار انعطاف‌پذیر.

۳. گام‌به‌گام با تابع

  1. تشخیص ورودی: اگر str فاقد نویسهٔ غیرعادی (/\W/) بود، آن را آیدیِ یک تگ <script type="text/html"> در نظر می‌گیریم، محتوایش را می‌خوانیم و در cache نگه می‌داریم — بارهای بعدی دیگر کدِ کامپایل‌شده از کش برمی‌گردد. در غیر این صورت خودِ str قالب است.
  2. پاک‌سازی و برچسب‌گذاری: [\r\t\n]ها حذف می‌شوند، <% به تب \t تبدیل می‌شود (تا بعداً به «بستنِ رشته» بدل شود)، آپاستروف‌های داخل قالب با \r نشانه‌گذاری می‌شوند تا هنگام ساخت رشتهٔ کد خراب نشوند.
  3. تبدیل برچسب‌ها به کد: <%=expr%> به ',$1,' تبدیل می‌شود — یعنی «خروجیِ این عبارت را به آرایه اضافه کن»؛ \t به '); (بستن push) و %> به p.push(' (باز کردن push). نتیجهٔ نهایی رشتهٔ بدنهٔ تابع است.
  4. ساخت تابع با with(obj): داخل تابعِ ساخته‌شده، متغیرهای قالب از درونِ object داده در دسترس‌اند — with(obj){ p.push('...') } — و آرایهٔ p قطعه‌ها را جمع می‌کند تا در انتها p.join('') خروجی نهایی شود.
  5. فراخوانی: اگر data داده شده باشد، تابع با داده اجرا و خروجی می‌شود؛ اگر نه، خودِ تابع (برای استفادهٔ بعدی) برگردانده می‌شود.

۴. چرا این همه راه دور؟

  • اجرای واقعی جاوااسکریپت داخل قالب: هر چیزی که در قالب بنویسید — حلقه، شرط، فراخوانی تابع — واقعاً اجرا می‌شود؛ مثلاً <% for (var i=0; i<items.length; i++) { %>…<% } %>.
  • کشِ خودکار: قالب‌های برچسب‌دار فقط یک‌بار کامپایل می‌شوند؛ سرعتِ اجرای مکرر به سطح توابع معمولی می‌رسد.
  • بدون وابستگی: یک تابع خالصِ جاوااسکریپت که در هر محیطی (مرورگر، Node) کار می‌کند — و همین سادگی بود که الهام‌بخش موتورهای بعدی (مثل موتور ۲۰ خطی همین مجموعه) شد.
نکتهٔ امنیتی/عملی: استفاده از new Function یعنی اجرای کدِ درونِ قالب؛ در عملِ واقعی (با ورودی کاربر) باید دقت کنید. اما به‌عنوان یک «شگفتی مهندسی»، درک همین ۳۳ خط، نیم‌ساعت تأمل می‌ارزد.

۵. جمع‌بندی

میکرو-قالب‌سازی جان رسیگ نشان داد «موتور قالب» لزوماً پروژهٔ بزرگ نیست: یک رشته، یک regex، یک new Function و یک کش — تمام. با درک این پیاده‌سازی، خواندن هر موتور قالبِ جاوااسکریپت (EJS، Underscore و…) برایتان روشن می‌شود، چون همه از همین ایدهٔ «قالب → کد» تغذیه می‌کنند.

کپیرایت: تابع «JavaScript Micro-Templating» اثر جان رسیگ (John Resig) است و مقالهٔ «Understanding JavaScript Micro-Templating» در Medium (web dev Stack، wdstack) منتشر شده. این صفحه فقط ترجمهٔ فارسی است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسنده اصلی است. برای مشاهده اصل مطلب به سایت اصلی و پست اصلیِ جان رسیگ مراجعه کنید.
