MVC یعنی چه؟

MVC تفکیک مسئولیت است: Model با دیتا و منطق سروکار دارد، View فقط نمایش (HTML)، و Controller بین این دو پل می‌زند؛ درخواست کاربر را می‌گیرد، Model را صدا می‌زند و نتیجه را به View می‌دهد. فریم‌ورک‌های Laravel و CodeIgniter همین الگو را منظم کرده‌اند.

Front Controller و routing

اولین قدم: همهٔ درخواست‌ها به یک فایل (index.php) بیایند. با `.htaccess` همه چیز به index هدایت می‌شود و آن هم با متن URL تصمیم می‌گیرد کدام کنترولر/اکشن اجرا شود:

HTAccessRewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteRule ^(.*)$ index.php?url=$1 [QSA,L]
PHPclass Application {
    public function run() {
        // مثل: home/index/5
        $parts = explode('/', trim($_GET['url'] ?? 'home/index', '/'));
        $controller = ucfirst($parts[0] ?? 'Home') . 'Controller';
        $action = $parts[1] ?? 'index';

        $file = "app/controllers/$controller.php";
        if (!file_exists($file)) { http_response_code(404); die('یافت نشد'); }

        require $file;
        $obj = new $controller;
        $obj->$action();   // کنترولر را با اکشن صدا بزن
    }
}

تمام راز routing همین است: شکستن URL و صدا زدن کلاس روشن. (امنیت: فقط نام‌های معتبر دایرکتوری داخل کنترلرها پذیرفته می‌شوند.)

کنترولر و مدل

کنترولر از مدل، داده می‌گیرد و به ویو می‌دهد:

PHPclass HomeController {
    public function index() {
        $posts = (new PostModel())->latest();   // داده از مدل
        require "app/views/home.php";           // نمایش: $posts
    }
}

class Model {
    protected $db;
    public function __construct() {
        $this->db = new PDO('sqlite:app.db');   // یک اتصال مشترک
    }
    protected function query($sql, $params = []) {
        $st = $this->db->prepare($sql);
        $st->execute($params);
        return $st->fetchAll();
    }
}

با `PDO` آماده‌سازی (prepared) و bind کردن پارامترها — اولین رد پای امنیت در برابر SQL injection.

ساختار نهایی

پوشه‌بندی پایه: `app/controllers`، `app/models`، `app/views`، `core/` برای کلاس‌های پایه و `public/` برای فایل‌های استاتیک. این همان ساختاری است که همهٔ فریم‌ورک‌های معروف با همین ترتیب دارند؛ حالا که از صفرش ساخته‌اید، خواندن کد منبع فریم‌ورک‌ها مثل متن آشناست.
