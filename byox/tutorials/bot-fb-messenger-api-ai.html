ساخت ربات هوشمند پیام‌رسان فیسبوک با API.ai در Node.js

⚙ زبان: Node.js 📁 دسته: ربات ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمه فارسی آموزش «Creating a Simple Facebook Messenger AI Bot with API.ai in Node.js» نوشتهٔ «تومومی ایمورا (Tomomi Imura)» است که در Bots Floor منتشر شده و توسط «تومومی ایمورا» به زبان انگلیسی نوشته شده است. نسخه کامل را از سایت اصلی (یا آرشیو Wayback) بخوانید.
↗ مشاهده منبع اصلی

مقدمه

در این آموزش یاد می‌گیرید چطور یک ربات هوشمند (AI bot) برای پیام‌رسان فیسبوک با استفاده از API.ai (که امروزه با نام Dialogflow شناخته می‌شود) و Node.js بسازید. ربات ساده‌ای می‌سازیم که «حسابدارِ» هوشمندانهٔ شماست: با API.ai به آن گفتار (Natural Language) می‌دهیم تا بتواند مکالمه‌های ساده را بفهمد — حتی می‌تواند شوخی کند! به آخرش برسید تا یک ربات واقعاً کاری داشته باشید.

این آموزش بر پایهٔ Facebook Messenger Platform و شروع سریع رسمی آن است، اما با دو تفاوت بزرگ: اول اینکه ربات را با Express.js و Node.js می‌سازیم؛ دوم اینکه — به‌جای پاسخ‌های از پیش تعریف‌شده — به ربات هوش مصنوعی با API.ai اضافه می‌کنیم.

آنچه نیاز دارید

  • یک اپ فیسبوک و صفحهٔ فیسبوکی (برای دریافت Page Token)
  • حساب API.ai (رایگان) و یک Agent جدید
  • سرور Node.js —— با ngrok برای وب‌هوک محلی آزمایش کنید
  • دسترسی به ترمینال/CLI (Node و npm نصب شده)

گام ۱: راه‌اندازی پروژه Node.js

ابتدا یک پوشهٔ پروژه بسازید و package.json را مقداردهی کنید. برای ربات به دو کتابخانه‌ی نیاز داریم: express برای وب‌سرور و request برای فراخوانی APIهای فیسبوک و API.ai. اگر می‌خواهید دست‌کم از الگوی شروع سریع فیسبوک استفاده کنید، پیشنهاد می‌کنم کد خودِ‌ آموزش را دنبال کنید.

bashnpm init
npm install express request --save

سپس فایل app.js را بسازید. کد شروع‌کنندهٔ آن (ساده‌سازی‌شده و از الگوی آموزش):

js// app.js — ربات پیام‌رسان فیسبوک با API.ai
const express = require('express');
const request = require('request');

const app = express();

// توکن دسترسی صفحه — از تنظیمات اپ فیسبوک
const PAGE_ACCESS_TOKEN = 'صفحه_توکن_شما';
// توکن تأیید وب‌هوک — که خودتان تعیین می‌کنید
const VERIFY_TOKEN = 'توکن_تأیید_شما';

app.use(express.json());

// تأیید وب‌هوک توسط فیسبوک
app.get('/webhook', (req, res) => {
  if (req.query['hub.mode'] === 'subscribe' &&
      req.query['hub.verify_token'] === VERIFY_TOKEN) {
    res.status(200).send(req.query['hub.challenge']);
  } else {
    res.sendStatus(403);
  }
});

// دریافت پیام‌ها از فیسبوک
app.post('/webhook', (req, res) => {
  const body = req.body;
  if (body.object === 'page') {
    body.entry.forEach(entry => {
      entry.messaging.forEach(event => {
        const senderId = event.sender.id;
        if (event.message && event.message.text) {
          handleMessage(senderId, event.message.text);
        }
      });
    });
    res.sendStatus(200);
  }
});

function handleMessage(senderId, messageText) {
  // این‌جا متن پیام را به API.ai می‌فرستیم
  console.log('دریافت پیام:', messageText);
}

app.listen(process.env.PORT || 3000, () => {
  console.log('سرور ربات روشن شد');
});

گام ۲: ساخت اپ فیسبوک و دریافت Page Token

به developers.facebook.com بروید و:

  1. یک بستهٔ پیام‌رسان (Messenger product) به اپ خود اضافه کنید
  2. صفحهٔ فیسبوکی‌تان را به اپ متصل کنید
  3. یک Page Access Token کپی کنید و در app.js بگذارید
  4. یک Verify Token دلخواه تعیین کنید (مثلاً یک رشتهٔ تصادفی) و در کد بگذارید

راه‌اندازی وب‌هوک

در تنظیمات Facebook Developer، بخش Webhooks را باز کنید، آدرس https://YOUR_SERVER/webhook را بدهید و Verify Token را وارد کنید. فیسبوک برای تأیید، یک درخواست GET به آدرس شما می‌فرستد؛ کد بالا با hub.challenge پاسخ می‌دهد و اتصال برقرار می‌شود.

گام ۳: تست محلی با ngrok

برای اینکه فیسبوک بتواند به سرور محلی‌تان دسترسی داشته باشد، ngrok یک تونل امن ایجاد می‌کند:

bashnode app.js
# در ترمینال دوم:
ngrok http 3000

ngrok یک آدرس عمومی مثل https://xxxx.ngrok.io می‌دهد — همان را به‌عنوان آدرس Callback وب‌هوک (با /webhook) در فیسبوک ثبت کنید.

گام ۴: اتصال API.ai به ربات

در داشبورد API.ai یک Agent جدید بسازید. دو کار کلیدی انجام می‌دهیم:

  1. Small Talk: در منوی Agent باید افزونه‌ی (Domain) «Small Talk» را فعال کنید تا ربات به مکالمه‌های روزمره (سلام، حال‌ت چطوره، شوخی و...) پاسخ بداند.
  2. Intent سفارشی: یک Intent مثل get.current.time بسازید تا ربات درک کند کاربر چه می‌خواهد — مثلاً وقتی کاربر می‌پرسد «ساعت چند است؟»، API.ai آن را درک کرده و پاسخ مناسب می‌فرستد.

سپس در handleMessage متن پیام را به https://api.dialogflow.com/v1/query بفرستید و پاسخ (result.fulfillment.speech) را با «Send API» فیسبوک به کاربر برگردانید:

jsfunction handleMessage(senderId, messageText) {
  request({
    url: 'https://api.dialogflow.com/v1/query',
    method: 'POST',
    headers: { Authorization: 'Bearer ' + APIAI_TOKEN },
    json: { query: messageText, lang: 'en', sessionId: senderId }
  }, (err, res, body) => {
    if (err) { console.error(err); return; }
    const reply = body.result.fulfillment.speech;
    sendTextMessage(senderId, reply);
  });
}

گام ۵: اشتراک‌گذاری ربات

بعد از تست موفق، ربات خود را منتشر کنید: کد را روی Heroku (یا سرویس مشابه) deploy کنید و آدرس عمومی‌ را جایگزین ngrok کنید. صفحهٔ فیسبوکی‌تان را به پیام‌رسان فیسبوک متصل کنید تا همه بتوانند با آن چت کنند.

شما اکنون یک ربات هوشمند دارید — نه صرفاً یک پاسخ‌دهندهٔ کلمه‌به‌کلمه. دمو و کد کامل این آموزش در ریپازیتوری گیت‌هاب نویسنده (شاخهٔ tutorial-01) موجود است.
