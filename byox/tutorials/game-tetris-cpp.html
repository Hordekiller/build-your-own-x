۱. ایدهٔ اصلی: جداسازی منطق از گرافیک

کلاس Board (منطق) هیچ‌چیز دربارهٔ گرافیک نمی‌داند: نه SDL، نه OpenGL و نه پنجره. فقط با ماتریس‌ها و توابع ساده کار می‌کند — همین یعنی کد بازی روی هر پلتفرمی (دسکتاپ، موبایل، وب) با هر کتابخانه‌ای قابل استفاده است. در این آموزش، منطق با SDL 1.2 نمایش داده می‌شود اما تمرکز مقاله روی خود منطق است.

نکته: این رویکرد، بهترین تمرین برای درک «چرا بازی‌های حرفه‌ای موتورشان را از بازی جدا می‌کنند» است.

۲. نمایش قطعه‌ها با ماتریس

هر قطعه (tetromino) و خود صفحهٔ بازی، یک ماتریس است — ساده‌ترین و در عین حال قدرتمندترین راه برای نمایش شبکه‌ای تتریس:

۳. هک چرخش بدون ریاضی پیچیده

به‌جای محاسبهٔ چرخش با ضرب ماتریس، هر قطعه چهار حالت چرخش از پیش تعریف‌شده دارد که هنگام چرخش، فقط اندیس حالت عوض می‌شود:

cpp// چرخش: تغییر به حالت بعدی چرخش — هر قطعه ۴ حالت دارد
void rotate(int x, int y, int rotation) {
  switch (rotation) {
    case 0: // حالت اصلی (همان ماتریس)
      ...
    case 1: // چرخش ۹۰ درجه — از پیش محاسبه‌شده
      ...
    // ...
  }
}

دلیل کارایی این روش: چرخش‌های ۹۰ درجهٔ هر قطعه فقط ۴ حالت دارند و می‌توان آن‌ها را از قبل روی کاغذ نوشت؛ نیازی به فرمول چرخش نیست.

۴. برخورد و حلقهٔ اصلی

cpp// بررسی برخورد: آیا قطعه در (x, y) با این چرخش جای می‌گیرد؟
bool Board::isFreeBlock(int pX, int pY, int pType, int pRotation) {
  // هر خانهٔ غیرصفر ماتریس قطعه را با صفحه مقایسه کن
  for (int i1 = pX, i2 = 0; i1 < pX + size(pType); i1++, i2++) {
    for (int j1 = pY, j2 = 0; j1 < pY + size(pType); j1++, j2++) {
      if (getBlock(i2, j2, pType, pRotation) != 0 && isBlock(i1, j1)) {
        return false; // تداخل → برخورد
      }
    }
  }
  return true;
}
