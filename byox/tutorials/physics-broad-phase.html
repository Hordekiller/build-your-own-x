تشخیص برخورد فاز گسترده با استفاده از تقسیم فضایی

⚙ زبان: JavaScript ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمه فارسی مقاله «Broad Phase Collision Detection Using Spatial Partitioning» از Andrew Petersen (سایت Build New Games، ۲۰۱۲) است — کاهش هزینه تشخیص برخورد با تقسیم فضایی (شبکه سلولی) در جاوااسکریپت.
↗ مشاهده منبع اصلی

۱. مسأله: هزینه O(n²) برخوردها

ساده‌ترین راه تشخیص برخورد، مقایسه هر جسم با همه جسم‌های دیگر است: n × (n-1) / 2 جفت. با ۱۰ جسم فقط ۴۵ جفت است، اما با ۱۰۰ جسم ۴۹۵۰ و با ۱۰۰۰ جسم نزدیک ۵۰۰ هزار آزمایش — و هزینه هر آزمایش (بسته به شکل) می‌تواند سنگین باشد. این رشد درجه دوم به‌سرعت موتور را از پا در می‌آورد.

javascript// روش ساده‌لوحانه: همه با همه
for (var i = 0; i < bodies.length; i++) {
    for (var j = i + 1; j < bodies.length; j++) {
        if (collide(bodies[i], bodies[j])) {
            handleCollision(bodies[i], bodies[j]);
        }
    }
}

راه‌حل: بیشتر جفت‌ها در دنیا اصلاً به هم نزدیک نیستند. نمی‌شود اول کم‌هزینه مشخص کنیم کدام جفت‌ها «احتمالاً» برخورد دارند و فقط همان‌ها را دقیق تست کنیم؟

۲. دو فاز: گسترده و محدود

تشخیص برخورد به دو مرحله تقسیم می‌شود:

  • فاز گسترده (Broad Phase): با هزینه کم، فهرست جفت‌های «نامزد» را پیدا می‌کند — جفت‌هایی که جعبه مرزی‌شان همپوشانی دارد. بعضی از آن‌ها در واقع برخورد ندارند، ولی تعدادشان از کل جفت‌ها بسیار کمتر است.
  • فاز محدود (Narrow Phase): برای هر جفت نامزد، برخورد دقیق (مثلاً با SAT یا برخورد دایره‌ها) انجام می‌شود؛ همین‌جا منیفولد تماس ساخته می‌شود.

فرمول اصلی فاز محدود به شکل برخورد بستگی دارد — مثلاً دایره‌ها با مقایسه فاصله مرکزها با مجموع شعاع‌ها:

javascriptfunction circleCollision(a, b) {
    var dx = b.x - a.x;
    var dy = b.y - a.y;
    var dist = Math.sqrt(dx * dx + dy * dy);
    return dist < (a.radius + b.radius);
}

۳. تقسیم فضایی با شبکه سلولی

یک راه مؤثر برای فاز گسترده، شبکه (Grid) است: دنیا را به سلول‌های هم‌اندازه تقسیم کنید و هر جسم را در سلول(های)ی که پوشش می‌دهد ثبت کنید. فقط جفت‌هایی می‌توانند برخورد داشته باشند که در یک سلول مشترک باشند. کارایی این‌جا به‌جای O(n²) تقریباً خطی می‌شود.

اندازه سلول را معمولاً هم‌تراز بزرگ‌ترین جسم انتخاب می‌کنند تا هر جسم در حداکثر چند سلول (مثلاً ۴) قرار بگیرد:

javascript// کلید سلول: "cellX,cellY"
function cellKey(x, y) {
    var cx = Math.floor(x / CELL_SIZE);
    var cy = Math.floor(y / CELL_SIZE);
    return cx + "," + cy;
}

// هر جسم را در سلول‌های پوشش‌داده‌شده ثبت کن (مثال: مستطیل)
function insertBody(grid, body) {
    var minX = cellKey(body.x, body.y);
    var maxX = cellKey(body.x + body.w, body.y + body.h);
    // ... و سپس برای همه سلول‌های بین آن‌ها

    grid[key].push(body);
}

۴. پیدا کردن برخوردها با شبکه

بعد از ساخت شبکه، به‌جای حلقه دوتایی روی همه اجسام، روی سلول‌ها می‌چرخیم و جفت‌های داخل هر سلول را تست می‌کنیم. هر جفت نامزد دقیقاً یک‌بار تست شود (مثلاً با ردیابی در Set):

javascriptvar pairs = new Set();

for (var key in grid) {
    var cell = grid[key];
    for (var i = 0; i < cell.length; i++) {
        for (var j = i + 1; j < cell.length; j++) {
            pairs.add(makePairKey(cell[i], cell[j]));
        }
    }
}

// حالا فقط جفت‌های نامزد: فاز محدود
pairs.forEach(function (pairKey) {
    if (narrowPhaseCollision(pairA, pairB)) {
        resolveCollision(pairA, pairB);
    }
});

۵. به‌روزرسانی در حرکت

چون اجسام در هر فریم جابه‌جا می‌شوند، شبکه باید به‌روز شود. ساده‌ترین روش: بازسازی شبکه در هر فریم (با تعداد متوسط جسم کاملاً قابل قبول است) یا به‌روزرسانی فقط اجسام متحرک — جسمی که سلول عوض کرده از سلول قبلی حذف و در سلول جدید افزوده می‌شود.

javascript// به‌روزرسانی یک جسم متحرک
function moveBody(body, dx, dy) {
    removeFromGrid(grid, body);        // حذف از سلول قبلی
    body.x += dx;
    body.y += dy;
    insertBody(grid, body);            // درج در سلول جدید
}

همچنین می‌توان فاز گسترده را با جعبه مرزی (AABB) ترکیب کرد: اگر جعبه‌های مرزی دو جسم همپوشانی نداشتند، نیازی به تست دقیق نیست. نتیجه نهایی: تشخیص برخورد برای هزاران جسم در زمان واقعی.

نکته: برای اجسام با اندازه‌های خیلی متفاوت، شبکه «سلسله‌مراتبی» یا درخت چهارتایی (Quadtree) کارایی بهتری می‌دهد؛ مقاله مرجع روی شبکه ساده تمرکز دارد.
کپیرایت: مقاله «Broad Phase Collision Detection Using Spatial Partitioning» اثر اندرو پترسن (Andrew Petersen) و متعلق به سایت Build New Games است. این صفحه فقط ترجمه فارسی آن است و تمام حقوق محتوا و کدها متعلق به نویسنده اصلی است. برای مشاهده اصل مطلب به سایت اصلی مراجعه کنید.
