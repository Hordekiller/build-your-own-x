ترکیب‌گرهای Parserچیست؟

به‌جای نوشتن یک پارسر بزرگ و پیچیده، روش ترکیب‌گر (combinator) پارسرهای کوچک را تعریف می‌کند که هرکدام یک قالب ساده را می‌شناسند و سپس با عملگرهای ترکیب، آن‌ها را به‌وجود پارس‌کنندهٔ کامل ترکیب می‌کند. نتیجهٔ نهایی، کدی ماژولار و قابل‌مطالعه است که برای هر ساختار نحو یا باینری کار می‌کند.

فلسفهٔ اصلی آن است که یک پارسر در نگاه «تابع» است: ورودی‌ای می‌گیرد، و اگر موفق بود مقداری و باقی‌ماندهٔ ورودی را برمی‌گرداند و اگر ناموفق بود یک خطا. این طراحی ساده، پایهٔ هماهنگی همهٔ ترکیب‌گرهاست.

ساختار پایه در Rust

در Rust این الگو با یک ترِیت (trait) و یک تابع ژنریک قابل بیان است. در تعریف این آموزش، پارسر با `Parser` و تابع `parse` تعریف می‌شود:

Rustpub trait Parser<I, O> {
    fn parse(&self, input: I) -> Result<(O, I), ParserErr>;
}

// ترکیب‌گر pair: دو پارسر را پشت سر هم اجرا می‌کند
pub fn pair<P1, P2, I, O1, O2>(
    p1: P1,
    p2: P2,
) -> impl Parser<I, (O1, O2)>
where
    P1: Parser<I, O1>,
    P2: Parser<I, O2>,
{
    move |input: I| {
        let (o1, rest) = p1.parse(input)?;
        let (o2, rest) = p2.parse(rest)?;
        Ok(((o1, o2), rest))
    }
}

مشاهده می‌کنید که `pair` هیچ دانشی دربارهٔ محتوای خاص ندارد؛ فقط دو پارسر دریافت می‌کند و آن‌ها را دنبال هم اجرا می‌کند. این ترکیب‌پذیری، ویژگی اصلی روش است.

ترکیب‌گر many: صفر یا بیشتر

برای موارد مثل یک لیست یا دنباله، به پارسری نیاز داریم که «صفر یا چند بار» اجرا شود. این همان `many` است:

Rust// many: پارسرِ ورودی را تا جایی که ممکن است اجرا می‌کند
pub fn many<P, I, O>(p: P) -> impl Parser<I, Vec<O>>
where
    P: Parser<I, O>,
    I: Clone,
{
    move |mut input: I| {
        let mut result = Vec::new();
        while let Ok((o, next)) = p.parse(input.clone()) {
            input = next;
            result.push(o);
        }
        Ok((result, input))
    }
}

نکتهٔ آموزشی مهم: چون پارسرها می‌توانند شکست بخورند، برای «برگرداندن عقب» (backtracking) باید ورودی را clone کنیم و فقط در صورت موفقیت جلو برویم.

ساخت پارسر JSON

پس از شناختن `map`، `and_then`، `left` و `right`، آموزش گام‌به‌گام پارسر JSON را می‌سازد: ابتدا `null`، `boolean` و `number`، سپس جفت `key: value`، سپس «object» و «array» با جداکنندهٔ `,`. هر مرحله از ترکیب‌گرهای تعریف‌شده استفاده می‌کند.

برای تست، مجموعه‌ای از تست‌های ساده هم نوشته می‌شود که نشان می‌دهد پارسر روی داده‌های درست و غلط چگونه رفتار می‌کند؛ نتیجه این است که پاسر نهایی با کمتر از ۲۰۰ خط کد، JSON کامل را می‌خواند.

جمع‌بندی

این آموزش به‌خوبی نشان می‌دهد که چگونه می‌توان بدون ابزار خارجی و فقط با چند تابع کوچک، یک پارسر کامل و قابل‌اعتماد ساخت. تکنیک ترکیب‌گرها در پروژه‌های واقعی (مثل مفسرها و ابزارهای خط فرمان) بسیار پرکاربرد است.
