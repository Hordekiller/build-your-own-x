Write You a Haskell — پیاده‌سازی Haskell در Haskell

⚙ زبان: Haskell ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور کتاب «Write You a Haskell» از استیون دیهل است که ساخت یک کامپایلر تابعی مدرن (Hindley-Milner) را در Haskell آموزش می‌دهد.

مقدمه و هدف

اگر «Write Yourself a Scheme در ۴۸ ساعت» را خوانده‌اید، این کتاب گام بعدی است: به‌جای مفسر ساده، یک کامپایلر کامل زبان تابعی با سیستم تایپی Hindley-Milner، type classes، الگوریتم دارنیکا (desugaring) و اجرای نهایی از طریق ترجمه به C می‌سازید. خروجی نهایی یک اجرایی واقعی است.

محتوا و معماری

کتاب در ۱۴ فصل: نحو با Parsec؛ AST (ترم‌ها با pattern matching)؛ نمایش میان‌مدّهای (Core Language)؛ سیستم تایپ (substitution، unification، Hindley-Milner)؛ type classes و instance resolution؛ تبدیل نوع تاپل/رشته به ساختارهای پایه؛ desugaring؛ مونومورفیسم؛ و در نهایت code generator که Core را به C ترجمه می‌کند.

نمونهٔ کد: وحدت (Unification)

Haskell-- جایگزینی تایپ‌ها
type Subst = Map.Map TVar Type

-- وحدت: دو تایپ را با جایگزینی به‌یک‌شکل می‌کند
unify :: Type -> Type -> Subst -> Either String Subst
unify (TAp l r) (TAp l' r') s = do
  s1 <- unify l l' s
  s2 <- unify r r' s1
  return s2
unify (TVar a) t s = bind a t s
unify t (TVar a) s = bind a t s
unify TInt TInt s = return s
unify TBool TBool s = return s
unify t1 t2 _ =
  Left ("عدم تطابق تایپ: " ++ show t1 ++ " و " ++ show t2)

همین الگوریتم (Robinson) است که در بسیاری از کامپایلرهای تابعی واقعی از جمله GHC وجود دارد.

نکتهٔ پایانی: ترجمه به C

پس از تایپ‌چک، برنامه‌های Core Language به کد C ترجمه می‌شوند (بسته Crunch) — اینجا با مسائل واقعی مثل مدیریت heap و garbage collection روبه‌رو می‌شوید (تخصیص با malloc و جمع‌آوری با علامت‌گذاری). قدم‌های پایانی، اجرای نمونه‌های واقعی (مانند بخش پیش‌بینی و طرح‌های کوچک) است.

جمع‌بندی

منبعی پیشرفته اما بی‌نظیر برای درک کامپایلرهای تابعی: سیستم تایپی هیدلی-میلنر، الگوریتم وحدت، typeclasses و ترجمه به زبان میانی — همه را در عمل می‌بینید. پیش‌نیاز: آشنایی با Haskell و مفاهیم پایهٔ کامپایلر.

کپیرایت: استیون دیهل (Stephen Diehl). این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
