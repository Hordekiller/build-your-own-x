موتور قالب جاوااسکریپت در فقط ۲۰ خط

⚙ زبان: JavaScript ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی مقالهٔ «JavaScript template engine in just 20 lines» اثر کراسیمیر تسونف (Krasimir Tsonev) (منتشرشده: ۱ دسامبر ۲۰۱۳) است که خودش الهام‌گرفته از مقالهٔ میکرو-قالب‌سازی جان رسیگ (John Resig) است. نسخه کامل و به‌روز را از سایت اصلی بخوانید.
↗ مشاهده منبع اصلی

۱. داستان‌چرا

نویسنده در حال ساخت AbsurdJS — یک preprocessor جاوااسکریپتی است که ابتدا CSS و بعد CSS/HTML تولید می‌کند. چون HTML تولید می‌کرد، طبیعی بود که به‌عنوان موتور قالب هم عمل کند؛ یعنی نوعی «پرکردن مارک‌آپ با داده». اما موتورهای قالبِ موجود بیشتر فقط NodeJS بودند و در مرورگر به درد نمی‌خوردند. او به پست وبلاگ جان رسیگ (JavaScript Micro-Templating) رسید، آن را کمی تغییر داد و در ۲۰ خط جا گرفت. در این مقاله همان موتور قدم‌به‌قدم بازسازی می‌شود.

هدف ما تابعی است که یک قالب و داده می‌گیرد و خروجیِ نهایی را برمی‌گرداند:

javascriptvar TemplateEngine = function(tpl, data) {
    // جادو اینجاست ...
}
var template = 'Hello, my name is <%name%>. I\'m <%age%> years old.';
console.log(TemplateEngine(template, {
    name: "Krasimir",
    age: 29
}));
// خروجی: Hello, my name is Krasimir. I'm 29 years old.

۲. رگکس و گرفتن همهٔ جای‌نگه‌دارها

اولین قدم، یافتنِ تکه‌های پویا داخل قالب است. با رگکس شروع می‌کنیم — عبارتی که همهٔ بخش‌های بین <% و %> را می‌گیرد، و با پرچمِ g (سراسری) همهٔ تطبیق‌ها را، نه فقط اولی:

javascriptvar re = /<%([^%>]+)?%>/g;
var match = re.exec(tpl);
// match شامل: "<%name%>" ، "name" ، index و input می‌شود

// برای پردازشِ همهٔ تطبیق‌ها داخل حلقهٔ while
var re = /<%([^%>]+)?%>/g, match;
while(match = re.exec(tpl)) {
    console.log(match);   // هم <%name%> و هم <%age%> دیده می‌شوند
}

۳. چرا جایگزینی ساده کافی نیست؟

ساده‌ترین راه، tpl.replace(match[0], data[match[1]]) است — جواب می‌دهد اما فقط برای دادهٔ صاف و یک‌سطحی. اگر دادهٔ ما تودرتو باشد، مثلاً { profile: { age: 29 } } و در قالب <%profile.age%> بنویسیم، عبارتِ data["profile.age"] حاصل می‌شود که undefined است. راه درست؟ بین <% و %> کد واقعی جاوااسکریپت بگذاریم که در برابر داده اجرا شود؛ مثلِ <%this.profile.age%>. و برای این‌کار به new Function نیاز داریم: ساختِ تابع از رشته:

javascriptvar fn = new Function("arg", "console.log(arg + 1);");
fn(2); // خروجی: 3  — معادلِ fn = function(arg) { console.log(arg + 1); }

۴. مونتاژ بدنهٔ تابع: حلقه‌ها قالب را می‌شکنند

حالا باید بدنهٔ تابع را «بسازیم». اگر فقط با + رشته‌ها را کنار هم بچسبانیم، وقتی کاربر داخل قالب حلقه بنویسد خراب می‌شود:

javascriptvar template =
'My skills:' +
'<%for(var index in this.skills) {%>' +
'<%this.skills[index]%>' +
'<%}%>';

چسباندن با + به return 'My skills:' + for(...) { + ...} می‌رسد که خطای سینتکس می‌دهد. راه‌حل جان رسیگ: همهٔ قطعه‌ها را در یک آرایه بریزیم و آخر کار join کنیم — آن‌وقت کدهای کنترلی می‌توانند «مستقیم» داخل متد بروند:

javascriptvar r = [];
r.push('My skills:');
for(var index in this.skills) {
    r.push(this.skills[index]);
}
return r.join('');

برای تولید این‌دست کد، از یک متغیرِ cursor استفاده می‌کنیم که «کجا در قالب هستیم» را نشان می‌دهد و یک تابع add که خط به خط به code اضافه می‌کند. جای‌نگه‌دارها «کد» هستند (نباید داخل کوتیشن بروند)، بقیهٔ متن «رشته» است (باید کوتیشن بگیرد و گریزِ " شود):

javascriptvar TemplateEngine = function(tpl, data) {
    var re = /<%([^%>]+)?%>/g,
        code = 'var r=[];\n',
        cursor = 0, match;
    var add = function(line, js) {
        js ? code += 'r.push(' + line + ');\n'
           : code += 'r.push("' + line.replace(/"/g, '\\"') + '");\n';
    }
    while(match = re.exec(tpl)) {
        add(tpl.slice(cursor, match.index));
        add(match[1], true);            // محتویات جای‌نگه‌دار کد است
        cursor = match.index + match[0].length;
    }
    add(tpl.substr(cursor, tpl.length - cursor));
    code += 'return r.join("");';
    return new Function(code.replace(/[\r\t\n]/g, '')).apply(data);
}

خروجیِ new Function بدون آرگومان ساخته شده و با apply(data) صدا زده می‌شود؛ «این» داخل بدنهٔ تابع به دادهٔ ما اشاره می‌کند — به همین دلیل <%this.name%> کار می‌کند.

۵. پشتیبانی از منطق: if/else و حلقه

با همان مثالِ حلقه، خروجیِ فعلی خطای Unexpected token for می‌دهد؛ چون خطِ for(...) { نباید r.push(...) شود؛ باید «همان‌طور» داخل اسکریپت آورده شود. راه‌حل، یک رگکس دوم است که تشخیص می‌دهد کدِ داخل جای‌نگه‌دار با کلیدواژه‌های کنترل شروع می‌شود:

javascriptvar reExp = /(^( )?(if|for|else|switch|case|break|{|}))(.*)?/g;

var add = function(line, js) {
    js ? code += line.match(reExp) ? line + '\n' : 'r.push(' + line + ');\n'
       : code += 'r.push("' + line.replace(/"/g, '\\"') + '");\n';
}

حالا می‌توانید داخل قالب منطق کامل بنویسید:

javascriptvar template =
'My skills:' +
'<%if(this.showSkills) {%>' +
    '<%for(var index in this.skills) {%>' +
    '<a href="#"><%this.skills[index]%></a>' +
    '<%}%>' +
'<%} else {%>' +
    '<p>none</p>' +
'<%}%>';

۶. نسخهٔ نهایی: حتی فقط ۱۵ خط

با چند بهینه‌سازی کوچک (برگرداندنِ add برای زنجیره‌شدن و نادیده‌گرفتن خطوط خالی)، نسخهٔ نهایی نه‌تنها ۲۰ خط نیست؛ فقط ۱۵ خط است:

javascriptvar TemplateEngine = function(html, options) {
    var re = /<%([^%>]+)?%>/g, reExp = /(^( )?(if|for|else|switch|case|break|{|}))(.*)?/g,
        code = 'var r=[];\n', cursor = 0, match;
    var add = function(line, js) {
        js ? (code += line.match(reExp) ? line + '\n' : 'r.push(' + line + ');\n')
           : (code += line != '' ? 'r.push("' + line.replace(/"/g, '\\"') + '");\n' : '');
        return add;
    }
    while(match = re.exec(html)) {
        add(html.slice(cursor, match.index))(match[1], true);
        cursor = match.index + match[0].length;
    }
    add(html.substr(cursor, html.length - cursor));
    code += 'return r.join("");';
    return new Function(code.replace(/[\r\t\n]/g, '')).apply(options);
}
نکتهٔ آموزشی: این موتور «قالب را به کد ترجمه می‌کند» (compiling)، نه اینکه قالب را در لحظه تجزیه کند؛ همان منطقی که پشت موتورهای مدرن مثل EJS هم هست — و دلش می‌خواهد پاورقی‌ای به میکرو-قالب‌سازی جان رسیگ بدهید، که در آموزش بعدی همین مجموعه ترجمه شده است.
