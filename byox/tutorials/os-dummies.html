۱. رویکرد مقاله

نویسنده — همان‌طور که از عنوان «برای مبتدیان» پیداست — فرض را بر این می‌گذارد که خواننده هیچ تجربه‌ای در توسعهٔ سیستم‌عامل ندارد. مقاله با ساده‌ترین زبانی که می‌شود، سیستم‌عامل را معرفی می‌کند: «برنامه‌ای که هنگام بوت شدن اجرا می‌شود و منابع سخت‌افزاری را مدیریت می‌کند»، و سپس در چند مرحلهٔ عملی با C و اسمبلی، یک نمونهٔ بوت‌شونده می‌سازد.

۲. مراحل ساخت

  • مرحلهٔ ۱ — پیش‌نیازها: نصب کامپایلر متقاطع (gcc)، شبیه‌ساز (QEMU یا Bochs) و آشنایی با ابزارهای لازم؛ توضیح چرایی استفاده از کامپایلر متقاطع به‌جای کامپایلر معمولی.
  • مرحلهٔ ۲ — بوت‌لودر: ساخت یک بوت‌لودر ساده با اسمبلی و چاپ اولین پیام روی صفحه.
  • مرحلهٔ ۳ — ورود به حالت محافظت‌شده: GDT و پرش به حالت ۳۲-بیتی؛ توضیح سادهٔ «چرا حالت ۱۶-بیتی کافی نیست».
  • مرحلهٔ ۴ — هستهٔ C: نوشتن اولین کرنل با C، مدیریت صفحه‌نمایش و یک حلقهٔ اصلی.
  • مرحلهٔ ۵ — توسعه: افزودن ویژگی‌هایی مثل مدیریت وقفه و صفحه‌کلید با مسیرهای پیشنهادی برای ادامه.

۳. نمونهٔ کد: ساختار بوت و هسته

همان الگوی کلاسیک اما با توضیحاتی که برای مبتدی واقعاً قابل فهم است — بوت‌لودر کنترل را به تابع kernel_main در C می‌سپارد:

bash# ساخت و اجرای سریع سیستم‌عامل نمونه
nasm -f elf32 boot.asm -o boot.o
gcc -m32 -c kernel.c -o kernel.o
ld -m elf_i386 -T linker.ld boot.o kernel.o -o kernel.bin

# اجرا در شبیه‌ساز
qemu-system-i386 -kernel kernel.bin
c// kernel.c — حلقه‌ی اصلی کرنل
void kernel_main(void) {
    char *video = (char *) 0xB8000;   // حافظه‌ی ویدیویی VGA

    video[0] = 'H';
    video[1] = 0x07;                  // سفید روی مشکی
    video[2] = 'i';
    video[3] = 0x07;

    while (1) {
        __asm__("hlt");               // تا وقفه‌ی بعدی منتظر بمان
    }
}

۴. چرا برای شروع خوب است؟

  • زبان ساده و گرم: مفاهیم سخت سیستم‌عامل بدون اصطلاحات خشک دانشگاهی توضیح داده شده.
  • گام‌های کوتاه: هر مرحله نتیجهٔ قابل مشاهده دارد و سریع انگیزه می‌دهد.
  • مسیر ادامه: نویسنده در پایان، منابع پیشنهادی برای ادامهٔ مسیر داده است.
نکتهٔ تکمیلی: اگر بعد از این مقاله هنوز احساس می‌کنید برخی مفاهیم (GDT، وقفه‌ها) مبهم‌اند، آموزش os-tutorial در همین مجموعه با درس‌های ریزتر دقیقاً همین مسیر را قدم‌به‌قدم می‌پیماید.
کپیرایت: مقالهٔ «Operating Systems Development for Dummies» اثر لئو وایتهد (Leo Whitehead) است و در Medium منتشر شده. این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
