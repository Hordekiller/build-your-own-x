سرویس کوتاه‌کننده چه کاری می‌کند؟

یک URL بلند (مثلاً خبر یا صفحهٔ فروشگاه) داده می‌شود و سرویس یک کد کوتاه مثل `abc123` برمی‌گرداند. سپس با درخواست `GET /abc123`، کاربر با `301 Redirect` به لینک اصلی می‌رود. خبر خوب این است که خود نوع «کوتاه شدن» با یک نگاشت در Redis/DB حل می‌شود.

ایدهٔ کلیدی: کدگذاری Base62

از اعداد صعودی (مثلاً شمارنده در Redis با INCR) استفاده می‌کنیم و عدد را به الفبای ۶۲ کاراکتری (a-z، A-Z، 0-9) ترجمه می‌کنیم تا کد کوتاه و مرتب شود:

Nimconst Alphabet = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789"

# تبدیل عدد به کد base62
proc toBase62(num: int): string =
  var n = num
  while n > 0:
    result.add(Alphabet[n mod 62])
    n = n div 62
  result.reverse()   # کم‌ارزش‌ترین رقم آخر

# تبدیل کد به عدد (برای دیکدر / جست‌وجو)
proc fromBase62(code: string): int =
  for c in code:
    result = result * 62 + Alphabet.find(c)

با ۷ کاراکتر، ۶۲^۷ ≈ ۳.۵ تریلیون لینک ممکن است؛ یعنی برای هر کاربرد عملی کافی است.

سرویس HTTP

نیم‌قسمت HTTP: دو مسیر اصلی. `GET /` فرم کوتاه‌کردن را نشان می‌دهد؛ `POST /shorten` لینک را ثبت می‌کند؛ و `GET /<code>` مسیر را به مقصد هدایت می‌کند. برای ماندگاری شمارنده‌ها از Redis استفاده می‌شود:

Nimproc shortenHandler(req: Request, resp: Response) =
  let longUrl = req.body["url"]
  # شمارنده را در Redis یک واحد بالا ببر
  let id = redis.incr("url_counter")
  let code = toBase62(id)
  # نگاشت کد → URL را هم ذخیره کن
  redis.set("short:" & code, longUrl)
  resp.send("لینک کوتاه: /" & code)

proc redirectHandler(code: string, resp: Response) =
  let target = redis.get("short:" & code)
  if target.isEmpty:
    resp.send("یافت نشد", Http404)
  else:
    resp.redirect(target, Http301)   # هدایت دائمی

استفاده از `301` مهم است: موتورهای جست‌وجو آن را «انتقال دائمی محتوا» می‌دانند و رتبهٔ صفحه را منتقل می‌کنند.

چالش‌های دنیای واقعی

برای سرویس واقعی: اعتبارسنجی URL، محافظت از spam (همه لینک‌ها به سایت‌های بد نروند)، محدودیت نرخ، و آمار کلیک. اما هستهٔ سرویس — شمارنده + Base62 + redirect — دقیقاً همین‌جا نشان داده شد و در کمتر از ۱۰۰ خط کامل می‌شود.

کپیرایت: احمد منصور (xmonader). این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
