BYTEPATH — آموزش ساخت کامل یک بازی با Lua و LÖVE (a327ex)

⚙ زبان: Lua ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه معرفی و مرور فارسی مجموعه‌آموزش BYTEPATH اثر a327ex است که در بخش issues وبلاگ گیت‌هاب او (github.com/SSYGEN/blog) منتشر شده — یک سری کامل بازی‌سازی با Lua و LÖVE (Love2d) که به یک بازی واقعی شبیه «Bit Blaster XL + درخت مهارت Path of Exile» ختم می‌شود.

۱. دربارهٔ آموزش

BYTEPATH یک سری آموزشی پانزده قسمتی است که یک بازی کامل شوتر فضایی با سیستم درخت مهارت را می‌سازد — ترکیبی از Bit Blaster XL و درخت پسیو Path of Exile. مخاطب: برنامه‌نویسانی با کمی تجربه (نه کاملاً مبتدی). همهٔ قسمتها در issues وبلاگ a327ex (SSYGEN/blog) قابل خواندن است و هر قسمت کد کامل دارد.

نکته: ساختار سری عالی است: هر قسمت یک سیستم مستقل (حرکت، دشمنان، امتیاز، درخت مهارت، ذخیرهٔ بازی) و در مجموع معماری یک بازی کامل را نشان می‌دهد.

۲. نقشهٔ قسمتها

  • #0 مقدمه و ساختار پروژه
  • سیستم حرکت بازیکن، شلیک و دشمنان
  • الگوها و subs (مواد مصرفی)
  • سیستم مهارت: درخت مهارت با node ها و پیشرفت
  • حالت‌های بازی، ذخیره‌سازی، مپ و افکت‌ها
  • و… تا یک بازی کامل و صفحه‌بندی‌شده

۳. نمونهٔ کد

lua-- حرکت بازیکن (سبک قوس‌دار)
function Player:update(dt)
    -- فیزیک با شتاب/میرایی به‌جای سرعت ثابت
    local move_speed = self.stats.move_speed
    if input:down('left') then self.vx = self.vx - move_speed * dt end
    if input:down('right') then self.vx = self.vx + move_speed * dt end
    if input:down('up') then self.vy = self.vy - move_speed * dt end
    if input:down('down') then self.vy = self.vy + move_speed * dt end

    -- میرا کردن حرکت: به‌تدریج به صفر برگرد
    self.vx = self.vx * (1 - 0.5 * dt)
    self.vy = self.vy * (1 - 0.5 * dt)

    self.x = self.x + self.vx * dt
    self.y = self.y + self.vy * dt
end

-- درخت مهارت: هر کاربر یک node دارد و node ها به هم وصل‌اند
SkillTree = {}
function SkillTree:new(skills)
    self.skills = skills   -- جدول node ها
    self.owners = {}       -- هر node صاحب دارد؟
end

۴. جمع‌بندی

این سری یکی از کامل‌ترین آموزش‌های بازی‌سازی با LÖVE است و در طول آن همهٔ مهارت‌های یک توسعه‌دهندهٔ بازی (نسبت‌ها، سیستم‌ها، مدیریت state، UI) را با هم تمرین می‌کنید. پیاده‌سازی درخت مهارت، به‌تنهایی یک پروژهٔ آموزشی ارزشمند است.

کپیرایت: سری BYTEPATH اثر a327ex است و در وبلاگ گیت‌هاب او (github.com/SSYGEN/blog) منتشر شده. این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل سری به گیت‌هاب مراجعه کنید.
