ساختن سیستمی شبیه کافکا از صفر — راهنمای گام‌به‌گام

اگر به دنبال درک واقعی معماری کافکا هستید و می‌خواهید با پیاده‌سازی نسخه‌ای ساده‌شده از آن، این کار را انجام دهید، به جای درستی آمده‌اید. به‌جای اینکه فقط کد را کپی کنیم، «سیمپل‌کافکا (SimpleKafka)» را به‌صورت تدریجی می‌سازیم و در هر مرحله، هر کامپوننت را می‌فهمیم. این رویکرد درک عمیقی از سیستم‌های پیام‌رسان توزیع‌شده به شما می‌دهد.

خلاصهٔ گردش کار

این رویکردِ مرحله‌به‌مرحله به شما اجازه می‌دهد هر کامپوننت یک سیستم شبیه‌کافکا را از مرحلهٔ ۱ تا ۷ به‌تفصیل بسازید و بفهمید:

  1. راه‌اندازی ساختار پروژه
  2. ایجاد لایهٔ اصلی پروتکل
  3. پیاده‌سازی یکپارچه‌سازی ZooKeeper
  4. ساخت لایهٔ ذخیره‌سازی
  5. ساخت بروکر (Broker)
  6. توسعهٔ کتابخانهٔ کلاینت
  7. ساخت APIهای سطح‌بالاتر تولیدکننده و مصرف‌کننده
  8. آزمایش سیستم

مرحله‌های ۱ تا ۷

برای مرحله‌های ۱ تا ۷، مقالهٔ گام‌به‌گام و مفصل Medium را دنبال کنید و هم‌زمان ریپازیتوری گیت‌هاب را مرجع بگیرید. این ترکیب به شما کمک می‌کند به‌صورت منظم در هر بخش پیش بروید.

با ساختن هر کامپوننت به‌صورت دستی، درک عمیقی از معماری کافکا و تصمیم‌های طراحی پشت آن به دست می‌آورید. این دانش وقتی با کافکای واقعی کار می‌کنید یا سیستم‌های توزیع‌شدهٔ خودتان را طراحی می‌کنید، فوق‌العاده ارزشمند خواهد بود.

آزمایش سیستم

۱. کامپایل پروژه با Maven:

bashmvn clean package

۲. راه‌اندازی ZooKeeper

bash# راه‌اندازی ZooKeeper با پیکربندی پیش‌فرض
zkServer start

# اگر جواب نداد، این را امتحان کنید:
zookeeper-server-start /usr/local/etc/kafka/zookeeper.properties

# یا یک فایل کانفیگ ساده بسازید:
echo "tickTime=2000" > zk.cfg
echo "dataDir=/tmp/zookeeper" >> zk.cfg
echo "clientPort=2181" >> zk.cfg
zookeeper-server-start zk.cfg

۳. راه‌اندازی چند نمونه بروکر

bash# ترمینال ۱ — بروکر ۱
java -cp target/simple-kafka-1.0-SNAPSHOT.jar com.simplekafka.broker.SimpleKafkaBroker 1 localhost 9091 2181

# ترمینال ۲ — بروکر ۲
java -cp target/simple-kafka-1.0-SNAPSHOT.jar com.simplekafka.broker.SimpleKafkaBroker 2 localhost 9092 2181

# ترمینال ۳ — بروکر ۳
java -cp target/simple-kafka-1.0-SNAPSHOT.jar com.simplekafka.broker.SimpleKafkaBroker 3 localhost 9093 2181

۴. تولید پیام

bashjava -cp target/simple-kafka-1.0-SNAPSHOT.jar com.simplekafka.client.SimpleKafkaProducer localhost 9091 test-topic

۵. مصرف پیام

bashjava -cp target/simple-kafka-1.0-SNAPSHOT.jar com.simplekafka.client.SimpleKafkaConsumer localhost 9091 test-topic 0

مفاهیم کلیدی برای تمرکز در هنگام آزمایش

۱. پارتیشن‌بندی تاپیک و تکثیر (Replication)

تماشا کنید که چطور یک تاپیک به پارتیشن‌ها تقسیم می‌شود و آن پارتیشن‌ها چطور بین بروکرها توزیع می‌شوند.

۲. مکانیک لیدر و فالوور

  • چطور یک بروکر لیدر می‌شود
  • چطور فالوورها داده را از لیدر تکثیر می‌کنند
  • وقتی لیدر از کار می‌افتد و لیدر جدیدی انتخاب می‌شود چه اتفاقی می‌افتد

۳. نقش کنترلر (Controller)

  • کنترلر از طریق ZooKeeper انتخاب می‌شود
  • مدیریت تخصیص پارتیشن‌ها را بر عهده دارد
  • خرابی بروکرها را مدیریت می‌کند
  • اگر کنترلر جاری از کار بیفتد، کنترلر جدیدی انتخاب می‌شود

۴. ماندگاری پیام (Message Persistence)

  • ساختار سگمنت لاگ (Log Segment)
  • چطور پیام‌ها به‌صورت ترتیبی append می‌شوند
  • چطور ایندکس‌ها آفست‌ها را به موقعیت‌های فایل نگاشت می‌کنند

۵. پروتکل کلاینت-بروکر

  • فرمت پروتکل باینری
  • الگوهای درخواست/پاسخ (Request/Response)
  • چطور کلاینت‌ها بروکرهای درست را پیدا و به آن‌ها متصل می‌شوند

درباره پروژه

پروژهٔ «SimpleKafka» یک پیاده‌سازی آموزشی و ساده‌شده از یک سیستم پیام‌رسان توزیع‌شده شبیه کافکا است که با جاوا و Maven ساخته شده. ساختار آن شامل پکیج‌هایی برای بروکر، کلاینت و لایه‌های ذخیره‌سازی است و با ZooKeeper برای انتخاب لیدر و مدیریت کنترلر یکپارچه می‌شود. مخزن با مجوز MIT منتشر شده است.
