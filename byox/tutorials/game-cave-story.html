بازسازی Cave Story — پلی‌لیست ویدیویی کامل

⚙ زبان: C++ 🎥 ویدیو (پلی‌لیست یوتیوب) ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه معرفی و مرور فارسی پلی‌لیست ویدیویی «Cave Story Remake/Reconstruction» است — یک بازسازی کامل از بازی Cave Story در C++ که همهٔ بخش‌های بازی (و نه فقط نمونهٔ اولیه) را پوشش می‌دهد.
↗ مشاهده منبع اصلی

۱. دربارهٔ پلی‌لیست

این پلی‌لیست یک پروژهٔ بلندمدت بازسازی است: Cave Story به‌طور کامل — از راه‌اندازی موتور تا مراحل، دشمنان، سلاح‌ها و باس‌فایت‌ها — در C++ ساخته می‌شود. برخلاف ویدیوی تک‌جلسه‌ای، این سری به عمق مکانیک‌های بازی می‌رود: سیستم سلاح با سه سطح ارتقا، موتور گفتگو (dialogue)، پورتال‌ها، ذخیرهٔ بازی و حتی صداها.

نکته: اگر ویدیوی «Cavestory Part 1» را دیده‌اید و می‌خواهید پروژه را تا انتها ببینید، این پلی‌لیست تکمیل‌کنندهٔ آن است.

۳. اجزای بازی که ساخته می‌شوند

نمونه‌ای از منطق سیستم‌هایی که در طول سری پیاده می‌شوند — ارتقای سلاح با جمع‌آوری کریستال:

cpp// سیستم سلاح سه‌سطحی (شبیه Cave Story)
class Weapon {
public:
  int level;        // ۱، ۲ یا ۳
  int exp;          // تجربه برای ارتقا

  void addExp(int amount) {
    exp += amount;
    if (exp >= REQUIREMENTS[level] && level < 3) {
      exp -= REQUIREMENTS[level];
      level++;      // ارتقا
    }
  }

  void takeDamage() {
    // وقتی آسیب می‌بینید، تجربه کم می‌شود و سطح ممکن است بیفتد
    exp -= PENALTY;
    if (exp < 0 && level > 1) { level--; exp = REQUIREMENTS[level]; }
  }
};

بخش‌های دیگر سری: ساخت نقشه با ادیتور، مدیریت تریگرها، درهای مخفی، دشمنان با رفتار متفاوت (پرنده‌ها، شناگرها، توپ‌اندازها)، مکانیک آسیب و سلامت، گفتگو با NPC ها و گیم‌پلی کامل نبرد باس.

۴. جمع‌بندی

اگر می‌خواهید ببینید یک بازی واقعی و کامل — با همهٔ سیستم‌هایش — چطور ساخته می‌شود، این پلی‌لیست یکی از بهترین منابع است. شروع آن نیازمند سطح متوسط C++ است و در انتها یک بازسازی قابل بازی از Cave Story خواهید داشت.

کپیرایت: پلی‌لیست «Cave Story» اثر سازندهٔ کانال یوتیوب است و بازی Cave Story متعلق به Daisuke "Pixel" Amaya است. این صفحه فقط ترجمهٔ فارسی و مرور آن است. برای مشاهدهٔ اصل ویدیوها به یوتیوب مراجعه کنید.
