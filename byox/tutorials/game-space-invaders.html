Space Invaders از صفر — ساخت با OpenGL مدرن (3.3) در C++

⚙ زبان: C++ ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور مقالهٔ «Space Invaders from Scratch» از نیک تازیوس (Nick Tasios) در وبلاگ nicktasios.nl است — یک بازسازی کامل از بازی کلاسیک فضایی با OpenGL 3.3، GLFW و GLEW.
↗ مشاهده منبع اصلی

۱. دربارهٔ آموزش

Space Invaders (۱۹۷۸) یکی از ساده‌ترین و در عین حال کامل‌ترین بازی‌ها برای بازسازی است. این آموزش آن را با OpenGL 3.3 (خط لولهٔ مدرن با شیدرهای GLSL) می‌سازد — نه OpenGL قدیمی. ابزارها: GLFW برای پنجره و ورودی و GLEW برای بارگذاری توابع OpenGL. نتیجه: یک بازی قابل اجرا با تکنیک‌های گرافیک مدرن.

نکته: این سری برای کسانی عالی است که هم می‌خواهند بازی بسازند و هم OpenGL مدرن را جدی یاد بگیرند؛ هم شیدر می‌نویسید، هم VBO/VAO راه می‌اندازید.

۲. ساختار سری

  • قسمت ۱: راه‌اندازی پنجره با GLFW، بافرها و اولین شیدر
  • قسمت ۲: رسم بازی‌گر (هاورکرافت) و فیزیک حرکت
  • قسمت ۳: گلوله‌ها و شلیک
  • قسمت ۴: دشمنان — حرکت، بازتاب و حذف
  • بعد از آن: برخورد، امتیاز، سطوح و سبک بازی کلاسیک

۳. نمونهٔ کد: رندر با شیدر

cpp// یک چهارضلعی ساده با VBO و شیدر
float vertices[] = {
  // موقعیت    // رنگ
  -0.5f, -0.5f, 1.0f, 1.0f, 1.0f,
   0.5f, -0.5f, 1.0f, 1.0f, 1.0f,
   0.5f,  0.5f, 1.0f, 1.0f, 1.0f,
  -0.5f,  0.5f, 1.0f, 1.0f, 1.0f,
};
unsigned int indices[] = { 0, 1, 2, 2, 3, 0 };

GLuint VBO, VAO, EBO;
glGenVertexArrays(1, &VAO);
glGenBuffers(1, &VBO);
glGenBuffers(1, &EBO);

glBindVertexArray(VAO);
glBindBuffer(GL_ARRAY_BUFFER, VBO);
glBufferData(GL_ARRAY_BUFFER, sizeof(vertices), vertices, GL_STATIC_DRAW);
glBindBuffer(GL_ELEMENT_ARRAY_BUFFER, EBO);
glBufferData(GL_ELEMENT_ARRAY_BUFFER, sizeof(indices), indices, GL_STATIC_DRAW);

// صفت‌ها: موقعیت (۳ عدد) و رنگ (۳ عدد)
glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 6 * sizeof(float), (void*)0);
glEnableVertexAttribArray(0);
glVertexAttribPointer(1, 3, GL_FLOAT, GL_FALSE, 6 * sizeof(float), (void*)(3 * sizeof(float)));
glEnableVertexAttribArray(1);

بعد از آن، همهٔ اشیای بازی (بازیکن، دشمنان، گلوله‌ها) با همین الگوی VAO/VBO و یک شیدر واحد رسم می‌شوند؛ فقط موقعیت‌شان با uniform به‌روز می‌شود.

۴. جمع‌بندی

این آموزش، هم معرفی کامل OpenGL مدرن است و هم یک بازی کلاسیک کارا. کد کامل سری در گیت‌هاب نویسنده موجود است و در انتها می‌توانید آن را با صداها و سطوح جدید گسترش دهید.

کپیرایت: مقالهٔ «Space Invaders from Scratch» اثر نیک تازیوس (Nick Tasios) است و در وبلاگ nicktasios.nl منتشر شده. این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
