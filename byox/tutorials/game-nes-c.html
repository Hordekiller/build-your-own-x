۱. چرا NES؟

کنسول NES محدودیت‌های سخت‌افزاری بسیار سخت‌گیرانه‌ای دارد: پردازندهٔ Ricoh 2A03 (یک کلون از 6502 با فرکانس ۱٫۷۹ مگاهرتز)، ۲ کیلوبایت RAM و یک چیپ گرافیکی جدا (PPU). ساختن بازی برای چنین سخت‌افزاری، درک عمیقی از برنامه‌نویسی سطح پایین، مدیریت حافظه و طراحی محدودیت‌محور می‌دهد — و چالش آن لذت‌بخش است!

نکته: برای شروع، نیازی به سخت‌افزار واقعی نیست؛ بازی‌ها را با شبیه‌سازها (مثل Mesen یا FCEUX) اجرا می‌کنید.

۲. ساختار آموزش‌ها

آموزش‌های nesdoug با درس‌های شماره‌دار (۰۱ تا ۲۴ و…) پیش می‌روند؛ هر درس یک موضوع مستقل دارد:

  • راه‌اندازی پروژه با cc65 و ساخت اولین خروجی (فایل .nes)
  • انتظار برای v-blank (ناحیهٔ پنهان صفحه) و ساخت فلیپ‌فلاپ رندر
  • کار با nametableها، صفات (attributes) و رنگ‌ها
  • خواندن کنترلر (دکمه‌های A/B/Select/Start و جهت‌ها)
  • اسپرایت‌ها (OAM) و صدمات برخورد اسپرایت با اسپرایت
  • افکت‌های صفحه‌نمایش (scroll و split screen)
  • کار با mapperها (MMC1، MMC3) و نوارهای بزرگ‌تر
  • زاپر (اسلحهٔ نوری)، Power Pad و …

۳. یک نمونهٔ ساده: اسپرایت و حرکت

c// ساختار سادهٔ یک اسپرایت در OAM (RAM صفت اسپرایت)
// هر اسپرایت ۴ بایت: موقعیت y، شمارهٔ تایل، صفت‌ها، موقعیت x
struct sprite {
  unsigned char y;
  unsigned char tile;
  unsigned char attr;
  unsigned char x;
};

// متغیر OAM سراسری — ۶۴ اسپرایت
struct sprite sprites[64];

// نمونه: حرکت اسپرایت با کنترلر
void move_sprite(void) {
  // خواندن ورودی: bit های کنترلر
  if (pad & PAD_LEFT)  sprites[0].x -= 1;
  if (pad & PAD_RIGHT) sprites[0].x += 1;
  if (pad & PAD_UP)    sprites[0].y -= 1;
  if (pad & PAD_DOWN)  sprites[0].y += 1;
}

برای کار با تایل‌ها، دو منطقهٔ حافظه مهم است: CHR-ROM (جایی که تایل‌های ۸×۸ پیکسلی ذخیره‌اند) و nametable (که می‌گوید کدام تایل کجا نمایش داده شود). گرافیک NES یعنی چیدن تایل‌های ۸×۸ در یک شبکهٔ ۳۲×۳۰.

۴. ابزارها

  • cc65: کامپایلر C که به زبان اسمبلی 6502 خروجی می‌دهد (با ld65 برای لینک).
  • اسپریت‌سازها و ادیتورهای تایل برای ساخت گرافیک CHR.
  • ابزارهایی مانند Nesst برای چیدن نقشهٔ نَم‌تیبل.

۵. جمع‌بندی

آموزش‌های nesdoug شاید بهترین منبع رایگان برای شروع برنامه‌نویسی NES به زبان C باشند. با ساخت چند بازی ساده (مثل پنگ، مار و پلتفرمر)، هم تاریخچهٔ بازی‌سازی را درک می‌کنید و هم مهارت‌های سطح پایین‌تان تقویت می‌شود.

کپیرایت: وبلاگ و آموزش‌های Nesdoug اثر داگ (Nesdoug) است و تمام حقوق آن متعلق به اوست. این صفحه فقط ترجمهٔ فارسی و مرور آن است. برای مشاهدهٔ اصل آموزش‌ها به سایت اصلی مراجعه کنید.
