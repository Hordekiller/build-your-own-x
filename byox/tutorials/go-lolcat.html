ساخت یک اپلیکیشن خط فرمان با Go: lolcat

منبع اصلی: این صفحه ترجمه فارسی مقاله «Build a Command line app with Go: lolcat» نوشته «فلاویو کوپس (Flavio Copes)» است. نسخه کامل و به‌روز را از سایت اصلی بخوانید.
↗ مشاهده منبع اصلی

مقدمه

یاد بگیرید چگونه یک ابزار خط فرمان (CLI) از نوع lolcat در Go بسازید که متن را با کدهای گریز ANSI و یک تابع rgb() رنگین‌کمانی می‌کند و به‌صورت یک پایپ (pipe) عمل می‌کند که از stdin می‌خواند.

نکته: به اپلیکیشن‌های خط فرمان علاقه دارید؟ آموزش cowsay را هم از دست ندهید!

داشتم دنبال اپلیکیشن‌های ترمینال می‌گشتم تا الهام بگیرم که به lolcat برخوردم.

نسخهٔ اصلی آن در https://github.com/busyloop/lolcat است و همین حالا هم پیاده‌سازی‌های Go متعددی برای آن وجود دارد:

  • https://github.com/cezarsa/glolcat
  • https://github.com/latotty/lolcat
  • https://github.com/lalyos/lolcat
  • https://github.com/vbatts/gogololcat

به نظر می‌رسد ساختنش کاملاً بی‌فایده باشد؛ پس بیایید آن را بسازیم!

بیایید با چاپ چند مقدار روی صفحه شروع کنیم؛ سپس به سراغ رنگ‌آمیزی آن‌ها می‌رویم و در نهایت بررسی می‌کنیم که چگونه ورودی کاربر را بپذیریم تا به‌عنوان یک پایپ کار کند.

تولید خروجی ساختگی با faker

برای تولید خروجی ساختگی از https://github.com/enodata/faker استفاده می‌کنم.

shellgo get -u github.com/enodata/faker

این برنامه تعدادی عبارت تولید می‌کند:

gopackage main

import (
    "fmt"
    "strings"

    "github.com/enodata/faker"
)

func main() {
    var phrases []string

    for i := 1; i < 3; i++ {
        phrases = append(phrases, faker.Hacker().Phrases()...)
    }

    fmt.Println(strings.Join(phrases[:], "; "))
}

افزودن رنگ

متأسفانه، این همه سیاه‌وسفید خسته‌کننده است. بیایید کمی رنگ اضافه کنیم. می‌توانیم این کار را با پیشوند قرار دادن یک دنبالهٔ کاراکتر گریز (escape character sequence) در fmt.Printf انجام دهیم. این کار همهٔ رشته‌ها را به رنگ طلایی #FFD700 چاپ می‌کند که کد رنگ RGB آن (255,215,0) است:

gopackage main

import (
    "fmt"
    "strings"

    "github.com/enodata/faker"
)

func main() {
    var phrases []string

    for i := 1; i < 3; i++ {
        phrases = append(phrases, faker.Hacker().Phrases()...)
    }

    output := strings.Join(phrases[:], "; ")
    r, g, b := 255, 215, 0 // رنگ طلایی

    for j := 0; j < len(output); j++ {
        fmt.Printf("\033[38;2;%d;%d;%dm%c\033[0m", r, g, b, output[j])
    }
}

رنگین‌کمان

حالا که یک رشته در دست داریم و زیرساخت لازم برای رنگ‌کردن هر کاراکتر به شکلی متفاوت را ساخته‌ایم، وقت آن رسیده است که رنگین‌کمان را معرفی کنیم.

gopackage main

import (
    "fmt"
    "math"
    "strings"

    "github.com/enodata/faker"
)

func rgb(i int) (int, int, int) {
    var f = 0.1
    return int(math.Sin(f*float64(i)+0)*127 + 128),
        int(math.Sin(f*float64(i)+2*math.Pi/3)*127 + 128),
        int(math.Sin(f*float64(i)+4*math.Pi/3)*127 + 128)
}

func main() {
    var phrases []string

    for i := 1; i < 3; i++ {
        phrases = append(phrases, faker.Hacker().Phrases()...)
    }

    output := strings.Join(phrases[:], "; ")

    for j := 0; j < len(output); j++ {
        r, g, b := rgb(j)
        fmt.Printf("\033[38;2;%d;%d;%dm%c\033[0m", r, g, b, output[j])
    }
    fmt.Println()
}

این دیگر استایل است!

رنگ رنگین‌کمانی با تابع rgb() تولید می‌شود؛ همان‌طور که در کد منبع اصلی Ruby در https://github.com/busyloop/lolcat/blob/master/lib/lolcat/lol.rb پیاده‌سازی شده است.

کار به‌صورت پایپ (Pipe)

حالا بیایید برنامه را ویرایش کنیم و به‌جای اینکه خروجی خودش را تولید کند، بگذاریم به‌عنوان یک پایپ برای برنامه‌های دیگر کار کند. محتوا را از os.Stdin می‌خواند و آن را رنگین‌کمانی می‌کند.

gopackage main

import (
    "bufio"
    "fmt"
    "io"
    "math"
    "os"
)

func rgb(i int) (int, int, int) {
    var f = 0.1
    return int(math.Sin(f*float64(i)+0)*127 + 128),
        int(math.Sin(f*float64(i)+2*math.Pi/3)*127 + 128),
        int(math.Sin(f*float64(i)+4*math.Pi/3)*127 + 128)
}

func print(output []rune) {
    for j := 0; j < len(output); j++ {
        r, g, b := rgb(j)
        fmt.Printf("\033[38;2;%d;%d;%dm%c\033[0m", r, g, b, output[j])
    }
    fmt.Println()
}

func main() {
    info, _ := os.Stdin.Stat()
    var output []rune

    if info.Mode()&os.ModeCharDevice != 0 {
        fmt.Println("The command is intended to work with pipes.")
        fmt.Println("Usage: fortune | gorainbow")
    }

    reader := bufio.NewReader(os.Stdin)
    for {
        input, _, err := reader.ReadRune()
        if err != nil && err == io.EOF {
            break
        }
        output = append(output, input)
    }

    print(output)
}

هر بار یک رون (rune) از os.Stdin می‌خواند و آن را به برش (slice) رون‌های output اضافه می‌کند.

رندر کردن خروجی به تابع print() منتقل شده است؛ اما می‌توانیم هر رون را همان لحظه که خوانده می‌شود، «درجا» (just in time) پایپ کنیم:

gopackage main

import (
    "bufio"
    "fmt"
    "io"
    "math"
    "os"
)

func rgb(i int) (int, int, int) {
    var f = 0.1
    return int(math.Sin(f*float64(i)+0)*127 + 128),
        int(math.Sin(f*float64(i)+2*math.Pi/3)*127 + 128),
        int(math.Sin(f*float64(i)+4*math.Pi/3)*127 + 128)
}

func main() {
    info, _ := os.Stdin.Stat()

    if info.Mode()&os.ModeCharDevice != 0 {
        fmt.Println("The command is intended to work with pipes.")
        fmt.Println("Usage: fortune | gorainbow")
    }

    reader := bufio.NewReader(os.Stdin)
    j := 0
    for {
        input, _, err := reader.ReadRune()
        if err != nil && err == io.EOF {
            break
        }
        r, g, b := rgb(j)
        fmt.Printf("\033[38;2;%d;%d;%dm%c\033[0m", r, g, b, input)
        j++
    }
}

این هم دقیقاً مثل قبل کار می‌کند.

حالا می‌توانیم با fortune و cowsay سرگرم شویم.

تبدیل به فرمان سیستمی

بیایید با اجرای go build و go install این برنامه را به یک فرمان سیستمی (system-wide command) تبدیل کنیم. این فرمان با نام gololcat اجرا خواهد شد، چون ما از همین نام برای نام‌گذاری پوشه استفاده کردیم.
