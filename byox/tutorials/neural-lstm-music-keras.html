چگونه با یک شبکهٔ عصبی LSTM در Keras موسیقی تولید کنیم

⚙ زبان: Python 🧠 LSTM + Music21 ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور مقالهٔ «How to Generate Music using a LSTM Neural Network in Keras» از سیگورور اسکولی (Sigurður Skúli) (۲۰۱۸) در Towards Data Science است که با LSTM و کتابخانهٔ Music21، موسیقی تولید می‌کند.
↗ مشاهده منبع اصلی

۱. ایده: موسیقی به‌عنوان یک «زبان»

موسیقی مانند متن، توالی‌ای از نمادهاست: نوت‌ها و آکوردها. اگر نوت‌های یک قطعه را به‌صورت پشت‌سرهم درآوریم، مسئله تبدیل می‌شود به: «با دیدن N نماد قبلی، نماد بعدی را پیش‌بینی کن» — یعنی یک مسئلهٔ مدل‌سازی توالی (sequence modeling). شبکه‌های بازگشتی (RNN) و به‌ویژه LSTM برای همین ساخته شده‌اند: حافظه‌ای درونی دارند که وابستگی‌های بلندمدت (مثل بازگشت تم اصلی بعد از چند میزان) را نگه می‌دارد.

۲. استخراج نوت‌ها از فایل MIDI با Music21

اولین گام، تبدیل فایل‌های MIDI به توالی نمادهاست. کتابخانهٔ Music21 این کار را ساده می‌کند: converter.parse() فایل را می‌خواند و flat.notes همهٔ نوت‌ها و آکوردها را به ترتیب برمی‌گرداند. هر نوت با «نام + اکتاو» (مثل D#4) و هر آکورد با فهرست نوت‌هایش (مثل D#4.F#4.A#4) نمایش داده می‌شود:

pythonfrom music21 import converter

# خواندن فایل MIDI و استخراج توالی نوت‌ها و آکوردها
notes = []
for element in converter.parse("song.mid").flat.notes:
    if element.isNote:
        notes.append(str(element.pitch))            # مثل "D#4"
    elif element.isChord:
        notes.append(".".join(str(n) for n in element.pitches))  # مثل "D#4.F#4.A#4"

print("تعداد نمادها:", len(notes), "| نمادهای یکتا:", len(set(notes)))

۳. کدگذاری نمادها و ساخت پنجره‌ها

شبکه اعداد می‌فهمد، نه رشته. پس نمادها به اندیس عددی تبدیل می‌شوند (نگاشت دیکشنری‌ای). سپس توالی به پنجره‌های هم‌پوشان تقسیم می‌شود: هر پنجرهٔ ورودی sequence_length نماد دارد و خروجی همان یک نماد بعدی است. خروجی به‌صورت one-hot کدگذاری می‌شود (بردار صفر و یک، با ۱ در جای نماد درست):

pythonsequence_length = 100  # طول حافظه: ۱۰۰ نماد قبل

network_input = []   # ورودی‌های پنجره‌ای
network_output = []  # نماد بعدی هر پنجره

for i in range(0, len(notes) - sequence_length, 1):
    seq_in = notes[i:i + sequence_length]
    seq_out = notes[i + sequence_length]
    network_input.append([note_to_int[n] for n in seq_in])
    network_output.append(note_to_int[seq_out])

# تبدیل به آرایه‌ی numpy و one-hot کردن خروجی
X = np.reshape(network_input, (len(network_input), sequence_length, 1))
X = X / float(n_vocab)                     # نرمال‌سازی ورودی
y = to_categorical(network_output, num_classes=n_vocab)

۴. معماری LSTM

مدل از دو لایهٔ LSTM و دو لایهٔ Dense ساخته می‌شود. لایهٔ LSTM دو نکتهٔ مهم دارد: return_sequences=True در لایهٔ اول تا خروجی کامل توالی به لایهٔ دوم برسد، و return_state=True در آخرین لایهٔ LSTM تا در مرحلهٔ تولید، حالت حافظه حفظ شود. خروجی نهایی با softmax توزیع احتمال روی همهٔ نمادهاست:

pythonfrom keras.models import Sequential
from keras.layers import LSTM, Dense, Dropout

model = Sequential()
model.add(LSTM(512, return_sequences=True, input_shape=(X.shape[1], X.shape[2])))
model.add(Dropout(0.3))
model.add(LSTM(512, return_state=True))   # حالت را برای تولید برمی‌گردانیم
model.add(Dropout(0.3))
model.add(Dense(256, activation="relu"))
model.add(Dense(n_vocab, activation="softmax"))

model.compile(loss="categorical_crossentropy", optimizer="rmsprop")
model.fit(X, y, epochs=200, batch_size=64)

۵. تولید موسیقی: نمونه‌گیری نماد به نماد

تولید یعنی «زنجیره‌زدن پیش‌بینی‌ها»: یک توالی تصادفی از نمادها به عنوان نقطهٔ شروع انتخاب می‌شود؛ در هر گام، شبکه توزیع احتمال نماد بعدی را می‌دهد؛ نماد بعدی با نمونه‌گیری (sampling) از این توزیع انتخاب می‌شود (نه همیشه محتمل‌ترین!) — این تصادفی‌سازی به خروجی خلاقیت می‌دهد و از تکرار بی‌پایان جلوگیری می‌کند. سپس پنجره یک نماد جلو می‌رود و همین‌طور تا رسیدن به طول دلخواه:

pythondef generate_notes(model, start, n_vocab, int_to_note):
    pattern = start.copy()
    output = []
    for _ in range(500):
        # آماده‌سازی الگوی فعلی برای شبکه
        x = np.reshape(pattern, (1, len(pattern), 1)) / float(n_vocab)
        prediction = model.predict(x, verbose=0)[0]

        # نمونه‌گیری از توزیع احتمال (با خلاقیت تصادفی)
        index = np.argmax(prediction)
        output.append(int_to_note[index])
        pattern.append(index)
        pattern = pattern[1:]   # پنجره را یک قدم جلو می‌بریم
    return output

۶. تبدیل خروجی به فایل MIDI

در پایان، توالی نمادها دوباره به یک شیء Music21 تبدیل و به‌عنوان فایل MIDI ذخیره می‌شود تا در هر نرم‌افزار موسیقی پخش شود. برای اینکه ملودی شنیدنی باشد، یک ریتم ثابت (مثلاً هر نوت یک ضرب) در نظر گرفته می‌شود:

pythonfrom music21 import stream, note, chord, tempo

def notes_to_midi(notes, output_file):
    offset = 0
    stream_notes = []
    for pattern in notes:
        if "." in pattern:          # آکورد
            notes_list = [note.Note(n) for n in pattern.split(".")]
            c = chord.Chord(notes_list)
            c.quarterLength = 0.5
            stream_notes.append(c)
        else:                       # نوت ساده
            n = note.Note(pattern)
            n.quarterLength = 0.5
            stream_notes.append(n)
        offset += 0.5

    midi_stream = stream.Stream(stream_notes)
    midi_stream.write("midi", fp=output_file)

۷. جمع‌بندی و بهبودها

  • موسیقی = توالی نماد؛ LSTM برای توالی‌ها عالی است.
  • Music21 کار خواندن/نوشتن MIDI را می‌گیرد؛ تمرکز روی مدل می‌ماند.
  • نمونه‌گیری تصادفی (به‌جای argmax همیشگی) خلاقیت تولید می‌کند.
  • بهبودها: افزودن مدت‌زمان نوت‌ها به ورودی، دو لایهٔ bidirectional، آموزش روی دیتاست بزرگ‌تر از یک آهنگ.
