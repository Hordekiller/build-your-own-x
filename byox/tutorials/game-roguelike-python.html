۱. دربارهٔ آموزش

این سایت خانهٔ یکی از معروف‌ترین آموزش‌های roguelike است: قبلاً نسخهٔ مبتنی بر libtcod داشت و در سال ۲۰۱۹ بازنویسی شد تا با python-tcod کار کند. نسخهٔ جدید معماری تمیزی دارد (تشخیص وابستگی‌ها، فایل‌های مجزا مثل engine.py) و در قسمت‌های متوالی، یک roguelike کامل می‌سازد: از رسم «@» در ترمینال تا سیستم‌های پیچیده.

نکته: بخش اول هر دو نسخه (قدیم و جدید) «رسم یک @» است؛ بعد از آن حرکت، ورودی، FOV و… — بهترین نقطهٔ شروع برای اولین roguelike پایتون.

۲. نقشهٔ قسمتها

  • رسم کاراکتر «@» و حرکت با کلید
  • ترمینال و ورودی (با tcod و keydown)
  • تولید سیاه‌چاه با اتاق‌ها و راهروها
  • میدان دید (FOV) و اکتشاف
  • برخورد، چرخهٔ نوبت و مدیریت player
  • هیولاها، حمله و آسیب
  • کنترل بازی‌های عمیق‌تر: inventory، تجهیزات، افسون‌ها
  • ذخیره‌سازی، سطوح و…

۳. نمونهٔ کد قسمت اول

python# engine.py — هستهٔ بازی (نسخهٔ جدید)
import tcod

from input_handlers import EventHandler

class Engine:
    def __init__(self, event_handler: EventHandler):
        self.event_handler = event_handler

    def handle_events(self, events) -> None:
        for event in events:
            action = self.event_handler.dispatch(event)
            if action is None:
                continue
            action.perform(self, self.player)
            # ...

def main() -> None:
    screen_width = 80
    screen_height = 50

    tileset = tcod.tileset.load_tilesheet(
        "dejavu10x10_gs_tc.png", 32, 8, tcod.tileset.CHARMAP_TCOD
    )

    with tcod.context.new_terminal(
        columns=screen_width,
        rows=screen_height,
        tileset=tileset,
        title="Roguelike من",
    ) as context:

        event_handler = EventHandler()
        engine = Engine(event_handler)

        while True:
            root_console = tcod.console.Console(screen_width, screen_height)
            # ... رسم صحنه روی کنسول ...

            context.present(root_console)  # نمایش
            events = tcod.event.wait()     # منتظر رویداد
            root_console.clear()
            engine.handle_events(events)

if __name__ == "__main__":
    main()
