ساخت یک چت‌بات هوش مصنوعی ساده با Web Speech API و Node.js

⚙ زبان: Node.js 📁 دسته: ربات ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمه فارسی مقاله «Building A Simple AI Chatbot With Web Speech API And Node.js» نوشته «تومومی ایمورا (Tomomi Imura)» در «Smashing Magazine» است. نسخه کامل و به‌روز را از سایت اصلی بخوانید.
↗ مشاهده منبع اصلی

مقدمه

با توجه به وضعیت فعلی برنامه‌های وب، می‌توانیم برای تعامل با کاربران روی عناصر رابط کاربری (user interface) مختلفی تکیه کنیم. با API گفتار وب (Web Speech API) می‌توانیم برنامه‌های وب غنی‌ای با تعاملات طبیعی کاربر و رابط بصری حداقلی بسازیم، فقط با استفاده از فرمان‌های صوتی (voice commands).

استفاده از فرمان‌های صوتی این روزها تقریباً همه‌گیر شده است؛ زیرا روزبه‌روز کاربران بیشتری از گوشی‌های موبایل برای استفاده از دستیارهای صوتی (voice assistants) مانند سیری (Siri) و کورتانا (Cortana) استفاده می‌کنند و دستگاه‌هایی مانند Amazon Echo و Google Home در حال هجوم به اتاق‌های نشیمن ما هستند. این سیستم‌ها با نرم‌افزار تشخیص گفتار (speech recognition) ساخته شده‌اند که به کاربران‌شان اجازه می‌دهد فرمان‌های صوتی صادر کنند. حالا نوبت مرورگرهای وب ماست که با Web Speech API آشنا شوند؛ APIای که به کاربران اجازه می‌دهد داده‌های صوتی را در برنامه‌های وب ادغام کنند.

این API موارد استفادهٔ بی‌شماری برای برنامه‌های وب غنی‌تر فراهم می‌کند. افزون بر این، Web Speech API می‌تواند برنامه‌های وب را در دسترس‌پذیر (accessible) کند و به افراد دارای محدودیت یا آسیب جسمی یا شناختی کمک کند. وب آینده گفتگو‌محورتر و در دسترس‌تر خواهد بود!

ارتقای تجربهٔ کاربری: Web Speech API به وب‌سایت‌ها و برنامه‌های وب امکان می‌دهد نه‌تنها با شما صحبت کنند، بلکه به شما گوش دهند. به چند نمونهٔ عالی از اینکه چگونه می‌توان از آن برای ارتقای تجربهٔ کاربری (UX) استفاده کرد نگاهی بیندازید: مقالهٔ مرتبط را بخوانید ←

در این آموزش، از API برای ساخت یک رابط چت صوتی هوش مصنوعی (AI) در مرورگر استفاده خواهیم کرد. برنامه به صدای کاربر گوش می‌دهد و با یک صدای مصنوعی پاسخ می‌دهد. چون Web Speech API همچنان آزمایشی است، برنامه فقط در مرورگرهای پشتیبانی‌کننده کار می‌کند. امکانات استفاده‌شده در این مقاله — هم تشخیص گفتار و هم تبدیل متن به گفتار (speech synthesis) — در حال حاضر فقط در مرورگرهای مبتنی بر کرومیوم (Chromium) وجود دارند، از جمله کروم ۲۵ به بعد و اپرا ۲۷ به بعد؛ در حالی که فایرفاکس، اج و سافاری فعلاً فقط از تبدیل متن به گفتار پشتیبانی می‌کنند.

(مشاهده نسخه بزرگ)

این ویدیو دمو را در مرورگر کروم نشان می‌دهد و دقیقاً همین چیزی است که در این آموزش می‌سازیم!

دموی ویدیویی: ویدیوی دموی چت‌بات روی Vimeo — «A simple AI chat bot demo with Web Speech API» در دسترس است (ویدیو را خودمان میزبانی نمی‌کنیم؛ همان منبع اصلی).

برای ساختن برنامهٔ وب، سه گام اصلی برمی‌داریم:

  1. از رابط SpeechRecognition موجود در Web Speech API برای گوش دادن به صدای کاربر استفاده می‌کنیم.
  2. پیام کاربر را به‌صورت یک رشتهٔ متنی به یک API تجاری پردازش زبان طبیعی (natural-language-processing) ارسال می‌کنیم.
  3. وقتی API.AI متن پاسخ را بازگرداند، از رابط SpeechSynthesis برای تبدیل آن به یک صدای مصنوعی استفاده می‌کنیم.

کد منبع کامل استفاده‌شده در این آموزش در GitHub در دسترس است.

پیش‌نیازها

این آموزش به Node.js وابسته است. باید با جاوااسکریپت راحت باشید و درک پایه‌ای از Node.js داشته باشید.

مطمئن شوید Node.js روی دستگاه شما نصب است و سپس شروع می‌کنیم!

راه‌اندازی برنامهٔ Node.js

اول، اجازه دهید یک چارچوب برنامهٔ وب (web app framework) با Node.js راه‌اندازی کنیم. پوشهٔ برنامهٔ خود را بسازید و ساختار برنامه را این‌گونه بچینید:

bash.
├── index.js
├── public
│   ├── css
│   │   └── style.css
│   └── js
│       └── script.js
└── views
    └── index.html

سپس، این دستور را برای مقداردهی اولیهٔ برنامهٔ Node.js اجرا کنید:

bash$ npm init -f

پرچم -f تنظیمات پیش‌فرض را می‌پذیرد؛ یا بدون این پرچم می‌توانید برنامه را به‌صورت دستی پیکربندی کنید. همچنین این کار یک فایل package.json تولید می‌کند که اطلاعات پایهٔ برنامهٔ شما را در خود دارد.

حالا، همهٔ وابستگی‌های مورد نیاز برای ساخت این برنامه را نصب کنید:

bash$ npm install express socket.io apiai --save

با افزودن پرچم --save، فایل package.json شما به‌صورت خودکار با وابستگی‌ها به‌روزرسانی می‌شود.

ما از Express — یک چارچوب سرور برنامهٔ وب Node.js — برای اجرای سرور به‌صورت محلی استفاده خواهیم کرد. برای فعال‌کردن ارتباط دوسویهٔ بلادرنگ (real-time bidirectional communication) بین سرور و مرورگر، از Socket.IO استفاده می‌کنیم. همچنین ابزار سرویس پردازش زبان طبیعی، یعنی API.AI را نصب خواهیم کرد تا یک چت‌بات هوش مصنوعی بسازیم که بتواند یک گفتگوی مصنوعی داشته باشد.

Socket.IO یک کتابخانه است که به ما امکان می‌دهد به‌سادگی با Node.js از وب‌سوکت (WebSocket) استفاده کنیم. با برقراری یک اتصال سوکت بین کلاینت و سرور، پیام‌های چت ما به محض بازگشت دادهٔ متنی از Web Speech API (پیام صوتی) یا از API API.AI (پیام «هوش مصنوعی») بین مرورگر و سرور ما ردوبدل می‌شوند.

حالا، بیایید یک فایل index.js بسازیم، Express را نمونه‌سازی کنیم و به سرور گوش دهیم:

jsconst express = require('express');
const app = express();

app.use(express.static(__dirname + '/views')); // فایل‌های html
app.use(express.static(__dirname + '/public')); // فایل‌های js، css و تصاویر

const server = app.listen(5000);
app.get('/', (req, res) => {
  res.sendFile('index.html');
});

حالا بگذارید روی برنامهٔ خودمان کار کنیم! در گام بعدی، کد فرانت‌اند را با Web Speech API یکپارچه می‌کنیم.

دریافت گفتار با رابط SpeechRecognition

Web Speech API یک رابط کنترل‌کنندهٔ اصلی به نام SpeechRecognition دارد تا گفتار کاربر را از میکروفون دریافت کند و بفهمد چه می‌گوید.

ساخت رابط کاربری

رابط کاربری این برنامه ساده است: فقط یک دکمه برای راه‌اندازی تشخیص صدا. بیایید فایل index.html را آماده کنیم و فایل جاوااسکریپت فرانت‌اند خود (script.js) و Socket.IO را — که بعداً برای فعال‌کردن ارتباط بلادرنگ از آن استفاده می‌کنیم — به آن اضافه کنیم:

html<html lang="en">
  <head>…</head>
  <body>
    …
    <script src="https://cdnjs.cloudflare.com/ajax/libs/socket.io/2.0.1/socket.io.js"></script>
    <script src="js/script.js"></script>
  </body>
</html>

سپس، یک رابط دکمه‌ای در بدنهٔ HTML اضافه کنید:

html<button>Talk</button>

برای استایل‌دادن به دکمه همان‌طور که در دمو دیده می‌شود، به فایل style.css موجود در کد منبع مراجعه کنید.

ثبت صدا با جاوااسکریپت

در script.js، یک نمونه از SpeechRecognition — رابط کنترل‌کنندهٔ Web Speech API برای تشخیص صدا — فراخوانی (invoke) کنید:

jsconst SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
const recognition = new SpeechRecognition();

ما هر دو شیءِ دارای پیشوند (prefixed) و بدون پیشوند را قرار می‌دهیم، زیرا کروم در حال حاضر API را با ویژگی‌های دارای پیشوند پشتیبانی می‌کند.

همچنین در این آموزش از بخشی از نحو (syntax) ECMAScript6 استفاده می‌کنیم؛ زیرا این نحو — از جمله const و توابع پیکانی (arrow functions) — در مرورگرهایی در دسترس است که هر دو رابط Speech API یعنی SpeechRecognition و SpeechSynthesis را پشتیبانی می‌کنند.

به‌صورت اختیاری می‌توانید انواعی از ویژگی‌ها را برای سفارشی‌سازی تشخیص گفتار تنظیم کنید:

jsrecognition.lang = 'en-US';
recognition.interimResults = false;

سپس، ارجاع DOM به دکمهٔ رابط کاربری را بگیرید و برای راه‌اندازی تشخیص گفتار به رویداد کلیک گوش دهید:

jsdocument.querySelector('button').addEventListener('click', () => {
  recognition.start();
});

وقتی تشخیص گفتار آغاز شد، از رویداد result برای بازیابی آنچه گفته شده به‌صورت متن استفاده کنید:

jsrecognition.addEventListener('result', (e) => {
  let last = e.results.length - 1;
  let text = e.results[last][0].transcript;

  console.log('Confidence: ' + e.results[0][0].confidence);

  // بعداً Socket.IO را در همین‌جا استفاده خواهیم کرد…
});

این کار یک شیء SpeechRecognitionResultList برمی‌گرداند که نتیجه را در خود دارد و می‌توانید متن را از درون آرایه بازیابی کنید. همچنین همان‌طور که در نمونهٔ کد می‌بینید، این کار confidence (ضریب اطمینان) ترانویسی (transcription) را هم برمی‌گرداند.

حالا، بیایید از Socket.IO برای انتقال نتیجه به کد سرورمان استفاده کنیم.

ارتباط بلادرنگ با Socket.IO

Socket.IO یک کتابخانه برای برنامه‌های وب بلادرنگ است. این کتابخانه ارتباط دوسویهٔ بلادرنگ بین کلاینت‌های وب و سرورها را فعال می‌کند. ما از آن برای انتقال نتیجه از مرورگر به کد Node.js و سپس بازگرداندن پاسخ به مرورگر استفاده خواهیم کرد.

شاید از خود بپرسید چرا از HTTP ساده یا AJAX استفاده نمی‌کنیم. می‌توانید داده را از طریق POST به سرور بفرستید. بااین‌حال، ما از طریق Socket.IO از وب‌سوکت استفاده می‌کنیم، زیرا سوکت‌ها بهترین راه‌حل برای ارتباط دوسویه هستند — به‌ویژه وقتی بخواهیم رویدادی را از سرور به مرورگر push کنیم. با یک اتصال سوکت پیوسته، نیازی به بارگذاری مجدد مرورگر یا ارسال مکرر درخواست AJAX در بازه‌های زمانی کوتاه نخواهیم داشت.

Socket.IO را در script.js در جایی نمونه‌سازی کنید:

jsconst socket = io();

سپس، این کد را همان‌جا که به رویداد result از SpeechRecognition گوش می‌دهید وارد کنید:

jssocket.emit('chat message', text);

حالا، برگردیم به کد Node.js تا این متن را دریافت کنیم و با هوش مصنوعی به کاربر پاسخ دهیم.

دریافت پاسخ از هوش مصنوعی

پلتفرم‌ها و سرویس‌های متعددی به شما امکان می‌دهند برنامه‌ای را با یک سیستم هوش مصنوعی با استفاده از تبدیل گفتار به متن و پردازش زبان طبیعی یکپارچه کنید — از جمله IBM Watson، Microsoft LUIS و Wit.ai. برای ساخت یک رابط گفتگومحور سریع، از API.AI استفاده خواهیم کرد؛ زیرا یک حساب توسعه‌دهندهٔ رایگان فراهم می‌کند و به ما اجازه می‌دهد به‌سرعت و با رابط وب و کتابخانهٔ Node.js آن، یک سیستم گفتگوی کوچک (small-talk) راه‌اندازی کنیم.

راه‌اندازی API.AI

وقتی حساب کاربری‌تان را ساختید، یک «عامل» (agent) ایجاد کنید. به راهنمای «شروع کار»، گام اول، مراجعه کنید.

سپس، به‌جای طی کردن مسیر سفارشی‌سازی کامل با ساخت موجودیت‌ها (entities) و نیت‌ها (intents)، اول به‌سادگی از منوی سمت چپ روی پیش‌تنظیم «Small Talk» کلیک کنید و دوم، کلید (toggle) را برای فعال‌کردن سرویس بچرخانید.

(مشاهده نسخه بزرگ)

عامل Small Talk خود را با استفاده از رابط API.AI هر‌طور که دوست دارید سفارشی کنید.

با کلیک روی آیکون چرخ‌دندهٔ کنار نام عامل خود در منو، به صفحهٔ «تنظیمات عمومی» (General Settings) بروید و کلید API خود را بگیرید. برای استفاده از SDK نود.js به «توکن دسترسی کلاینت» (client access token) نیاز خواهید داشت.

استفاده از SDK نود.js API.AI

بیایید برنامهٔ Node.js خود را با استفاده از SDK نود.js API.AI به آن وصل کنیم! به فایل index.js برگردید و API.AI را با توکن دسترسی خود مقداردهی کنید:

jsconst apiai = require('apiai')(APIAI_TOKEN);

اگر فقط می‌خواهید کد را به‌صورت محلی اجرا کنید، می‌توانید کلید API خود را همین‌جا به‌صورت سخت‌کدنویسی (hardcode) کنید. راه‌های متعددی برای تنظیم متغیرهای محیطی (environment variables) وجود دارد، اما من معمولاً یک فایل .env می‌سازم تا متغیرها را در آن قرار دهم.

حالا از Socket.IO سمت سرور برای دریافت نتیجه از مرورگر استفاده می‌کنیم.

وقتی اتصال برقرار شد و پیام دریافت شد، برای به‌دست‌آوردن پاسخی برای پیام کاربر از APIهای API.AI استفاده کنید:

jsio.on('connection', function(socket) {
  socket.on('chat message', (text) => {

    // دریافت پاسخ از API.AI

    let apiaiReq = apiai.textRequest(text, {
      sessionId: APIAI_SESSION_ID
    });

    apiaiReq.on('response', (response) => {
      let aiText = response.result.fulfillment.speech;
      socket.emit('bot reply', aiText); // ارسال نتیجه به مرورگر!
    });

    apiaiReq.on('error', (error) => {
      console.log(error);
    });

    apiaiReq.end();

  });
});

وقتی API.AI نتیجه را برمی‌گرداند، از socket.emit() موجود در Socket.IO برای ارسال آن به مرورگر استفاده کنید.

دادن صدا به هوش مصنوعی با رابط SpeechSynthesis

بار دیگر به script.js برگردیم تا برنامه را تکمیل کنیم!

یک تابع برای تولید صدای مصنوعی بسازید. این بار از رابط کنترل‌کنندهٔ SpeechSynthesis موجود در Web Speech API استفاده می‌کنیم.

این تابع یک رشته را به‌عنوان آرگومان می‌گیرد و مرورگر را قادر می‌سازد متن را بخواند:

jsfunction synthVoice(text) {
  const synth = window.speechSynthesis;
  const utterance = new SpeechSynthesisUtterance();
  utterance.text = text;
  synth.speak(utterance);
}

در این تابع، اول یک ارجاع به نقطهٔ ورود API یعنی window.speechSynthesis بسازید. شاید متوجه شده باشید که این بار هیچ ویژگی دارای پیشوندی وجود ندارد: این API پشتیبانی گسترده‌تری نسبت به SpeechRecognition دارد و همهٔ مرورگرهایی که از آن پشتیبانی می‌کنند، پیشوند را برای SpeechSynthesis حذف کرده‌اند.

سپس، با استفاده از سازندهٔ آن، یک نمونهٔ جدید SpeechSynthesisUtterance() بسازید و متنی را تنظیم کنید که هنگام بیان گفتار، سنتز (synthesise) شود. می‌توانید ویژگی‌های دیگری مانند voice را تنظیم کنید تا نوع صداهایی را که مرورگر و سیستم‌عامل باید پشتیبانی کنند انتخاب کنید.

در نهایت، از SpeechSynthesis.speak() استفاده کنید تا آن را به حرف درآورید!

حالا، بار دیگر با Socket.IO پاسخ را از سرور بگیرید. به محض دریافت پیام، تابع را صدا بزنید.

jssocket.on('bot reply', function(replyText) {
  synthVoice(replyText);
});

تمام شد! بیایید یک گفتگوی خودمانی با چت‌بات هوش مصنوعی‌مان امتحان کنیم!

نکته: توجه کنید که مرورگر اولین بار از شما اجازهٔ استفاده از میکروفون را می‌خواهد. مانند سایر APIهای وب — مانند API موقعیت‌یابی جغرافیایی (Geolocation API) و API اعلان (Notification API) — مرورگر هرگز به اطلاعات حساس شما دسترسی پیدا نمی‌کند مگر اینکه شما اجازه دهید؛ بنابراین صدای شما بدون اطلاع شما به‌صورت مخفیانه ضبط نخواهد شد.

به‌زودی از گفتگو خسته خواهید شد، چون هوش مصنوعی بیش از حد ساده است. بااین‌حال، API.AI قابل پیکربندی و آموزش‌پذیر است. برای هوشمندتر کردن آن، مستندات API.AI را بخوانید.

امیدوارم از آموزش لذت برده باشید و یک چت‌بات سرگرم‌کننده ساخته باشید!

وب را به آینده سوق دهید!

تعامل صوتی نحوهٔ کنترل کامپیوترها و دستگاه‌های متصل توسط کاربران را دگرگون کرده است. حالا با Web Speech API، تجربهٔ کاربری روی وب نیز در حال دگرگونی است. در ترکیب با هوش مصنوعی و یادگیری عمیق (deep learning)، برنامه‌های وب شما هوشمندتر می‌شوند و تجربه‌های بهتری برای کاربران فراهم می‌کنند!

مراجع

این آموزش فقط ویژگی‌های اصلی API را پوشش داده است؛ اما API در واقع کاملاً منعطف و قابل سفارشی‌سازی است. می‌توانید زبان تشخیص و سنتز گفتار، صدای مصنوعی — از جمله لهجه (مانند انگلیسی آمریکایی یا بریتانیایی) — زیروبمی گفتار (speech pitch) و سرعت گفتار (speech rate) را تغییر دهید. در این‌جا می‌توانید دربارهٔ API بیشتر بیاموزید:

  • «Web Speech API» — شبکهٔ توسعه‌دهندگان موزیلا (Mozilla Developer Network)
  • «Web Speech API Specification» — W3C
  • «Web Speech API: Speech Synthesis» (مستندات مایکروسافت اج) — مایکروسافت

همچنین، برای یادگیری Node.js و کتابخانه‌های استفاده‌شده در این آموزش، موارد زیر را بررسی کنید:

  • راهنما — Node.js
  • مستندات — npm
  • «مثال Hello world» — Express
  • «شروع کار» — Socket.IO

در نهایت، ابزارهای مختلف پردازش زبان طبیعی و پلتفرم‌های گفتگومحور را بررسی کنید:

  • API.AI — گوگل
  • Wit.ai — فیسبوک
  • LUIS — مایکروسافت
  • Watson — IBM
  • Lex — آمازون
