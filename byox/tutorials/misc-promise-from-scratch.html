پرامیس‌های جاوااسکریپت را با ساختن یک Promise از صفر یاد بگیر

پرامیس چیست؟

پرامیس (Promise) یک شیء است که نتیجهٔ یک عملیات ناهمگام را نشان می‌دهد: یا موفق شد (fulfilled)، یا شکست خورد (rejected)، یا هنوز در جریان است (pending). مهم‌ترین مزیت آن، زنجیره‌کردن عملیات با `then` و مدیریت خطا با `catch` است.

برای اینکه واقعاً بفهمیم چطور کار می‌کند، بهترین راه این است که خودمان یک نسخهٔ کوچک از آن بسازیم که با رفتار استاندارد مطابقت داشته باشد.

ساختار پایه: state و handlers

قلب کلاس MyPromise: نگه‌داشتن وضعیت، مقدار، و لیست پردازشگرها (handlers). وقتی مقدار ست شد، همهٔ handlers صدا زده می‌شوند:

JavaScriptclass MyPromise {
  constructor(executor) {
    this.state = 'pending';   // pending | fulfilled | rejected
    this.value = undefined;
    this.handlers = [];

    // resolve و reject را به executor می‌دهیم
    const resolve = value => this.settle('fulfilled', value);
    const reject  = reason => this.settle('rejected', reason);

    try {
      executor(resolve, reject);
    } catch (e) {
      reject(e);
    }
  }

  settle(state, value) {
    if (this.state !== 'pending') return;  // فقط یک بار
    this.state = state;
    this.value = value;
    // همهٔ handlers معلق را اجرا کن
    this.handlers.forEach(h => h());
    this.handlers = [];
  }
}

این `settle` نقطهٔ مرکزی است: یک پرامیس فقط یک‌بار «نشست» می‌کند و بعد همهٔ آن‌هایی که منتظر بودند خبردار می‌شوند.

زنجیره با then

سخت‌ترین بخش، `then` است: باید یک پرامیس جدید برگرداند و اگر پردازشگر مقدار return کند، آن را زنجیره کند:

JavaScript  then(onFulfilled, onRejected) {
    // یک پرامیس جدید که به پرامیس قبلی متصل می‌شود
    return new MyPromise((resolve, reject) => {
      const handle = () => {
        if (this.state === 'fulfilled') {
          try {
            const result = onFulfilled ? onFulfilled(this.value) : this.value;
            // اگر نتیجه پرامیس بود، زنجیره ادامه می‌یابد
            if (result instanceof MyPromise) {
              result.then(resolve, reject);
            } else {
              resolve(result);
            }
          } catch (e) { reject(e); }
        } else {
          try {
            const result = onRejected ? onRejected(this.value) : this.value;
            resolve(result);
          } catch (e) { reject(e); }
        }
      };
      this.handlers.push(handle);
    });
  }

  catch(onRejected) { return this.then(undefined, onRejected); }
}

با این پیاده‌سازی، `promise.then(a).then(b)` درست کار می‌کند و خطاها در `catch` جمع می‌شوند.

جمع‌بندی

مشاهده می‌کنید که پرامیس فقط یک «اتوماتای وضعیت» با صف handlers است. حالا که آن را از صفر ساختید، رفتارهای `Promise.all`، `Promise.race` و میکروتسک‌ها (queueMicrotask) هم شفاف‌تر می‌شوند.

کپیرایت: نویسندهٔ مقالهٔ levelup (GitConnected). این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
