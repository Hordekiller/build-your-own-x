RAG از صفر

⚙ زبان: Python 📁 دسته: مدل هوش مصنوعی ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمه فارسی معرفی و راهنمای ریپازیتوری «RAG From Scratch» از «LangChain» در گیت‌هاب است — مجموعه نوتبوک‌های همراه پلی‌لیست ویدیویی «RAG From Scratch» که RAG را از پایه می‌سازد.
↗ مشاهده منبع اصلی

درباره پروژه

مدل‌های زبانی بزرگ (LLMها) روی یک بدنهٔ دادهٔ بزرگ اما ثابت آموزش دیده‌اند که توانایی آن‌ها را برای استدلال دربارهٔ اطلاعات خصوصی یا اخیر محدود می‌کند. تنظیم دقیق (Fine-tuning) یکی از راه‌های کاهش این محدودیت است، اما اغلب برای بازیابی واقعیت‌ها مناسب نیست و می‌تواند پرهزینه باشد.

تولید با بازیابی افزوده (Retrieval Augmented Generation — RAG) به‌عنوان یک مکانیزم محبوب و قدرتمند برای گسترش پایگاه دانش LLM ظهور کرده است: با استفاده از اسنادی که از یک منبع دادهٔ خارجی بازیابی می‌شوند، تولید LLM از طریق یادگیری درون‌بافتی (in-context learning) زمین‌دار (ground) می‌شود.

این نوتبوک‌ها همراه یک پلی‌لیست ویدیویی هستند که درک RAG را از صفر می‌سازند — شروع از مبانی ایندکس‌گذاری (indexing)، بازیابی (retrieval) و تولید (generation).

مفاهیم کلیدی

  • ایندکس‌گذاری (Indexing): آماده‌سازی و سازمان‌دهی اسناد برای ورود به پایگاه دانش
  • بازیابی (Retrieval): یافتن اسناد مرتبط با سؤال کاربر (جست‌وجوی شباهت برداری)
  • تولید (Generation): پاسخ‌گویی مدل با استفاده از اسناد بازیابی‌شده به‌عنوان زمینه (grounding)
  • ترجمهٔ پرس‌وجو (Query Translation): تکنیک‌هایی مثل چند پرس‌وجو، رَگ RAG و decomposition برای بهبود بازیابی
  • مسیریابی (Routing): انتخاب مسیر مناسب (پرس‌وجو در چند source متفاوت) بر اساس سؤال
  • ساخت پرس‌وجو (Query Construction): تبدیل پرس‌وجوی طبیعی به ساختارهای قابل جست‌وجو (مثل SQL یا داده‌های ساختاریافته)
  • نمره‌دهی (Scoring): بازیابی با نمره‌دهی نوعگذاری‌شده (type-aware) و مقایسهٔ معیارهای مختلف بازیابی

ویدیوها گام‌به‌گام این مفاهیم را با کد پیاده‌سازی می‌کنند و نوتبوک‌های مخزن همان کدها را به‌صورت قابل اجرا نگه می‌دارند.

Python# چرخهٔ پایهٔ RAG: ایندکس‌گذاری → بازیابی → تولید
from langchain_text_splitters import RecursiveCharacterTextSplitter

# ۱) ایندکس‌گذاری: اسناد را خرد می‌کنیم و برداریشان می‌سازیم
chunks = RecursiveCharacterTextSplitter(chunk_size=500).split_documents(docs)
index = FAISS.from_documents(chunks, embeddings)

# ۲) بازیابی: نزدیک‌ترین اسناد به پرس‌وجو
hits = index.similarity_search("سؤال کاربر", k=4)

# ۳) تولید: اسناد بازیابی‌شده را به‌عنوان زمینه به مدل می‌دهیم
answer = llm.invoke(f"بر اساس این اسناد پاسخ بده:\n{hits}")

همین سه گام، هستهٔ تمام نوتبوک‌های مخزن است؛ ویدیوهای بعدی هر گام را عمیق‌تر می‌کنند (بازیابی پیشرفته، مسیریابی، نمره‌دهی و…).
