بازی‌ها با Go — پلی‌لیست ویدیویی

⚙ زبان: Go 🎥 ویدیو (پلی‌لیست یوتیوب) ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه معرفی و مرور فارسی پلی‌لیست ویدیویی «Games with Go» است — جمع‌آوری ویدیوهایی که بازی‌های مختلف را با زبان Go می‌سازند (اغلب با کتابخانهٔ Ebiten یا raylib-go).

مشاهدهٔ ویدیو

این آموزش به‌صورت ویدیویی است و در آن گام‌به‌گام کدنویسی انجام می‌شود. برای تماشا و دنبال‌کردن هم‌زمان، روی دکمهٔ زیر بزنید:

▶ تماشای ویدیو

۱. دربارهٔ پلی‌لیست

Go (گاه‌گولنگ) با گوروتین‌ها، جمع‌آوری زباله و کامپایل سریع، زبان بسیار مناسبی برای توسعهٔ بازی است — و کتابخانه‌هایی مثل Ebiten (ساخت بازی دوبعدی با پشتیبانی چندپلتفرم) آن را ساده‌تر هم کرده‌اند. در این پلی‌لیست، بازی‌های ساده تا متوسط (پلتفرمر، دایور، پازل و…) در Go ساخته می‌شوند و مفاهیم اصلی — حلقهٔ بازی، ورودی، رندر با اسپرایت — قدم‌به‌قدم پیاده می‌شوند.

نکته: Ebiten از Go استفاده می‌کند که برای وب هم خروجی می‌دهد (WASM) — بازی‌های ساخته‌شده را می‌توانید در مرورگر هم اجرا کنید.

۲. ویدیوها را تماشا کنید

این آموزش ویدیویی است و محتوای آن در این صفحه میزبانی نمی‌شود؛ کل پلی‌لیست را از لینک زیر در یوتیوب ببینید:

▶ مشاهدهٔ پلی‌لیست «Games with Go»

۳. نمونهٔ کد: یک بازی ساده با Ebiten

gopackage main

import (
	"log"

	"github.com/hajimehoshi/ebiten/v2"
)

// هر بازی یک struct است که اینترفیس Game را پیاده می‌کند
type Game struct {
	// وضعیت بازی: موقعیت بازیکن، ورودی و ...
	playerX, playerY float64
}

// به‌روزرسانی منطق: ورودی و فیزیک
func (g *Game) Update() error {
	if ebiten.IsKeyPressed(ebiten.KeyArrowLeft) {
		g.playerX -= 2
	}
	if ebiten.IsKeyPressed(ebiten.KeyArrowRight) {
		g.playerX += 2
	}
	return nil
}

// رندر: رسم صحنه روی صفحه
func (g *Game) Draw(screen *ebiten.Image) {
	// رسم مستطیل بازیکن روی screen (جزئیات با DrawImage)
}

// ابعاد پنجره و عنوان
func (g *Game) Layout(outsideWidth, outsideHeight int) (int, int) {
	return 640, 480
}

func main() {
	ebiten.SetWindowSize(640, 480)
	ebiten.SetWindowTitle("بازی من با Go")
	if err := ebiten.RunGame(&Game{}); err != nil {
		log.Fatal(err)
	}
}

۴. جمع‌بندی

اگر Go را می‌دانید و می‌خواهید بازی‌سازی را شروع کنید، این پلی‌لیست نقطهٔ شروع خوبی است؛ و اگر Go را نمی‌دانید، ساخت یک بازی کوچک با Ebiten یکی از لذت‌بخش‌ترین راه‌های یادگیری آن است.

کپیرایت: پلی‌لیست «Games with Go» اثر سازندهٔ کانال یوتیوب است و تمام حقوق آن متعلق به اوست. این صفحه فقط ترجمهٔ فارسی و مرور آن است. برای مشاهدهٔ اصل ویدیوها به یوتیوب مراجعه کنید.
