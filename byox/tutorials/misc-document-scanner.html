چگونه یک اسکنر اسناد موبایل فوق‌العاده در فقط ۵ دقیقه بسازیم

⚙ زبان: Python + OpenCV ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور آموزش PyImageSearch است که با OpenCV عکس کاغذ را تشخیص و به اسکن صاف و تمیز تبدیل می‌کند.
↗ مشاهده منبع اصلی

چهار قدم تا اسکن

اسکنر موبایل (مثل CamScanner) این چهار کار را با هم می‌کند: ۱) پیدا کردن لبه‌های کاغذ، ۲) استخراج گوشه‌های آن، ۳) تبدیل پرسپکتیو (به‌خاطرِ عکسبرداری اریب)، ۴) بهبود تصویر (خاکستری/آستانه). همه با OpenCV در چند ده خط.

پیدا کردن کاغذ

مشکل کلاسیک: عکس اریب است، نور بد است، زمینه متفاوت است. راه‌حل استاندارد: خاکستری → کم‌کردن نویز → آستانه‌یابی → پیدا کردن کانتور بزرگ:

Pythonimport cv2
import numpy as np

def find_document(image):
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    blur = cv2.GaussianBlur(gray, (5, 5), 0)
    edged = cv2.Canny(blur, 75, 200)      # لبه‌ها

    cnts, _ = cv2.findContours(edged.copy(), cv2.RETR_LIST,
                               cv2.CHAIN_APPROX_SIMPLE)
    # بزرگ‌ترین کانتور = کاغذ
    cnt = max(cnts, key=cv2.contourArea)
    peri = cv2.arcLength(cnt, True)
    approx = cv2.approxPolyDP(cnt, 0.02 * peri, True)

    # کاغذ باید چهار ضلع داشته باشد
    return approx if len(approx) == 4 else None

`approxPolyDP` گوشه‌های کانتور را ساده می‌کند؛ کاغذ A4 در هر عکسی چهار ضلع می‌شود.

تبدیل پرسپکتیو

حالا چهار گوشه داریم. آن‌ها را با `getPerspectiveTransform` به یک مستطیل کامل A4 نگاشت می‌کنیم و با `warpPerspective` تصویر جدید را می‌چینیم. ترتیب گوشه‌ها (بالا-چپ، بالا-راست و...) مهم است و باید مرتب‌سازی شود:

Pythondef order_points(pts):
    # مرتب‌سازی: TL, TR, BR, BL با مجموع و تفاضل مختصات
    s = pts.sum(axis=1); d = np.diff(pts, axis=1)
    return np.array([
        pts[np.argmin(s)], pts[np.argmin(d)],
        pts[np.argmax(s)], pts[np.argmax(d)]
    ], dtype="float32")

def scan(image, corners):
    rect = order_points(corners)
    w = int(max(np.linalg.norm(rect[0]-rect[1]),
                np.linalg.norm(rect[2]-rect[3])))
    h = int(max(np.linalg.norm(rect[0]-rect[2]),
                np.linalg.norm(rect[1]-rect[3])))
    dst = np.array([[0,0],[w-1,0],[w-1,h-1],[0,h-1]], dtype="float32")
    M = cv2.getPerspectiveTransform(rect, dst)
    return cv2.warpPerspective(image, M, (w, h))

می‌بینید که «فقط ۵ دقیقه» یعنی همین ۳۰ خط! نتیجه را با `cv2.threshold` آستانه بگیرید تا مثل اسکنر واقعی شود.
