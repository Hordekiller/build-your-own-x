چرا LSTM برای سری زمانی؟

قیمت سهام یک «سری زمانی» است: نتیجهٔ هر روز به روزهای قبل وابسته است. شبکه‌های عصبی معمولی گذشته را نمی‌بینند؛ LSTM (حافظهٔ بلند-کوتاه) دریچه‌هایی دارد که به شبکه می‌گوید چه چیزی از گذشته را نگه دارد و چه چیزی را فراموش کند.

⚠️ نکتهٔ واقع‌بینانه: بازار قابل پیش‌بینی قطعی نیست؛ هدف آموزش، یادگیری مدل‌سازی سری زمانی است، نه ثروتمند شدن!

آماده‌سازی داده

قیمت‌ها مقیاس سختی دارند؛ اول نرمال می‌کنیم (بین ۰ و ۱)، بعد پنجره‌ها می‌سازیم: برای پیش‌بینی روز t، ورودی قیمت ۶۰ روز قبلی است:

Pythonimport numpy as np
from sklearn.preprocessing import MinMaxScaler

scaler = MinMaxScaler(feature_range=(0, 1))
scaled = scaler.fit_transform(df['Close'].values.reshape(-1, 1))

def make_windows(data, window=60):
    X, y = [], []
    for i in range(window, len(data)):
        X.append(data[i-window:i, 0])
        y.append(data[i, 0])
    return np.array(X), np.array(y)

X, y = make_windows(scaled)
X = X.reshape(X.shape[0], X.shape[1], 1)   # شکل LSTM

شکل ورودی LSTM: (تعداد نمونه، طول پنجره، تعداد ویژگی).

مدل LSTM

Pythonfrom keras.models import Sequential
from keras.layers import LSTM, Dense, Dropout

model = Sequential([
    LSTM(units=50, return_sequences=True, input_shape=(60, 1)),
    Dropout(0.2),
    LSTM(units=50, return_sequences=False),
    Dropout(0.2),
    Dense(units=1)          # قیمت بعدی

`return_sequences=True` برای لایه‌های میانی لازم است تا خروجی توالی به لایهٔ LSTM بعدی برسد. بعد از پیش‌بینی، با `inverse_transform` مقدار را به مقیاس واقعی برمی‌گردانیم.

ارزیابی صادقانه

هرگز دقت را روی همان داده‌های آموزش نگیرید؛ داده را به train/validation/test تقسیم کنید و «پیش‌بینی‌های خارج از بازهٔ دیده‌شده» را با RMSE بسنجید. در عمل، مدل‌های LSTM برای روند کوتاه‌مدت مفیدند و برای جهش‌های ناگهانی نه.
