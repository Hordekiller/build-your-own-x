write-a-C-interpreter: مفسر C که خودش را Interpretation می‌کند

⚙ زبان: C ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور پروژهٔ «write-a-C-interpreter» از lotabout است؛ یک مفسر C که با C نوشته شده و می‌تواند خودش را اجرا کند (Self-host).
↗ مشاهده منبع اصلی

چه چیزی می‌سازیم؟

این پروژه یکی از جاه‌طلبانه‌ترین آموزش‌هاست: یک مفسر کامل زبان C که در C نوشته شده و — پروژهٔ بالغ — توانایی اجرای خودش را دارد (یعنی فایل‌های سورس مفسر را می‌گیرد و خودش را تفسیر می‌کند). مسیر این کار از سه مؤلفهٔ اصلی می‌گذرد: lexer، parser و evaluator.

ساختار کد

کد به ۹ فایل کوچک تقسیم شده است که هرکدام یک مرحلهٔ یادگیری است: lexer (تبدیل سورس به تابع‌های token)، parser (ساخت AST از tokenها)، eval (ارزیابی AST). هر فایل با یک مثال ساده شروع می‌شود و به‌تدریج کامل می‌شود.

برخلاف بسیاری از آموزش‌ها، این پروژه از ابتدا برای زبان واقعی C طراحی شده — پس با ساختارهای واقعی مثل struct، enum، pointer، typedef، آرایه‌ها و حتی پیش‌فرض‌های استاندارد (مثل int ضمنی) آشنا می‌شوید.

نمونهٔ کد: هستهٔ eval

C// ارزیابی یک statement
void eval(struct AST_node *ast) {
  if (!ast) return;

  switch (ast->type) {
    case NODE_EXPR:          // عبارت: تماس تابع، عملگر و...
      handle_expr(ast);
      break;
    case NODE_ASSIGN:        // انتساب: a = b;
      handle_assign(ast);
      break;
    case NODE_IF:            // if/else
      handle_if(ast);
      break;
    case NODE_WHILE:         // حلقهٔ while
      while (is_true(eval_expr(ast->cond)))
        eval(ast->body);
      break;
    ...
  }
}

مدیریت حافظه با یک جدول تابع‌ها و یک heap شماره‌دار (make_label) انجام می‌شود؛ همین باعث می‌شود پوینترها به‌صورت «ایه‌پی‌های میانی» ترجمه شوند و خود interpreter بتواند با حافظهٔ واقعی مفسر ارتباط برقرار نکند.

گام‌های پیاده‌سازی (نقشهٔ مطالعه)

۱. lexer: تشخیص tokenها (شناسه‌ها، اعداد، عملگرها، کلیدواژه‌ها). ۲. parser: گرامر C زیرمجموعه — از declaration‌ها و expression‌ها تا struct/enum. ۳. eval: پیاده‌سازی scope (بلوک‌های تودرتو با zset/zget)، توابع (با جدول تابع‌ها و بازگشت)، pointerها (با نمایهٔ heap). ۴. در نهایت سعی کنید مفسر خودش را اجرا کند — رفع باگ‌های این مرحله بهترین درس است.

پروژه همچنین شامل فایل‌های توضیحی (قسمت ۱ تا ۴ به زبان چینی در docs) و کامنت‌های فارسی‌نویسی‌شده در کد نیست، ولی مستندات انگلیسی کافی وجود دارد.

جمع‌بندی

اگر می‌خواهید بفهمید زبان C واقعاً چطور کار می‌کند — نه فقط نحوش — این پروژه عالی است: از مهم‌ترین چیزهایی که یاد می‌گیرید، رفتار pointer، ساختار scope و پیاده‌سازی تابع‌هاست؛ و دیدن اجرای مفسرتان با خودش، لحظهٔ شیرینی دارد.
