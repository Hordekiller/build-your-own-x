۱. مقدمه: شبکهٔ عصبی چیست؟

شبکهٔ عصبی مصنوعی از نورون‌های مصنوعی ساخته می‌شود: هر نورون جمع وزن‌دار ورودی‌ها را می‌گیرد، بایاس را اضافه می‌کند و نتیجه را از یک تابع فعال‌سازی می‌گذراند. نویسنده همهٔ این‌ها را با مفاهیم پایه‌ای ماتریس‌ها در Go پیاده می‌کند — هیچ کتابخانهٔ یادگیری ماشینی در کار نیست. خروجی، یک شبکهٔ کوچک اما کاملاً کاراست که می‌تواند یک مسئلهٔ طبقه‌بندی ساده را یاد بگیرد.

go// نورون مصنوعی: Σ(ورودی × وزن) + بایاس ← سپس تابع فعال‌سازی
output := activation(bias + sum(wi * xi, for i = 1..n))

۲. تابع فعال‌سازی سیگموئید

سیگموئید مقدار واقعی را به بازهٔ (۰, ۱) فشرده می‌کند و به شبکه اجازهٔ «خروجی احتمالی» می‌دهد. برای آموزش، مشتق آن هم لازم است — مشتق سیگموئید برحسب خود سیگموئید ساده است: σ(x)(1−σ(x)):

go// تابع سیگموئید و مشتق آن
func sigmoid(x float64) float64 {
    return 1.0 / (1.0 + math.Exp(-x))
}

func sigmoidPrime(x float64) float64 {
    return sigmoid(x) * (1.0 - sigmoid(x))
}

۳. ساختار شبکه: دو ماتریس وزن

شبکهٔ نمونه دو لایه دارد: ورودی و خروجی (بدون لایهٔ پنهان). پس فقط دو ماتریس لازم است: w1 که ورودی را به خروجی می‌برد و w2 که در نسخهٔ تک‌لایه معادل همان اتصال است. برای عمومیت، مدل با آرایه‌ای از ماتریس‌های وزن تعریف می‌شود تا بعدها لایهٔ بیشتری اضافه شود:

gotype Network struct {
    inputs        int
    hidden        int
    outputs       int
    hiddenWeights *mat.Dense
    outputWeights *mat.Dense
    learningRate  float64
}

// ساخت شبکه: ورودی ۲، خروجی ۱
net := Network{
    inputs: 2, hidden: 2, outputs: 1,
    hiddenWeights: mat.NewDense(2, 2, nil), // وزن‌ها به‌صورت تصادفی مقداردهی می‌شوند
    outputWeights: mat.NewDense(2, 1, nil),
    learningRate: 0.1,
}

۴. انتشار پیشرو با gonum

خروجی با ضرب ماتریسی gonum/mat محاسبه می‌شود: ورودی ضرب در hiddenWeights، اعمال سیگموئید، دوباره ضرب در outputWeights و سیگموئید نهایی. خروجی نهایی پیش‌بینی شبکه است:

go// محاسبهٔ خروجی شبکه برای یک بردار ورودی
func (n *Network) feedforward(x *mat.VecDense) *mat.VecDense {
    // لایهٔ پنهان = سیگموئید(ورودی × وزن‌های پنهان)
    hidden := mat.NewVecDense(n.hidden, nil)
    hidden.MulVec(n.hiddenWeights, x)
    applySigmoid(hidden)

    // خروجی = سیگموئید(لایهٔ پنهان × وزن‌های خروجی)
    output := mat.NewVecDense(n.outputs, nil)
    output.MulVec(n.outputWeights, hidden)
    applySigmoid(output)
    return output
}

۶. آزمایش: یادگیری تابع XOR

نمونهٔ کلاسیک، یادگیری XOR است — تابعی که شبکهٔ تک‌نورونی هرگز نمی‌تواند بیاموزد (غیرخطی است) اما با همین شبکهٔ کوچک و چند عصر آموزش، به‌خوبی یاد گرفته می‌شود. این آزمایش ارزشمند است چون نشان می‌دهد عمق (لایهٔ پنهان) واقعاً قدرت بیان مدل را بالا می‌برد.

نکتهٔ تکمیلی: با تغییر شکل دیتاست ورودی (مثلاً عددهای صحیح) و فعال‌سازی‌های متفاوت، همین ساختار برای دستهٔ بزرگی از مسائل سادهٔ طبقه‌بندی قابل استفاده است.

۷. جمع‌بندی

  • شبکهٔ عصبی = ماتریس‌های وزن + فعال‌سازی غیرخطی + گرادیان نزولی.
  • gonum/mat همهٔ ضرب‌های ماتریسی را تمیز و خوانا می‌کند.
  • مشتق سیگموئید ساده است و backprop را به چند خط کد تبدیل می‌کند.
  • یادگیری XOR اثبات می‌کند که لایهٔ پنهان ضروری و کافی است.
