Build Your Own Lisp — زبان Lisp خودت را در C بساز

منبع اصلی: این صفحه ترجمهٔ فارسی و مرور کتاب آنلاین «Build Your Own Lisp» نوشتهٔ دانیل هولدن است که ساخت یک مفسر Lisp کامل را در C (حدود ۱۰۰۰ خط) آموزش می‌دهد.
↗ مشاهده منبع اصلی

کتابی که از «صفر» شروع می‌کند

دانیل هولدن با فرض اینکه خواننده C بلد نیست، از نصب کامپایلر تا ساخت کامل یک زبان Lisp را قدم‌به‌قدم می‌برد. نتیجهٔ نهایی «Lispy» است: زبانی با توابع، متغیرها، شرط‌ها، حلقه و قواعد لامبدا که روی REPL اجرا می‌شود.

ویژگی متمایز کتاب استفاده از کتابخانهٔ mpc (یک کتابخانهٔ parser combinator ساده که در خود کتاب ساخته می‌شود) برای تعریف گرامر زبان است — به این ترتیب خواننده با معماری واقعی کامپایلرها آشنا می‌شود بدون اینکه درگیر پیچیدگی lexer شود.

مفاهیم کلیدی: mpc و گرامر زبان

در فصل اول، شما یک ماشین‌حساب لهستانی (Polish notation) می‌سازید: ورودی مثل + 1 (* 2 3). سپس با mpc_parser_t* گرامر زبان را تعریف می‌کنید:

Cmpc_parser_t* Number    = mpc_new("number");
mpc_parser_t* Operator  = mpc_new("operator");
mpc_parser_t* Expr      = mpc_new("expr");
mpc_parser_t* Lispy     = mpc_new("lispy");

mpca_lang(MPCA_LANG_DEFAULT,
  " number : /-?[0-9]+/ ;            "
  " operator: '+' | '-' | '*' | '/' ;"
  " expr    :  | '('  + ')' ;"
  " lispy   : /^/  + /$/ ; ",
  Number, Operator, Expr, Lispy);

این گرامر به‌صورت بازگشتی تعریف شده — expr می‌تواند داخل خودش expr داشته باشد — که اساسِ درک ساختارهای تودرتوی زبان‌های برنامه‌نویسی است.

از پارسر تا مفسر: eval

پس از اینکه mpc درخت نحو (AST) را می‌سازد، می‌نویسید که هر گره چه‌طور ارزیابی شود. قلب مفسر تابعی است که یک لیست را می‌گیرد، عملگر و عملوندها را جدا می‌کند و محاسبه را انجام می‌دهد:

Clval* eval(lval* v) {
  if (v->type == LVAL_NUM) return v;      // عدد = مقدار نهایی
  lval* f = pop(v, 0);                    // عملگر را بردار
  if (f->type != LVAL_FUN) { lval_del(f); lval_del(v); error! }
  for (int i = 0; i < v->count; i++)
    v->cell[i] = eval(v->cell[i]);       // ارزیابی بازگشتی آرگومان‌ها
  return call(f, v);                      // اجرای تابع
}

بعداً با افزودن Q-Expression (لیست‌هایی که ارزیابی نمی‌شوند) توابعی مثل list، head و tail به زبان اضافه می‌شوند؛ و در فصل‌های بعدی متغیرها با def و =، توابع تعریف‌شده با \ (lambda) و حتی مدیریت خطا و GC ساده هم می‌آید.

گام‌های پایانی

کتاب در فصل‌های آخر: (۱) سیستم مدیریت خطا و انواع داده؛ (۲) ذخیره‌سازی و بارگذاری کد در فایل؛ (۳) افزودن کتابخانهٔ استاندارد کوچک (مثل sum، len). در پایان می‌توانید برنامه‌های واقعی با Lispy بنویسید.

همهٔ کدهای کتاب روی لینوکس و macOS و با cc ساده کامپایل می‌شوند؛ هیچ وابستگی خارجی جز mpc (که خودتان ساخته‌اید) نیست.

جمع‌بندی

بهترین انتخاب برای کسی که «اصلاً هیچ چیز دربارهٔ زبان‌های برنامه‌نویسی نمی‌داند»: با C شروع می‌کنید و در پایان یک مفسر لیسپ دارید که توابع و متغیر دارد؛ مفاهیم parser، AST، eval و REPL را عمقاً می‌فهمید.

کپیرایت: دانیل هولدن (Daniel Holden). این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
