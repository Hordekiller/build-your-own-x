Kaleidoscope — پیاده‌سازی زبان خودت با LLVM

⚙ زبان: C++ ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور آموزش رسمی «My First Language Frontend with LLVM» است — ده بخش ساخت زبان Kaleidoscope با پشتیبانی کامل از LLVM.
↗ مشاهده منبع اصلی

در این آموزش چه می‌سازید؟

LLVM (مخفف Low Level Virtual Machine) یک مجموعه‌ابزار برای ساخت کامپایلر است؛ خروجی آن «کد میانی» (IR) و سپس کد ماشین بهینه‌شده است. این آموزش رسمی LLVM، زبان Kaleidoscope را می‌سازد: زبانی تابعی با دستور def برای تعریف تابع، extern برای توابع خارجی، شرط‌ها، حلقه‌ها، عملگرهای تعریف‌شدهٔ کاربر و متغیرهای متغیر.

معماری ده بخشی

بخش‌ها طوری طراحی شده‌اند که هرکدام یک لایه اضافه می‌کنند: (۱) lexer؛ (۲) parser و AST؛ (۳) تولید IR با IRBuilder؛ (۴) اضافه‌کردن JIT برای اجرای لحظه‌ای؛ (۵) بهینه‌ساز (Optimizer با PassManager)؛ (۶) شرط‌های if/else (با گره‌های PHI)؛ (۷) حلقه‌ها (for)؛ (۸) عملگرهای دودویی تعریف‌شدهٔ کاربر (با جدول اولویت دینامیک)؛ (۹) متغیرهای تغییرپذیر (با alloca)؛ (۱۰) خروجی فایل آبجکت‌کد.

نمونهٔ کد: ساخت IR با IRBuilder

برای مثال، کد def add(a, b) a + b این‌گونه IR تولید می‌کند:

C++Value *CodegenVisitor::visit(BinaryExpr &e) {
  Value *L = codegen(e.LHS);
  Value *R = codegen(e.RHS);
  switch (e.Op) {
  case '+':
    return Builder->CreateFAdd(L, R, "addtmp");  // جمع ممیز شناور
  case '-':
    return Builder->CreateFSub(L, R, "subtmp");
  case '*':
    return Builder->CreateFMul(L, R, "multmp");
  case '/':
    return Builder->CreateFDiv(L, R, "divtmp");
  default:
    return LogErrorV("عملگر ناشناخته");
  }
}

نتیجهٔ این کد، یک ماژول LLVM است که می‌توانید با lli اجرا کنید حتی قبل از اینکه backend کامل شود.

نکته‌های فنی ارزشمند

بخش‌های ۶ و ۷ کار با گره‌های PHI را نشان می‌دهند — مفهومی مهم در SSA که در زبان‌های لو-لوول مثل Rust هم می‌بینید. بخش ۹ با alloca (متغیر روی پشته) نشان می‌دهد که چرا متغیرهای تغییرپذیر در SSA کار سختی هستند. بخش ۱۰ با خروجی آبجکت‌فایل، کامپایلرتان را «واقعی» می‌کند.

جمع‌بندی

کامل‌ترین معرفی رسمی برای ساخت frontend روی LLVM در C++ است. اگر به‌دنبال مسیری هستید که زبان شما بتواند بعداً روی CPU واقعی سرعت بگیرد (JIT یا AOT)، با این آموزش شروع کنید — سپس می‌توانید Kaleidoscope را با انواع داده و ماژول‌ها گسترش دهید.
