۱. مقدمه — چه می‌سازیم؟

این پلی‌لیست یک مجموعهٔ کامل ویدیویی است که موتور فیزیک سه‌بعدی را گام‌به‌گام و از صفر می‌سازد. رویکرد سری «همه‌چیز را خودمان بسازیم» است: به‌جای استفاده از کتابخانه‌های آمادهٔ فیزیک، بردارها، ماتریس‌ها، یکپارچه‌سازی و تشخیص برخورد را مستقیم پیاده می‌کنید — و برای اینکه نتیجه را ببینید، با OpenGL یک صحنهٔ بصری رندر می‌شود.

خروجی سری یک موتور قابل اجراست: اجسام صلب (کره‌ها و جعبه‌ها) که زیر اثر گرانش سقوط می‌کنند، با سطح زمین و همدیگر برخورد می‌کنند و با ضربه و چرخش واکنش نشان می‌دهند — همان قابلیت‌های پایهٔ هر موتور فیزیک بازی.

نکته: طبق سیاست این وب‌سایت، ویدیوها میزبانی نمی‌شوند؛ برای تماشای سری به پلی‌لیست اصلی یوتیوب بروید و ویدیوها را به‌ترتیب ببینید.

۲. مسیر یادگیری سری

سری تقریباً این مراحل را پشت سر می‌گذارد (با تقسیم‌بندی موضوعی از روی محتوای خود سری):

مرحلهٔ ۱ — پایهٔ ریاضیات ۳بعدی

  • کلاس بردار سه‌بعدی (Vec3): جمع، تفریق، ضرب اسکالر، ضرب داخلی، ضرب خارجی، اندازه و نرمال‌سازی
  • کلاس ماتریس ۴×۴ و کواترنیون برای چرخش — چون چرخش سه‌بعدی با زاویهٔ ساده قابل نمایش نیست
C++// هستهٔ کلاس بردار سه‌بعدی — همان چیزی که سری اول می‌سازد
struct Vec3 {
  float x, y, z;

  Vec3 operator+(const Vec3& o) const { return {x + o.x, y + o.y, z + o.z}; }
  Vec3 operator*(float s)     const { return {x * s,   y * s,   z * s};   }

  float dot(const Vec3& o) const { return x * o.x + y * o.y + z * o.z; }
  Vec3  cross(const Vec3& o) const {
    return {y * o.z - z * o.y, z * o.x - x * o.z, x * o.y - y * o.x};
  }
  Vec3 normalized() const { return *this * (1.0f / sqrt(dot(*this))); }
};

مرحلهٔ ۲ — پایهٔ فیزیک

  • قوانین حرکت نیوتن و مفاهیم نیرو، جرم، شتاب، سرعت و موقعیت
  • یکپارچه‌سازی عددی (روش اویلر و نسخه‌های پایدارتر) با گام زمانی ثابت
  • اعمال گرانش و محدودسازی گام زمانی برای پایداری

مرحلهٔ ۳ — جسم صلب سه‌بعدی

  • ساختار RigidBody: موقعیت، سرعت خطی، جهت‌گیری، سرعت زاویه‌ای، جرم و ممان اینرسی
  • دینامیک چرخش با کواترنیون‌ها و به‌روزرسانی ممان اینرسی در فضای دنیا (تنسور اینرسی)

مرحلهٔ ۴ — تشخیص برخورد

  • تست‌های پایه: کره با کره (فاصلهٔ مراکز با مجموع شعاع‌ها)، کره با صفحه (فاصلهٔ علامت‌دار)، کره با AABB (نزدیک‌ترین نقطه)
  • تولید نرمال برخورد و عمق نفوذ برای ورود به مرحلهٔ حل

مرحلهٔ ۵ — حل برخورد

  • ضربهٔ خطی برای جداسازی اجسام با ضریب بازگشت (restitution)
  • ضربهٔ چرخشی: با بردار بازوی r از مرکز جرم تا نقطهٔ تماس، انرژی به سرعت زاویه‌ای هم منتقل می‌شود — همان معادلهٔ استاندارد موتورهای مثل Bullet

مرحلهٔ ۶ — رندر و صحنه

  • رندر اجسام با OpenGL برای دیدن نتیجه در عمل
  • حلقهٔ صحنه: به‌روزرسانی فیزیک، برخوردها و رسم هر فریم

۳. چرا این سری را ببینم؟

  1. سه‌بعدی واقعی: بیشتر آموزش‌های رایگان «موتور فیزیک خودت» دوبعدی‌اند؛ این سری دردسرهای واقعی ۳بعدی (کواترنیون، تنسور اینرسی، رندر) را نشان می‌دهد.
  2. همه‌چیز از صفر: هیچ موتوری وارد نشده؛ بعد از سری، هر بخشی را که دیده‌اید مستقیم نوشته‌اید — بهترین تمرین برای خواندن کد موتورهای بزرگ مثل Bullet.
  3. چرخهٔ بستهٔ ساخت: ریاضی ← جسم ← برخورد ← حل ← رندر؛ یک موتور کامل در دست دارید که می‌تواند پایهٔ پروژهٔ بعدی‌تان باشد.

پیش‌نیازها: آشنایی متوسط با C++ و مفاهیم پایهٔ ریاضی (بردارها). اگر جبر خطی را مرور می‌خواهید، مقاله‌های متنی فیزیک همین وب‌سایت (مثل «موتورهای فیزیک چگونه کار می‌کنند») مکمل خوبی است.
