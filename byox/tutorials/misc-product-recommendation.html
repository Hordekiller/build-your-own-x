پیشنهاد محتوامحور چیست؟

«اگر این را دوست داری، این‌ها را هم دوست داری» — بر اساس خودِ آیتم‌ها، نه رفتار دیگران. هر محصول به یک بردار ویژگی تبدیل می‌شود (متن توضیح، دسته، برند) و آیتم‌هایی که بردارشان نزدیک‌تر است، پیشنهاد می‌شوند. مزیت: برای محصول جدید بدون سابقهٔ فروش هم کار می‌کند (cold start حل می‌شود).

ساخت بردار با TF-IDF

اگر محصولات توصیف متنی داشته باشند (یا ترکیب ویژگی‌ها به یک رشته)، TF-IDF آن را به بردار تبدیل می‌کند؛ کلمه‌هایی که فقط در بعضی محصولات آمده‌اند وزن بیشتری می‌گیرند:

Pythonfrom sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import linear_kernel

# هر محصول: id + ترکیب متن ویژگی‌ها (title, brand, category)
docs = products['combined'].values

vec = TfidfVectorizer(stop_words='english')
matrix = vec.fit_transform(docs)          # (n_products, n_terms)

# ماتریس شباهت بین همهٔ محصولات (یک‌بار محاسبه)
cosine = linear_kernel(matrix, matrix)

`linear_kernel` همان شباهت کسینوسی است ولی سریع‌تر از brute force برای ماتریس‌های بزرگ.

پیشنهاد برای یک محصول

Pythondef recommend(product_id, top_n=5):
    idx = products.index[products['id'] == product_id][0]

    scores = list(enumerate(cosine[idx]))   # شباهت به همه
    scores = sorted(scores, key=lambda x: x[1], reverse=True)

    # اولی خودِ محصول است؛ از دومی شروع کن و محصولات مشابه بگیر
    similar = [products.iloc[i]['id'] for i, s in scores[1:top_n + 1]]
    return similar

print(recommend('P-1042'))   # پنج محصول مشابه

جذابیت این رویکرد: هیچ آموزشی لازم نیست — فقط TF-IDF و یک ضرب ماتریس؛ در کمتر از ۵۰ خط یک فروشگاه اینترنتی می‌تواند «محصولات مشابه» داشته باشد.

توسعه‌ها

در نسخهٔ پیشرفته: ترکیب چند ویژگی با وزن‌های متفاوت (برند مهم‌تر از کلمات توضیح)، بردارهای embedding (Word2Vec) به‌جای TF-IDF برای درک معنایی، و ترکیب با پیشنهاد همکارانه (hybrid) برای بهترین دقت.

کپیرایت: Untrod. این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
