معرفی سری

نرا سندلر در ۱۰ مقالهٔ مفصل، یک کامپایلر برای زیرمجموعهٔ بزرگی از زبان C را با OCaml می‌سازد: از int main() { return 1; } شروع می‌کند و در پایان به ساختارهای پیشرفته (struct، نوع‌های منطق، پوینتر) می‌رسد. خروجی، اسمبلی x86-64 است که با gcc پیوند می‌خورد و اجرا می‌شود.

مهم‌ترین بخش‌ها

بخش ۱: lexer و parser برای ساده‌ترین برنامه؛ بخش ۲: تولید اسمبلی برای return؛ بخش ۳: متغیرهای محلی و انتساب (with stack allocation)؛ بخش ۴: if/else و حلقه‌ها؛ بخش ۵: توابع و آرگومان؛ بخش ۶: عملگرهای unary/binary کامل (مثل ~ و !)؛ بخش ۷: پوینتر (dereference) و آدرس‌گیری (&)؛ بخش ۸: struct و union؛ بخش ۹: کلیدواژه‌های باقی‌مانده و پشتیبانی از typedef؛ بخش ۱۰: انواع دادهٔ پیشرفته (long، unsigned و…).

نمونهٔ کد: قانون parser برای جمع

OCaml(* پارس اکسپرژن با اولویت از چپ *)
let rec parse_exp tokens =
  let left, tokens = parse_exp1 tokens in
  parse_exp_tail left tokens

(* exp-tail := ("+"|"-"|"*"|"/") exp exp-tail | eps *)
and parse_exp_tail left tokens =
  match tokens with
  | Tok_PLUS :: rest ->
      let right, rest' = parse_exp1 rest in
      parse_exp_tail (Exp_Binop (Add, left, right)) rest'
  | Tok_MINUS :: rest ->
      let right, rest' = parse_exp1 rest in
      parse_exp_tail (Exp_Binop (Sub, left, right)) rest'
  | _ -> left, tokens

چرا این سری خاص است؟

پیاده‌سازی با OCaml یعنی: pattern matching بی‌نقص برای AST، و تایپ‌های خواناتر — به‌طوری که «کد کامپایلر» خودش به یک درس تایپ‌سازی تبدیل می‌شود. همچنین هر بخش دارای تست‌ها و راهنمای رفع اشکال است؛ و در پایان، کامپایلرتان برنامه‌های C واقعی را (با محدودیت‌های مشخص) ترجمه می‌کند.

جمع‌بندی

یک سری کامل، خوانا و نزدیک به واقعیت. اگر با OCaml (یا حتی با فرض یادگیری آن در مسیر) راحتید، این مسیر برای ساخت کامپایلر «واقعی» (نه اسباب‌بازی) عالی است. پیشنهاد می‌شود بعد از آن با تست C به سمت استانداردها بروید.
