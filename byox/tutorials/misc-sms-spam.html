تشخیص‌دهنده اسپم SMS با Scikit-learn بنویس

⚙ زبان: Python ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور مقالهٔ ولاد کپیلف است که با خبره scikit-learn روی دیتاست SMS اسپم کگل، مدل تشخیص می‌سازد.
↗ مشاهده منبع اصلی

مسئله: متن را دسته‌بندی کن

دیتاست (از کگل) شامل هزاران SMS با برچسب «spam» یا «ham» است. کار: یادگیری الگوریتمی که برای متن جدید تشخیص دهد. این یک مسئلهٔ کلاسیک NLP سطح پایین است و با scikit-learn در چند خط حل می‌شود.

از متن به اعداد: TF-IDF

الگوریتم‌ها فقط عدد می‌فهمند. متن را به بردار «بسامد کلمات» تبدیل می‌کنیم؛ بهتر از شمارش خام، TF-IDF است که کلمه‌های پرتکرار در همهٔ پیام‌ها را کم‌اهمیت و کلمه‌های خاص را مهم می‌کند:

Pythonfrom sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.model_selection import train_test_split
from sklearn.naive_bayes import MultinomialNB
from sklearn.metrics import accuracy_score, confusion_matrix

# df: ستون‌های 'text' و 'label' (spam/ham)
X = df['text']; y = df['label'].map({'spam': 1, 'ham': 0})

# تبدیل متن به بردار TF-IDF
vec = TfidfVectorizer(stop_words='english')
Xv = vec.fit_transform(X)

X_train, X_test, y_train, y_test = train_test_split(
    Xv, y, test_size=0.2, random_state=42)

چرا Multinomial NB؟ چون برای دسته‌بندی متن با شمارش کلمات ذاتاً مناسب است و سریع.

آموزش و ارزیابی

Pythonmodel = MultinomialNB()
model.fit(X_train, y_train)

pred = model.predict(X_test)
print('دقت:', accuracy_score(y_test, pred).round(3))

# جدول درهم: کجاست که اشتباه می‌کند؟
print(confusion_matrix(y_test, pred))

نکتهٔ حرفه‌ای: در اسپم، دقت (accuracy) کافی نیست؛ recall و precision مهم‌اند — چون از دست دادن یک اسپم ارزشی ندارد اما گمراه کردن یک کاربر عادی بد است. `classification_report` هر سه را نشان می‌دهد.

جمع‌بندی و قدم بعدی

با حدود ۱۵ خط کد یک طبقه‌بند کار می‌کند. چالش‌های بعدی: دادهٔ نامتعادل (اسپم کمتر است)، زبان فارسی (نیاز به توکن‌ساز فارسی)، و مدل‌های بهتر (SVM، fastText). اما پایه — TF-IDF + NB — هنوز در تولید هم کار می‌کند.
