یک سرور DNS در Node.js بساز

DNS چطور کار می‌کند؟

وقتی مرورگر می‌خواهد `example.com` را باز کند، اول باید IP آن را پیدا کند. این «دفترچه تلفن اینترنت» سیستم DNS است: درخواست UDP روی پورت ۵۳ فرستاده می‌شود؛ پاسخ می‌گوید `example.com → 93.184.216.34`. نام‌ها ساختار سلسله‌مراتبی دارند: از ریشه (.) تا TLD (com) تا نام‌سرورهای دامنه.

در این آموزش، پیام DNS را به صورت باینری خودمان می‌خوانیم و می‌نویسیم — بدون کتابخانه.

قالب پیام DNS

هر پیام DNS ۱۲ بایت header دارد و سپس سوال‌ها (questions) و پاسخ‌ها (answers). بخش‌های مهم header: شناسه (ID)، پرچم‌ها (QR، Opcode، RD) و شمارنده‌ها. نام‌ها با قالب label (طول+کاراکتر) و با `\0` تمام می‌شوند:

JavaScript (نمونهٔ ساخت سوال)// ساخت بخش سوال برای "example.com"
// قالب: labelها + نوع (A) + کلاس (IN)
function makeQuestion(name) {
  const labels = name.split('.').map(l =>
    Buffer.from([l.length]).toString() + l).join('');
  return Buffer.from(labels + '\x00' + '\x00\x01' + '\x00\x01', 'binary');
}

`\x00\x01` یعنی نوع رکورد A (آدرس IPv4) و `\x00\x01` کلاس IN (اینترنت).

خود سرور

سرور با `dgram` (UDP) روی پورت ۵۳ می‌شنود، سوال را پارس می‌کند و می‌تواند از پاسخی از پیش تعریف‌شده (مثل یک رکورد A ثابت) جواب بدهد — دقیقاً یک DNS سادهٔ شبیه hosts file:

JavaScriptconst dgram = require('dgram');
const server = dgram.createSocket('udp4');

const ZONE = { 'example.com': '93.184.216.34' };

server.on('message', (msg, rinfo) => {
  // 1. پارس سوال از پیام
  const qname = parseName(msg, 12);
  // 2. جست‌وجو در زون
  const ip = ZONE[qname];
  // 3. ساخت پاسخ: کپی ID درخواست + پاسخ A
  const response = buildResponse(msg, qname, ip);
  server.send(response, rinfo.port, rinfo.address);
});

server.bind(53);

مهم‌ترین نکته: پاسخ باید همان `ID` درخواست را کپی کند، وگرنه کلاینت پاسخ را قبول نمی‌کند.

گام بعدی: recursive resolver

سرور DNS واقعی اگر پاسخی نداند، سوال را به سرور‌های بالاتر (ریشه → TLD → نام‌سرور دامنه) می‌فرستد و برگشت‌پذیر پیگیری می‌کند. با همین پایه می‌توانید آن الگوریتم را هم اضافه کنید: `dns.resolve` داخلی Node را به عنوان «سرور بالادست» فراخوانی کنید و جواب را برای کاربر کش کنید.
