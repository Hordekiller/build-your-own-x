ساخت یک بازی Roguelike در C# — آموزش RogueSharp

⚙ زبان: C# ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه معرفی و مرور فارسی وبلاگ RogueSharp — خانهٔ آموزش رسمی کتابخانهٔ RogueSharp (برای ساخت بازی‌های Roguelike در C#) و سری آموزشی «Creating a Roguelike in C#» که با RogueSharp v3 و RLNET یک بازی کامل می‌سازد.
↗ مشاهده منبع اصلی

۱. RogueSharp چیست؟

RogueSharp یک کتابخانهٔ متن‌باز C# مخصوص بازی‌های roguelike است که کارهای سخت را برایتان انجام می‌دهد: تولید نقشهٔ سیاه‌چاه، میدان دید (Field of View)، مسیریابی (Pathfinding) و تشخیص خط دید (Line of Sight). در آموزش، RogueSharp v3 با RLNET (برای رندر ترمینال) ترکیب می‌شود — و نسخهٔ قدیمی‌تر v2 با MonoGame هم پوشش داده شده بود.

نکته: اگر می‌خواهید همهٔ منطق roguelike را خودتان بنویسید، بخش‌های دیگر این سایت (همان آموزش معروف «How to Make Your First Roguelike») هم به همین محتوا مربوط است.

۲. نقشهٔ درس‌ها

سری آموزشی گام‌به‌گام زیر را پوشش می‌دهد:

  • راه‌اندازی پروژه RLNET و نمایش اولین «@»
  • ساخت نقشه و تولید تصادفی سیاه‌چاه (اتاق‌ها و راهروها)
  • میدان دید با الگوریتم (FOV) و دیوارهای کشف‌شده
  • حرکت و تعامل: قدم زدن، باز کردن درها
  • مسیریابی دشمن به سمت بازیکن (Pathfinding)
  • مبارزه: هیولاها، حمله، آسیب و مرگ
  • سیستم آیتم‌ها، فونت و پالت، ذخیرهٔ بازی

۳. نمونهٔ کد: نقشه و میدان دید

csharpusing RogueSharp;
using RogueSharp.MapCreation;

// ساخت نقشه با تولیدکنندهٔ تصادفی سیاه‌چاه (شبیه Rogue)
IMapCreationStrategy<Map> strategy =
    new RandomRoomsMapCreationStrategy<Map>(width: 80, height: 50,
                                            maxRooms: 30, roomMaxSize: 12, roomMinSize: 6);
Map map = Map.Create(strategy);

// محاسبهٔ میدان دید از دید بازیکن
map.ComputeFov(x: playerX, y: playerY, radius: 10, lightWalls: true);

// پیمایش نقشه و رسم: فقط سلول‌های «در دید» یا «کشف‌شده» را نمایش بده
foreach (Cell cell in map.GetAllCells())
{
    if (cell.IsInFov)
        // روشن — رسم سلول
    else if (cell.IsExplored)
        // تاریک ولی دیده‌شده — رسم با رنگ کم‌نور
}

با همین، حس کلاسیک «تاریکی ناشناخته» بازی‌های roguelike به دست می‌آید — بدون بازنویسی الگوریتم FOV.

۴. جمع‌بندی

  • RogueSharp کار سنگین (FOV، pathfinding، تولید نقشه) را آماده می‌دهد؛ تمرکز شما روی گیم‌پلی است.
  • سری آموزشی رسمی، کامل و به‌روز است و کد هر درس تکمیل‌شونده.
  • یک راه خوب: اول این سری، بعد بازنویسی منطق (مثل FOV) با دست، برای درک عمیق.
