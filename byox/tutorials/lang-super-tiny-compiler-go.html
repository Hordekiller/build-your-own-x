The Super Tiny Compiler — کامپایلر فوق‌کوچک در Go

⚙ زبان: Go ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور پورت Go از «The Super Tiny Compiler» نوشتهٔ hazbo است — بازنویسی نسخهٔ مشهور جاوااسکریپتی jamiebuilds در Go.
↗ مشاهده منبع اصلی

داستان کامپایلر ۲۰۰ خطی

کامپایلر اصلی (the-super-tiny-compiler) توسط جیمز کایل (jamiebuilds) در حدود ۲۰۰ خط جاوااسکریپت نوشته شد تا نشان دهد که ساختار کامپایلر در اصل ساده است؛ ورودی شبیه Lisp (add 2 (subtract 4 2)) و خروجی شبیه C add(2, subtract(4, 2)). نسخهٔ Go همین مسیر را با تایپ‌های صریح و توابع تمیز دنبال می‌کند.

چهار مرحلهٔ اصلی

۱) Tokenizer: درشت‌نمایی ورودی به توکن‌ها؛ ۲) Parser: توکن‌ها را به AST (درخت نحو) تبدیل می‌کند؛ ۳) Transformer: AST ورودی را به AST خروجی (که ساختار C دارد) تبدیل می‌کند؛ ۴) Code Generator: از AST خروجی، رشتهٔ کد C می‌سازد.

برای ساختاردهی، «کامپایلر» در سه تابع tokenizer، parser و transformer (با traverser داخلی) پیاده شده و در انتها codeGenerator کار چاپ را انجام می‌دهد.

نمونهٔ کد: مرحلهٔ transformer در Go

Go// تبدیل گره‌ها: ولدها به "CallExpression"
func transform(node *Node, parent *Node) {
  switch n := (*node).(type) {
  case *NumberLiteral:
    if parent != nil {
      (*parent).(type) = ... // تبدیل به NumberLiteral خروجی
    }
  case *CallExpression:
    // بخش اول: تابع به CallExpression جدا تبدیل می‌شود
    expression := &CallExpression{Callee: n.Callee, Arguments: []Node{}}
    // بخش دوم: آرگومان‌ها را با خودش (به‌عنوان والد) بازگشت بزن
    for _, arg := range n.Arguments {
      transform(&arg, newParent)
    }
  }
}

ترفند اصلی کامپایلر اصلی، یک تابع traverser است که با دو نوع بازدید (enter و exit) روی AST حرکت می‌کند؛ نسخهٔ Go هم همین الگو را دارد.

چه چیزی یاد می‌گیرید

با ۲۰۰ خط کد، با مفاهیم اصلی کامپایلر آشنا می‌شوید: lexing (تشخیص کاراکترهای گروه‌بندی)، parsing (ساخت سلسله‌مراتب)، AST (درخت داده)، traverser (پیمایش بازگشتی) و codegen (چاپ کد). چون ورودی ساده است، تمرکز روی مفاهیم است نه جزئیات زبان.

جمع‌بندی

بهترین «اولین کامپایلر» برای شروع: کوتاه، خوانا، با تست. نسخهٔ Go برای کسانی که به تایپ و وضوح Go علاقه دارند عالی است؛ نسخهٔ جاوااسکریپت برای آشنایی سریع با مفاهیم. بعد از آن، به سراغ کامپایلرهای واقعی‌تر (مثل acwj یا Crafting Interpreters) بروید.

کپیرایت: hazbo. این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
