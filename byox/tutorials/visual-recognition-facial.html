ساخت پایپ‌لاین تشخیص چهره با یادگیری عمیق در TensorFlow

⚙ زبان: Python 🧠 TensorFlow + Dlib + scikit-learn ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور مقالهٔ «Building a Facial Recognition Pipeline with Deep Learning in Tensorflow» از کول ماری (Cole Murray) در HackerNoon (۲۰۱۷) است. کد کامل در GitHub موجود است.

۱. مقدمه: چهره را چطور «نمایندگی» کنیم؟

تشخیص چهره یک راه‌حل بیومتریک است که ویژگی‌های منحصربه‌فرد چهره را اندازه می‌گیرد. سؤال اصلی: چگونه یک چهره را به شکلی عددی و قابل مقایسه نمایندگی کنیم؟ پیشینه: در ۱۹۶۰، وودرو بلدسو (Woodrow Bledsoe) مختصات ویژگی‌های برجستهٔ چهره (خط مو، چشم‌ها، بینی) را علامت‌گذاری می‌کرد. سپس در ۲۰۱۵، محققان گوگل مقالهٔ FaceNet را منتشر کردند: یک شبکهٔ عصبی پیچشی (CNN) که به‌جای استخراج دستی ویژگی، مستقیم از پیکسل‌های تصویر استفاده می‌کند و به رکورد دقت ۹۹/۶۳٪ روی دیتاست LFW رسید.

نکتهٔ کلیدی FaceNet: بازنمایی چهره به‌صورت embedding — یک بردار ۱۲۸-بعدی. چون این بردارها در یک فضای برداری مشترک قرار دارند، فاصلهٔ برداری، معیار شباهت دو چهره می‌شود؛ و همین embedding ها به‌عنوان ورودی کارهای طبقه‌بندی، خوشه‌بندی یا رگرسیون استفاده می‌شوند. تابع هزینهٔ FaceNet، «triplet loss» است: کمینه‌کردن فاصله از نمونه‌های مثبت (هم‌هویتی) و بیشینه‌کردن فاصله از نمونه‌های منفی — یعنی چهره‌های یک شخص باید به هم نزدیک‌تر باشند تا چهره‌های دو شخص متفاوت.

۲. ابزارها: Docker، TensorFlow، Dlib و OpenCV

نصب TensorFlow، OpenCV و مخصوصاً Dlib (که تشخیص و ترازبندی چهره را فراهم می‌کند) دردسرساز است؛ برای همین نویسنده همه را داخل Docker نصب می‌کند تا محیطی سازگار و مستقل از پلتفرم داشته باشد. ساختار پروژه:

text├── Dockerfile
├── etc/20170511-185253/20170511-185253.pb     # وزن‌های از‌پیش‌آموزش‌دیدهٔ مدل
├── data/                                      # دیتاست LFW
└── medium_facenet_tutorial/
    ├── align_dlib.py                          # ابزارهای ترازبندی Dlib
    ├── preprocess.py                          # پیش‌پردازش (تشخیص+برش+تراز)
    ├── download_and_extract_model.py
    ├── lfw_input.py                           # بارگذاری موازی تصاویر
    ├── train_classifier.py                    # آموزش SVM
    └── shape_predictor_68_face_landmarks.dat  # مدل نقاط کلیدی چهره

دیتاست آموزشی: LFW (Labeled Faces in the Wild) — ۱۷۷ مگابایت، هر شخص در یک پوشه با چند تصویر (مثلاً Tyra_Banks_0001.jpg). این ساختار پوشه‌ای را می‌توانید با دیتاست خودتان هم جایگزین کنید.

۳. پیش‌پردازش: تشخیص، برش و ترازبندی با Dlib

پیش‌پردازش دو مشکل را حل می‌کند: جداسازی (segmentation) و ترازبندی (alignment). اول، با align_dlib.py بزرگ‌ترین چهرهٔ تصویر پیدا می‌شود (پس لازم نیست داده از قبل برش‌خورده باشد). دوم، چون صورت معمولاً در تصویر دقیقاً وسط نیست، تصویر با استفاده از مدل نقطه‌های کلیدی (shape_predictor_68_face_landmarks.dat) بر اساس موقعیت چشم‌های داخلی و لب پایین تراز می‌شود تا همهٔ ورودی‌ها استاندارد شوند (نور، پوشیدگی و اختلاف پس‌زمینه هم از مشکلات رایجی‌اند که این استانداردسازی کمک می‌کند): 

bash$ docker run -v $PWD:/medium-facenet-tutorial \
  -e PYTHONPATH=$PYTHONPATH:/medium-facenet-tutorial \
  -it colemurray/medium-facenet-tutorial \
  python3 medium_facenet_tutorial/preprocess.py \
  --input-dir data --output-dir output/intermediate --crop-dim 180

اسکریپت هر تصویر را می‌خواند، بزرگ‌ترین چهره را پیدا می‌کند، تراز می‌کند و نتیجه را می‌نویسد؛ اگر چهره‌ای پیدا نشود، نام فایل لاگ می‌شود. چون اسکریپت از موازی‌سازی پشتیبانی می‌کند، با چند هسته سریع‌تر اجرا می‌شود.

۴. ساخت Embeddingها با TensorFlow

شبکهٔ عصبی انتخاب‌شده Inception Resnet V1 است (همان معماری FaceNet). وزن‌های از‌پیش‌آموزش‌دیده (مدل 20170511-185253.pb) دانلود می‌شود. سپس با TensorFlow از Queue API استفاده می‌شود تا تصاویر پیش‌پردازش‌شده به‌صورت موازی (چندنخی) بارگذاری شوند — روی GPU این یعنی پیش‌پردازش روی CPU و ضرب ماتریس‌ها روی GPU انجام می‌شود، بدون توقف. خروجی برای هر چهره یک بردار ۱۲۸-بعدی است.

۵. آموزش دسته‌بند SVM

Embedding ها حالا به‌عنوان «ویژگی» ورودی ماشین بردار پشتیبان (SVM) اسکای‌لرن می‌شوند تا روی هر هویت آموزش ببیند. هویت‌هایی با کمتر از ۱۰ تصویر حذف می‌شوند (پارامتری قابل تنظیم از خط فرمان):

bash$ docker run -v $PWD:/medium-facenet-tutorial \
  -e PYTHONPATH=$PYTHONPATH:/medium-facenet-tutorial \
  -it colemurray/medium-facenet-tutorial \
  python3 medium_facenet_tutorial/train_classifier.py \
  --input-dir output/intermediate \
  --model-path etc/20170511-185253/20170511-185253.pb \
  --classifier-path output/classifier.pkl \
  --num-threads 16 --num-epochs 25 \
  --min-num-images-per-class 10 --is-train
# ~۱۶ دقیقه روی MacBook Pro

برای ارزیابی، همان دستور بدون --is-train اجرا می‌شود تا روی تصاویر دیده‌نشده پیش‌بینی کند؛ نویسنده با ۵ دوره به دقت ۸۵٪ می‌رسد.

۶. جمع‌بندی و درس‌ها

  • خط لوله‌ٔ مدرن تشخیص چهره: تشخیص + تراز با Dlib ← embedding با شبکهٔ عمیق ← طبقه‌بندی با SVM. هر مرحله یک مسئلهٔ مجزا با بهترین ابزار خودش.
  • embedding به‌جای طبقه‌بندی مستقیم: بردار ۱۲۸-بعدی FaceNet را می‌توان برای هر کار پایین‌دستی (طبقه‌بندی، خوشه‌بندی، رگرسیون، جست‌وجوی شباهت) استفاده کرد.
  • مدیریت محیط با Docker: بازتولیدپذیری در یادگیری ماشین از نیمه‌های راه شروع می‌شود — وابستگی‌های سخت مثل dlib را کانتینری کنید.
  • پیش‌پردازش > مدل: ترازبندی چهره پیش از ورود به مدل، تأثیری بزرگ‌تر از پیچیده‌کردن شبکه دارد.
نکتهٔ تکمیلی: از همان سال‌ها، این معماری (Dlib + FaceNet-style embedding + SVM) به استاندارد ابزارهایی مثل face_recognition تبدیل شد؛ در کاربردهای امروزی تشخیص چهرهٔ باز (زاویه و نور متغیر) با مدل‌های قوی‌تر جایگزین می‌شود، اما منطق خط لوله همان است.
