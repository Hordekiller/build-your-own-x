نوشتن یک زباله‌روب (Garbage Collector) ساده در C

هدف آموزش

وقتی مفسر زبان خودتان را می‌نویسید، به‌جای اتکا به malloc/free خام، می‌توانید یک جمع‌کنندهٔ زبالهٔ مخصوص خودتان بسازید. این آموزش با تکنیک mark-and-sweep نشان می‌دهد که چطور یک GC کوچک و کارآمد در C پیاده شود — دقیقاً همان کاری که مفسرهای واقعی می‌کنند.

طراحی: بلوک‌های مدیریت‌شده

ایدهٔ اصلی: تمام اشیای تخصیص‌داده‌شده را در یک لیست پیوندی از «بلوک‌ها» نگه می‌داریم. هر بلوک (که با MAP_ENTRY متادیتا دارد) شامل: اندازه، آدرس حافظهٔ واقعی، و فلگ‌هایی برای علامت‌گذاری. تخصیص از طریق map_alloc انجام می‌شود که بلوک را ساخته و به لیست اضافه می‌کند.

برای اینکه GC بداند چه چیزهایی «ریشه» هستند، آموزش از یک پشتهٔ global استفاده می‌کند: هر وقت متغیری را «زنده» می‌خواهید، آن را با map_stack_push روی این پشته می‌گذارید؛ GC از آن‌جا شروع به علامت‌گذاری می‌کند.

نمونهٔ کد: ساختار بلوک و حلقهٔ sweep

Ctypedef struct map_entry {
  size_t      size;     // اندازهٔ بلوک
  char*       memory;   // حافظهٔ واقعی
  struct map_entry* next;
  uint8_t     marked;   // فلگ علامت‌گذاری
} map_entry_t;

// پاکسازی: تمام بلوک‌های علامت‌نشده را آزاد کن
void gc_sweep(void) {
  map_entry_t** entry = &map.entries;   // اشاره‌گر به سر لیست
  while (*entry) {
    map_entry_t* cur = *entry;
    if (!cur->marked) {                 // زباله پیدا شد!
      *entry = cur->next;
      free(cur->memory);
      free(cur);
    } else {
      cur->marked = 0;                 // برای چرخهٔ بعدی
      entry = &cur->next;
    }
  }
}

مهم‌ترین نکتهٔ فنی این مقاله، استفاده از اشاره‌گر به اشاره‌گر (map_entry_t**) است تا بدون نیاز به متغیر قبلی، حذف از لیست پیوندی به‌سادگی انجام شود.

گام‌های پیاده‌سازی

۱) ساختن map_alloc با مترادم (alignment) صحیح برای انواع C؛ ۲) پشتهٔ ریشه‌ها و map_stack_push؛ ۳) تابع gc_mark که به‌صورت بازگشتی روی اشیای مرجع (مثلاً آرایه‌ها) حرکت می‌کند؛ ۴) gc_sweep و پاکسازی؛ ۵) تست با برنامه‌ای که حلقه‌ای از تخصیص‌ها انجام می‌دهد.

نویسنده همچنین به محدودیت‌ها اشاره می‌کند: این GC «غیرفعال» است (فقط وقتی صدا زده شود کار می‌کند) و برای کار واقعی (مثل مفسر) باید استراتژی‌های دیگر مثل metaprogramming یا conservative scanning اضافه شوند.

جمع‌بندی
