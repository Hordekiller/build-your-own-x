چگونه Virtual DOM خودت را بنویسی

⚙ زبان: JavaScript ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور مقالهٔ «How to write your own Virtual DOM» از لئونید کوتومیس (Leonid Kutiumis) در Medium است. او یک پیاده‌سازی کامل Virtual DOM — ساخت نود مجازی، رندر به DOM و الگوریتم diff — را در چند ده خط توضیح می‌دهد.
↗ مشاهده منبع اصلی

۱. چرا Virtual DOM؟

دستکاری مستقیم DOM برای به‌روزرسانی رابط کاربری هم کند است و هم پرهزینه؛ ایدهٔ Virtual DOM: اول درخت UI را در یک نمایش دادهٔ سبک بساز (شیءهای سادهٔ جاوااسکریپت، نه DOM)، بعد تفاوت بین نسخهٔ قبلی و جدید را حساب کن و فقط همان تفاوت‌ها را روی DOM واقعی اعمال کن. این دقیقاً همان چیزی است که React و Vue انجام می‌دهند.

۲. گره‌های مجازی و h()

هر گرهٔ مجازی یک شیء ساده با سه فیلد است: نوع عنصر، ویژگی‌ها (props) و بچه‌ها (children). تابع h() (شبیه React.createElement) آن‌ها را می‌سازد:

js// ساختار گرهٔ مجازی
const vnode = {
  tag: 'div',             // نام تگ
  props: { className: 'card' },  // صفات
  children: [/* گره‌های مجازی یا متن */],
};

// تابع کمکی h — ساخت گره با آرگومان‌های مرتب
function h(tag, props, ...children) {
  return { tag, props, children: children.flat() };
}

const tree = h('div', { id: 'app' },
  h('h1', {}, 'سلام!'),
  h('p', {}, 'این درخت مجازی است.'),
);

۳. رندر: تبدیل درخت مجازی به DOM

تابع render به‌صورت بازگشتی گره‌ها را به عنصرهای واقعی تبدیل می‌کند؛ بچه‌های رشته‌ای به textNode تبدیل می‌شوند:

jsfunction render(vnode) {
  if (typeof vnode === 'string') {
    return document.createTextNode(vnode);
  }

  const el = document.createElement(vnode.tag);

  // تنظیم صفات (props)
  for (const key in vnode.props) {
    el.setAttribute(key, vnode.props[key]);
  }

  // رندر بازگشتی بچه‌ها
  vnode.children.forEach((child) => el.appendChild(render(child)));

  return el;
}

۴. diff و patch: مقایسه و اعمال تغییرات

قلب مقاله تابع diff است: درخت مجازی قبلی را با درخت جدید مقایسه می‌کند و حداقل تغییرات را روی DOM واقعی اعمال می‌کند. سه حالت اصلی:

jsfunction diff(oldVnode, newVnode, parentNode) {
  // حالت ۱: یکی از درخت‌ها متن و دیگری عنصر — جایگزین کامل
  if (typeof oldVnode === 'string' || typeof newVnode === 'string') {
    if (oldVnode !== newVnode) {
      // به‌روزرسانی سادهٔ متن
      parentNode.childNodes[0].nodeValue = newVnode;
    }
    return;
  }

  // حالت ۲: تگ‌ها متفاوت — ساخت کل نود جدید و جایگزینی
  if (oldVnode.tag !== newVnode.tag) {
    const newEl = render(newVnode);
    parentNode.replaceChild(newEl, parentNode.childNodes[0]);
    return;
  }

  // حالت ۳: تگ یکسان — به‌روزرسانی صفات
  const domNode = parentNode.childNodes[0];
  updateProps(domNode, oldVnode.props, newVnode.props);

  // و سپس مقایسهٔ بچه‌ها (بازگشتی)
  const max = Math.max(oldVnode.children.length, newVnode.children.length);
  for (let i = 0; i < max; i++) {
    // ... diff روی هر جفت بچه با childNodes[i]
  }
}

function updateProps(domNode, oldProps, newProps) {
  // حذف صفات حذف‌شده
  for (const key in oldProps) {
    if (!(key in newProps)) domNode.removeAttribute(key);
  }
  // به‌روزرسانی صفات جدید
  for (const key in newProps) {
    if (oldProps[key] !== newProps[key]) {
      domNode.setAttribute(key, newProps[key]);
    }
  }
}

نکتهٔ طراحی: مقایسه بر اساس شاخص بچه‌ها انجام می‌شود، نه بر اساس نوع — بنابراین جابه‌جایی عناصر به این الگوریتم ساده «مشکوک» است؛ اینجاست که keyها در React/Vue وارد می‌شوند تا diff هوشمندتر شود.

۵. یک مثال کامل

jsconst app = document.getElementById('app');

// رندر اولیه
const v1 = h('div', { className: 'box' },
  h('h2', {}, 'عنوان'),
  h('button', { onclick: () => update() }, 'کلیک کن'),
);
app.appendChild(render(v1));

function update() {
  // درخت مجازی جدید (مثلاً بعد از تغییر state)
  const v2 = h('div', { className: 'box big' },
    h('h2', {}, 'عنوان جدید'),
    h('button', { onclick: () => update() }, 'کلیک کن'),
  );
  // فقط تفاوت‌ها روی DOM اعمال می‌شود
  diff(v1, v2, app);
}

در این مثال، صفت className تغییر می‌کند و متن h2 عوض می‌شود؛ بقیهٔ نودها (مثل button) اصلاً دست نمی‌خورند — این همان کارایی است که Virtual DOM به ارمغان می‌آورد.

۶. جمع‌بندی

  • Virtual DOM فقط یک ساختار داده است؛ قدرت آن در الگوریتم diff است که «چه چیزی عوض شده» را می‌فهمد.
  • کل پیاده‌سازی در حدود ۱۰۰ خط جاوااسکریپت خالص جا می‌گیرد.
  • React و Vue از همین ایده استفاده می‌کنند و به‌جای شاخص، با key مقایسهٔ هوشمندتری انجام می‌دهند.
