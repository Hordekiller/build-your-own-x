۱. معرفی سری

سری فیزیک بازی آلن چو، مجموعه‌ای از نوشته‌های فنی است که از دیدگاه یک برنامه‌نویس موتور بازی در صنعت (با سابقه کار روی عناوین بزرگ) به فیزیک بازی‌ها نگاه می‌کند. سری به سه گروه اصلی تقسیم می‌شود:

  • ریاضیات بازی (Game Math): پایه‌های جبر خطی که هر موتور فیزیکی روی آن‌ها سوار است.
  • فیزیک بازی (Game Physics): دینامیک، برخورد و شبیه‌سازی.
  • برنامه‌نویسی (Programming): جنبه‌های مهندسی پیاده‌سازی موتور.

نکته قابل توجه این سری، توازن بین «ریاضی دقیق» و «روش‌های عملی صنعت» است: هر مفهوم اول به‌صورت شهودی توضیح داده می‌شود و سپس با ریاضیات کامل و مثال‌های پیاده‌سازی دنبال می‌شود.

۲. ریاضیات بازی

بخش ریاضیات بازی، پیش‌نیاز درک فیزیک است:

  • بردارها در دو و سه بعد: جمع، ضرب، ضرب داخلی و خارجی، و کاربردشان در محاسبه نرمال و زاویه.
  • ماتریس‌ها: تبدیل‌های خطی، چرخش، مقیاس و ترجمه؛ و چرا ماتریس‌ها برای ترکیب تبدیل‌ها مفیدند.
  • کواترنیون‌ها (Quaternions): جایگزین بهتری برای ماتریس چرخش — بدون قفل شدن زوایای اویلر و با درون‌یابی نرم‌تر.
cpp// نمونه: چرخاندن یک بردار با کواترنیون (چهارچوب کلی)
// q: کواترنیون چرخش (w, x, y, z)
// v: بردار ورودی

Vector3 Rotate(Quaternion q, Vector3 v) {
    Quaternion vq(0, v.x, v.y, v.z);
    Quaternion r = q * vq * Conjugate(q);
    return Vector3(r.x, r.y, r.z);
}

این بخشها در مقالهها با شهود هندسی و مثالهای تعاملی همراهاند؛ مثلاً این‌که ضرب داخلی چه «رابطهای» بین دو بردار را اندازه میگیرد و چرا برای تشخیص برخورد به نرمال سطح نیاز داریم.

۳. دینامیک جسم صلب

بخش فیزیک با دینامیک شروع می‌شود:

  • سینماتیک و دینامیک خطی: مکان، سرعت، شتاب و انتگرال‌گیری عددی.
  • دینامیک چرخشی: سرعت زاویه‌ای، گشتاور و تنسور لختی (inertia tensor).
  • قالب حرکت (Equations of Motion) و گام شبیه‌سازی با زمان ثابت (fixed timestep).
cpp// انتگرال‌گیری نیمه-ضمنی (semi-implicit / symplectic Euler)
void Step(RigidBody& body, float dt, const Vector3& gravity) {
    // ۱) سرعت را با شتاب به‌روز کن
    body.linearVelocity += gravity * dt;
    body.angularVelocity += body.invInertia * (body.torque - ...) * dt;

    // ۲) مکان و چرخش را با سرعت جدید به‌روز کن
    body.position += body.linearVelocity * dt;
    body.orientation = Normalize(body.orientation * QuaternionFromAxisAngle(body.angularVelocity * dt));
}

۴. تشخیص برخورد

یکی از ارزشمندترین بخش‌های سری، مقالات تشخیص برخورد است که هم جنبه نظری و هم پیاده‌سازی دارند:

  • آزمون‌های شکل‌های ساده: کره-کره، AABB، کره-صفحه و ترکیب‌های پایه.
  • الگوریتم‌های عمومی محدب: جداسازی محور (SAT) و الگوریتم‌های GJK/EPA بر پایه تفاضل مینکوفسکی.
  • تشخیص برخورد پیوسته (CCD): جلوگیری از نفوذ اجسام سریع در گام‌های بزرگ (tunneling).
cpp// تابع پشتیبان (support function) — بلوک سازنده الگوریتم GJK
// در جهت d، دورترین نقطه شکل محدب را برمی‌گرداند
Vector3 Support(const ConvexShape& shape, const Vector3& d) {
    float maxDot = -FLT_MAX;
    Vector3 best = Vector3::Zero;
    for (const Vector3& v : shape.vertices) {
        float d_ = Dot(v, d);
        if (d_ > maxDot) { maxDot = d_; best = v; }
    }
    return best;
}

این الگوریتم‌ها هسته موتورهای حرفه‌ای مثل Bullet و PhysX هستند؛ درک آن‌ها با خواندن مستقیم سری بسیار آسان‌تر از خواندن کد موتورهای آماده است.

۵. حل‌کننده برخورد و قیود

بعد از یافتن نقاط برخورد، نوبت پاسخ برخورد است: تولید نقطه تماس با نرمال، نفوذ و بافت تماس (contact manifold)، سپس حل ایمپالس برای هر نقطه به‌همراه اصطکاک. در نهایت سری وارد قیود عمومی (constraints) می‌شود — همان مکانیزمی که با آن لولا، فنر و مفاصل ساخته می‌شود و قلب هر موتور فیزیک مدرن است.

نکته: سری به‌صورت فزاینده ساخته شده؛ اگر تازه‌کارید، اول بخش ریاضیات بازی را کامل بخوانید، سپس مقالات دینامیک و بعد سراغ تشخیص برخورد و حل‌کننده‌ها بروید.
کپیرایت: مقالات سری فیزیک بازی اثر آلن چو (Allen Chou) است. این صفحه فقط ترجمه و معرفی فارسی آن است و تمام حقوق محتوا و کدها متعلق به نویسنده اصلی است. برای مشاهده اصل مطالب به وبلاگ اصلی مراجعه کنید.
