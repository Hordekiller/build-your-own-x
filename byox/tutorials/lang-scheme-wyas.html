چه تفاوتی با نسخهٔ ۱ دارد؟

نسخهٔ ۱ (2013) مفسر را ساده می‌ساخت؛ نسخهٔ ۲ (2015) با بازنگری کامل، از ابتدا با روش‌های مهندسی مدرن نوشته شده: پشتیبانی از cabal، آزمون‌های خودکار (QuickCheck و golden tests)، مستندسازی با haddock، سیستم ماکروی بهداشتی (hygienic macros) و ساختار داده‌های bottom-up.

معماری پروژه

کد در ماژول‌های کوچک سازماندهی شده: Language.Scheme.* شامل parser، runtime (ارزیابی)، environment و types. هر ماژول در پوشهٔ test تست اختصاصی دارد؛ مثلاً با golden-test رفتار eval روی اسکریپت‌های نمونهٔ Scheme مقایسه می‌شود.

نمونهٔ کد: محیط و ارزیابی

Haskell-- تعریف محیط با نوع دادهٔ قابل دسترسی سریع
data Env = Env { envParent :: Maybe Env
               , envValues :: Map.Map Text LispVal
               }

-- ارزیابی with pattern matching
eval :: Env -> LispVal -> IOThrowsError LispVal
eval env (LispAtom a) = lookupEnv env a

eval env (LispList [LispAtom "if", cond, cons, alt]) = do
  result <- eval env cond
  case result of
    LispBool False -> eval env alt
    LispList []    -> eval env alt   -- در Scheme: لیست خالی = false
    _              -> eval env cons

eval env (LispList [LispAtom "lambda", params, body]) = ...

ویژگی‌های برجسته

۱) ماکروهای بهداشتی: با syntax-rule و define-syntax — بدون تداخل نام بین ماکرو و کد کاربر؛ ۲) بازنمایی دادهٔ LispVal به‌صورت sum type با pattern matching؛ ۳) خطاها با MonadError؛ ۴) یک سیستم تست کامل که هم نمونه‌ی قانون‌مندی کد است و هم رگرسیون را تضمین می‌کند.

جمع‌بندی

برای کسی که نسخهٔ ۱ یا «Scheme در ۴۸ ساعت» را خوانده و می‌خواهد ببیند یک مفسر «حرفه‌ای» چطور نوشته می‌شود: معماری ماژولار، تست‌ها و ماکروها، همه الگوهای خوب Haskell را نشان می‌دهد.
