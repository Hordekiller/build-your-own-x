راهنمای Beej برای برنامه‌نویسی شبکه

⚙ زبان: C ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمه فارسی «Beej's Guide to Network Programming» از Brian "Beej" Jorgensen Hall است — شناخته‌شده‌ترین راهنمای برنامه‌نویسی سوکت: از ساختارها و getaddrinfo تا سرور و کلاینت کامل TCP/UDP، select و DNS، به‌همراه مثال‌های آماده کامپایل.
↗ مشاهده منبع اصلی

۱. مقدمه

راهنمای Beej، کلاسیک برنامه‌نویسی سوکت است: برای همه کسانی که آشنایی مقدماتی با C دارند، مسیر شبکه‌سازی با Internet Sockets را از صفر هموار می‌کند. سوکت‌ها (که از دانشگاه برکلی شروع شدند) به تقریباً همه پلتفرم‌ها — Unix، لینوکس و حتی ویندوز — منتقل شده‌اند. این راهنما در قالب‌های HTML تک‌صفحه و چندصفحه، PDF و ZIP دانلود در دسترس است و نسخه‌های ترجمه‌شده (چینی، فرانسوی، ایتالیایی، کرهای و...) هم دارد.

۲. دو نوع سوکت

برنامه‌نویسی سوکت با دو پرسش شروع می‌شود:

  • سوکت استریم (SOCK_STREAM / TCP): اتصال‌محور، مرتب و بدون خطا؛ دو طرف با connect و accept اتصال می‌سازند. مثل مکالمه تلفنی.
  • سوکت دیتاگرام (SOCK_DGRAM / UDP): بدون اتصال و بدون تضمین؛ پیام‌ها با sendto/ recvfrom ارسال می‌شوند. مثل نامه پستی.

همچنین باید ساختارهای آدرس را شناخت: struct sockaddr_in (IPv4)، sockaddr_in6 (IPv6) و addrinfo که با getaddrinfo() از نام میزبان/نوع سوکت پر می‌شود — روش مدرن و سازگار با IPv6.

cstruct addrinfo hints;
struct addrinfo *res;

memset(&hints, 0, sizeof hints);
hints.ai_family = AF_UNSPEC;      // IPv4 یا IPv6
hints.ai_socktype = SOCK_STREAM;  // TCP

getaddrinfo("www.example.com", "80", &hints, &res);

۳. API اصلی

جریان کامل برنامه‌نویسی سوکت با این توابع ساخته می‌شود:

  • socket() — ساخت سوکت (اخذ توصیف‌کننده).
  • bind() — اتصال سوکت به یک پورت/آدرس (اجباری برای شنود).
  • listen() — آماده شنیدن اتصال‌های ورودی.
  • accept() — پذیرش اتصال جدید (سوکت جدید مخصوص آن کلاینت می‌سازد).
  • connect() — برقراری اتصال به سرور (در سمت کلاینت).
  • send() / recv() — ارسال و دریافت داده روی اتصال.
  • sendto() / recvfrom() — نسخه دیتاگرامِ بدون اتصال.
  • close() / shutdown() — بستن سوکت.

۴. مثال کامل: سرور TCP

سرور کلاسیک: getaddrinfo → socket → setsockopt برای اجازه استفاده مجدد از پورت → bind → listen → حلقه accept:

c#include <stdio.h>
#include <sys/socket.h>
#include <netdb.h>

int main(void) {
    struct addrinfo hints, *p;
    int listener, new_fd;
    struct sockaddr_storage their_addr;
    socklen_t addr_size;

    memset(&hints, 0, sizeof hints);
    hints.ai_family = AF_UNSPEC;
    hints.ai_socktype = SOCK_STREAM;
    hints.ai_flags = AI_PASSIVE; // آدرس خودمان

    getaddrinfo(NULL, "3490", &hints, &p);
    listener = socket(p->ai_family, p->ai_socktype, p->ai_protocol);
    bind(listener, p->ai_addr, p->ai_addrlen);
    listen(listener, 10);

    addr_size = sizeof their_addr;
    new_fd = accept(listener, (struct sockaddr *)&their_addr, &addr_size);

    send(new_fd, "سلام، دنیا!", 12, 0);
    close(new_fd);
    close(listener);
    return 0;
}

۵. مثال کامل: کلاینت

کلاینت ساده‌تر است: getaddrinfo با نام سرور، سپس socket و connect و در پایان send/recv:

cint main(int argc, char *argv[]) {
    int sockfd;
    struct addrinfo hints, *p;
    char buf[64];

    memset(&hints, 0, sizeof hints);
    hints.ai_family = AF_UNSPEC;
    hints.ai_socktype = SOCK_STREAM;

    getaddrinfo(argv[1], "3490", &hints, &p);
    sockfd = socket(p->ai_family, p->ai_socktype, p->ai_protocol);
    connect(sockfd, p->ai_addr, p->ai_addrlen);

    recv(sockfd, buf, sizeof buf - 1, 0);
    printf("دریافت شد: %s\n", buf);
    close(sockfd);
    return 0;
}

۶. مباحث پیشرفته

کتاب بعد از مثال‌های پایه به این موضوع‌ها می‌پردازد: برنامه‌نویسی چندکلاینت با select() و poll()، سوکت‌های مسدودکننده/غیرمسدودکننده، مرجع کامل توابع و ساختارها، errno و گزارش خطا (perror/gai_strerror)، و پیوست‌های مفید مانند تفاوت IPv4/IPv6 و نکات ویندوز (Winsock). کل راهنما پر از مثال‌های قابل کامپیل است که یک‌به‌یک بنیاد شبکه‌سازی سوکت را کامل می‌کنند.

نکته: اگر می‌خواهید «زیرِ سوکت‌ها» را ببینید، مقاله بعدی این دسته — پشته TCP/IP از صفر — همان سطح را در لایه‌های اترنت و ARP ادامه می‌دهد.
