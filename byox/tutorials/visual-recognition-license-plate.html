۱. سیستم LPR چیست؟

سیستم‌های تشخیص پلاک خودرو (License Plate Recognition — LPR) با استفاده از مفهوم «تشخیص نوری کاراکتر» (OCR) کاراکترهای روی پلاک را می‌خوانند: یک عکس از خودرو وارد می‌شود و خروجی، کاراکترهای پلاک است. ساخت چنین سیستمی بدون یادگیری ماشین هم ممکن است (مثلاً با template matching یا feature extraction)، اما با یادگیری ماشین، دقت از طریق بهبود فرایند آموزش بیشتر می‌شود — در این آموزش، بخش تشخیص کاراکتر با یادگیری ماشین انجام می‌شود: نگاشت تصویر یک کاراکتر به کاراکتر واقعی (تمایز بین A ها، B ها و…).

الگوریتم LPR (گاهی ALPR — Automatic LPR) سه مرحلهٔ اصلی دارد:

  1. تشخیص پلاک (License Plate Detection): اولین و مهم‌ترین مرحله — ورودی تصویر خودرو، خروجی موقعیت پلاک.
  2. جداسازی کاراکترها (Character Segmentation): ترسیم و بریدن تک‌تک کاراکترهای روی پلاک به تصاویر مستقل.
  3. تشخیص کاراکتر (Character Recognition): شناسایی کاراکترهای بریده‌شده — همان جایی که یادگیری ماشین وارد می‌شود.

۲. آماده‌سازی محیط

اول یک محیط مجازی (virtualenv) برای مدیریت وابستگی‌ها ساخته می‌شود و بستهٔ scikit-image (پردازش تصویر) نصب می‌شود که به‌نوبهٔ خود به scipy، numpy و matplotlib وابسته است، و کتابخانهٔ تصویر Pillow.

bash$ virtualenv venv
$ source venv/bin/activate
$ pip install scikit-image pillow

۳. مرحلهٔ اول: تشخیص موقعیت پلاک

تصویر خوانده و به خاکستری تبدیل می‌شود (هر پیکسل بین ۰ تا ۲۵۵)، سپس به تصویر دودویی (سیاه/سفید کامل) تبدیل می‌گردد. حالا برای یافتن ناحیهٔ پلاک، از مفهوم تحلیل مؤلفه‌های متصل (Connected Component Analysis — CCA) استفاده می‌شود: CCA به ما کمک می‌کند نواحی متصلِ پیش‌زمینه را گروه‌بندی و برچسب‌گذاری کنیم (دو پیکسل متصل‌اند اگر مقدار یکسان داشته باشند و مجاور هم باشند).

pythonimport numpy as np
from skimage.measure import label, regionprops
from skimage.morphology import closing, square

car_image = mpimg.imread('car.jpg')
gray = rgb2gray(car_image)

# تبدیل به دودویی: نواحی روشنِ خودرو (پلاک سفید) جدا می‌شوند
bw = closing(gray > 0.5, square(3))

label_image = label(bw)              # برچسب‌گذاری همهٔ مؤلفه‌های متصل
for region in regionprops(label_image):   # هر ناحیه با ویژگی‌هایش
    if region.area < 50:             # حذف نویزهای ریز
        continue
    minr, minc, maxr, maxc = region.bbox
    rect = patches.Rectangle((minc, minr), maxc - minc, maxr - minr,
                             fill=False, edgecolor='red', linewidth=2)

مشکل: ناحیه‌های دیگری غیر از پلاک هم برچسب می‌خورند (چراغ‌ها، برچسب‌ها و…). برای حذف آن‌ها، از ویژگی‌های هندسی پلاک واقعی استفاده می‌کنیم — مثل این‌که مساحت پلاک حدود ۱۵٪ تا ۴۰٪ کل تصویر باشد و عرض از ارتفاع بیشتر باشد. حتی با این فیلتر هم ممکن است ناحیه‌هایی مثل چراغ جلو باقی بمانند؛ برای حذف آن‌ها، پرتاب عمودی (vertical projection) انجام می‌شود: جمع پیکسل‌های هر ستون — فرض بر این است که ناحیهٔ پلاک چون رویش کاراکتر نوشته شده، مقدار پیکسلی زیادی دارد. ناحیه‌هایی که این معیار را برآورده نکنند حذف می‌شوند.

۴. مرحلهٔ دوم: جداسازی کاراکترها

با همان تکنیک CCA روی خودِ پلاک، تک‌تک کاراکترها جداسازی و بریده می‌شوند. در نسخهٔ سادهٔ مقاله، از چند ناحیهٔ نامزد، ایندکس پلاک واقعی دستی انتخاب می‌شود (نویسنده می‌گوید نسخهٔ نهایی شامل اعتبارسنجی خودکار ناحیهٔ پلاک است). سپس هر کاراکتر به اندازهٔ ۲۰ × ۲۰ پیکسل تغییر اندازه می‌دهد — چون مرحلهٔ بعد (تشخیص با یادگیری ماشین) به ورودی‌های هم‌اندازه نیاز دارد.

۵. مرحلهٔ سوم: تشخیص کاراکتر با یادگیری ماشین

این مرحله مفهوم یادگیری ماشین را وارد می‌کند. چون از قبل می‌دانیم حروف چطور به نظر می‌رسند، از یادگیری نظارت‌شده استفاده می‌کنیم و تشخیص کاراکتر از نوع طبقه‌بندی (classification) است. فرایند: تهیهٔ دیتاست آموزش ← انتخاب دسته‌بند ← آموزش مدل ← آزمایش دقت ← استفاده از مدل برای پیش‌بینی.

دیتاست آموزش: هر حرف (به‌جز O و I که در پلاک نیجریه‌ای وجود ندارند چون شبیه ۰ و ۱ هستند) ۱۰ تصویر ۲۰×۲۰ دارد. نویسنده چند دسته‌بند را مقایسه کرده و SVC (ماشین بردار پشتیبان) را انتخاب می‌کند چون بهترین عملکرد را داشت:

pythonfrom sklearn import svm
from sklearn.model_selection import cross_val_score
import pickle

X, y = load_training_data()          # همهٔ تصاویر ۲۰×۲۰ کاراکترها و برچسب‌ها
clf = svm.SVC(kernel='linear')       # یا kernel دیگر
scores = cross_val_score(clf, X, y, cv=4)   # اعتبارسنجی ۴-تایی
clf.fit(X, y)

with open('classifier.pkl', 'wb') as f:
    pickle.dump(clf, f)              # ذخیرهٔ مدل برای پیش‌بینی‌های بعدی

بعد از آموزش، مدل بارگذاری می‌شود و کاراکترهای بریده‌شدهٔ مرحلهٔ قبل را پیش‌بینی می‌کند: clf.predict(segment_1) → «A» و همین‌طور برای بقیه.

۶. نسخهٔ کامل و نتیجه‌گیری

مقاله در انتها به مخزن کامل پروژه (که در خود GitHub توسعه یافته) اشاره می‌کند و در آن یک GUI با wxPython وجود دارد که همهٔ مراحل ALPR (مکان‌یابی، جداسازی، تشخیص)، ذخیرهٔ پلاک در پایگاه داده، تولید مدل و مقایسهٔ دسته‌بندها را پشتیبانی می‌کند.

  • یادگیری: تفکیک مرحله‌ای مسائل بینایی (محل‌یابی ← برش ← شناسایی).
  • نقش پردازش تصویر سنتی (CCA، پرتاب عمودی) در کنار یادگیری ماشین.
  • انتخاب و ارزیابی مدل: SVC با cross-validation، و ذخیره‌سازی مدل با pickle.
نکتهٔ تکمیلی: برای پلاک‌های با زاویهٔ دید ثابت، همین پایپ‌لاین سنتی کافی است؛ اما در محیط‌های بدون محدودیت (زاویه و نور متغیر) راه‌حل‌های مبتنی بر یادگیری عمیق (مثل مدل‌های تشخیص شیء) و OCR اختصاصی توصیه می‌شود — قدم بعدی طبیعی بعد از این آموزش.

۷. جمع‌بندی

سیستم تشخیص پلاک = پردازش تصویر سنتی (برای مکان‌یابی و جداسازی) + یادگیری ماشین (برای طبقه‌بندی کاراکترها). این آموزش تمام پازل را با کتابخانه‌های رایگان پایتون کنار هم می‌چیند و یک الگوی واقعی «حل مسئلهٔ دنیای واقعی با ML» ارائه می‌دهد.
