Lexical Scanning در Go — سخنرانی راب پایک

🎥 ویدیو ⚙ زبان: Go ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه مرور سخنرانی «Lexical Scanning in Go» از راب پایک (هم‌بنیان‌گذار Go) است که الگوی اسکنر متنی Go را با ماشین‌حالت (state machine) توضیح می‌دهد.
↗ مشاهده منبع اصلی

دربارهٔ سخنرانی

راب پایک در این سخنرانی نحوهٔ پیاده‌سازی اسکنر (lexer) بسته‌های text/template و html/template گو را توضیح می‌دهد — الگویی که بعدها در ساخت کامپایلرها و ابزارها بسیار استفاده شد. این یک درس کلاسیک در طراحی «ماشین حالت» (State Machine) است.

▶ تماشای ویدیو

ایدهٔ مرکزی: تابع حالت به‌جای جدول حالت

در الگوی پیشنهادی پایک، هر «حالت» یک تابع است که ورودی (اسکنر) را می‌گیرد و تابع حالت بعدی را برمی‌گرداند. به این ترتیب lexer به‌صورت یک حلقهٔ اصلی (for state != nil) اجرا می‌شود و هر تابع حالت مسئول تشخیص بخشی از ورودی است:

Gotype stateFn func(*lexer) stateFn

func (l *lexer) run() {
  for state := l.state; state != nil; {
    state = state(l)   // اجرای حالت فعلی، دریافت حالت بعدی
  }
}

// حالت ابتدایی
func lexText(l *lexer) stateFn {
  for {
    if strings.HasPrefix(l.input[l.pos:], "{{") {
      l.pos += 2
      return lexLeftDelim   // برو به حالت داخل تگ
    }
    l.next()
    if l.pos >= len(l.input) {
      l.emit(itemEOF)
      return nil   // پایان
    }
  }
}

خروجی اسکنر: آیتم‌ها و کانال

اسکنر همهٔ توکن‌ها را از طریق یک channel به مصرف‌کننده (parser) می‌فرستد؛ هر آیتم (item) دارای تایپ و متن است. این الگو، lexer را از parser کاملاً جدا می‌کند و امکان اجرای هم‌زمان (goroutine) را ساده می‌دهد.

Gotype item struct {
  typ itemType  // نوع آیتم (itemText, itemLeftDelim, ...)
  val string    // متن خام
  line int      // شماره خط برای خطاها
}

func (l *lexer) emit(t itemType) {
  l.items <- item{t, l.input[l.start:l.pos], l.line}
  l.start = l.pos
}

چرا این الگو مهم است؟

اول اینکه تمرکز روی «حالت به‌جای منطق شرطی» باعث می‌شود lexerها تمیز و قابل‌آزمایش شوند. دوم، همین سخنرانی منبع الهام بسیاری از پیاده‌سازی‌های lexer در زبان‌های دیگر (Rust، Python و…) شده است. اگر می‌خواهید زبان خودتان را بسازید و به lexer نیاز دارید، این الگو بهترین انتخاب است.

جمع‌بندی

۳۰ دقیقه ویدیو + چند ساعت تمرین، شما را به مهارت طراحی lexer با ماشین حالت می‌رساند. با این زبان، ساخت بخش اول کامپایلر شما (تجزیهٔ متن) حرفه‌ای و تمیز خواهد بود.
