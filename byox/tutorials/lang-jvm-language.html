Enkel — ساخت زبان JVM خودت (سری جاکوب دوورسکی)

⚙ زبان: Java ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور سری «Enkel» از جاکوب دوورسکی است؛ ساخت زبانی که مستقیم به بایت‌کد ماشین مجازی جاوا (JVM) کامپایل می‌شود.
↗ مشاهده منبع اصلی

هدف پروژه

Enkel زبانی ساده و جاوا-مانند است که به‌جای تولید بایت‌کد عمومی، مستقیم بایت‌کد JVM تولید می‌کند؛ یعنی خروجی کامپایلر شما با java قابل اجراست! این یعنی با یادگیری JVM bytecode، کامپایلر شما به یک «جزیرهٔ امن» برای اجرا در JVM تبدیل می‌شود.

بخش‌های سری

سری شامل چند بخش اصلی است: (۱) طراحی زبان و ساختار AST؛ (۲) lexer و parser با Apache Antlr یا دستی؛ (۳) تولید بایت‌کد با ASM (کتابخانهٔ معروف جاوا)؛ (۴) پشتیبانی از متغیرها، توابع، شرط‌ها، حلقه‌ها، کلاس‌ها و inheritance؛ (۵) مدیریت error reporting.

برای مثال، تبدیل عبارت x + 3 به بایت‌کد با ASM این‌گونه است:

Java// با استفاده از کتابخانهٔ ASM
MethodVisitor mv = cw.visitMethod(
    Opcodes.ACC_PUBLIC, "compute", "(I)I", null, null);   // متد compute(int):int

// بارگذاری مقدار متغیر x (ایندکس ۱ در local variables)
mv.visitVarInsn(Opcodes.ILOAD, 1);
// بارگذاری ثابت 3
mv.visitIntInsn(Opcodes.BIPUSH, 3);
// جمع دو عدد صحیح
mv.visitInsn(Opcodes.IADD);
// ذخیره نتیجه در متغیر
mv.visitVarInsn(Opcodes.ISTORE, 1);

چرا این آموزش خاص است؟

بیشتر آموزش‌ها خروجی اسمبلی تولید می‌کنند؛ کاری که در اینجا با بایت‌کد JVM انجام می‌شود، مزایای عملی دارد: (۱) نتیجهٔ نهایی .class بدون نیاز به لینکر اجرا می‌شود؛ (۲) با javap -c می‌توانید بایت‌کد تولیدی را بخوانید و مقایسه کنید؛ (۳) ساختار کلاس‌ها، متدها و exception table در JVM خودش یک درس کامل از طراحی ماشین مجازی است.

نکات آموزشی

در هنگام ساخت، با مفاهیم مهمی آشنا می‌شوید: جدول local variables؛ invokevirtual در برابر invokespecial؛ مدیریت پشتهٔ operand stack؛ و اینکه چرا آرگومان ارسال‌شده به متد اول در ایندکس ۰ است (this). همین‌ها پایهٔ هر زبان JVM مانند Kotlin و Scala است.

جمع‌بندی

اگر به جاوا علاقه دارید و می‌خواهید زبان‌های JVM را درک کنید، Enkel مسیر عالی‌ای است: از ساخت lexer تا فایل اجرایی .class. انعطاف‌پذیر، قابل اجرا و پر از مثال‌های واقعی.

کپیرایت: جاکوب دوورسکی (Jakub Dziworski). این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
