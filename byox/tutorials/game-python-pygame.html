ساخت بازی با پایتون و Pygame — کتاب رایگان آل اسویگارت

⚙ زبان: Python ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه معرفی و مرور فارسی کتاب «Making Games with Python & Pygame» از آل اسویگارت (Al Sweigart) است — یک کتاب رایگان و کامل (فایل PDF) که با ساخت ۱۰ بازی گرافیکی، پایتون و Pygame را آموزش می‌دهد.

۱. دربارهٔ کتاب

آل اسویگارت — نویسندهٔ کتاب‌های معروف «Invent Your Own Computer Games with Python» و «Automate the Boring Stuff» — این کتاب را برای کسانی نوشته که پایتون را یاد گرفته‌اند و می‌خواهند وارد بازی‌سازی شوند. کتاب کاملاً رایگان است (فایل PDF از inventwithpython.com قابل دانلود) و سطح آن «متوسط» است: پیش‌نیاز آن، مبانی پایتون (از کتاب قبلی او) است.

۲. بازی‌های کتاب

کتاب با کد کامل و توضیح خط‌به‌خط این بازی‌ها را می‌سازد:

  • Flippy (پازل رِوِرسی/اتلو)
  • Ink Spill (بازی پنج دقیقه‌ای)
  • Gemgem (بازی تطبیق جواهرات)
  • Slide Puzzle و Simon
  • Star Pusher (سوکووبان)
  • Four in a Row، Memory Puzzle و Pong
  • و…

۳. سبک آموزش

نمونهٔ ساختار کد کتاب — حلقهٔ بازی با رویدادها و رندر:

python# الگوی رایج بازی‌های کتاب
import pygame, sys
from pygame.locals import *

pygame.init()
FPS = 60
fpsClock = pygame.time.Clock()
DISPLAYSURF = pygame.display.set_mode((400, 300))
pygame.display.set_caption('بازی نمونه')

WHITE = (255, 255, 255)

while True:
    for event in pygame.event.get():
        if event.type == QUIT:
            pygame.quit()
            sys.exit()

    # رسم صحنه
    DISPLAYSURF.fill(WHITE)
    # ... رسم اشیای بازی ...

    pygame.display.update()
    fpsClock.tick(FPS)

ویژگی کتاب: هر بازی کامل است و می‌توانید مستقیم آن را اجرا کنید؛ تمرین‌های هر فصل هم خلاقیت را تقویت می‌کنند.

۴. جمع‌بندی

  • رایگان، قابل دانلود و کاملاً عملی — ده بازی کامل با کد کامل.
  • مناسب بعد از اتمام مبانی پایتون؛ پل خوبی به بازی‌سازی واقعی.
  • کد بازی‌ها روی هر پلتفرمی (ویندوز، لینوکس، مک) اجرا می‌شود.
کپیرایت: کتاب «Making Games with Python & Pygame» اثر آل اسویگارت (Al Sweigart) است و به‌صورت رایگان در inventwithpython.com منتشر شده. این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا و کدها متعلق به نویسندهٔ اصلی است. برای دانلود کتاب به سایت اصلی مراجعه کنید.
