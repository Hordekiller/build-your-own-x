System call چیست؟

برنامه‌های کاربردی برای دسترسی به منابع سیستم (فایل، شبکه، پردازنده به‌وقت) باید از طریق API هسته اقدام کنند. System call همان پنجرهٔ ورود از فضای کاربر (user space) به فضای هسته (kernel space) است — یک عدد مشخص که پردازنده به‌عنوان ایندکسِ تابع در جدول syscall استفاده می‌کند.

در این آموزش، شما یک syscall ساده می‌نویسید که یک رشته را در هسته چاپ می‌کند؛ سپس آن را در جدول سیستم و از برنامهٔ کاربر فراخوانی می‌کنید.

ساختار: جدول syscall

در هستهٔ لینوکس، هر syscall در جدولی به نام `sys_call_table` ثبت می‌شود و تمام آن‌ها در `SYSCALL_DEFINEx` تعریف می‌شوند. برای مثال، یک syscall که پیام را می‌گیرد:

C// تعریف یک syscall با یک آرگومان رشته‌ای
SYSCALL_DEFINE1(hello, const char __user*, buffer) {
    // کپی امن از فضای کاربر (نسخه‌های kernel 5.16+)
    char kernel_buf[128];
    size_t len;
    ssize_t copied;

    copied = strncpy_from_user(kernel_buf, buffer, sizeof(kernel_buf) - 1);
    if (copied < 0) {
        return -EFAULT;
    }
    kernel_buf[copied] = '\0';

    printk(KERN_INFO "hello syscall: %s\n", kernel_buf);
    return 0;
}

نکتهٔ امنیتی کلیدی: چون داده از فضای کاربر می‌آید، نباید مستقیماً `copy_from_user` را بدون بررسی اندازه انجام داد. در غیر این صورت ممکن است پایدارسازی نشت یا crash رخ دهد.

فراخوانی از فضای کاربر

برای فراخوانی syscall از C، می‌توانید از `syscall()` استفاده کنید. عدد syscall باید پیش‌تر در جدول ثبت شده باشد:

C#define SYS_HELLO 548   // عددی که در هسته اختصاص داده‌اید

#include <unistd.h>
#include <sys/syscall.h>
#include <stdio.h>

int main(void) {
    // فراخوانی syscall دلخواه
    long ret = syscall(SYS_HELLO, "سلام از فضای کاربر!");
    if (ret < 0) {
        perror("syscall");
        return 1;
    }
    printf("syscall بازگشت: %ld\n", ret);
    return 0;
}

بعد از خروجی گرفتن از هسته (dmesg) پیام چاپ‌شده را خواهید دید — یعنی برنامهٔ شما واقعاً وارد هسته شده و آن‌جا اجرا شده است.

جمع‌بندی

نوشتن syscall بهترین راه برای درک «مرز» میان هسته و برنامه‌های کاربردی است. مفاهیم جدول نام، کپی امن بین فضاها و کنترل دسترسی را عملاً تجربه می‌کنید و برای ادامهٔ مسیر ساخت هسته آماده می‌شوید.
