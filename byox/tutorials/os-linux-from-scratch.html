Linux From Scratch — ساخت لینوکس، «کاملاً از صفر»

⚙ زبان: Shell + C 🐧 توزیع شخصی لینوکس ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور پروژهٔ Linux From Scratch (LFS) اثر جرارد بیکمنز (Gerard Beekmans) و بروس دابز (Bruce Dubbs) است — یک توزیع کامل و عملاً کارآمد لینوکس که فقط با کامپایل کردن سورس همهٔ بسته‌ها، ساخته می‌شود.
↗ مشاهده منبع اصلی

۱. LFS چیست؟

Linux From Scratch یک پروژهٔ مستند و دقیق است که می‌گوید: «چگونه یک سیستم لینوکس کامل را فقط از سورس کد بسازید.» هیچ بستهٔ باینری آماده‌ای استفاده نمی‌شود؛ هر بسته (glibc، gcc، coreutils و…) با دستورهای دقیق کتاب، از سورس کامپایل و نصب می‌شود. نتیجه یک توزیع لینوکسِ شخصی، مینیمال و کاملاً قابل فهم است — شما می‌دانید هر فایل سیستم کجا بوده و چرا نصب شده.

۲. ساختار کتاب

  • فصل‌های ۱ تا ۳ — آماده‌سازی: معرفی ابزارها، بررسی دیسک، پارتیشن‌بندی و ساخت فایل‌سیستم، نصب پکیج‌های میزبان (host).
  • فصل ۴ — مراحل مقدماتی: ساختار دایرکتوری‌ها، محدودسازی محیط و حقوق کاربری (هیچ‌چیز نباید با root ساخته شود!).
  • فصل ۵ — ساخت toolchain موقت: کامپایل Binutils pass 1، GCC pass 1 و Glibc — اولین «زنجیرهٔ ابزار» که هنوز به سیستم میزبان وابسته است.
  • فصل ۶ — ابزار موقت: کامل کردن مجموعهٔ ابزارها با ساخت بسته‌هایی مثل Coreutils، Bash و Make (هنوز موقتی).
  • فصل ۷ — ورود به محیط LFS: ساخت فایل‌سیستم مجازی و chroot به محیط جدید؛ ساخت initramfs.
  • فصل ۸ — نصب بسته‌های نهایی: ساخت دوبارهٔ Binutils و GCC (pass 2) و همهٔ بسته‌های اصلی — این بار «واقعی» و بدون وابستگی به میزبان.
  • فصل ۹ — تنظیمات سیستم: فایل‌های boot، /etc، هستهٔ Linux kernel و ساخت کامل آن.
  • فصل ۱۰ — قابل بوت کردن: grub، fstab و اولین بوت لینوکس شخصی‌تان.

۳. ایدهٔ toolchain (دو-گذره)

مفهوم کلیدی LFS — و سخت‌ترین بخش برای فهم — ساخت «دو گذره»ی کامپایلر است: چون هنوز Glibc نداریم، GCC اول (pass 1) فقط برای ساخت ابزارهای موقت استفاده می‌شود و با دستورات کوتاه‌کننده از نگاه داشتن به فایل‌های سیستم میزبان جلوگیری می‌کنیم:

bash# خلاصه‌ای از ساخت GCC pass 1 (فصل ۵ LFS)
mkdir -v build && cd build
../configure --prefix=$LFS/tools \
    --with-local-prefix=$LFS/tools \
    --disable-nls --disable-shared --disable-libssp \
    --enable-languages=c --disable-bootstrap

make -j$(nproc) && make install

# مهم‌ترین نکته: یک «گادز» مخصوص که کامپایلر را وادار
# می‌کند هرگز به فایل‌های سیستم میزبان نگاه نکند
ln -sv $LFS/tools/bin/gcc /usr/bin/gcc   # در chroot موقت
cat > dummy-gcc.sh << "EOF"
# ...
EOF

این همان جایی است که بسیاری شکست می‌خورند: کامپایلر موقت نباید هدرها و کتابخانه‌های میزبان را ببیند وگرنه باینری‌های «تمیز» ساخته نمی‌شوند. کتاب، این خطاها را دقیق توضیح می‌دهد.

۴. ارزش آموزشی LFS

  • فهم زنجیرهٔ کامپایل: binutils → gcc → glibc و چرخهٔ «مرغ و تخم‌مرغ» در ساخت اولیه.
  • فهم سیستم لینوکس: در پایان، معنی هر دایرکتوری و هر فایل پیکربندی را می‌دانید.
  • دقت و نظم: ساخت چندین بارهٔ ابزارها، صبر و دقت را تمرین می‌کند.
  • قدم بعدی BLFS: بعد از LFS، کتاب Beyond LFS (BLFS) نصب نرم‌افزارهای بیشتر (شبکه، GUI و…) را آموزش می‌دهد.
نکتهٔ تکمیلی: LFS با دیگر آموزش‌های این مجموعه فرق دارد — شما هستهٔ لینوکس را نمی‌نویسید، بلکه کل سیستم‌عامل اطراف آن را با دست خودتان می‌سازید؛ بهترین مکمل برای کسانی که آموزش‌های کرنل‌نویسی را گذرانده‌اند.
