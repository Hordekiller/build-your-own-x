ساخت پشتهٔ شبکه در Ruby — بدون هیچ کتابخانه‌ای (Building a network stack in Ruby)

⚙ زبان: Ruby ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: ترجمهٔ فارسی «Building a network stack in Ruby» اثر دنیل آپتون (Daniel Upton) — مهندس Geckoboard — که در آن با سوکت‌های خام لینوکس، فریم اترنت، هدر IPv4 و دیتاگرام UDP را در Ruby پیاده می‌کند: تمام راه تا یک «سرور uppercase» که در سطح بیت‌ها، قلب شبکه را از نو می‌سازد.
↗ مشاهده منبع اصلی

۱. ایده: چرا پشتهٔ شبکهٔ خودت را بسازی؟

هر روز با شبکه کار می‌کنیم، اما لایه‌های آن معمولاً از ما پنهان‌اند. این مقاله یک سفر «زیر کاپوت» است: ساخت یک پشتهٔ شبکهٔ یود wait—با سوکت خام — از بیت‌های سیمی تا `puts "Hello"`، کار از اینجا شروع می‌شود که میلهٔ خام لینوکس در Ruby به دو راه باز شود:

ruby# مثل TCP — اما قاب خام شبکیه؛ 'INET' بسته را از خودمان می‌گیرد!
socket = Socket.open(Socket::AF_INET, Socket::SOCK_RAW, Socket::IPPROTO_UDP)
# socket() / bind() / recvfrom() / sendto() از اینجا به دست است.

چرا UDP؟ چون بدون دست‌وپنجه‌نرم‌کردن با اتصال‌های پیچیده، ساختار بسته را ساده می‌کند: هدر IP را خودش در کرنل نمی‌سازد — کار را با دادهٔ مبدأ برای ما راحت می‌کند. بینتیجه‌مان این است که هر بستهٔ دریافتی باید خودمان آنالیز شود، چون کرنل هیچ تصمیمی برایمان نگرفته.

۲. فریم اترنت: ورود بایت‌ها

اولین چیز که از سوکت می‌گیریم، یک فریم اترنت است — که در آن هدرهای IP و UDP «غرق» هستند. موقعیت (بایت ۰ تا ۱۳)‌اش را با دست تحديد می‌کنیم:

rubyclass EthernetFrame
  ETH_P_IP = 0x0800          # نوع پاکت: IPv4

  def initialize(raw)
    @raw = raw
    @dst_mac = raw[0, 6].unpack("H*").first
    @src_mac = raw[6, 6].unpack("H*").first
    @ethertype = raw[12, 2].unpack("n").first
  end

  def ipv4?   # بستهٔ IP است؟
    @ethertype == ETH_P_IP
  end
end

این ساختار در Ruby با پرش به بعد از اترنت، به ipv4_packet می‌رسیم.

۳. هدر IPv4: بیتی‌به-بیتی

هدر IP چارچوبی است که همه چیز روی آن سوار می‌شود: نسخهٔ پروتکل، IHL (طول هدر در کلمات ۳۲بیتی)، TTL، پروتکلِ بالادست، و مشخصاً آدرس مبدأ و مقصد. در Ruby با unpack‌کردن رشتهٔ بایت‌ها، بیت‌هایش را جدا می‌کنیم:

rubyclass IPv4Packet
  IPPROTO_UDP = 17

  def initialize(raw)
    @raw = raw
    version_and_ihl = raw[0].unpack("C").first
    @version = (version_and_ihl >> 4) & 0x0F   # چهار بیت بالایی
    @ihl     = version_and_ihl & 0x0F           # چهار بیت پایینی
    @protocol = raw[9].unpack("C").first
    @src_ip = raw[12, 4].unpack("C4").join(".")
    @dst_ip = raw[16, 4].unpack("C4").join(".")
  end

  def udp?; @protocol == IPPROTO_UDP; end
end

و مشخصاً مهم: @ihl به ما می‌گوید payload از کجا شروع می‌شود (بایتِ ihl * 4) — چون فقط نوع استاندارد برای ما مهندسی می‌کند. سرگرم‌کننده‌ترین حالت: اینها بیت‌هایی‌اند که پشتهٔ واقعی کرنل همیشه بدون تامل office می‌کند!

۴. دیتاگرام UDP

Next step: دیتاگرام UDP — یک هدر ۸ بایتی با پورت مبدأ/مقصد، طول و جمع‌بست:

rubyclass UDPDatagram
  def initialize(raw)
    @src_port = raw[0, 2].unpack("n").first
    @dst_port = raw[2, 2].unpack("n").first
    @length   = raw[4, 2].unpack("n").first
    @checksum = raw[6, 2].unpack("n").first
    @payload  = raw[8, @length - 8]     # طول شامل خود هدر است!
  end
end

حالا مدل کامل ما سه لایه دارد: EthernetFrame ← IPv4Packet ← UDPDatagram — و یک پشتهٔ «بالا-به-پایین» هم لازم است برای ارسال: بستهٔ UDP آخر را بسته‌بندی (pack) می‌کنیم، هدر IP را جلویش می‌گذاریم، سرانجام فریم اترنت — و با sendto از سوکت خام فریاد می‌زنیم.

۵. پیوند ساختارها و «سرور uppercase»

حالا که هر دو طرف را داریم، از «مدل»ها در برابر جهان بیرون قرار می‌دهیم: یک سرور بی‌دغدغه که هر دیتاگرام UDP را می‌گیرد، رشتهٔ داخلش را اپرکیس (uppercase) می‌کند و پاسخی برمی‌گرداند. این یعنی همان زنجیرهٔ واقعی شبکه‌ای‌ای که مرورگر شبکه‌ها تراواست در ما بازسازی شده — اما این‌بار خط آنالیز و ساخت کاملاً زیر انگشتان خودمان:

rubysocket = Socket.open(Socket::AF_INET, Socket::SOCK_RAW, Socket::IPPROTO_UDP)

puts "listening for raw frames on #{packet socket…}"

loop do
  frame = EthernetFrame.new(socket.recvfrom(65535).first)
  next unless frame.ipv4?

  packet = IPv4Packet.new(frame.payload)
  next unless packet.udp?

  datagram = UDPDatagram.new(packet.payload)
  puts "RX #{datagram.payload.inspect} from #{packet.src_ip}:#{datagram.src_port}"

  # ساده: جوابِ upper-case را بازمی‌گردانیم
  reply = UDPDatagram.to_bytes(
    src_port: datagram.dst_port, dst_port: datagram.src_port,
    payload: datagram.payload.upcase)
  packet.send_ipv4(socket, packet.src_ip, reply)
end

برای دیدن نتیجه: از یک فایل جدا، یک دیتاگرام UDP روی همان اینترفیس لوپ‌بک بفرستید — با یک-خطی ruby -rsocket -e 'u = UDPSocket.new; u.bind("127.0.0.1", 0); u.send("hello", 0, "127.0.0.1", 1337)' — و سرور ما پاسخ «Hello» را برمی‌گرداند. اندازهٔ انجام کار هم یک کشف است: تقریباً صفر نگاه داشتن خطوط برای کار واقعی؛ بیشترِ کد، توصیف ساختارها است.

۶. درس‌ها و گام‌های بعد

یادگیری عمده از این تمرین، درک توضیح ماهرانهٔ «پشته» به‌عنوان خط مونتاژ است: هر لایه فقط با «payload» خودش کار می‌کند، نه چیز بیشتر. کارهای بعدی برای شما — هم‌سطح آنچه شبکه‌های واقعی‌اند: parsing TCP (با ماشین حالات و ترتیب بایت‌ها — سخت‌تر)، محاسبهٔ checksum برای UDP/IPv4، پیاده‌سازی ARP برای یافتن MAC همسایه، و نهایتاً یک «راوبط» با چند اینترفیس و جدول روتینگ. کد کامل پروژه (پشتهٔ RUDP) در گیت‌هاب: geckoboard/RUDP.

پینوشت مهندسی: هدر IPv4 ساخت کرنل (در IPPROTO_RAW) ممکن است کمی تفاوت داشته باشد — ولی همین که مدل شفاف است، حدِ وسطی برای شروع است.
