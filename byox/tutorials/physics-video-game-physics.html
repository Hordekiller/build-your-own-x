۱. چرا موتورهای فیزیک؟

در بازی‌های ویدیویی مدرن، فیزیک چیزی است که به دنیای بازی «جان» می‌دهد: سقوط اجسام، برخوردها، پرش‌ها، اشیا شناور و واکنش‌های طبیعی. به‌جای انیمیشن‌های از پیش ضبط‌شده، موتور فیزیک رفتار اجسام را در هر لحظه با استفاده از قوانین مکانیک نیوتنی محاسبه می‌کند. این مقاله اولین قسمت یک مجموعه آموزشی است که با مفاهیم پایه شروع می‌کند: دینامیک جسم صلب (Rigid Body Dynamics) — مطالعه حرکت اجسام سفت‌وسخت که تحت تأثیر نیروها جا نمی‌شوند.

پیش‌نیاز خواندن این مقاله، آشنایی مقدماتی با حساب دیفرانسیل و انتگرال و البته یک زبان برنامه‌نویسی (مثلاً C یا C++) است. مثال‌های کد مقاله در C نوشته شده‌اند.

۲. سینماتیک و دینامیک

مکانیک یا به دو شاخه تقسیم می‌شود:

  • سینماتیک (Kinematics): توصیف حرکت بدون توجه به علت آن — جابه‌جایی، سرعت و شتاب چگونه در طول زمان تغییر می‌کنند.
  • دینامیک (Dynamics): بررسی رابطه بین حرکت و نیروها — چرا جسم این‌طور حرکت می‌کند؟

مفاهیم اصلی سینماتیک سه‌تاست:

  • جابه‌جایی (Δx): تغییر مکان جسم.
  • سرعت (v): نرخ تغییر جابه‌جایی نسبت به زمان؛ مشتق مکان.
  • شتاب (a): نرخ تغییر سرعت؛ مشتق دوم مکان.
c// مفاهیم پایه سینماتیک
// سرعت: مشتق مکان نسبت به زمان
v = dx / dt;

// شتاب: مشتق سرعت نسبت به زمان
a = dv / dt;

// در شتاب ثابت a، مکان بر حسب زمان:
x(t) = x0 + v0 * t + 0.5f * a * t * t;

در بازی‌ها معمولاً با گام زمانی ثابت کار می‌کنیم و انتگرال‌گیری عددی (مثلاً روش اویلر) را جایگزین انتگرال تحلیلی می‌کنیم:

c// انتگرال‌گیری اویلر با گام زمانی ثابت dt
velocity += acceleration * dt;
position += velocity * dt;

۳. ریاضیات لازم: بردارها

تقریباً همه‌چیز در موتور فیزیک با بردارها بیان می‌شود: مکان، سرعت، شتاب، نیرو و ایمپالس همگی بردارند. در بازی دوبعدی از بردار دو مؤلفه‌ای و در بازی سه‌بعدی از بردار سه مؤلفه‌ای استفاده می‌شود.

  • ضرب داخلی (Dot Product): نتیجه یک عدد است و برای تشخیص «هم‌جهت بودن» دو بردار و محاسبه پیش‌بینی (projection) به کار می‌رود.
  • ضرب خارجی (Cross Product): نتیجه یک بردار است و در محاسبه گشتاور و عمودها استفاده می‌شود.
ctypedef struct { float x, y; } vec2;

// ضرب داخلی موجودی دو بردار (در ۲بعد)
float dot(vec2 a, vec2 b) {
    return a.x * b.x + a.y * b.y;
}

// طول بردار
float len(vec2 v) {
    return sqrtf(dot(v, v));
}

// نرمال‌سازی: بردی یکه با همان جهت (طول ۱)
vec2 normalize(vec2 v) {
    float l = len(v);
    return (vec2){ v.x / l, v.y / l };
}

۴. قوانین حرکت نیوتن

هسته دینامیک جسم صلب، سه قانون نیوتن است:

  • قانون اول: جسم در حال سکون ساکن می‌ماند و جسم در حال حرکت به حرکت یکنواخت ادامه می‌دهد، مگر اینکه نیروی خارجی اثر کند. (در بازی‌ها معمولاً اصطکاک و مقاومت هوا را به‌طور صریح مدل می‌کنیم.)
  • قانون دوم: شتاب جسم با نیروی خالص وارد بر آن نسبت مستقیم و با جرم آن نسبت عکس دارد: F = m·a.
  • قانون سوم: هر عمل، عکس‌العملی هم‌اندازه و در جهت مخالف دارد. در برخورد، هر دو جسم هم‌زمان نیروهای مساوی و مخالف دریافت می‌کنند.
c// گرانش به‌عنوان یک شتاب ثابت (در ۲بعد، محور y رو به پایین)
vec2 gravity = { 0.0f, 9.81f };

// قانون دوم نیوتن: نیروی خالص = جرم × شتاب
vec2 net_force = ...;
vec2 acceleration = (vec2){ net_force.x / mass, net_force.y / mass };

جرمِ بیشتر یعنی واکنش کمتر به نیروی یکسان — همان چیزی که در بازی با «سنگینی» اجسام تجربه می‌کنیم.

۵. تکانه و ایمپالس

تکانه خطی (Momentum) برابری است با حاصل‌ضرب جرم در سرعت: p = m·v. قانون بقای تکانه می‌گوید در یک سیستم بسته (بدون نیروی خارجی)، مجموع تکانه‌ها ثابت می‌ماند. برخوردها را به‌جای نیرو، معمولاً با ایمپالس (Impulse) مدل می‌کنیم: تغییر ناگهانی تکانه در یک بازه زمانی بسیار کوتاه.

روش استاندارد پاسخ برخورد در موتورهای فیزیک، حل ایمپالس است: در لحظه برخورد، به هر جسم یک تغییر سرعت لحظه‌ای می‌دهیم به‌طوری که قوانین بقا و رفتار الاستیک/پلاستیک برآورده شود.

۶. پاسخ برخورد با ایمپالس

برای دو جسم کروی (یا هر دو جسم چرخان‌نشده) که با سرعت‌های vA و vB و جرم‌های mA و mB با هم برخورد می‌کنند، ایمپالس j از این فرمول به‌دست می‌آید:

c// n: بردار نرمال برخورد (از A به B، یکه)
// e: ضریب بازگشت (0 = کاملاً پلاستیک، 1 = کاملاً الاستیک)
// vrel: سرعت نسبی دو جسم در جهت نرمال

float vrel = dot(vB - vA, n);
float j = -(1.0f + e) * vrel;
j /= (1.0f / mA) + (1.0f / mB);

// اعمال ایمپالس روی هر دو جسم (قانون سوم نیوتن)
vA -= (j / mA) * n;
vB += (j / mB) * n;

این همان فرمول کلاسیکی است که در مقاله با جزئیات بیشتر — از جمله حالت‌های خاص (جرم بی‌نهایت برای زمین، برخورد بدون اصطکاک و...) — بررسی می‌شود. دقت کنید پس‌از حل ایمپالس باید اجسام را «از هم بیرون» (positional correction) هم کرد تا در فریم‌های بعدی به هم نچسبند.

۷. ضریب بازگشت (Restitution)

ضریب بازگشت مقدار انرژی جنبشی را که بعد از برخورد باقی می‌ماند مشخص می‌کند:

  • e = 1: برخورد کاملاً الاستیک — کل انرژی حفظ می‌شود (مثل دو توپ بیلیارد ایده‌آل).
  • e = 0: برخورد کاملاً پلاستیک — اجسام به هم می‌چسبند و انرژی از دست می‌رود (مثل خمیر).

در عمل مقدارهای واقعی بین ۰ و ۱ هستند و مقادیر بزرگ معمولاً در بازی‌ها با ضریب epsilon تنظیم می‌شوند تا رفتار طبیعی‌تر دیده شود. این‌ها پایه‌های اصلی موتورهای فیزیک هستند؛ در قسمت‌های بعدی مجموعه، چرخش (دینامیک چرخشی)، اصطکاک و برخورد چندشیء بررسی می‌شود.
