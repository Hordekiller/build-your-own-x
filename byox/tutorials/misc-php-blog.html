وبلاگ بدون فریم‌ورک

یک وبلاگ ساده سه بخش دارد: نمایش فهرست پست‌ها، نمایش تک‌پست، و مدیریت (نوشتن/ویرایش پست). این آموزش همه را با PHP خالص و MySQL می‌سازد تا ببینید پشت وردپرس و لاراول که اسمش را می‌شنوید، چه موجود ساده‌ای هست.

اتصال و جدول‌ها

ابتدا پایگاه داده: جدولی برای پست‌ها (id، title، content، created_at) و در نسخهٔ کامل‌تر جدول کامنت‌ها. اتصال با PDO انجام می‌شود:

PHP// db.php — اتصال مشترک
$pdo = new PDO(
    'mysql:host=localhost;dbname=blog;charset=utf8',
    'user', 'pass',
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

// دریافت پست‌ها (query آماده)
$stmt = $pdo->query('SELECT * FROM posts ORDER BY created_at DESC');
$posts = $stmt->fetchAll();

فعال کردن `ERRMODE_EXCEPTION` باعث می‌شود خطای SQL به‌جای سکوت، استثنا بدهد — برای دیباگ حیاتی است.

نوشتن یک پست با فرم

بخش مدیریت با فرم HTML و درج با prepared statement — که از تزریق SQL جلوگیری می‌کند:

PHPif ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $title = $_POST['title'] ?? '';
    $content = $_POST['content'] ?? '';

    $stmt = $pdo->prepare(
        'INSERT INTO posts (title, content) VALUES (:t, :c)'
    );
    $stmt->execute([':t' => $title, ':c' => $content]);

    header('Location: index.php');   // برگرد به لیست
    exit;
}

نکتهٔ امنیتی `htmlspecialchars` هنگام چاپ عنوان در ویو: ورودی کاربر را در HTML خام نگذارید، وگرنه XSS می‌شود.

مشاهدهٔ تک‌پست

PHP$id = (int)($_GET['id'] ?? 0);   // cast به int: تزریق ناممکن
$stmt = $pdo->prepare('SELECT * FROM posts WHERE id = ?');
$stmt->execute([$id]);
$post = $stmt->fetch();

if (!$post) { http_response_code(404); echo 'پست یافت نشد'; exit; }

الگوهای این آموزش (PDO، prepared، فرم، redirect-after-POST) همان‌هایی هستند که در همهٔ فریم‌ورک‌ها به صورت خودکار انجام می‌شوند. بعد از ساخت این وبلاگ، وردپرس دیگر جعبهٔ سیاه نیست.
