۱. دربارهٔ دوره

این دورهٔ رایگان C# را با یک پروژهٔ واقعی آموزش می‌دهد: یک RPG متنی ساده بدون گرافیک — با ۹ مکان، ۳ هیولا، ۲ سلاح و ۲ کوئست. از «هیچ» شروع می‌شود: حتی نصب Visual Studio هم آموزش داده می‌شود. نتیجه: درک کامل کلاس‌ها، ویژگی‌ها (properties)، تابع‌ها، شرط‌ها و حلقه‌ها — بهترین‌ها برای شروع.

نکته: کاملاً مبتدی‌پسند: اگر حتی یک خط کد هم ننوشته‌اید، این دورهٔ مناسبی است؛ هر مفهوم با مثال داخل بازی توضیح داده می‌شود.

۲. ساختار درس‌ها

  • نصب ابزارها و ساخت اولین پروژه
  • ساختار برنامه، namespace و using
  • متغیرها، نوع‌های داده و تبدیل
  • تابع‌ها و پارامترها؛ خروجی و بازگشت
  • کلاس‌ها: ساخت حیوان خانگی، سلاح، هیولا و تجهیزات
  • ورودی کاربر و شرط‌ها (if/switch)
  • حلقه‌ها و ذخیره‌سازی در لیست‌ها
  • مدیریت نبردِ نوبتی، کوئست‌ها و جادو

۳. نمونهٔ کد: کلاس یک شیء بازی

csharp// کلاس پایهٔ تمام اشیای بازی
public class WorldObject
{
    public int ID { get; set; }
    public string Name { get; set; }
    public string Description { get; set; }

    public WorldObject(int id, string name, string description)
    {
        ID = id;
        Name = name;
        Description = description;
    }
}

// کلاسی که از پایه ارث‌بری می‌کند: سلاح
public class Weapon : WorldObject
{
    public int MaximumDamage { get; set; }

    public Weapon(int id, string name, string description, int maximumDamage)
        : base(id, name, description)
    {
        MaximumDamage = maximumDamage;
    }
}

به همین ترتیب کلاس‌های Monster، Quest، Location و Player ساخته می‌شوند و سپس دنیای بازی — مکان‌ها، موجودیت‌ها و آیتم‌ها — با آن‌ها ساخته می‌شود.

۴. جمع‌بندی

در پایان دوره یک بازی کوچک اما کامل دارید: در مکان‌ها حرکت می‌کنید، با هیولاها می‌جنگید، سلاح و تجهیزات برمی‌دارید و کوئست انجام می‌دهید. بعد از این دوره، نسخهٔ WPF با گرافیک (SOSCSRPG از همان نویسنده) بهترین گام بعدی است.

کپیرایت: سری «Learn C# by Building a Simple RPG» اثر اسکات لیلی (Scott Lilly) است و در وبلاگ scottlilly.com منتشر شده. این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل دوره به سایت اصلی مراجعه کنید.
