یادگیری عمیق را از صفر بساز — بازپیاده‌سازی درونی‌های PyTorch در ۳۵ مرحله

⚙ زبان: Python 🧠 autodiff → CNN → Transformer ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور مخزن آموزشی Build-Deep-Learning-From-Scratch (نویسنده: roiamiel1) است که در ۳۵ مرحله، درونی‌های PyTorch را از پایه با پایتون خالص بازپیاده‌سازی می‌کند.
↗ مشاهده منبع اصلی

۱. فلسفهٔ پروژه: «شما خودِ کتابخانهٔ autodiff هستید»

این دوره با یک ایدهٔ روشن شروع می‌شود: برای فهمیدن یادگیری عمیق، هیچ‌چیز بهتر از ساختن آن نیست. مسیر به‌صورت ۳۵ مرحلهٔ کوچک و مستقل سازماندهی شده که از ساده‌ترین سنگ‌بنا شروع می‌کند: یک کلاس Value — همان هستهٔ micrograd کارپتی — و با هر مرحله، یک لایهٔ پیچیدگی به آن اضافه می‌شود تا در نهایت یک «مینی‌پایتورچ» (MiniPyTorch) داشته باشیم.

۲. مراحل ۰۱ تا ۰۵: بازپیاده‌سازی micrograd

پنج مرحلهٔ اول دقیقاً همان سفر ویدیوی معروف کارپتی است: کلاس Value با مقدار و مشتق (grad)؛ ساختن گراف محاسباتی با نگه‌داشتن _prev (والدین) و _backward (مشتق موضعی)؛ عملیات جمع و ضرب و توان؛ و در نهایت backward() که با مرتب‌سازی توپولوژیک، گرادیان‌ها را در کل گراف پخش می‌کند:

python# مرحله‌ی ۱ تا ۵: هسته‌ی autodiff — یک گره‌ی حساب‌دار از والدینش
class Value:
    def __init__(self, data, _children=(), _op=""):
        self.data = data
        self.grad = 0.0
        self._prev = set(_children)   # والدین در گراف محاسباتی
        self._backward = lambda: None # مشتق موضعی — در هر عملیات تعریف می‌شود

    def __add__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data + other.data, (self, other), "+")
        def _backward():
            self.grad += out.grad            # + یعنی توزیع برابر گرادیان
            other.grad += out.grad
        out._backward = _backward
        return out

    def backward(self):
        # پخش گرادیان‌ها با مرتب‌سازی توپولوژیک (عقب‌به‌جلو)
        order = []
        seen = set()
        def visit(v):
            if v not in seen:
                seen.add(v)
                for c in v._prev:
                    visit(c)
                order.append(v)
        visit(self)
        self.grad = 1.0
        for v in reversed(order):
            v._backward()

۳. از اسکالر تا تنسور

مراحل بعدی مقدارهای اسکالر را به تنسورها (آرایه‌های چندبعدی) ارتقا می‌دهند تا شبکه‌های واقعی روی دادهٔ واقعی آموزش ببینند. همین‌جا قانون زنجیره‌ای به‌صورت عملی دیده می‌شود: هر عملیات، مشتق موضعی‌اش را تعریف می‌کند و backward آن‌ها را به هم می‌چسباند. سپس نوبت به اجزای شبکه می‌رسد:

  • لایه‌های (Layers): Linear، Embedding و فعال‌سازی‌ها (ReLU، tanh، GELU و…).
  • بهینه‌سازها (Optimizers): SGD، Adam و… — حلقهٔ آموزش کامل با forward، loss و backward.
  • توابع هزینه: Mean Squared Error، Cross Entropy و…

۴. ادامهٔ مسیر: CNN، attention و Transformer

بعد از شبکه‌های تمام‌متصل، معماری‌های مدرن از پایه ساخته می‌شوند:

  • شبکه‌های کانولوشنی (CNN): لایه‌های Conv2d، Pooling و کاربردشان در بینایی ماشین.
  • مکانیزم توجه (Attention): ساختار Self-Attention و Multi-Head Attention — قلب مدل‌های ترنسفورمر.
  • Transformer: ساخت کامل یک ترنسفورمر و سپس ViT (ویژن ترنسفورمر) برای تصاویر.
  • مدل زبانی: آموزش یک مدل زبانی کوچک با همهٔ اجزای ساخته‌شده.
