مقدمه

با توجه به اینکه حدود ۱۵٪ از توییتر از ربات‌ها تشکیل شده، می‌خواستم دستی در این کار ببرم. گوگل کردم که چگونه یک ربات توییتر بسازم و به یک وب‌اپلیکیشن (web app) تمیز و مرتب هدایت شدم. این اپلیکیشن به شما امکان می‌داد رباتی بسازید که بر اساس یک کلیدواژه (keyword) یک توییت را لایک (like) کند، فالو (follow) کند یا ریتوییت (retweet) کند. مشکل این بود که فقط می‌توانستید برای یک عملکرد، یک ربات بسازید.

پس تصمیم گرفتم خودم با پایتون و کتابخانهٔ Tweepy رباتی بنویسم.

راه‌اندازی (Setup)

اول از همه Tweepy را دانلود کردم. می‌توانید این کار را با استفاده از مدیر بستهٔ pip انجام دهید.

shellpip install tweepy

اگر pip نصب ندارید، می‌توانید مخزن GitHub را هم کلون (clone) کنید.

shellgit clone https://github.com/tweepy/tweepy.git
cd tweepy
python setup.py install

باید Tweepy و Tkinter (برای رابط گرافیکی) را ایمپورت کنید.

pyimport tweepy
import Tkinter

اعتبارنامه‌ها (Credentials)

در مرحلهٔ بعد باید حساب توییتر خود را به اسکریپت پایتون‌مان متصل کنیم. به apps.twitter.com بروید و با حساب خود وارد شوید. یک اپلیکیشن توییتر بسازید و کلید مصرف‌کننده (Consumer Key)، رمز مصرف‌کننده (Consumer Secret)، توکن دسترسی (Access Token) و رمز توکن دسترسی (Access Token Secret) را تولید کنید. حالا آمادهٔ شروع هستید!

زیر دستورات ایمپورت خود، اعتبارنامه‌ها را داخل متغیرها ذخیره کنید و سپس از بلوک دوم کد برای احراز هویت (authentication) حساب خود با tweepy استفاده کنید.

pyconsumer_key = 'consumer key'
consumer_secret = 'consumer secrets'
access_token = 'access token'
access_token_secret = 'access token secret'
pyauth = tweepy.OAuthHandler(consumer_key, consumer_secret)

api = tweepy.API(auth)

برای اینکه بررسی کنید برنامهٔ شما درست کار می‌کند، می‌توانید این کد را اضافه کنید:

pyuser = api.me()
print (user.name)

این کد باید نام حساب توییتر شما را در کنسول (console) برگرداند.

ساخت ربات (Building the Bot)

این ربات قرار است کارهای زیر را انجام دهد:

  1. همهٔ کسانی را که شما را فالو می‌کنند، فالو کند.
  2. بر اساس کلیدواژه‌ها یک توییت را لایک و ریتوییت کند.
  3. بر اساس یک کلیدواژه به یک کاربر پاسخ دهد.

قدم اول ساده‌ترین است؛ فقط کافی است در میان فالوورهای خود حلقه (loop) بزنید و سپس تک‌به‌تک آن‌ها را فالو کنید.

pyfor follower in tweepy.Cursor(api.followers).items():
    follower.follow()
    print ("Followed everyone that is following " + user.name)

در این نقطه، برای اطمینان از درست کار کردن کدتان، باید وارد توییتر شوید و شاهد افزایش تعداد افرادی که آن‌ها را فالو می‌کنید باشید.

از این نقطه به بعد، به‌جز راه‌اندازی و قرار دادن برچسب‌ها (labels) در رابط گرافیکی، همه‌چیز را زیر تابع mainFunction() می‌نویسم.

ساخت رابط گرافیکی (Creating the GUI)

می‌توانیم یک اپلیکیشن گرافیکی بسازیم که ورودی‌های ما را دریافت کند؛ کلیدواژه‌ای که می‌خواهید جست‌وجو کنید و این‌که آیا می‌خواهید یک توییت را لایک کنید یا نه.

ابتدا باید Tkinter را راه‌اندازی کنیم و چیدمان (layout) را آماده کنیم.

برای ساخت رابط کاربری، هفت برچسب برای جست‌وجو، تعداد توییت‌ها و پاسخ خواهیم داشت. به‌علاوهٔ پرسش‌هایی برای این‌که آیا می‌خواهید به توییت پاسخ دهید، آن را لایک کنید، ریتوییت کنید و کاربر را فالو کنید.
