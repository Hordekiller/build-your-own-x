WebGL + Rust: آموزش آب پایه

⚙ زبان: Rust + wasm-bindgen ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور «3D WebGL + Rust: Basic Water Tutorial» از چیندو است که آب انیمیت‌شده را با Rust و Three.js روی وب می‌سازد.

Rust روی وب؟!

Rust می‌تواند به WebAssembly (wasm) کامپایل شود و در مرورگر اجرا شود. این آموزش یک صحنهٔ سه‌بعدی با وب می‌سازد که در آن: صحنه و آب با Three.js ساخته می‌شود اما منحنی موج آب با Rust محاسبه می‌شود و نتیجهٔ هر فریم به WebGL داده می‌شود.

حلقهٔ رندر در Rust

کلید اصلی: یک ساختار `Water` در Rust که هر فریم، ارتفاع نقاط را محاسبه می‌کند. سه‌بعدی‌ها با `nalgebra` و ارسال عددها با `wasm-bindgen` انجام می‌شود:

Rustuse wasm_bindgen::prelude::*;
use nalgebra::Vector3;

/// هندسهٔ آب: سطحی از نقاط (چند ضلعی)
#[wasm_bindgen]
pub struct Water {
    pub segments: usize,
}

impl Water {
    /// ارتفاع نقطه در لحظهٔ t — موج سینوسی ساده
    pub fn height_at(&self, x: f32, y: f32, t: f32) -> f32 {
        ((x * 0.3 + t) as f64).sin() as f32 * 0.5
            + ((y * 0.2 - t) as f64).cos() as f32 * 0.3
    }
}

ترکیب دو موج با فاز مخالف، الگوی «آب آرام» می‌دهد — پایهٔ همهٔ موج‌سازی‌های واقعی (FFT، Gerstner) همان نوسان ساده است.

اتصال با Three.js

در سمت JS، صحنه ساخته می‌شود و در هر فریم از متد Rust ارتفاع می‌گیرد تا vertex ها به‌روز شوند. مثل یک «عملگر بومی» که فریم به فریم کار می‌کند:

JavaScriptconst { Water } = wasm_bindgen('water_wasm.js');

// ساخت هندسه با گرید 16×16
const geometry = new THREE.PlaneGeometry(10, 10, 15, 15);
const water = Water.new(16);
const material = new THREE.MeshPhongMaterial({ color: 0x1e88e5, wireframe: true });

function animate(time) {
  const pos = geometry.attributes.position;
  for (let i = 0; i < pos.count; i++) {
    const x = pos.getX(i), y = pos.getY(i);
    pos.setZ(i, water.height_at(x, y, time / 1000));  // Rust در کار
  }
  pos.needsUpdate = true;
  renderer.render(scene, camera);
  requestAnimationFrame(animate);
}

ترکیب «Rust محاسبه، JS رندر» معماری محبوبی است: عملکرد بالا و بدون GC جایی که مهم است.
