GTK به‌جز C؟

GTK اسم رابط گرافیکی لینوکس است (GNOME از آن استفاده می‌کند). با وجود اینکه GTK به زبان C نوشته شده، bindingهای عالی برای Ruby (gtk3 gem) دارد. این آموزش یک «فهرست کارها» (Todo list) کامل می‌سازد: پنجره، لیست، افزودن/حذف کار.

پنجره و حلقهٔ رویداد

GTK یک «حلقهٔ رویداد» دارد: برنامه منتظر رویدادها (کلیک، تایپ، بستن) می‌ماند و روی آن‌ها واکنش نشان می‌دهد. ساختار پایه:

Rubyrequire 'gtk3'

class TodoApp
  def initialize
    # ساخت پنجرهٔ اصلی
    @window = Gtk::Window.new('تودولیست من')
    @window.set_default_size(400, 500)
    @window.signal_connect('destroy') { Gtk.main_quit }

    # حالت عمودی: فیلد ورودی + دکمه + لیست
    @vbox = Gtk::Box.new(:vertical, 6)
    @entry = Gtk::Entry.new
    @entry.placeholder_text = 'کار جدید...'
    @add_button = Gtk::Button.new(label: 'افزودن')
    @list = Gtk::ListBox.new

    @vbox.pack_start(@entry, expand: false, fill: false, padding: 0)
    @vbox.pack_start(@add_button, expand: false, fill: false, padding: 0)
    @vbox.pack_start(@list, expand: true, fill: true, padding: 0)
    @window.add(@vbox)
  end

  def run
    @window.show_all
    Gtk.main   # شروع حلقهٔ رویداد
  end
end

TodoApp.new.run

`signal_connect` اتصال رویداد را انجام می‌دهد — همان مکانیزم callback که در همهٔ toolkitها (Qt، Swing) وجود دارد.

افزودن کار با سیگنال

Rubydef add_todo
  text = @entry.text.strip
  return if text.empty?

  row = Gtk::ListBoxRow.new
  row.add(Gtk::Label.new(text))
  @list.add(row)          # به لیست اضافه کن
  @entry.text = ''        # پاک کن ورودی
end

# اتصال: کلیک دکمه ← افزودن
@add_button.signal_connect('clicked') { add_todo }
# اتصال: فشردن Enter هم اضافه کند
@entry.signal_connect('activate') { add_todo }

برای حذف هم هر row یک دکمه با callback جدا می‌گیرد — همان الگوی «سیگنال» تکرار می‌شود.

توسعه‌ها و نتیجه

در ادامهٔ آموزش: ذخیره‌سازی در فایل SQLite، قاب‌بندی listview برای کارهای انجام‌شده و استایل با CSS (GTK CSS). بعد از این پروژه، هر برنامهٔ دسکتاپی برایتان ساختاری شفاف دارد: widget + signal + model.
