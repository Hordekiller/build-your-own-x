۱. دربارهٔ سری

در این سری، یک بازی کامل 8-Ball Pool (بیلیارد آمریکایی) با جاوااسکریپت و Canvas ساخته می‌شود — بدون هیچ کتابخانه‌ای. از فیزیک برخورد توپ‌ها مثل ضربهٔ نشانه (cue)، حرکت و اصطکاک تا قوانین بازی ۸ توپ و رابط کاربری؛ همه‌چیز قدم‌به‌قدم و با توضیح فارسی‌پسند (در اصل انگلیسی) پیاده می‌شود. سری از قسمت «Part 1» شروع می‌شود و در سه قسمت کامل می‌شود.

نکته: پروژه چند فیزیک کامل دارد: برخورد توپ-توپ، برخورد توپ-دیواره، اسپین (spin) و اصطکاک — یکی از بهترین آموزش‌های فیزیک دوبعدی واقعی در مرورگر.

▶ تماشای «8-Ball Pool Game Part 1»

۳. مفاهیم پیاده‌سازی

نمونه‌ای از فیزیک توپ‌ها که در سری ساخته می‌شود:

js// توپ: موقعیت، سرعت، شعاع و حالت
class Ball {
  constructor(x, y, radius, color, id) {
    this.x = x; this.y = y;
    this.vx = 0; this.vy = 0;
    this.radius = radius;
    this.color = color;
    this.id = id;
  }

  // حرکت و اعمال اصطکاک
  update(dt) {
    this.x += this.vx * dt;
    this.y += this.vy * dt;
    this.vx *= FRICTION; // اصطکاک میز
    this.vy *= FRICTION;
    if (Math.abs(this.vx) < EPSILON) this.vx = 0;
    if (Math.abs(this.vy) < EPSILON) this.vy = 0;
    this.collideWalls();
  }

  // برخورد الاستیک دایره-دایره بین دو توپ
  collide(other) {
    const dx = other.x - this.x;
    const dy = other.y - this.y;
    const dist = Math.hypot(dx, dy);
    if (dist < this.radius + other.radius) {
      // بردار نرمال و تبادل سرعت در امتداد آن
      const nx = dx / dist, ny = dy / dist;
      const relVx = this.vx - other.vx;
      const relVy = this.vy - other.vy;
      const speed = relVx * nx + relVy * ny;
      if (speed > 0) {
        this.vx -= speed * nx;
        this.vy -= speed * ny;
        other.vx += speed * nx;
        other.vy += speed * ny;
      }
    }
  }
}

در قسمت‌های بعد: نشانه‌گیری و ضربه با ماوس، قانون هشت (پیروزی با توپ ۸)، شمارش امتیاز و رابط کاربری زیبا.
