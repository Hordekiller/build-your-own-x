آشنایی با Cradle

مجموعهٔ «بیایید یک کامپایلر بسازیم» جک کرنشاو (۱۹۸۸) یکی از معروف‌ترین منابع آموزش ساخت کامپایلر با روش تک‌مرحله‌ای است. اصلی‌ترین نسخهٔ آن در پاسکال و برای پردازندهٔ 68000 نوشته شده بود؛ پروژهٔ Cradle آن را به Haskell منتقل می‌کند تا هم روی معماری‌های امروزی کار کند و هم از قدرت Haskell (تایپ‌سازی قوی و توابع pure) بهره ببرد.

تفاوت با نسخهٔ اصلی

در پاسکال، نگه‌داشتن «وضعیت» (کاراکتر فعلی ورودی و…) ساده بود؛ در Haskell باید از monad استفاده کنیم. پروژهٔ Cradle از State monad برای مدیریت وضعیت خواندن ورودی استفاده می‌کند — در نتیجه هم معنای ترجمه حفظ شده و هم کد کاملاً pure و قابل اثبات است.

Haskell-- وضعیت کامپایلر: کاراکتر فعلی + جریان جلو
data CradleState = CradleState { input :: String, cur :: Char }

type P a = State CradleState a

-- دریافت کاراکتر بعدی از ورودی
getChar' :: P Char
getChar' = do
  st <- get
  case input st of
    []     -> return '\0'          -- پایان ورودی
    (c:cs) -> put (st { input = cs, cur = c }) >> return c

-- چاپ کد خروجی
emit :: String -> P ()
emit s = liftIO $ putStrLn s

مسیر آموزشی: از جمع تا توابع

مانند سری اصلی، همین‌جا مراحل کم‌کم پیچیده می‌شوند: (۱) ماشین‌حساب چهارعملی؛ (۲) اولویت عملگرها (term/expression)؛ (۳) متغیرها و انتساب؛ (۴) شرط‌های if/else؛ (۵) حلقه‌ها؛ (۶) توابع و پارامترها. هر بخش در فایل جدا (Part1.hs تا Part16.hs مانند نسخهٔ اصلی) آمده است.

نمونه: تحلیل عبارت با اولویت

Haskell-- expr := term (('+'|'-') term)*
expression :: P ()
expression = do
  term
  whilePlusOrMinus
  where
    whilePlusOrMinus = do
      c <- peek
      case c of
        '+' -> add
        '-' -> subtract_
        _   -> return ()

add :: P ()
add = do
  match '+'
  term
  emit "pop ebx"
  emit "add eax, ebx"

جمع‌بندی
