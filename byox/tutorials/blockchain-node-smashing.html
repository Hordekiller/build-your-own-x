نوشتن یک بلاک‌چین در Node.js

💠 دسته: بلاک‌چین / ارز دیجیتال ⚙ زبان: JavaScript ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمه فارسی مقاله «نوشتن یک بلاک‌چین در Node.js» (Writing a Blockchain in Node.js) نوشته آلفریک اوپیدی (Alfrick Opidi) از «اسمشینگ مگزین» (Smashing Magazine) است. نسخه کامل و به‌روز را از سایت اصلی بخوانید.

مقدمه

فناوری بلاک‌چین به دلیل توانایی‌اش در تقویت امنیت در محیط‌های غیرقابل‌اعتماد (trustless)، اعمال تمرکززدایی و کارآمد کردن فرایندها، توجه زیادی را به خود جلب کرده است. در این آموزش، آلفریک اوپیدی نشان می‌دهد که چگونه می‌توان یک ارز دیجیتال ساده به نام smashingCoin را با استفاده از مفاهیم کلاس‌های جاوااسکریپت و Node.js ساخت. امتحانش کنید — ساده‌تر از چیزی است که فکر می‌کنید!

ظهور بی‌سابقه ارزهای دیجیتال و فناوری بلاک‌چینِ زیربنایی آن‌ها، جهان را با طوفان خود همراه کرده است — از آغاز فروتنانه‌اش به‌عنوان یک مفهوم دانشگاهی بیش از یک دهه پیش تا پذیرش روزافزون امروزی در صنایع گوناگون.

فناوری بلاک‌چین به دلیل توانایی‌اش در تقویت امنیت در محیط‌های غیرقابل‌اعتماد، اعمال تمرکززدایی و کارآمد کردن فرایندها، توجه زیادی را به خود جلب کرده است.

به‌طور سنتی، پایتون زبان برنامه‌نویسیِ دوفاکتو برای توسعه بلاک‌چین بوده است. اما با گسترش این فناوری شگفت‌انگیز، گزینه‌های توسعه نیز افزایش یافته‌اند — و Node.js هم عقب نمانده است.

در این آموزش، قرار است درباره چگونگی ساخت یک بلاک‌چین ساده برای ارز دیجیتال در Node.js صحبت کنم. قرار نیست خیلی فانتزی باشد، بلکه فقط برای کمک به شما در درک طرز کار یک بلاک‌چین کافی است.

نام این ارز دیجیتال ساده را smashingCoin می‌گذارم.

اگر توسعه‌دهنده جاوااسکریپت هستید و می‌خواهید به حوزه رو به رشد ارزهای دیجیتال گام بگذارید، این مقاله مهارت‌های لازم برای شروع را در اختیارتان می‌گذارد. یا اگر کنجکاو هستید بدانید در دنیای ارزهای دیجیتال کارها چگونه پیش می‌رود، این آموزش ممکن است به پاسخ برخی از پرسش‌های شما کمک کند.

پیش‌نیازها

برای دنبال کردن موفقیت‌آمیز این آموزش، به موارد زیر نیاز دارید:

  • Node.js روی سیستم‌تان نصب شده باشد. می‌توانید آن را از اینجا دانلود کنید؛
  • یک ویرایشگر کد، مانند Visual Studio Code، Sublime Text یا هر ویرایشگر دیگری.

بیایید شروع کنیم…

بلاک‌چین چیست؟

بلاک‌چین فناوری‌ای است که به ارزهای دیجیتالی مانند بیت‌کوین و اتریوم قدرت می‌بخشد. این فناوری، یک دفتر کل عمومی توزیع‌شده و نوآورانه است که فهرستی پیوسته در حال رشد از رکوردها، موسوم به بلاک‌ها، را نگهداری می‌کند که با استفاده از رمزنگاری به‌طور امن به یکدیگر متصل می‌شوند.

اصطلاح بلاک‌چین نام خود را از شیوه نگهداری داده‌های تراکنش گرفته است؛ یعنی در بلاک‌هایی که برای ایجاد یک زنجیره به یکدیگر متصل می‌شوند. اندازه بلاک‌چین با افزایش تعداد تراکنش‌های انجام‌شده رشد می‌کند.

هر داده تراکنش معتبری در شبکه بلاک‌چین ثبت می‌شود؛ شبکه‌ای که با قوانین همتا‌به‌همتای تعیین‌شده توسط شرکت‌کنندگان اداره می‌شود. برای مثال، این داده می‌تواند شامل «ارزش» بلاک مانند ارزهای دیجیتال، رکوردی از تراکنش‌ها (مانند زمانی که طرفین کالا و خدمات مبادله می‌کنند) یا امتیازات مالکیت (مانند زمانی که زنجیره اطلاعات مالکیت را ثبت می‌کند) باشد.

علاوه بر داده تراکنش، هر بلاک ممکن است حاوی هش رمزنگاری‌شده خود (شناسه یکتا یا اثر انگشت دیجیتال)، مقدار nonce خود (عدد تصادفی دلخواهی که فقط یک‌بار در محاسبات رمزنگاری استفاده می‌شود)، هش بلاک قبلی و زمان‌سنجی (timestamp) تراکنش‌های معتبر اخیر باشد.

از آنجا که هر بلاک جدید باید به بلاک قبلی اشاره کند، اگر بلاکی بدون داشتن هش صحیح آخرین بلاک در زنجیره ادغام شود، می‌تواند کل بلاک‌چین را نامعتبر کند. این ویژگی تغییرناپذیری، کلید امنیت بلاک‌چین‌هاست.

علاوه بر این، پروتکل‌های اجماع (consensus) مختلفی اغلب برای حفظ اصالت بلاک‌چین به کار گرفته می‌شوند. اجماع تضمین می‌کند که همه شرکت‌کنندگان بر تراکنش‌های تأییدشده توسط شبکه توافق دارند.

برای مثال، یک پروتکل اجماع پرکاربرد، اثبات کار (proof of work) است که هدف آن شناسایی عددی است که پس از انجام مقدار معینی کار محاسباتی، راه‌حلی برای یک مسئله ریاضی پیچیده پیدا می‌کند.

ایده اصلی اثبات کار این است که هر شرکت‌کننده در شبکه بلاک‌چین باید یافتن این عدد را دشوار بداند، اما تأیید آن آسان باشد. در نتیجه، این سازوکار اسپم‌کردن و دستکاری ساختار بلاک‌چین را دلسرد می‌کند.

در مورد بیشتر ارزهای دیجیتال، افزودن یک بلاک جدید به بلاک‌چین مستلزم حل یک معادله ریاضی پیچیده است که با رشد بلاک‌چین، دشواری آن در طول زمان افزایش می‌یابد. در نتیجه، هر شخصی که ثابت کند با حل این مسئله کار انجام داده است، در فرایندی که «استخراج» (mining) نامیده می‌شود، با یک ارز دیجیتال پاداش می‌گیرد.

چگونه یک بلاک بسازیم؟

حالا که با فناوری بلاک‌چین و طرز کار آن آشنا شدیم، ببینیم چگونه می‌توانیم این مفاهیم را در ساخت یک بلاک به کار ببریم. همان‌طور که پیش‌تر اشاره شد، بلاک‌ها همان چیزهایی هستند که برای تشکیل یک بلاک‌چین به یکدیگر پیوند می‌خورند.

برای ایجاد ارز smashingCoin، از کلاس‌های جاوااسکریپت استفاده می‌کنم که در ES6 معرفی شدند.

آماده‌اید؟

بیایید دست‌به‌کار شویم…

در اینجا کد کلاس CryptoBlock آمده است:

javascript// وارد کردن تابع هش SHA256 از کتابخانه crypto-js
const SHA256 = require('crypto-js/sha256');

// کلاس بلاک رمزنگاری‌شده — بلوک‌های سازنده بلاک‌چین
class CryptoBlock{
    // سازنده کلاس؛ با ایندکس، زمان‌سنجی، داده و هش بلاک قبلی مقداردهی می‌شود
    constructor(index, timestamp, data, precedingHash=" "){
        this.index = index;            // موقعیت بلاک در زنجیره
        this.timestamp = timestamp;    // زمان ثبت تراکنش
        this.data = data;              // داده‌های تراکنش (فرستنده، گیرنده، مقدار)
        this.precedingHash = precedingHash; // هش بلاک قبلی
        this.hash = this.computeHash();     // هش این بلاک
    }
    // محاسبه هش بلاک بر اساس ویژگی‌های آن
    computeHash(){
        return SHA256(this.index + this.precedingHash + this.timestamp + JSON.stringify(this.data)).toString();
    }
}

همان‌طور که در کد بالا می‌بینید، کلاس CryptoBlock را ایجاد کردم و متد constructor() را به آن اضافه کردم — درست همان‌طور که در هر کلاس جاوااسکریپت دیگری انجام می‌شود. سپس برای مقداردهی اولیه ویژگی‌های آن، پارامترهای زیر را به متد سازنده اختصاص دادم:

  • index: عددی یکتا است که موقعیت هر بلاک را در کل بلاک‌چین پیگیری می‌کند.
  • timestamp: رکوردی از زمان وقوع هر تراکنش تکمیل‌شده نگهداری می‌کند.
  • data: داده‌هایی درباره تراکنش‌های تکمیل‌شده فراهم می‌کند؛ مانند مشخصات فرستنده، مشخصات گیرنده و مقدار تراکنش.
  • precedingHash: به هش بلاک قبلی در بلاک‌چین اشاره می‌کند؛ چیزی که در حفظ یکپارچگی بلاک‌چین مهم است.

علاوه بر این، از متد computeHash برای محاسبه هش بلاک بر اساس ویژگی‌هایش استفاده کردم، همان‌طور که در داده‌های بالا آمده است.

همان‌طور که می‌بینید، کتابخانه جاوااسکریپتی crypto-js را وارد کردم و از ماژول crypto-js/sha256 آن برای محاسبه هش هر بلاک استفاده کردم. از آنجا که این ماژول یک شیء عددی برمی‌گرداند، از متد toString() برای تبدیل آن به رشته استفاده کردم.

برای افزودن کتابخانه crypto-js به پروژه‌تان، به ترمینال بروید و دستور زیر را برای نصب آن با npm اجرا کنید:

shellnpm install --save crypto-js

پس از اجرای دستور بالا، دایرکتوری node modules که شامل کتابخانه و سایر فایل‌های ضروری است، به پوشه پروژه شما اضافه خواهد شد.

چگونه یک بلاک‌چین بسازیم؟

همان‌طور که پیش‌تر توضیح داده شد، فناوری بلاک‌چین بر این مفهوم استوار است که همه بلاک‌ها به یکدیگر زنجیر می‌شوند. پس بیایید کلاسی به نام CryptoBlockchain بسازیم که مسئول مدیریت عملیات کل زنجیره خواهد بود. اینجاست که کار اصلی شروع می‌شود.

کلاس CryptoBlockchain عملیات بلاک‌چین را با استفاده از متدهای کمکی که کارهای مختلفی مانند ایجاد بلاک‌های جدید و افزودن آن‌ها به زنجیره را انجام می‌دهند، مدیریت خواهد کرد.

در اینجا کد کلاس CryptoBlockchain آمده است:

javascript// کلاس بلاک‌چین — مدیریت کل زنجیره بلاک‌ها
class CryptoBlockchain{
    // سازنده: نمونه‌سازی بلاک‌چین با بلاک پیدایش
    constructor(){
        // زنجیره با آرایه‌ای از بلاک‌ها شروع می‌شود؛ بلاک اول، بلاک پیدایش است
        this.blockchain = [this.startGenesisBlock()];
    }
    // ایجاد بلاک پیدایش (genesis) — اولین بلاک شبکه که به بلاک قبلی اشاره نمی‌کند
    startGenesisBlock(){
        return new CryptoBlock(0, "01/01/2020", "Initial Block in the Chain", "0");
    }
    // دریافت آخرین بلاک زنجیره
    obtainLatestBlock(){
        return this.blockchain[this.blockchain.length - 1];
    }
    // افزودن بلاک جدید؛ هش بلاک قبلی به بلاک جدید داده می‌شود تا زنجیره یکپارچه بماند
    addNewBlock(newBlock){
        newBlock.precedingHash = this.obtainLatestBlock().hash;
        newBlock.hash = newBlock.computeHash();
        this.blockchain.push(newBlock);
    }
}

بگذارید نقش هر یک از متدهای کمکی تشکیل‌دهنده کلاس CryptoBlockchain را توضیح دهم.

۱. متد سازنده (Constructor)

این متد بلاک‌چین را نمونه‌سازی می‌کند. در داخل سازنده، ویژگی blockchain را ایجاد کردم که به آرایه‌ای از بلاک‌ها اشاره می‌کند. توجه کنید که متد startGenesisBlock() را به آن پاس دادم که بلاک اولیه زنجیره را ایجاد می‌کند.

۲. ایجاد بلاک پیدایش (Genesis Block)

در یک بلاک‌چین، بلاک پیدایش به اولین بلاکی اشاره دارد که تاکنون در شبکه ایجاد شده است. هر زمان که یک بلاک با بقیه زنجیره یکپارچه می‌شود، باید به بلاک قبلی ارجاع دهد.

برعکس، در مورد این بلاک اولیه، هیچ بلاک قبلی برای اشاره‌کردن وجود ندارد. بنابراین، بلاک پیدایش معمولاً به‌صورت سخت‌کد (hardcoded) در بلاک‌چین گنجانده می‌شود. به این ترتیب، بلاک‌های بعدی می‌توانند روی آن ساخته شوند. این بلاک معمولاً ایندکس ۰ دارد.

از متد startGenesisBlock() برای ایجاد بلاک پیدایش استفاده کردم. توجه کنید که آن را با استفاده از کلاس CryptoBlock که پیش‌تر ساختیم ایجاد کردم و پارامترهای index، timestamp، data و precedingHash را به آن پاس دادم.

۳. دریافت آخرین بلاک

دریافت آخرین بلاک در بلاک‌چین کمک می‌کند تا اطمینان حاصل شود هش بلاک فعلی به هش بلاک قبلی اشاره می‌کند — و در نتیجه یکپارچگی زنجیره حفظ می‌شود.

برای بازیابی آن از متد obtainLatestBlock() استفاده کردم.

۴. افزودن بلاک‌های جدید

برای افزودن یک بلاک جدید به زنجیره از متد addNewBlock() استفاده کردم. برای انجام این کار، هش قبلی بلاک جدید را برابر با هش آخرین بلاک در زنجیره قرار دادم — تا از دستکاری‌ناپذیری زنجیره اطمینان حاصل شود.

از آنجا که ویژگی‌های بلاک جدید با هر محاسبه جدید تغییر می‌کنند، مهم است که هش رمزنگاری‌شده آن دوباره محاسبه شود. پس از به‌روزرسانی هش، بلاک جدید به آرایه blockchain اضافه (push) می‌شود.

در واقعیت، افزودن یک بلاک جدید به بلاک‌چین به این سادگی نیست، زیرا بررسی‌های متعددی در نظر گرفته شده است. با این حال، برای این ارز دیجیتال ساده، همین میزان برای نشان دادن طرز کار واقعی یک بلاک‌چین کافی است.

آزمایش بلاک‌چین

حالا بیایید بلاک‌چین ساده خود را آزمایش کنیم و ببینیم آیا کار می‌کند.

در اینجا کد آن آمده است:

javascript// ایجاد نمونه‌ای از بلاک‌چین
let smashingCoin = new CryptoBlockchain();

// افزودن دو بلاک با داده‌های دلخواه (فرستنده، گیرنده، مقدار)
smashingCoin.addNewBlock(new CryptoBlock(1, "01/06/2020", {sender: "Iris Ljesnjanin", recipient: "Cosima Mielke", quantity: 50}));
smashingCoin.addNewBlock(new CryptoBlock(2, "01/07/2020", {sender: "Vitaly Friedman", recipient: "Ricardo Gimenes", quantity: 100}) );

// چاپ کل بلاک‌چین با فرمت خوانا
console.log(JSON.stringify(smashingCoin, null, 4));

همان‌طور که در کد بالا می‌بینید، یک نمونه جدید از کلاس CryptoBlockchain ایجاد کردم و آن را smashingCoin نامیدم. سپس با استفاده از برخی مقادیر دلخواه، دو بلاک به بلاک‌چین اضافه کردم. در پارامتر data از یک شیء استفاده کردم و مشخصات فرستنده، مشخصات گیرنده و مقدار تراکنش را اضافه کردم.

اگر کد را روی ترمینال اجرا کنم، خروجی زیر را می‌گیرم:

این همان چیزی است که smashingCoin به نظر می‌رسد! این یک شیء است که شامل ویژگی blockchain است؛ آرایه‌ای که تمام بلاک‌های زنجیره را در خود دارد. همان‌طور که در تصویر بالا می‌بینید، هر بلاک به هش بلاک قبلی ارجاع می‌دهد. برای مثال، بلاک دوم به هش بلاک اول ارجاع می‌دهد.

پس از آزمایش و دیدن اینکه بلاک‌چین ما کار می‌کند، بیایید قابلیت‌های بیشتری برای تقویت ویژگی‌های smashingCoin اضافه کنیم.

چگونه یکپارچگی بلاک‌چین را بررسی کنیم؟

همان‌طور که پیش‌تر اشاره شد، ویژگی کلیدی یک بلاک‌چین این است که پس از افزودن یک بلاک به زنجیره، نمی‌توان آن را تغییر داد بدون اینکه یکپارچگی بقیه زنجیره باطل شود.

بنابراین، برای بررسی یکپارچگی بلاک‌چین، یک متد checkChainValidity() به کلاس CryptoBlockchain اضافه می‌کنم.

هش‌ها برای تضمین اعتبار و امنیت یک بلاک‌چین حیاتی هستند، زیرا هر تغییری در محتوای یک بلاک منجر به تولید یک هش کاملاً جدید و باطل شدن بلاک‌چین می‌شود.

به این ترتیب، متد checkChainValidity() از دستورهای if استفاده می‌کند تا بررسی کند آیا هش هر بلاک دستکاری شده است یا نه. با شروع از اولین بلاک ساخته‌شده، روی کل بلاک‌چین حلقه می‌زند و اعتبار آن را بررسی می‌کند. توجه داشته باشید که از آنجا که بلاک پیدایش سخت‌کد شده بود، بررسی نمی‌شود.

همچنین، این متد بررسی می‌کند که آیا هش‌های هر دو بلاک متوالی به یکدیگر اشاره می‌کنند یا نه. اگر یکپارچگی بلاک‌چین به خطر نیفتاده باشد، true برمی‌گرداند؛ در غیر این صورت، در صورت وجود هرگونه ناهنجاری، false برمی‌گرداند.

در اینجا کد آن آمده است:

javascript// بررسی یکپارچگی کل زنجیره؛ از بلاک دوم شروع می‌شود (بلاک پیدایش بررسی نمی‌شود)
checkChainValidity(){
    for(let i = 1; i < this.blockchain.length; i++){
        const currentBlock = this.blockchain[i];
        const precedingBlock = this.blockchain[i-1];

        // اگر هش ذخیره‌شده با هش محاسبه‌شده فعلی برابر نباشد، زنجیره دستکاری شده است
        if(currentBlock.hash !== currentBlock.computeHash()){
            return false;
        }
        // اگر هش قبلی بلاک فعلی به هش بلاک قبلی اشاره نکند، زنجیره معتبر نیست
        if(currentBlock.precedingHash !== precedingBlock.hash)
            return false;
    }
    return true;
}

چگونه اثبات کار را اضافه کنیم؟

همان‌طور که پیش‌تر اشاره شد، اثبات کار مفهومی است که برای افزایش دشواری استخراج یا افزودن بلاک‌های جدید به بلاک‌چین به کار می‌رود.

در مورد smashingCoin، الگوریتم ساده‌ای به کار می‌گیرم که مردم را از تولید آسان بلاک‌های جدید یا اسپم‌کردن بلاک‌چین بازمی‌دارد.

بنابراین، در کلاس CryptoBlock متد دیگری به نام proofOfWork() اضافه می‌کنم. اساساً، این الگوریتم ساده عددی را شناسایی می‌کند که به‌عنوان ویژگی difficulty پاس داده می‌شود، به‌گونه‌ای که هش هر بلاک حاوی صفرهای ابتدایی (leading zeros) متناظر با این سطح سختی باشد.

اطمینان از اینکه هش هر بلاک با تعداد صفرهای تعیین‌شده در سطح سختی آغاز می‌شود، به قدرت محاسباتی زیادی نیاز دارد. هرچه سطح سختی بالاتر باشد، استخراج بلاک‌های جدید زمان بیشتری می‌برد.

علاوه بر این، یک مقدار nonce تصادفی به هر بلاکِ هش‌شده اضافه می‌کنم، به‌گونه‌ای که وقتی هش مجدد انجام می‌شود، محدودیت‌های سطح سختی همچنان برآورده شوند.

در اینجا کد آن آمده است:

javascript// اثبات کار: عددی (nonce) پیدا می‌کند که هش با تعداد صفرهای ابتدایی سطح سختی شروع شود
proofOfWork(difficulty){
    // تا زمانی که هش با صفرهای کافی شروع نشود، nonce را افزایش بده و هش را دوباره محاسبه کن
    while(this.hash.substring(0, difficulty) !== Array(difficulty + 1).join("0")){
        this.nonce++;
        this.hash = this.computeHash();
    }
}

و در اینجا متد به‌روزرسانی‌شده computeHash() با گنجاندن متغیر nonce آمده است:

javascript// محاسبه هش؛ این بار nonce نیز در ورودی هش لحاظ می‌شود
computeHash(){
    return SHA256(this.index + this.precedingHash + this.timestamp + JSON.stringify(this.data) + this.nonce).toString();
}

علاوه بر این، برای پیاده‌سازی سازوکار اثبات کار در تولید بلاک‌های جدید، آن را در متد addNewBlock() نیز قرار می‌دهم:

javascript// افزودن بلاک جدید همراه با اجرای اثبات کار
addNewBlock(newBlock){
    newBlock.precedingHash = this.obtainLatestBlock().hash;
    // newBlock.hash = newBlock.computeHash();  // (پیش از این مستقیم محاسبه می‌شد)
    newBlock.proofOfWork(this.difficulty);      // اکنون هش با اثبات کار تولید می‌شود
    this.blockchain.push(newBlock);
}

جمع‌بندی

در اینجا کل کد ساخت ارز دیجیتال smashingCoin با استفاده از Node.js آمده است:

javascript// وارد کردن تابع هش SHA256 از کتابخانه crypto-js
const SHA256 = require("crypto-js/sha256");

// کلاس بلاک رمزنگاری‌شده
class CryptoBlock {
  constructor(index, timestamp, data, precedingHash = " ") {
    this.index = index;
    this.timestamp = timestamp;
    this.data = data;
    this.precedingHash = precedingHash;
    this.hash = this.computeHash();
    this.nonce = 0; // عدد تصادفی برای اثبات کار
  }

  // محاسبه هش بلاک (شامل nonce)
  computeHash() {
    return SHA256(
      this.index +
        this.precedingHash +
        this.timestamp +
        JSON.stringify(this.data) +
        this.nonce
    ).toString();
  }

  // اثبات کار: افزایش nonce تا رسیدن به تعداد صفرهای ابتدایی موردنیاز
  proofOfWork(difficulty) {
    while (
      this.hash.substring(0, difficulty) !== Array(difficulty + 1).join("0")
    ) {
      this.nonce++;
      this.hash = this.computeHash();
    }
  }
}

// کلاس بلاک‌چین
class CryptoBlockchain {
  constructor() {
    this.blockchain = [this.startGenesisBlock()];
    this.difficulty = 4; // سطح سختی: هش‌ها باید با ۴ صفر شروع شوند
  }
  // بلاک پیدایش
  startGenesisBlock() {
    return new CryptoBlock(0, "01/01/2020", "Initial Block in the Chain", "0");
  }

  // آخرین بلاک زنجیره
  obtainLatestBlock() {
    return this.blockchain[this.blockchain.length - 1];
  }
  // افزودن بلاک جدید با اثبات کار
  addNewBlock(newBlock) {
    newBlock.precedingHash = this.obtainLatestBlock().hash;
    // newBlock.hash = newBlock.computeHash();
    newBlock.proofOfWork(this.difficulty);
    this.blockchain.push(newBlock);
  }

  // بررسی یکپارچگی زنجیره
  checkChainValidity() {
    for (let i = 1; i < this.blockchain.length; i++) {
      const currentBlock = this.blockchain[i];
      const precedingBlock = this.blockchain[i - 1];

      if (currentBlock.hash !== currentBlock.computeHash()) {
        return false;
      }
      if (currentBlock.precedingHash !== precedingBlock.hash) return false;
    }
    return true;
  }
}

// ساخت ارز دیجیتال smashingCoin و افزودن بلاک‌ها
let smashingCoin = new CryptoBlockchain();

console.log("smashingCoin mining in progress....");
smashingCoin.addNewBlock(
  new CryptoBlock(1, "01/06/2020", {
    sender: "Iris Ljesnjanin",
    recipient: "Cosima Mielke",
    quantity: 50
  })
);

smashingCoin.addNewBlock(
  new CryptoBlock(2, "01/07/2020", {
    sender: "Vitaly Friedman",
    recipient: "Ricardo Gimenes",
    quantity: 100
  })
);

console.log(JSON.stringify(smashingCoin, null, 4));
