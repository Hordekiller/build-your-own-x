SlowTorch: پیاده‌سازی PyTorch از پایه با ۱۰۰٪ پایتون خالص

⚙ زبان: Python 🧠 autograd + NN از صفر ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور پروژهٔ SlowTorch (نویسنده: xames3) است — یک بازپیاده‌سازی آموزشی از PyTorch که فقط با پایتون خالص و بدون هیچ وابستگی خارجی نوشته شده تا درونی‌های autograd و لایه‌های شبکه را شفاف نشان دهد.

۱. هدف پروژه: «کند» ولی شفاف

نام SlowTorch یک مزاح دوستانه است: در مقایسه با PyTorch واقعی کند است — اما این «کندی» با شفافیت جبران می‌شود. این پروژه با پایتون خالص (بدون numpy حتی در هسته، فقط stdlib) نوشته شده تا کسی که PyTorch را جعبه‌سیاه می‌بیند، بتواند هر جزء آن را خط‌به‌خط بخواند و بفهمد: تنسور چیست، autograd چطور کار می‌کند، و لایه‌ها و بهینه‌سازها چه می‌کنند.

۳. لایه‌ها و توابع

بالای تنسورها، همان اجزای آشنا تعریف شده‌اند تا بتوان یک شبکهٔ واقعی ساخت: Linear (ضرب ماتریسی + بایاس)، فعال‌سازی‌ها (ReLU، Sigmoid، Tanh، Softmax)، توابع هزینه (MSELoss، CrossEntropyLoss) و ماژول پایهٔ Module — همان الگوی nn.Module:

python# تعریف یک شبکه با الگوی PyTorch
class TwoLayerNet(Module):
    def __init__(self, in_dim, hidden, out_dim):
        self.fc1 = Linear(in_dim, hidden)
        self.fc2 = Linear(hidden, out_dim)

    def forward(self, x):
        x = self.fc1(x)
        x = relu(x)
        x = self.fc2(x)
        return softmax(x)

۴. بهینه‌سازها و حلقهٔ آموزش

بهینه‌سازهایی مثل SGD و Adam پیاده شده‌اند تا چرخهٔ آموزش مثل PyTorch باشد: forward ← محاسبهٔ loss ← backward ← گام بهینه‌ساز. مشاهدهٔ این حلقه در پایتون خالص، «جادو» را از بین می‌برد:

python# حلقه‌ی آموزش استاندارد — دقیقاً مثل PyTorch، ولی همه‌چیز باز است
model = TwoLayerNet(2, 8, 1)
optimizer = SGD(model.parameters(), lr=0.1)

for epoch in range(100):
    loss_sum = 0
    for x, y in dataset:
        optimizer.zero_grad()
        pred = model(x)
        loss = mse_loss(pred, y)
        loss.backward()          # پخش گرادیان‌ها
        optimizer.step()         # به‌روزرسانی وزن‌ها
        loss_sum += loss.data
    print(f"epoch {epoch}: loss = {loss_sum / len(dataset):.6f}")
