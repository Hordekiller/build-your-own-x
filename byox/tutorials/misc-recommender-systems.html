پیشنهاددهنده‌ها چه می‌کنند؟

فروشگاه‌های بزرگ «ممکن است دوست داشته باشند» را پیشنهاد می‌دهند. دو خانوادهٔ اصلی: محتوامحور (Content-Based) که ویژگی‌های آیتم را با سلیقهٔ کاربر مقایسه می‌کند، و فیلتر همکاری (Collaborative Filtering) که رفتار کاربران مشابه را مقایسه می‌کند. ترکیب این دو بهترین نتیجه را دارد.

فیلتر همکاری با شباهت‌ها

ایده: ماتریس کاربران×آیتم‌ها. اگر کاربر A به فیلم‌های X و Y امتیاز داده و کاربر B هم همین‌طور، احتمالاً سلیقه‌شان نزدیک است؛ پس فیلم‌های جدید B به A هم پیشنهاد می‌شود. شباهت با cosine یا correlation محاسبه می‌شود:

Pythonimport pandas as pd
from sklearn.metrics.pairwise import cosine_similarity

# ماتریس: ردیف = کاربر، ستون = فیلم، سلول = امتیاز
ratings = pd.DataFrame({
    'user': ['u1','u1','u2','u2','u3'],
    'movie': ['M1','M2','M1','M3','M2'],
    'rating': [5, 3, 4, 1, 2]
})
matrix = ratings.pivot(index='user', columns='movie', values='rating')
matrix = matrix.fillna(0)   # امتیاز نداده = 0

sim = pd.DataFrame(          # شباهت بین کاربران
    cosine_similarity(matrix),
    index=matrix.index, columns=matrix.index)

# به u1 چه پیشنهاد بدهیم؟ کاربر مشابه: u2
print(sim.loc['u1'].sort_values(ascending=False))

بعد از یافتن کاربر مشابه، فیلم‌هایی که او امتیاز بالایی داده و کاربر ما هنوز ندیده را پیشنهاد بدهید.

رویکرد ماتریس فاکتورگیری

وقتی داده زیاد باشد، ماتریس کاربر×فیلم را به دو ماتریس کوچک (عوامل نهان) تجزیه می‌کنیم؛ هر کاربر و هر فیلم یک «بردار پنهان» می‌گیرد و امتیاز = ضرب داخلی آن‌ها. کتاب‌خانهٔ `surprise` این کار را راحت می‌کند:

Pythonfrom surprise import SVD, Dataset, Reader
from surprise.model_selection import cross_validate

reader = Reader(rating_scale=(1, 5))
data = Dataset.load_from_df(ratings, reader)

algo = SVD()   # Singular Value Decomposition
cross_validate(algo, data, cv=3, verbose=True)

این الگوریتم همان است که نتفلیکس و آمازون در اصل با آن شروع کردند.
