داستان lis.py

پیتر نورویگ (مدیر تحقیقات گوگل و نویسندهٔ کتاب معروف AI) این مفسر را در حدود ۹۰ خط پایتون نوشت و بعداً در هواپیما ادامه‌اش داد: یک Lisp کامل با توابع، متغیر، شرط و حتی quote. سه مفهوم اصلی: محیط (Environment)، eval و apply — دقیقاً مثل همتای مشهورش در مقالهٔ «The roots of Lisp» جان مک‌کارتی.

نمونهٔ کد: eval/apply اصلی

Pythondef eval(x, env=global_env):
    if isinstance(x, Symbol):      # متغیر
        return env.find(x)[x]
    elif not isinstance(x, list):  # عدد یا رشته
        return x
    elif x[0] == 'quote':          # quote: بدون ارزیابی
        (_, exp) = x
        return exp
    elif x[0] == 'if':             # شرط
        (_, test, conseq, alt) = x
        exp = (conseq if eval(test, env) else alt)
        return eval(exp, env)
    elif x[0] == 'define':         # تعریف متغیر
        (_, var, exp) = x
        env[var] = eval(exp, env)
    elif x[0] == 'lambda':         # تعریف تابع
        (_, parms, body) = x
        return Procedure(parms, body, env)
    else:                          # فراخوانی تابع
        proc = eval(x[0], env)
        args = [eval(arg, env) for arg in x[1:]]
        return proc(*args)

class Procedure(object):           # closure
    def __init__(self, parms, body, env):
        self.parms, self.body, self.env = parms, body, env
    def __call__(self, *args):
        return eval(self.body, Env(self.parms, args, self.env))

مفهوم محیط (Env) و زنجیره

کلاس Env یک dict به‌همراه «والد» است؛ find برای پیدا کردن متغیر در زنجیرهٔ والدها بالا می‌رود. این دقیقاً همان مکانیزم scope در زبان‌های واقعی است — درک آن، درک همهٔ زبان‌ها را ساده می‌کند.

برنامه‌های نمونه

مقاله با چند برنامهٔ واقعی تمام می‌شود: تابع fact (فاکتوریل) و count که روی همین مفسر اجرا می‌شوند. این اثباتی است که مفسر کوچک، واقعی هم هست. یک بخش اضافه «معرفی توابع Scheme پاسکال» هم دارد.

جمع‌بندی

کوتاه‌ترین، خواناترین و مشهورترین منبع ساخت مفسر: اگر فقط می‌خواهید «متوجه شوید مفسر چیست»، این را بخوانید. بعداً برای مقیاس واقعی، «Crafting Interpreters» را دنبال کنید.
