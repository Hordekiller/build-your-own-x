ساخت شبکه‌های عصبی در F#: بخش ۱ — مفاهیم و پیاده‌سازی پایه

۱. چرا F# برای شبکه عصبی؟

زبان‌های تابعی برای کار با ریاضیات شبکه‌های عصبی طبیعی‌اند: تغییرناپذیری داده‌ها، تیپ‌سازی قوی و نحو جمع‌وجور. نویسنده تصمیم می‌گیرد همه‌چیز را با MathNet.Numerics بسازد — نه چارچوب سنگین ML — تا عمق مفاهیم دیده شود: تابع فعال‌سازی، لایه‌ها، ماتریس وزن‌ها، هزینه و یادگیری با گرادیان نزولی. نتیجه نوع‌هایی است که هر کدام معنای مشخصی دارند و کامپایلر خطاهای منطقی را زود می‌گیرد.

fsharp// نوع‌هایی که ریاضی شبکه را معنا می‌بخشند
type Node<'a> = { Values: Vector<'a> }
type Layer<'a> = { Nodes: List<Node<'a>> }
type NodesVect<'a> = { Nodes: Vector<'a> }

۲. نورون و لایه: دو انتزاع پایه

هر نورون یک بردار از مقادیر است (مقادیر چند ورودی/خروجی هم‌زمان برای بهره‌وری ماتریسی). یک لایه، فهرستی از نورون‌هاست. این طراحی ساده، بعدها به ما اجازه می‌دهد لایه‌ها را زنجیر کنیم: خروجی لایهٔ اول، ورودی لایهٔ دوم. برای وزن‌ها از ماتریس MathNet استفاده می‌شود که توابع ضرب ماتریسی را بهینه و آماده دارد.

fsharp// ایجاد یک لایه با n نورون؛ هر نورون یک بردار مقادیر
let createLayer (n: int) (size: int) =
    { Nodes = [ for _ in 1 .. n -> { Values = Vector.Build.Random(size) } ] }

۳. تابع فعال‌سازی: مماس هذلولی (tanh)

تابع فعال‌سازی به شبکه غیرخطی‌بودن می‌دهد؛ بدون آن، هر عمق شبکه‌ای به یک تبدیل خطی می‌شکند. نویسنده tanh را انتخاب می‌کند: خروجی بین ۱- و ۱+، مشتق ساده و مرکز متقارن — که سرعت همگرایی را بهتر از سیگموئید می‌کند. مشتق tanh یعنی 1 - tanh(x)² در انتشار بازگشتی نقش محوری دارد:

fsharplet tanh (x: double) = Math.Tanh(x)

// مشتق tanh — در backpropagation برای انتشار خطا لازم است
let tanhDerivative (x: double) = 1.0 - (Math.Tanh(x) * Math.Tanh(x))

۴. انتشار پیشرو (forward pass)

خروجی هر نورون از ضرب ماتریس وزن‌ها در ورودی‌ها، جمع بایاس و سپس اعمال tanh به‌دست می‌آید. انتشار پیشرو یعنی اعمال لایه‌به‌لایهٔ این محاسبه تا رسیدن به خروجی نهایی. با نمای ماتریسی، همهٔ نورون‌های یک لایه یک‌جا و به‌صورت برداری محاسبه می‌شوند:

fsharp// یک گام پیشرو: خروجی لایه = tanh(ماتریس وزن‌ها × مقادیر نورون‌ها + بایاس)
let feedForward (weights: Matrix<double>) (inputs: Vector<double>) =
    weights * inputs
    |> Vector.map tanh

این بخش همان «پیش‌بینی» شبکه است: با وزن‌های تصادفی اولیه، خروجی بی‌معنی است؛ وزن‌ها باید با یادگیری تنظیم شوند.

۵. هزینه و خطا

برای یادگیری باید کمیت «بدی» شبکه را اندازه گرفت: تابع هزینهٔ میانگین مربعات خطا (MSE). خروجی پیش‌بینی‌شده با خروجی موردانتظار مقایسه می‌شود؛ مربع اختلاف میانگین گرفته می‌شود تا خطاهای بزرگ‌تر جریمهٔ بیشتری بگیرند و خطای منفی/مثبت هم‌جهت نشوند:

fsharp// خطای میانگین مربعات بین خروجی شبکه و پاسخ درست
let cost (outputs: Vector<double>) (expected: Vector<double>) =
    let errors = outputs - expected
    errors.PointwisePower(2.0) |> Vector.Sum / float errors.Count

۶. مسیر پیش رو

بخش اول زیرساخت را می‌سازد: نوع‌های Node/Layer، فعال‌سازی tanh، انتشار پیشرو و تابع هزینه. هنوز هیچ «یادگیری»ای رخ نداده — وزن‌ها تصادفی‌اند. در بخش دوم، نویسنده انتشار بازگشتی و گرادیان نزولی را پیاده می‌کند و شبکه را روی یک دیتاست واقعی آموزش می‌دهد و ارزیابی می‌کند.
