توسعه بازی با React، Redux و SVG — «Aliens, Go Home!» از Auth0

منبع اصلی: این صفحه ترجمهٔ فارسی و مرور مقالهٔ «Developing Games with React, Redux and SVG» از وبلاگ Auth0 است — ساخت بازی ویدیویی «Aliens, Go Home!» با React، Redux و SVG (بدون هیچ کتابخانهٔ بازی).

۱. دربارهٔ آموزش

این آموزش نشان می‌دهد چطور یک بازی واقعی — بدون موتور بازی! — با React + Redux + SVG ساخته می‌شود. بازی «Aliens, Go Home!» ساده است: یک توپ‌انداز (cannon) در پایین صفحه که با ماوس نشانه می‌گیرید و به دیسک‌های پرنده شلیک می‌کنید. پروژه با create-react-app بوت‌استرپ می‌شود و کد کاملش در GitHub (همراه با نسخه‌های گام‌به‌گام) موجود است.

نکته: اگر با Redux راحت هستید، این آموزش عالی است؛ معماری بازی (state به‌صورت اشیاء خالص، action ها و reducerها) بسیار تمیز طراحی شده.

۲. معماری: بازی به سبک React

  • State مرکزی در Redux: موقعیت دیسک‌ها، گلوله‌ها و cannon؛ همه‌چیز در یک store.
  • Rendering با SVG: هر عنصر بازی (توپ‌انداز، دیسک، گلوله) یک کامپوننت SVG است.
  • به‌روزرسانی با requestAnimationFrame: یک حلقه که هر فریم یک action پخش می‌کند و state جابه‌جا می‌شود.
  • برخورد و فیزیک ساده: با محاسبه در reducer یا helper خالص.

۳. نمونهٔ کد: کامپوننت بازی

jsx// کامپوننت توپ‌انداز: موقعیت آن از state می‌آید
const Cannon = ({ x, y }) => (
  <g>
    <polygon
      points="0,32 0,60 20,60 20,32"
      transform={`translate(${x}, ${y}) rotate(180)`}
      style={{ fill: '#000' }}
    />
  </g>
);

// حلقهٔ بازی: با هر فریم یک اکشن بازی تیکی می‌زند
const Game = ({ shots, aliens, cannon }) => (
  <svg width="1000" height="600">
    <Cannon x={cannon.x} y={cannon.y} />
    {shots.map((shot) => (
      <circle key={shot.id} cx={shot.x} cy={shot.y} r="4" />
    ))}
    {aliens.map((alien) => (
      <circle key={alien.id} cx={alien.x} cy={alien.y} r="15" />
    ))}
  </svg>
);

// در componentDidMount، حلقهٔ فریم با requestAnimationFrame
componentDidMount() {
  this.loopId = requestAnimationFrame(this.tick);
}
tick = () => {
  const { dispatch } = this.props;
  dispatch(moveAliensDown());   // حرکت دیسک‌ها
  dispatch(moveShotsUp());      // حرکت گلوله‌ها
  dispatch(checkCollisions());  // برخورد
  this.loopId = requestAnimationFrame(this.tick);
};
