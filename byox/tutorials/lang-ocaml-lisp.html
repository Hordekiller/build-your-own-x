معرفی سری

مکس برنستاین (که روی کامپایلرهای واقعی مثل OCaml و CMUCL کار کرده) در این مجموعه مقالات، مفسر Lisp را با OCaml می‌سازد و در هر مقاله یک قطعهٔ جدید اضافه می‌کند: از parsing و eval ساده تا closures، ماکروها و شبیه‌سازی سیستم‌های runtime. کد هر مقاله در یک پوشهٔ جدا (part1 تا partN) موجود است.

ساختار مقالات

مقاله‌ها به‌ترتیب: (۱) مفسر پایه — آرایه، لیست، eval ساده؛ (۲) نمادها و متغیرها؛ (۳) توابع lambda و محیط‌های تودرتو؛ (۴) ساختارهای مترقی مثل let*؛ (۵) مدیریت خطا و بازنمایی «Error» در رانتایم؛ (۶) ماکروها؛ (۷) و پایان‌بندی با بهینه‌سازی و بحث دربارهٔ runtime. هر مقاله با backend پایتون یا OCaml و سپس تست مقایسهٔ رفتار همراه است.

نمونهٔ کد: eval با pattern matching

OCaml(* ارزیابی: از نوع دادهٔ تجریدی استفاده می‌کنیم *)
let rec eval env = function
  | Atom a -> List.assoc a env      (* متغیر را در محیط پیدا کن *)
  | Number n -> Number n
  | List (Atom "quote" :: [x]) -> x (* quote: بدون ارزیابی *)
  | List (Atom "if" :: [c; t; f]) ->
      if eval env c = Bool true then eval env t else eval env f
  | List (Atom "lambda" :: [params; body]) ->
      (* closure: بدنه + پارامترها + محیط *)
      Closure (params, body, env)
  | List (Atom fn :: args) ->
      let f = eval env (Atom fn) in
      let args' = List.map (eval env) args in
      apply f args'
  | _ -> raise (Invalid_argument "عبارت نامعتبر")

نکته‌های جالب

۱) مقایسهٔ استراتژی‌های مختلف بازنمایی (مثلاً استفاده از Stone در برابر Variant)؛ ۲) بررسی اینکه چرا ارسال پارامترها با call-by-value برای محیط‌ها درست جواب می‌دهد؛ ۳) در پایان، بحث دربارهٔ runtime هزینه‌ها و بهینه‌سازی — که شما را با دید مهندسی کامپایلر واقعی آشنا می‌کند.
