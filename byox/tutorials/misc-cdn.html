ساخت یک CDN از صفر برای یادگیری دربارهٔ CDN

⚙ زبان: Lua ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور «CDN Up and Running» از لیندرو موریرا است که با OpenResty (Nginx + Lua) یک CDN کامل راه‌اندازی می‌کند.
↗ مشاهده منبع اصلی

CDN چیست و چطور کار می‌کند؟

شبکهٔ توزیع محتوا (CDN) محتوای شما (تصاویر، ویدیو، صفحه) را در سرورهای edge در نقاط مختلف جهان کپی می‌کند. وقتی کاربر از نزدیک‌ترین edge درخواست می‌کند، پاسخ سریع‌تر می‌آید و بار سرور اصلی کم می‌شود. اجزای اصلی: edge node، کش، فوروارد به origin و به‌روزرسانی هوشمند.

این آموزش با OpenResty (Nginx به‌همراه Lua) یک CDN واقعی و قابل‌اجرا می‌سازد که هم درک نظری می‌دهد و هم مهارت عملی.

تفاوت کش و پیش‌کش

دو نوع کش اصلی وجود دارد: pull caching که edge فقط وقتی درخواست بیاید محتوا را می‌گیرد، و push caching که محتوا از قبل به همهٔ edgeها فرستاده می‌شود. در شروع، pull کافی است. سرصفحه‌های HTTP مانند `Cache-Control: max-age` تعیین می‌کنند که چه چیزی چند وقت قابل‌کش است:

Lua (OpenResty)-- بررسی کش بودن درخواست و تنظیم سرصفحه‌ها
local cache_ttl = 3600   -- یک ساعت

function handle_request(ngx)
    local status, headers, body = ngx.location.capture('/proxy_upstream')

    if status == ngx.HTTP_OK then
        -- کَش کردن پاسخ با مدت اعتبار
        ngx.shared.cache:set(ngx.var.uri, body, cache_ttl)
        ngx.header['Cache-Control'] = 'public, max-age=' .. cache_ttl
    end
    ngx.status = status
    ngx.say(body or 'error')
end

کلیهٔ منطق در Lua نوشته می‌شود و Nginx بقیهٔ کار (TLS، HTTP/2، گزفب) را انجام می‌دهد.

پیکربندی کانفیگ Nginx

بخش فایل nginx.conf که edge را به origin می‌بندد:

Nginx# edge node: کش + پروکسی به origin
server {
    listen 8080;

    location / {
        # اسم این edge node را در هدر برای دیباگ بگذار
        add_header X-CDN-Node "edge-iran-1";

        # ارسال به backend با fetch از کش
        content_by_lua_block {
            local res = ngx.location.capture("/internal_origin")
            ngx.status = res.status
            ngx.say(res.body)
        }
    }

    location /internal_origin {
        proxy_pass http://origin-backend:3000;
        proxy_set_header Host $host;
    }
}

با این ساختار، هر درخواست می‌تواند از کش لوح_اشتراکی (shared dict) سرو شود یا به origin فرستاده شود.

پس‌زمینهٔ مفاهیم

در طول آموزش، مسائل واقعی CDN هم مطرح می‌شود: استهلال کش (پاک‌کردن با درخواست PURGE)، زمان‌بندی TTL بر اساس نوع محتوا، جغرافیای edgeها و ذخیرهٔ گرم (prefetch). هرکدام با مثال Lua پیاده می‌شود.

جمع‌بندی

با این آموزش، بخش‌های تاریک CDN شفاف می‌شوند و شما می‌توانید CDN شخصی (برای پروژه‌های داخلی) راه‌اندازی کنید. مهارت‌های Lua/OpenResty هم در دنیای واقعی (API Gatewayها) ارزشمند است.
