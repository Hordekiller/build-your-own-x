۱. دربارهٔ آموزش

Dangerous Dave یک بازی پلتفرمر کلاسیک DOS است که جان رومرو (خالق Doom و Wolfenstein) در سال ۱۹۸۸ ساخت — و به‌عنوان اولین بازی «گیم‌ساز» ساده و سرگرم‌کننده شناخته می‌شود. در این پلی‌لیست، همان بازی با گرافیک و جزئیات تقریباً یکسان، به زبان C بازسازی می‌شود: اسپرایت‌های ۱۶×۱۶، حرکت، گرانش، جمع‌آوری آیتم، دشمنان، پریدن و ساخت چند سطح.

نکته: این سری برای شروع عالی است: حجم کد هر قسمت کم است، ساختار ساده است و در انتها یک بازی کامل و قابل اجرا دارید.

۲. ویدیوها را تماشا کنید

۳. مفاهیم کلیدی

نمونه‌ای از ساختار بازی‌های پلتفرمر دوبعدی که در سری پیاده می‌شود:

c// ساختار سطح: شبکه‌ای از تایل‌ها
#define TILE_EMPTY 0
#define TILE_BLOCK 1
#define TILE_LADDER 2

typedef struct {
  int tile[ROWS][COLS];  // نقشهٔ سطح
  Player player;         // بازیکن
  Monster monsters[MAX_MONSTERS];
  Item items[MAX_ITEMS];
} Level;

// حلقهٔ اصلی بازی: ورودی → به‌روزرسانی فیزیک → رندر
void game_loop(void) {
  while (running) {
    handle_input();
    // فیزیک بازیکن: گرانش، حرکت افقی، برخورد با تایل‌ها
    update_player(&level.player, &level);
    // دشمنان و آیتم‌ها
    update_monsters(&level);
    render(&level);  // رسم اسپرایت‌ها روی بافر
    swap_buffers();  // نمایش
    delay_frame();
  }
}

مفاهیم آموزشی این سری: حلقهٔ بازی، حرکت مبتنی بر تایل، برخورد ساده، فیزیک گرانش و پرش، هوش مصنوعی سادهٔ دشمن و مدیریت چند سطح با فایل.

۴. جمع‌بندی

این پلی‌لیست یکی از لذت‌بخش‌ترین راه‌ها برای ساخت اولین بازی کامل شماست — بازی معروف، کد ساده و قابل توسعه. بعد از آن می‌توانید سراغ بازی‌های پیچیده‌تر با همان ساختار بروید.

کپیرایت: پلی‌لیست «Let's Build: Dangerous Dave» اثر سازندهٔ کانال یوتیوب است و بازی اصلی Dangerous Dave متعلق به جان رومرو است. این صفحه فقط ترجمهٔ فارسی و مرور آن است. برای مشاهدهٔ اصل ویدیوها به یوتیوب مراجعه کنید.
