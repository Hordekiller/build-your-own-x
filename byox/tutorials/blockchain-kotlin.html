بخش ۱ — بلاک‌چین (Blockchain)

با الهام از build-your-own-x نوشته دانیل استفانوویچ تصمیم گرفتم وقت آن رسیده که خواندن را کنار بگذارم و شروع به ساختن کنم.

«آنچه نمی‌توانم بسازم، درک نمی‌کنم.» — ریچارد فاینمن

در این مجموعه دو مقاله‌ای، توضیح می‌دهم چطور می‌توانید یک ارز دیجیتال بسیار ساده و در عین حال کاربردی بسازید. این پیاده‌سازی بر پایه بیت‌کوین است و امیدوارم تا پایان این مجموعه بتوانید بگویید تفاوت بین بلاک‌چین و یک دارایی رمزارزی (cryptoasset) چیست.

فرض می‌کنم خواننده کمی تجربه برنامه‌نویسی دارد، اما حتی اگر مبتدی باشید هم می‌توانید ادامه دهید. من از زبان Kotlin استفاده خواهم کرد، چون مدتی است با آن سر و کار دارم، اما این کار عملاً در هر زبانی قابل پیاده‌سازی است؛ بروید و آن را به زبان برنامه‌نویسی موردعلاقه خودتان پیاده‌سازی کنید!

شروع کار

این احتمالاً ساده‌ترین بخش خواهد بود: به سایت رسمی IntelliJ بروید، نسخه Community را دانلود کنید و یک پروژه جدید بسازید.

در حال حاضر سکه‌های زیادی با نام KOIN وجود دارد، از جمله KOIN که یک فریم‌ورک تزریق وابستگی (DI) برای Kotlin است؛ پس نام kCoin را انتخاب کردیم.

کمی تئوری

دو روش برای سازمان‌دهی ارتباط بین طرف‌ها وجود دارد:

  • متمرکز (Centralized): در این روش تمام ارتباطات از طریق یک واسطه انجام می‌شود. مثلاً در بانکداری سنتی، اگر بخواهید پولی به دوست‌تان منتقل کنید، این کار را از طریق رابط کاربری بانک انجام می‌دهید و بانک ممکن است برای این کار کارمزد بگیرد.
  • غیرمتمرکز یا توزیع‌شده (Decentralized / Distributed): در این روش هر طرف می‌تواند بدون واسطه با طرف دیگر ارتباط برقرار کند. مثلاً بیت‌تورنت (BitTorrent) که در آن فایل‌ها را مستقیم از کاربران دانلود می‌کنید، به‌جای یک سرور.

در هر دو حالت، نیازی به ذخیره اطلاعات در جایی وجود دارد؛ خواه فهرستی از تراکنش‌های انجام‌شده روی حساب شما باشد، خواه فهرستی از کاربرانی که می‌خواهید فایل‌ها را از آن‌ها دانلود کنید.

در مورد اول اطلاعات به‌صورت متمرکز روی سرورهای بانک ذخیره می‌شود و در مورد دوم — بین کاربران توزیع می‌شود.

بلاک‌چین یک راه‌حل ذخیره‌سازی برای یک سیستم توزیع‌شده است.

آن را مانند Amazon S3 تصور کنید، اما متعلق به همه و نه به آمازون.

بلاک‌چین از فهرستی از بلوک‌ها ساخته شده است که هر بلوک هش خودش، هش بلوک قبلی (والد) و داده کمکی مانند برچسب زمانی (timestamp) و مثلاً فهرست تراکنش‌های موجود در آن بلوک را دارد. در اصل، هر بلوک وضعیت سیستم را در یک لحظه خاص ثبت می‌کند.

مهم است ببینیم هش بلوک از چه چیزهایی ساخته می‌شود:

هش بلوک = هش (هش والد + داده‌های کمکی)

گنجاندن هش والد یعنی امکان تغییر داده‌های والد بدون تأثیر بر بلوک‌های فرزند در طول زنجیره وجود ندارد؛ به همین دلیل است که به آن «بلاک‌چین» (زنجیره بلوک‌ها) می‌گویند.

پیاده‌سازی

ابزارهای هش (Hash utils)

از آن‌جایی که دو‌سوم از داده‌های هر بلوک شامل هش است، یک تابع کمکی کوچک می‌نویسیم تا از روی یک String هش بگیریم.

بلاک‌چین‌ها از انواع خاصی از هش استفاده می‌کنند که به آن‌ها هش رمزنگاری‌شده (cryptographic hash) گفته می‌شود. بیت‌کوین از SHA-256 استفاده می‌کند و ما هم از همین الگوریتم استفاده خواهیم کرد. پیاده‌سازی واقعی به‌صورت یک تابع توسعه‌ای (Extension Function) روی کلاس موجود String انجام می‌شود. 

kotlinimport java.math.BigInteger
import java.security.MessageDigest

// تابع توسعه‌ای روی String که هش SHA-256 را برمی‌گرداند؛
// الگوریتم پیش‌فرض «SHA-256» است (همان الگوریتم بیت‌کوین)
fun String.hash(algorithm: String = "SHA-256"): String {
    // یک نمونه از MessageDigest با الگوریتم خواسته‌شده می‌سازیم
    val messageDigest = MessageDigest.getInstance(algorithm)
    // میزان MessageDigest را با بایت‌های رشته به‌روزرسانی می‌کنیم
    messageDigest.update(this.toByteArray())
    // مقدار digest را به‌صورت یک عدد BigInteger و سپس رشته HEX ۶۴ رقمی برمی‌گردانیم
    return String.format("%064x", BigInteger(1, messageDigest.digest()))
}

بسیار ساده است: String را به یک ByteArray تبدیل کنید، MessageDigest را با آن به‌روزرسانی کنید و در نهایت digest را به رشته HEX تبدیل کنید.

بلوک‌ها (Blocks)

مدل‌سازی بلوک‌ها با کلاس‌های داده (Data Classes) آسان است. آن‌ها تمام کدهای تکراری (boilerplate) جاوا را تولید می‌کنند و تغییرناپذیری (immutability) را هنگام کامپایل تضمین می‌کنند. 

kotlinimport java.time.Instant

data class Block(val previousHash: String,   // هش بلوک قبلی (والد)
                 val data: String,           // داده بلوک؛ فعلاً خالی است
                 val timestamp: Long = Instant.now().toEpochMilli(), // زمان ایجاد بلوک
                 var hash: String = "") {    // هش این بلوک

    // هنگام ساخت هر بلوک، هش آن محاسبه و تنظیم می‌شود
    init {
        hash = calculateHash()
    }

    // هش بلوک = هش(هش والد + داده + زمان)
    fun calculateHash(): String {
        return "$previousHash$data$timestamp".hash()
    }
}

همان‌طور که قبلاً اشاره کردم، هش شامل previousHash، data (که در مورد ما خالی است) و timestamp می‌شود. بیت‌کوین ساختار بسیار مشابهی با چند فیلد اضافه دیگر دارد که فعلاً می‌توانیم از آن‌ها صرف‌نظر کنیم.

بیایید چند بلوک بسازیم!

kotlinfun main(args: Array<String>) {

    // بلوک اول: هش والد آن «۰» است (بلوک نخست زنجیره)
    val block1 = Block(previousHash = "0", data = "I'm the first")

    // بلوک دوم: به بلوک اول متصل می‌شود
    val block2 = Block(previousHash = block1.hash, data = "I'm the second")

    // بلوک سوم: به بلوک دوم متصل می‌شود
    val block3 = Block(previousHash = block2.hash, data = "I'm the third")

    println(block1)
    println(block2)
    println(block3)
}

بلاک‌چین (Blockchain)

تا اینجا فقط بلوک ساختیم؛ حالا یک ظرف (container) برای نگهداری آن‌ها اضافه می‌کنیم — یعنی بلاک‌چین. 

kotlinclass BlockChain {

    // فهرست بلوک‌های زنجیره
    private val blocks: MutableList<Block> = mutableListOf()

    // بلوک جدید به انتهای زنجیره اضافه می‌شود
    fun add(block: Block) {
        blocks.add(block)
    }
}

استخراج (Mining)

در حال حاضر هیچ محدودیتی برای تعداد بلوک‌هایی که می‌توان به بلاک‌چین اضافه کرد و سرعت افزودن آن‌ها وجود ندارد. در یک سیستم متمرکز، مرجع مرکزی این فرایند را کنترل می‌کند، اما چون با یک سیستم توزیع‌شده سر و کار داریم، نمی‌توانیم چنین چیزی را بپذیریم.

همان‌طور که مشخص شد، این مشکل تازه نیست و صندوق ایمیل شما هر روز در قالب اسپم با آن دست‌وپنجه نرم می‌کند: تعداد زیادی اسپمر می‌خواهند برای شما بنویسند (ارسال کنند).

حدود ۲۰ سال پیش، آدام بک (Adam Back) راه‌حل HashCash را پیشنهاد کرد. ایده آدام این بود که به هر ایمیل ارسالی هزینه‌ای اضافه شود تا ارسال انبوه ایمیل پرهزینه شود؛ اما او نمی‌خواست پول بگیرد؛ در عوض ایده‌اش این بود که از فرستنده بخواهد یک کار سنگین پردازشی انجام دهد، مثلاً یافتن یک هش با قالب خاص. نکته جالب این راه‌حل این است که هیچ راه آسانی برای یافتن چنین هشی بدون انجام brute force وجود ندارد.

بیت‌کوین از همین ایده استفاده می‌کند و برای معتبر بودن، هش خاصی از بلوک انتظار می‌رود:

برای اینکه یک بلوک معتبر باشد، هش آن باید با تعداد معینی صفر شروع شود.

همان‌طور که قبلاً اشاره کردم، این فقط با brute force قابل دستیابی است، اما مدل فعلی بلوک ما تغییرناپذیر (immutable) است و هیچ تغییری را اجازه نمی‌دهد. پس فیلد جدیدی به نام nonce اضافه می‌کنیم که بتوانیم آن را تغییر دهیم: 

kotlinimport java.time.Instant

data class Block(val previousHash: String,   // هش بلوک قبلی
                 val data: String,           // داده بلوک
                 val timestamp: Long = Instant.now().toEpochMilli(), // زمان ایجاد بلوک
                 val nonce: Long = 0,        // عددی که در فرایند استخراج تغییر می‌کند
                 var hash: String = "") {    // هش بلوک

    init {
        hash = calculateHash()
    }

    // حالا هش شامل nonce هم می‌شود
    fun calculateHash(): String {
        return "$previousHash$data$timestamp$nonce".hash()
    }
}

حالا که این فیلد را داریم، الگوریتم واقعی استخراج بسیار ساده است: در یک حلقه، nonce را یکی‌یکی افزایش می‌دهیم تا هش خاص پیدا شود: 

kotlinclass BlockChain {

    private val blocks: MutableList<Block> = mutableListOf()

    // تعداد صفرهای ابتدایی هش بلوک معتبر؛ هرچه بیشتر باشد، استخراج سخت‌تر است
    private val difficulty = 2
    private val validPrefix = "0".repeat(difficulty)

    // اگر بلوک از قبل استخراج نشده باشد، آن را استخراج می‌کنیم
    fun add(block: Block) : Block {
        val minedBlock = if (isMined(block)) block else mine(block)
        blocks.add(minedBlock)
        return minedBlock
    }

    // بلوک معتبر است اگر هش آن با پیشوند صفرها شروع شود
    private fun isMined(block: Block) : Boolean {
        return block.hash.startsWith(validPrefix)
    }

    // حلقه استخراج: nonce را افزایش می‌دهیم تا هش معتبر پیدا شود
    private fun mine(block: Block) : Block {

        println("Mining: $block")

        // از روش کپی کلاس داده برای ساخت نسخه جدید با nonce جدید استفاده می‌کنیم
        var minedBlock = block.copy()
        while (!isMined(minedBlock)) {
            minedBlock = minedBlock.copy(nonce = minedBlock.nonce + 1)
        }

        println("Mined : $minedBlock")
        return minedBlock
    }
}

باز هم، کلاس داده (Data Class) کاتلین با ویژگی کپی (Copying) خود، کدهای تکراری را حذف می‌کند. همچنین تابع add را تغییر دادم تا بلوک را استخراج کند، اگر از قبل استخراج نشده باشد.

Difficulty به ما اجازه می‌دهد کنترل کنیم چقدر سریع می‌توانیم یک بلوک پیدا کنیم. بیت‌کوین این پارامتر را هر چند هفته یک‌بار بر اساس میانگین زمانی که در آن دوره برای استخراج بلوک‌ها صرف شده تنظیم می‌کند. من MacBook Pro مدل ۲۰۱۵ دارم و با difficulty بیشتر از ۱۰، استخراج یک بلوک زمان قابل‌توجهی می‌گیرد.

اعتبارسنجی (Validation)

حالا که می‌توانیم بلوک بسازیم، استخراج کنیم و اضافه کنیم، تابعی برای اعتبارسنجی بلاک‌چین اضافه می‌کنیم.

برای اینکه بلاک‌چین ما معتبر باشد:

  • بلاک‌چین معتبر است اگر خالی باشد
  • بلاک‌چین شامل یک بلوک واحد با هش معتبر باشد
  • همه بلوک‌ها استخراج شده باشند
  • برای هر بلوک در بلاک‌چین:
    • هش بلوک جاری معتبر باشد
    • هش بلوک قبلی معتبر باشد

من از ساختار when استفاده کردم و به نظر تمیز می‌رسد:

kotlin    // بررسی اعتبار کل زنجیره
    fun isValid() : Boolean {
        when {
            // زنجیره خالی معتبر است
            blocks.isEmpty() -> return true

            // زنجیره تک‌بلوکی: فقط هش بلوک را بررسی می‌کنیم
            blocks.size == 1 -> return blocks[0].hash == blocks[0].calculateHash()

            else -> {
                // از بلوک دوم به بعد، پیوند والد/فرزند را بررسی می‌کنیم
                for (i in 1 until blocks.size) {
                    val previousBlock = blocks[i - 1]
                    val currentBlock = blocks[i]

                    when {
                        // هش بلوک جاری باید معتبر باشد
                        currentBlock.hash != currentBlock.calculateHash() -> return false

                        // بلوک جاری باید به بلوک قبلی اشاره کند
                        currentBlock.previousHash != previousBlock.calculateHash() -> return false

                        // هر دو بلوک باید استخراج شده باشند
                        !(isMined(previousBlock) && isMined(currentBlock)) -> return false
                    }
                }
                return true
            }
        }
    }

بخش ۲ — کیف پول‌ها و تراکنش‌ها (Wallets and Transactions)

در بخش دوم، قطعات نهایی و آخر را برای ساختن یک ارز دیجیتال روی بلاک‌چین پیاده‌سازی می‌کنیم — یعنی تراکنش‌ها؛ و همان‌طور که بعداً خواهیم دید به یک کیف پول (Wallet) هم نیاز داریم، اما اول کمی تئوری.

تراکنش‌ها در بیت‌کوین بسیار شبیه به چک‌های فیزیکی کار می‌کنند. برای انجام تراکنش روی بلاک‌چین، اساساً باید:

  1. یک تراکنش بسازیم و فیلدهای From، To و Amount را پر کنیم
  2. تراکنش را امضا کنیم

در دنیای فیزیکی از شماره حساب خودتان برای فیلد From و شماره حساب گیرنده برای فیلد To استفاده می‌کنید و با یک خودکار تراکنش را امضا می‌کنید. از آن‌جایی که در فضای دیجیتال هستیم، از کلیدهای دیجیتال (Digital Keys) برای نمایش شماره حساب‌ها و از امضای دیجیتال (Digital Signatures) برای امضای تراکنش‌ها استفاده می‌کنیم.

امضای دیجیتال به دو کلید نیاز دارد: کلید عمومی (Public) که می‌توانید با هر کسی به اشتراک بگذارید و کلید خصوصی (Private) که باید محرمانه بماند. شما تراکنش را با کلید خصوصی امضا می‌کنید و امضا را با کلید عمومی تأیید (verify) می‌کنید.

کلیدهای دیجیتال به ما اجازه می‌دهند بدون اینکه واقعاً بدانیم شما کی هستید، تأیید کنیم که واقعاً خودتان تراکنش را ایجاد کرده‌اید.

در بانکداری سنتی شما یک حساب در سیستم دارید و شماره حسابی می‌گیرید، اما در بیت‌کوین هیچ حسابی وجود ندارد و در عوض از کلیدهای عمومی به‌عنوان شماره حساب استفاده می‌شود. همان‌طور که بعداً خواهیم دید، ایجاد KeyPair بسیار آسان است و غیرمعمول نیست که چند جفت کلید (KeyPair) برای اهداف مختلف داشته باشید؛ مثلاً می‌توانید یک جفت کلید برای خریدهای کوچک روزمره داشته باشید و جفت دیگری برای نگهداری بیشتر سکه‌هایتان.

کیف پول (Wallet)

بیایید کلاسی به نام Wallet بسازیم که کلیدهای عمومی و خصوصی را ذخیره کند.

kotlinimport java.security.KeyPairGenerator
import java.security.PrivateKey
import java.security.PublicKey

// کیف پول: کلیدهای عمومی و خصوصی + ارجاع به بلاک‌چین
data class Wallet(val publicKey: PublicKey, val privateKey: PrivateKey, val blockChain: BlockChain) {

    companion object {

        // ساخت کیف پول جدید: یک جفت کلید RSA جدید تولید می‌کنیم
        fun create(blockChain: BlockChain): Wallet {
            val generator = KeyPairGenerator.getInstance("RSA")
            generator.initialize(2048)          // طول کلید ۲۰۴۸ بیت
            val keyPair = generator.generateKeyPair()

            return Wallet(keyPair.public, keyPair.private, blockChain)
        }
    }

    // موجودی = مجموع همه UTXOهایی که مالک آن‌ها هستیم
    val balance: Int get() {
        return getMyTransactions().sumBy { it.amount }
    }

    // همه خروجی‌های تراکنش خرج‌نشده (UTXO) متعلق به کلید عمومی ما
    private fun getMyTransactions() : Collection<TransactionOutput> {
        return blockChain.UTXO.filterValues { it.isMine(publicKey) }.values
    }
}

به‌خاطر سادگی مثال، هر بار که یک کیف پول می‌سازیم یک KeyPair جدید ایجاد می‌کنیم؛ همچنین، برخلاف بیت‌کوین، از کلیدهای RSA استفاده می‌کنیم.

وقتی سکه‌ای ارسال می‌کنید، آن را به کلید عمومی گیرنده می‌فرستید و این اطلاعات را روی بلاک‌چین ذخیره می‌کنیم. به این‌ها خروجی تراکنش خرج‌نشده یا UTXO گفته می‌شود و مفهوم موجودی (balance) توسط کیف پول ساخته می‌شود که همه آن‌ها را جمع می‌کند:

موجودی، مجموع همه UTXOهایی است که کیف پول کاربر می‌تواند با کلید عمومیای که در اختیار دارد خرج کند.

برای اینکه سکه‌ای داشته باشید، اول باید کسی آن را برای شما ارسال کند؛ این کار در قالب UTXO مرتبط با کلید شما انجام می‌شود.

تراکنش‌ها (Transactions)

در بیت‌کوین، هر تراکنش اساساً فهرستی از UTXOها را مصرف (consume) می‌کند و فهرست دیگری از UTXO تولید می‌کند. همچنین، چون موجودی در جایی ثبت نمی‌شود، در صورت لزوم کیف پول باید یک باقی‌مانده (change) در قالب UTXO تولید کند که به فرستنده بازگردانده می‌شود.

اگر فقط ۱۰ سکه به‌صورت یک واحد داشته باشید و بخواهید ۵ سکه برای باب (Bob) بفرستید، کیف پول دو UTXO تولید می‌کند: یکی برای باب با ۵ سکه و یکی دیگر برای خودتان با همان ۵ سکه.

هر تراکنش باید با کلید خصوصی فرستنده امضا شود تا تأیید شود که واقعاً فرستنده است که می‌خواهد وجوه را ارسال کند. از نظر پیاده‌سازی، یعنی باید چند تابع توسعه‌ای دیگر به کلاس استاندارد String اضافه کنیم: 

kotlinimport java.math.BigInteger
import java.security.*
import java.util.*

// هش رمزنگاری‌شده SHA-256 روی رشته
fun String.hash(algorithm: String = "SHA-256"): String {
    val messageDigest = MessageDigest.getInstance(algorithm)
    messageDigest.update(this.toByteArray())
    return String.format("%064x", BigInteger(1, messageDigest.digest()))
}

// امضای دیجیتال رشته با کلید خصوصی (SHA256withRSA)
fun String.sign(privateKey: PrivateKey, algorithm: String = "SHA256withRSA") : ByteArray {
    val rsa = Signature.getInstance(algorithm)
    rsa.initSign(privateKey)
    rsa.update(this.toByteArray())
    return rsa.sign()
}

// تأیید امضای دیجیتال با کلید عمومی
fun String.verifySignature(publicKey: PublicKey, signature: ByteArray, algorithm: String = "SHA256withRSA") : Boolean {
    val rsa = Signature.getInstance(algorithm)
    rsa.initVerify(publicKey)
    rsa.update(this.toByteArray())
    return rsa.verify(signature)
}

// نمایش کلید به‌صورت رشته Base64 (به‌عنوان شماره حساب)
fun Key.encodeToString() : String {
    return Base64.getEncoder().encodeToString(this.encoded)
}

پیاده‌سازی بسیار ساده است.

بعد از آن، وقت آن است که کلاس Transaction را بسازیم:

kotlinimport java.security.PrivateKey
import java.security.PublicKey

// خروجی تراکنش: گیرنده، مبلغ و پیوند به تراکنش مبدأ
data class TransactionOutput(val recipient: PublicKey,
                             val amount: Int,
                             val transactionHash: String,
                             var hash: String = "") {

    // هش خروجی بر اساس گیرنده، مبلغ و هش تراکنش
    init {
        hash = "${recipient.encodeToString()}$amount$transactionHash".hash()
    }

    // آیا این خروجی متعلق به کلید عمومی من است؟
    fun isMine(me: PublicKey) : Boolean {
        return recipient == me
    }
}

// تراکنش: فرستنده، گیرنده، مبلغ + ورودی‌ها و خروجی‌ها
data class Transaction(val sender: PublicKey,
                       val recipient: PublicKey,
                       val amount: Int,
                       var hash: String = "",
                       val inputs: MutableList<TransactionOutput> = mutableListOf(),
                       val outputs: MutableList<TransactionOutput> = mutableListOf()) {

    private var signature: ByteArray = ByteArray(0)

    init {
        // Salt باعث می‌شود دو تراکنش یکسان، هش‌های متفاوتی داشته باشند
        hash = "${sender.encodeToString()}${recipient.encodeToString()}$amount$salt".hash()
    }

    companion object {
        fun create(sender: PublicKey, recipient: PublicKey, amount: Int) : Transaction {
            return Transaction(sender, recipient, amount)
        }

        // شمارنده Salt: با هر تراکنش جدید مقدارش افزایش می‌یابد
        var salt: Long = 0
            get() {
                field += 1
                return field
            }
    }

    // امضای تراکنش با کلید خصوصی فرستنده
    fun sign(privateKey: PrivateKey) : Transaction {
        signature = "${sender.encodeToString()}${recipient.encodeToString()}$amount".sign(privateKey)
        return this
    }

    // بررسی معتبر بودن امضای تراکنش با کلید عمومی فرستنده
    fun isSignatureValid() : Boolean {
        return "${sender.encodeToString()}${recipient.encodeToString()}$amount".verifySignature(sender, signature)
    }
}

Salt برای این است که مطمئن شویم دو تراکنش یکسان نداریم.

جمع‌آوری همه قطعات (Putting it all together)

حالا که کلاس Transaction را داریم، وقت آن است که توابعی به کلاس Wallet اضافه کنیم تا بتواند وجوه ارسال کند، و همچنین Block را گسترش دهیم تا تراکنش‌های ایجادشده را شامل شود و BlockChain را به‌روزرسانی کنیم تا UTXO خود را پس از موفقیت‌آمیز بودن استخراج بلوک به‌روز کند.

برای ارسال وجوه، اول بررسی می‌کنیم که واقعاً سکه کافی داریم و سپس TransactionOutputها را برای ذخیره داده‌های تراکنش تولید می‌کنیم. همچنین، در صورت لزوم، خروجی باقی‌مانده (change) تولید می‌کنیم تا باقی‌مانده را به کلید عمومی خودمان برگردانیم. 

kotlinimport java.security.KeyPairGenerator
import java.security.PrivateKey
import java.security.PublicKey

data class Wallet(val publicKey: PublicKey, val privateKey: PrivateKey, val blockChain: BlockChain) {

    companion object {
        fun create(blockChain: BlockChain): Wallet {
            val generator = KeyPairGenerator.getInstance("RSA")
            generator.initialize(2048)
            val keyPair = generator.generateKeyPair()

            return Wallet(keyPair.public, keyPair.private, blockChain)
        }
    }

    val balance: Int get() {
        return getMyTransactions().sumBy { it.amount }
    }

    private fun getMyTransactions() : Collection<TransactionOutput> {
        return blockChain.UTXO.filterValues { it.isMine(publicKey) }.values
    }

    // ارسال وجوه به گیرنده
    fun sendFundsTo(recipient: PublicKey, amountToSend: Int) : Transaction {

        // اول بررسی می‌کنیم موجودی کافی داریم
        if (amountToSend > balance) {
            throw IllegalArgumentException("Insufficient funds")
        }

        // تراکنش را می‌سازیم؛ فعلاً فرستنده و گیرنده خودمان هستند تا هش تراکنش شکل بگیرد
        val tx = Transaction.create(sender = publicKey, recipient = publicKey, amount = amountToSend)
        tx.outputs.add(TransactionOutput(recipient = recipient, amount = amountToSend, transactionHash = tx.hash))

        // UTXOهای خودمان را به‌عنوان ورودی مصرف می‌کنیم تا مبلغ جمع شود
        var collectedAmount = 0
        for (myTx in getMyTransactions()) {
            collectedAmount += myTx.amount
            tx.inputs.add(myTx)

            // اگر بیشتر از مبلغ لازم جمع شد، باقی‌مانده را به خودمان برمی‌گردانیم
            if (collectedAmount > amountToSend) {
                val change = collectedAmount - amountToSend
                tx.outputs.add(TransactionOutput(recipient = publicKey, amount = change, transactionHash = tx.hash))
            }

            // اگر مبلغ کافی جمع شد، ادامه نمی‌دهیم
            if (collectedAmount >= amountToSend) {
                break
            }
        }
        // در نهایت تراکنش را با کلید خصوصی خودمان امضا می‌کنیم
        return tx.sign(privateKey)
    }
}

هر بلوک حالا همچنین فهرستی از تراکنش‌ها را نگه می‌دارد:

kotlinimport java.time.Instant

data class Block(val previousHash: String,                                              // هش بلوک قبلی
                 val transactions: MutableList<Transaction> = mutableListOf(),           // تراکنش‌های این بلوک
                 val timestamp: Long = Instant.now().toEpochMilli(),                     // زمان ایجاد بلوک
                 val nonce: Long = 0,                                                    // عدد استخراج
                 var hash: String = "") {                                                // هش بلوک

    init {
        hash = calculateHash()
    }

    // هش بلوک حالا از تراکنش‌ها هم محاسبه می‌شود
    fun calculateHash(): String {
        return "$previousHash$transactions$timestamp$nonce".hash()
    }

    // افزودن تراکنش به بلوک؛ فقط تراکنش‌های با امضای معتبر پذیرفته می‌شوند
    fun addTransaction(transaction: Transaction) : Block {

        if (transaction.isSignatureValid())
            transactions.add(transaction)
        return this
    }
}

در نهایت، BlockChain را گسترش می‌دهیم و آرایه UTXO را با TransactionOutputهای جدید به‌روزرسانی می‌کنیم و همچنین موارد قدیمی را حذف می‌کنیم: 

kotlinclass BlockChain {

    private val blocks: MutableList<Block> = mutableListOf()
    private val difficulty = 2
    private val validPrefix = "0".repeat(difficulty)

    // نگاشت همه خروجی‌های تراکنش خرج‌نشده (UTXO) بر اساس هش آن‌ها
    var UTXO: MutableMap<String, TransactionOutput> = mutableMapOf()

    // همان تابع اعتبارسنجی بخش اول
    fun isValid() : Boolean {
        when {
            blocks.isEmpty() -> return true
            blocks.size == 1 -> return blocks[0].hash == blocks[0].calculateHash()
            else -> {
                for (i in 1 until blocks.size) {
                    val previousBlock = blocks[i - 1]
                    val currentBlock = blocks[i]

                    when {
                        currentBlock.hash != currentBlock.calculateHash() -> return false
                        currentBlock.previousHash != previousBlock.calculateHash() -> return false
                        !(isMined(previousBlock) && isMined(currentBlock)) -> return false
                    }
                }
                return true
            }
        }
    }

    fun add(block: Block) : Block {
        val minedBlock = if (isMined(block)) block else mine(block)
        blocks.add(minedBlock)
        return minedBlock
    }

    private fun isMined(block: Block) : Boolean {
        return block.hash.startsWith(validPrefix)
    }

    private fun mine(block: Block) : Block {

        println("Mining: $block")

        var minedBlock = block.copy()
        while (!isMined(minedBlock)) {
            minedBlock = minedBlock.copy(nonce = minedBlock.nonce + 1)
        }

        println("Mined : $minedBlock")

        // پس از استخراج موفق، UTXOها را به‌روزرسانی می‌کنیم
        updateUTXO(minedBlock)

        return minedBlock
    }

    // خروجی‌های مصرف‌شده (ورودی‌های تراکنش) حذف و خروجی‌های جدید اضافه می‌شوند
    private fun updateUTXO(block: Block) {

        // همه UTXOهایی که به‌عنوان ورودی مصرف شدند را حذف کن
        block.transactions.flatMap { it.inputs }.map { it.hash }.forEach { UTXO.remove(it) }

        // خروجی‌های جدید را اضافه کن
        UTXO.putAll(block.transactions.flatMap { it.outputs }.associateBy { it.hash })
    }
}

و حالا می‌توانیم تراکنش انجام دهیم:

kotlinimport kcoin.*

fun main(args: Array<String>) {

    // بلاک‌چین و دو کیف پول می‌سازیم
    val blockChain = BlockChain()
    val wallet1 = Wallet.create(blockChain)
    val wallet2 = Wallet.create(blockChain)

    println("Wallet 1 balance: ${wallet1.balance}")
    println("Wallet 2 balance: ${wallet2.balance}")

    // بلوک پیدایش (genesis): ۱۰۰ سکه به کیف پول ۱ صادر می‌کنیم
    val tx1 = Transaction.create(sender = wallet1.publicKey, recipient = wallet1.publicKey, amount = 100)
    tx1.outputs.add(TransactionOutput(recipient = wallet1.publicKey, amount = 100, transactionHash = tx1.hash))
    tx1.sign(wallet1.privateKey)

    var genesisBlock = Block(previousHash = "0")
    genesisBlock.addTransaction(tx1)
    genesisBlock = blockChain.add(genesisBlock)

    println("Wallet 1 balance: ${wallet1.balance}")
    println("Wallet 2 balance: ${wallet2.balance}")

    // کیف پول ۱ یک تراکنش واقعی می‌فرستد: ۳۳ سکه برای کیف پول ۲
    val tx2 = wallet1.sendFundsTo(recipient = wallet2.publicKey, amountToSend = 33)
    val secondBlock = blockChain.add(Block(genesisBlock.hash).addTransaction(tx2))

    println("Wallet 1 balance: ${wallet1.balance}")
    println("Wallet 2 balance: ${wallet2.balance}")
}

// Wallet 2 balance: 0
// Wallet 1 balance: 100
// Wallet 2 balance: 0

// Wallet 2 balance: 33
