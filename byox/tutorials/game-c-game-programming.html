مشاهدهٔ ویدیو

این آموزش به‌صورت ویدیویی است و در آن گام‌به‌گام کدنویسی انجام می‌شود. برای تماشا و دنبال‌کردن هم‌زمان، روی دکمهٔ زیر بزنید:

▶ تماشای ویدیو

۱. دربارهٔ آموزش

این پلی‌لیست یک دورهٔ کامل ویدیویی برای یادگیری C با بازی‌سازی است — مناسب مبتدیان و کسانی که با C شروع می‌کنند. به‌جای مثال‌های خشک ترمینال، مستقیماً بازی‌های قابل اجرا می‌سازید (مثل پونگ و بازی‌های سادهٔ مبتنی بر گرافیک) و در طول مسیر مفاهیم C — متغیرها، حلقه‌ها، تابع‌ها، آرایه‌ها و اشاره‌گرها — را یاد می‌گیرید.

۲. ویدیوها را تماشا کنید

این آموزش ویدیویی است و محتوای آن در این صفحه میزبانی نمی‌شود؛ کل پلی‌لیست را از لینک زیر در یوتیوب ببینید:

▶ مشاهدهٔ پلی‌لیست «Learn Video Game Programming in C»

۳. مفاهیم کلیدی

نمونه‌ای از ساختار حلقهٔ بازی که در دوره استفاده می‌شود:

c// حلقهٔ اصلی بازی — سه گام ثابت
while (game_is_running) {
  // ۱) پردازش ورودی
  handle_events();

  // ۲) به‌روزرسانی منطق (حرکت توپ، برخوردها، امتیاز)
  update();

  // ۳) رندر: رسم روی صفحه
  render();
}

در طول دوره، بازی‌هایی مثل پونگ ساخته می‌شود که شامل: حرکت راکت با کلید، حرکت توپ، بازتاب از دیوار، برخورد با راکت و شمارش امتیاز است — و سپس مفاهیم پیشرفته‌تر (آرایهٔ دشمنان، امتیازدهی، سطوح) به آن اضافه می‌شود.

۴. جمع‌بندی

اگر C را نمی‌دانید اما می‌خواهید با یک هدف جذاب یاد بگیرید، این پلی‌لیست انتخاب خوبی است: مباحث زبان C را با بازی‌های واقعی ترکیب می‌کند و انگیزه را در تمام مسیر حفظ می‌کند.

کپیرایت: پلی‌لیست «Learn Video Game Programming in C» اثر سازندهٔ کانال یوتیوب است و تمام حقوق آن متعلق به اوست. این صفحه فقط ترجمهٔ فارسی و مرور آن است. برای مشاهدهٔ اصل ویدیوها به یوتیوب مراجعه کنید.
