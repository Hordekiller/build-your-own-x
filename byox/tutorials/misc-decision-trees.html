درخت تصمیم یعنی «سوال پرسیدن»

درخت تصمیم دسته‌بندی را به سوال‌های سادهٔ متوالی تبدیل می‌کند: «سن بالای ۳۰؟»، «رنگ آیفون؟». هر سوال داده را به دو شاخه تقسیم می‌کند، تا به برگ‌هایی برسد که بیشتر نمونه‌های یک کلاس را دارند. سوال اصلی ساخت: کدام ویژگی، با کدام آستانه، بهترین تقسیم را می‌دهد؟

معیار ناخالصی: Gini

یک تقسیم خوب، کلاس‌های مخلوط را جدا می‌کند. «ناخالصی Gini» اندازه می‌گیرد چقدر کلاس‌ها داخل یک گروه قاطی‌اند (۰ = خالص)؛ هر split گزینش می‌شود که کاهش ناخالصی بیشینه باشد:

Pythondef gini(groups, classes):
    """ناخالصی وزنی کل شاخه‌ها"""
    total = sum(len(g) for g in groups)
    score = 0.0
    for group in groups:
        size = len(group)
        if size == 0: continue
        # احتمال هر کلاس داخل این شاخه
        probs = [group.count(c) / size for c in classes]
        score += (size / total) * (1 - sum(p ** 2 for p in probs))
    return score

`1 - Σp²`: اگر همه یک کلاس‌اند → صفر. هر چه آمیخته‌تر → بزرگ‌تر.

یافتن بهترین تقسیم

برای هر ویژگی، آستانه‌های کاندید (مقادیر میانی) را امتحان می‌کنیم و آنی که کمترین Gini را دارد برنده است:

Pythondef best_split(data, classes):
    """کوچک‌ترین gini را برای هر (ویژگی، آستانه) پیدا کن"""
    best = None
    for col in range(len(data[0]) - 1):
        values = sorted({row[col] for row in data})
        for i in range(len(values) - 1):
            threshold = (values[i] + values[i + 1]) / 2
            left = [r for r in data if r[col] <= threshold]
            right = [r for r in data if r[col] > threshold]
            g = gini([left, right], classes)
            if best is None or g < best[0]:
                best = (g, col, threshold, left, right)
    return best

ساختن آستانه از «میانگین مقدارهای مجاور» باعث می‌شود ویژگی‌های پیوسته هم قابل استفاده باشند.

ساخت بازگشتی درخت

همان تابع بازگشتی که چارچوب: اگر گروه خالص بود → برگ؛ وگرنه بهترین split را بزن و روی دو شاخه تکرار کن. پیش‌بینی هم همین مسیر را از ریشه تا برگ طی می‌کند. با همین ~۸۰ خط، ایدهٔ تمام درخت‌های واقعی (Random Forest، XGBoost) را دارید؛ آن‌ها فقط صدها درخت مثل همین را ترکیب می‌کنند.
