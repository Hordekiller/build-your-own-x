SSG چیست و چرا؟

مولد سایت استاتیک، محتوا (معمولاً Markdown) را در زمان Build به HTML می‌کند؛ برخلاف CMS که در لحظهٔ درخواست، صفحه را روی سرور می‌سازد. مزیت: فوق‌العاده سریع، امن و ارزان (هر هاست استاتیک کافی است). Jekyll، Hugo و Next.js (SSG) همین روند را دارند.

قلب SSG در ۴۰ خط

فایل‌های Markdown در یک پوشهٔ `posts` قرار می‌گیرند. اسکریپت Node برای هر فایل: محتوا را می‌خواند، Markdown را به HTML تبدیل می‌کند و نتیجه را در قالب صفحهٔ کامل HTML می‌پیچد:

JavaScriptconst fs = require('fs');
const path = require('path');
const MarkdownIt = require('markdown-it')();

const md = new MarkdownIt();               // پارسر Markdown
const DIR = 'posts';
const OUT = 'public';

// قالب HTML اطراف هر پست
const template = (title, body) => `<!DOCTYPE html>
<html lang="fa"><head><meta charset="utf-8">
<title>${title}</title></head>
<body><article>${body}</article></body></html>`;

fs.readdirSync(DIR).forEach(file => {
  const content = fs.readFileSync(path.join(DIR, file), 'utf8');
  const html = md.render(content);         // Markdown → HTML
  const title = file.replace('.md', '');
  fs.writeFileSync(path.join(OUT, title + '.html'), template(title, html));
});

تمام! برای هر فایل `*.md` یک فایل HTML ساخته می‌شود — بدون سرور، بدون دیتابیس.

اضافه‌کردن متادیتا

پست‌های واقعی front matter دارند (عنوان، تاریخ، برچسب). می‌توانید ساده شروع کنید و بعد آن را با جداکردن دو خط `---` در ابتدای فایل اضافه کنید. همین الگو با template هم توسعه می‌یابد — فهرست پست‌ها (index) هم تولید می‌شود:

JavaScript// ساخت صفحهٔ فهرست از همهٔ پست‌ها
const indexItems = fs.readdirSync(DIR)
  .map(f => `<li><a href="${f.replace('.md', '.html')}">${f}</a></li>`)
  .join('\n');
fs.writeFileSync(path.join(OUT, 'index.html'),
  template('وبلاگ من', `<ul>${indexItems}</ul>`));

جمع‌بندی

این آموزش نشان داد که SSG ظاهراً بزرگ، از ترکیب سه عملگر ساده ساخته می‌شود: خواندن فایل، تبدیل Markdown، تزریق در قالب. همین بلوک‌ها را که بزرگ کنید (tag، RSS، صفحات تمیز) یک مولد واقعی دارید — بدون وابستگی به فناوری پیچیده.

کپیرایت: تیم WebDevDrops. این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
