۱. دربارهٔ آموزش

این آموزش در قالب بخش «بازی‌ها» (Games) سایت MDN منتشر شده و بازی Breakout را با Phaser می‌سازد. ویژگی خاص آن: هر مرحله یک نمونهٔ زندهٔ قابل ویرایش دارد که می‌توانید کدش را مستقیم در مرورگر تغییر دهید و نتیجه را فوراً ببینید. کد کامل در GitHub MDN موجود است. پیش‌نیاز: جاوااسکریپت نسبتاً مبتدی تا متوسط.

نکته: MDN نسخهٔ همین بازی را با جاوااسکریپت خالص (Canvas) هم دارد؛ اگر می‌خواهید بدون فریم‌ورک ببینید چگونه کار می‌کند، اول آن نسخه را بروید، بعد این آموزش Phaser را — تفاوت‌ها خیلی روشن‌کننده‌اند.

۲. نقشهٔ درس‌ها

  • راه‌اندازی Phaser و ساخت صحنهٔ بازی
  • رندر و جابه‌جایی تصویر (راکت، توپ)
  • تشخیص برخورد (collision detection)
  • کنترل‌ها: ماوس و کیبورد
  • انیمیشن: حرکت توپ، تویین‌ها (tweens)
  • وضعیت برد و باخت (win/lose states)

۳. نمونهٔ کد: صحنهٔ بازی

js// ساخت صحنه‌های بازی: Boot → Preload → Create → Update
class GameScene extends Phaser.Scene {
  constructor() {
    super({ key: 'GameScene' });
  }

  preload() {
    // بارگذاری تصاویر
    this.load.image('ball', 'images/ball.png');
    this.load.image('paddle', 'images/paddle.png');
    this.load.image('brick', 'images/brick.png');
  }

  create() {
    // توپ با فیزیک
    this.ball = this.physics.add.image(400, 300, 'ball');
    this.ball.setBounce(1);         // بازتاب کامل
    this.ball.setVelocity(160, 160); // سرعت اولیه

    // راکت: ثابت در پایین، حرکت با ماوس
    this.paddle = this.physics.add.image(400, 550, 'paddle');
    this.paddle.setImmovable(true);

    // برخورد توپ با راکت
    this.physics.add.collider(this.ball, this.paddle);

    // آجرها: شبکه
    for (let row = 0; row < 3; row++) {
      for (let col = 0; col < 8; col++) {
        const brick = this.physics.add.image(70 + col * 90, 60 + row * 40, 'brick');
        brick.setImmovable(true);
        this.physics.add.collider(this.ball, brick, this.hitBrick, null, this);
      }
    }

    this.input.on('pointermove', (p) => {
      this.paddle.x = Phaser.Math.Clamp(p.x, 50, 750);
    });
  }

  hitBrick(ball, brick) {
    brick.destroy(); // آجر نابود شد
  }
}
