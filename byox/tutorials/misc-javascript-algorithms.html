چرا این ریپو؟

یادگیری الگوریتم با کد معمولی، اغلب خشک و بی‌حاصل است. این ریپو بیش از ۱۲۰ الگوریتم و ساختار داده را در جاوااسکریپت خالص (بدون وابستگی) پیاده کرده است: از باینری‌سرچ و سریع‌ساز (sort) تا درختان، گراف‌ها و برنامه‌نویسی پویا. هر فایل دارای تست جِی‌زیست و توضیح نظری است.

برای هر مبحث (مدل، لینکدلیست، گراف…) کاملاً روشن است که «چرا» و «چطور» — با پیچیدگی زمانی Big-O در کنار هر تابع.

ساختار: الگوریتم‌ها و ساختارهای داده

پوشش‌ها: ساختارهای داده: لینکدلیست، صف، پشته، درخت دودویی (BST)، هش‌مپ، گراف، تری، هیپ (heap). الگوریتم‌ها: مرتب‌سازی (مقایسه‌ای، غیرمقایسه‌ای)، جست‌وجو (خطی، باینری، DFS/BFS)، ریاضیات (GCD، فاکتوریل، اعداد اول)، مسیرهای گراف (Dijkstra، Bellman-Ford) و DP.

این تنوع باعث می‌شود برای آماده‌سازی مصاحبه و نیز فهم الگوریتم‌ها، یک مرجع کامل در دسترس باشد.

نمونه: مرتب‌سازی سریع (Quick Sort)

مرتب‌سازی سریع با انتخاب یک pivot و تقسیم آرایه به دو بخش کوچک‌تر و بزرگ‌تر کار می‌کند:

JavaScript// مرتب‌سازی سریع با پیچیدگی میانگین O(n log n)
function quickSort(original) {
  const arr = [...original];
  if (arr.length <= 1) return arr;

  const pivot = arr[0];
  const left = [];
  const right = [];

  for (let i = 1; i < arr.length; i++) {
    (arr[i] < pivot ? left : right).push(arr[i]);
  }

  return [...quickSort(left), pivot, ...quickSort(right)];
}

// نمونه استفاده
console.log(quickSort([5, 2, 9, 1, 5, 6])); // [1, 2, 5, 5, 6, 9]

نسخهٔ بهینه‌تر در ریپو با پارتش درحال حرکت و pivot تصادفی پیاده شده است تا پایین‌ترین حالت (آرایه مرتب) را هم پوشش دهد.

درخت جست‌وجوی باینری

یکی از رسمی‌ترین ساختارها در ریپو، BST است که عملیات insert/find/delete را با recurse پیاده می‌کند:

JavaScriptclass BinarySearchTreeNode {
  constructor(value) {
    this.value = value;
    this.left = null;
    this.right = null;
  }

  insert(value) {
    if (value < this.value) {
      if (this.left) this.left.insert(value);
      else this.left = new BinarySearchTreeNode(value);
    } else if (value > this.value) {
      if (this.right) this.right.insert(value);
      else this.right = new BinarySearchTreeNode(value);
    }
    return this;
  }

  find(value) {
    if (value === this.value) return this;
    if (value < this.value) return this.left ? this.left.find(value) : null;
    return this.right ? this.right.find(value) : null;
  }
}

با این شاکله‌ی کوچک، عملیات جست‌وجو در یک درخت متوازن در O(log n) انجام می‌شود.

چطور از آن بیشترین بهره را ببریم؟

بهترین روش، پیاده‌سازی دوبارهٔ هر الگوریتم ابتدا بدون دیدن کد و بعد مقایسه با پیاده‌سازی ریپو است. هر فایل یک تست کوچک دارد که می‌توانید با `jest` اجرا کنید؛ این چرخه — تمرین، تست، مقایسه — یادگیری را عمیق و ماندگار می‌کند.
