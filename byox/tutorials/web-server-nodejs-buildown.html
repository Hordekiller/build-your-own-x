مقدمه

بیشتر مردم هر روز از HTTP استفاده می‌کنند، اما کمتر کسی از جزئیات درونیِ آن سر درمی‌آورد. این کتابِ «خودت بساز»، عمیق به موضوع می‌زند و اصول را از صفر آموزش می‌دهد تا درک واضح‌تری از ابزارها و فناوری‌هایی که به آن‌ها تکیه می‌کنیم به دست آوریم.

  • برنامه‌نویسی شبکه (Network Programming)
  • پروتکل‌ها و ارتباطات
  • HTTP به تفصیل

با کدنویسیِ یک وب سرور، مهارت‌های برنامه‌نویسی شبکه، پروتکل HTTP و WebSocket را یاد می‌گیرید.

چرا از صفر بسازیم؟

پروژه‌های «Build Your Own X» این‌جا در build-your-own.org شامل Redis، پایگاه داده، کامپایلر و وب سرور هستند. این رویکرد به شما اجازه می‌دهد همان‌طور که چرخ را دوباره اختراع می‌کنید، عمیقاً بفهمید چرخ واقعاً چگونه کار می‌کند — چیزی که هیچ آموزش سطح بالایی نمی‌تواند جایگزینش کند.

پس از این مقدمه، با فصل «HTTP Overview» شروع کنید، سپس یک سرور TCP با Node.js بسازید (ماژول net)، یک پروتکل ساده طراحی کنید و در نهایت سرور HTTP خودتان را با مفاهیم نحو و معنا (syntax و semantics) HTTP کامل کنید؛ در بخش دوم هم محتوای پویا، فایل IO، Range Requests، کش، فشرده‌سازی و نهایتاً WebSocket را اضافه می‌کنید.

کپیرایت: کتاب «Build Your Own Web Server From Scratch In Node.JS» اثر «جیمز اسمیت (James Smith)» است که در build-your-own.org منتشر شده. این صفحه فقط ترجمه فارسی مقدمه و فهرست آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسنده اصلی است. برای مشاهده اصل مطلب به سایت اصلی مراجعه کنید.
