۱. دربارهٔ آموزش

این سری معروف، یک roguelike کلاسیک را به سبک Roguebasin می‌سازد: شبکهٔ ASCII، سیاه‌چاه‌های تصادفی، حرکت با کلید، میدان دید، مسیریابی و هیولاها. نسخهٔ Rust از روی نسخهٔ پایتون/پایتون-لیبتکاد ترجمهٔ Concept شده و هر قسمت، هم در وبلاگ و هم در مخزن گیت‌هاب (tomassedovic/roguelike-tutorial) موجود است.

نکته: اگر قبلاً هیچ roguelike نساخته‌اید، بهتر است اول نسخهٔ پایتون (rogueliketutorials.com) را ببینید؛ این نسخه فرض می‌کند مفاهیم را می‌دانید و روی ترجمهٔ آن‌ها به Rust تمرکز دارد.

۲. نقشهٔ قسمتها

  • راه‌اندازی پروژه و نمایش «@»
  • حرکت با کلیدها و ورودی کیبورد/ماوس
  • تولید سیاه‌چاه (اتاق‌ها، راهروها و تونل‌ها)
  • میدان دید (FOV) با الگوریتم
  • هیولاها و هوش مصنوعی ساده (تعقیب)
  • ذخیره‌سازی با serde، آیتم‌ها و چرخهٔ نوبت

۳. نمونهٔ کد

rustuse tcod::console::*;
use tcod::colors;

// ساختار اصلی بازی: بازیکن + نقشه + کنسول
struct Game {
    player: Player,
    map: Map,
}

// حلقهٔ اصلی با tcod
fn main() {
    let mut root = Root::initializer()
        .font("arial10x10.png", FontLayout::Tcod)
        .font_type(FontType::Greyscale)
        .size(SCREEN_WIDTH, SCREEN_HEIGHT)
        .title("Roguelike در Rust")
        .init();

    let mut con = Offscreen::new(SCREEN_WIDTH, SCREEN_HEIGHT);
    let mut game = Game::new();

    while !root.window_closed() {
        // رسم نقشه و بازیکن روی con
        game.render(&mut con);

        // کپی از con به root و نمایش
        blit(&con, (0, 0), (SCREEN_WIDTH, SCREEN_HEIGHT), &mut root, (0, 0), 1.0);
        root.flush();

        // ورودی: میدان دید را با هر حرکت به‌روز کن
        let key = root.wait_for_keypress(true);
        game.handle_key(key);
    }
}
