ساخت ربات تلگرام با پایتون

⚙ زبان: Python 📁 دسته: ربات ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمه فارسی مقاله «How to Create a Telegram Bot using Python» (ساخت ربات تلگرام با پایتون) نوشته «اشوتوش کریشنا (Ashutosh Krishna)» در سایت freeCodeCamp است. نسخه کامل و به‌روز را از سایت اصلی بخوانید.

مقدمه

چت‌بات‌های خودکار برای برقراری تعاملات مفید هستند. ما می‌توانیم چت‌بات‌هایی برای اسلک (Slack)، دیسکورد (Discord) و سایر پلتفرم‌ها بسازیم.

در این مقاله، به شما یاد می‌دهم که چگونه یک چت‌بات تلگرام بسازید که طالع‌بینی (horoscope) شما را به شما می‌گوید. پس بیایید شروع کنیم!

چگونه توکن ربات خود را دریافت کنید

برای راه‌اندازی یک ربات جدید، باید با بات‌فادر (BotFather) صحبت کنید. نه، او یک انسان نیست — او هم یک ربات است و او رئیس همهٔ ربات‌های تلگرام است.

  1. در تلگرام دنبال @botfather بگردید.

ربات بات‌فادر در تلگرام

  1. با کلیک روی دکمهٔ Start یک گفت‌وگو با بات‌فادر شروع کنید.

کلیک روی دکمهٔ Start

  1. /newbot را تایپ کنید و برای راه‌اندازی یک ربات جدید از راهنمایی‌ها پیروی کنید. بات‌فادر به شما یک توکن (token) می‌دهد که از آن برای احراز هویت (authenticate) ربات خود و اعطای دسترسی آن به API تلگرام استفاده خواهید کرد.

دریافت توکن دسترسی

توجه: مطمئن شوید توکن را به‌صورت امن نگهداری می‌کنید. هر کسی که به توکن شما دسترسی داشته باشد می‌تواند به‌راحتی ربات شما را دستکاری کند.

چگونه محیط کدنویسی خود را راه‌اندازی کنید

بیایید محیط کدنویسی را راه‌اندازی کنیم. در حالی که کتابخانه‌های مختلفی برای ساخت ربات تلگرام وجود دارد، ما از کتابخانهٔ pyTelegramBotAPI استفاده خواهیم کرد. این کتابخانه یک پیاده‌سازی ساده اما قابل توسعهٔ (extensible) پایتون از API ربات تلگرام با قابلیت‌های همگام (synchronous) و ناهمگام (asynchronous) است.

کتابخانهٔ pyTelegramBotAPI را با استفاده از pip نصب کنید:

shellpip install pyTelegramBotAPI

در مرحلهٔ بعد، ویرایشگر کد موردعلاقهٔ خود را باز کنید و یک فایل .env برای ذخیرهٔ توکن خود به‌صورت زیر بسازید:

shellexport BOT_TOKEN=your-bot-token-here

پس از آن، دستور source .env را اجرا کنید تا متغیرهای محیطی از فایل .env خوانده شوند.

چگونه اولین ربات خود را بسازید

تمام پیاده‌سازی‌های API در یک کلاس واحد به نام TeleBot ذخیره شده‌اند. این کلاس راه‌های زیادی برای گوش دادن به پیام‌های ورودی و همچنین توابعی مانند send_message()، send_document() و موارد دیگر برای ارسال پیام ارائه می‌دهد.

یک فایل جدید bot.py بسازید و کد زیر را در آن قرار دهید:

pyimport os

import telebot

BOT_TOKEN = os.environ.get('BOT_TOKEN')

bot = telebot.TeleBot(BOT_TOKEN)

در کد بالا، از کتابخانهٔ os برای خواندن متغیرهای محیطی ذخیره‌شده در سیستم خود استفاده می‌کنیم.

اگر به یاد داشته باشید، در مرحلهٔ قبل یک متغیر محیطی به نام BOT_TOKEN را export کردیم. مقدار BOT_TOKEN در متغیری به نام BOT_TOKEN خوانده می‌شود. علاوه بر آن، از کلاس TeleBot برای ایجاد یک نمونهٔ (instance) ربات استفاده می‌کنیم و BOT_TOKEN را به آن پاس می‌دهیم.

سپس باید مدیریت‌کننده‌های پیام (message handlers) را ثبت کنیم. این مدیریت‌کننده‌های پیام شامل فیلترهایی هستند که یک پیام باید از آن‌ها عبور کند. اگر پیامی از فیلتر عبور کند، تابع تزئین‌شده (decorated) فراخوانی می‌شود و پیام ورودی به‌عنوان آرگومان به آن داده می‌شود.

بیایید یک مدیریت‌کنندهٔ پیام تعریف کنیم که دستورهای ورودی /start و /hello را مدیریت کند:

py@bot.message_handler(commands=['start', 'hello'])
def send_welcome(message):
    bot.reply_to(message, "Howdy, how are you doing?")

هر نامی برای تابعی که توسط مدیریت‌کنندهٔ پیام تزئین شده است قابل قبول است، اما تابع فقط می‌تواند یک پارامتر داشته باشد (خود پیام).

بیایید مدیریت‌کنندهٔ دیگری اضافه کنیم که همهٔ پیام‌های متنی ورودی را به فرستنده بازتاب (echo) می‌کند:

py@bot.message_handler(func=lambda msg: True)
def echo_all(message):
    bot.reply_to(message, message.text)

کد بالا از یک عبارت lambda برای آزمایش یک پیام استفاده می‌کند. از آنجا که باید همهٔ پیام‌ها را بازتاب کنیم، همیشه True را از تابع lambda برمی‌گردانیم.

اکنون یک ربات ساده دارید که به دستورهای /start و /hello با یک پیام ثابت پاسخ می‌دهد و همهٔ سایر پیام‌های ارسال‌شده را بازتاب می‌کند. موارد زیر را به انتهای فایل خود اضافه کنید تا ربات راه‌اندازی شود:

pybot.infinity_polling()

همین! ما یک ربات تلگرام آماده داریم. بیایید فایل پایتون را اجرا کنیم و به تلگرام برویم تا ربات را آزمایش کنیم.

اگر نتوانستید ربات را پیدا کنید، با نام کاربری آن جست‌وجو کنید. می‌توانید آن را با ارسال دستورهایی مانند /hello و /start و سایر متن‌های تصادفی آزمایش کنید.

آزمایش ربات

نکته: همهٔ مدیریت‌کننده‌های پیام به همان ترتیبی که در فایل منبع اعلام شده‌اند آزمایش می‌شوند.

برای اطلاعات بیشتر دربارهٔ استفاده از کتابخانهٔ pyTelegramBotAPI، می‌توانید به مستندات آن مراجعه کنید.

چگونه ربات طالع‌بینی را کدنویسی کنیم

حالا توجه خود را به ساخت ربات طالع‌بینی معطوف کنیم. ما در ربات از زنجیره‌سازی پیام (message chaining) استفاده خواهیم کرد. ربات ابتدا علامت زودیاک (zodiac sign) شما را می‌پرسد، سپس روز را می‌پرسد و در پایان با طالع‌بینی همان روز خاص پاسخ می‌دهد.

در پس‌زمینه، ربات برای دریافت داده‌های طالع‌بینی با یک API تعامل می‌کند.

ما از API طالع‌بینی استفاده خواهیم کرد که آن را در یک آموزش دیگر ساخته‌ام. اگر می‌خواهید یاد بگیرید چگونه یکی را بسازید، می‌توانید این آموزش را دنبال کنید. قبل از شروع، مطمئن شوید APIها را اینجا بررسی می‌کنید.

نحوهٔ دریافت داده‌های طالع‌بینی

بیایید یک تابع کمکی (utility function) برای دریافت داده‌های طالع‌بینی یک روز خاص ایجاد کنیم:

pyimport requests

def get_daily_horoscope(sign: str, day: str) -> dict:
    """دریافت طالع‌بینی روزانه برای یک علامت زودیاک.
    آرگومان‌های کلیدواژه‌ای:
    sign:str - علامت زودیاک
    day:str - تاریخ با قالب (YYYY-MM-DD) یا TODAY یا TOMORROW یا YESTERDAY
    بازگشت:dict - داده‌های JSON
    """
    url = "https://horoscope-app-api.vercel.app/api/v1/get-horoscope/daily"
    params = {"sign": sign, "day": day}
    response = requests.get(url, params)

    return response.json()

در کد پایتون بالا، تابعی ایجاد کردیم که دو آرگومان رشته‌ای — sign و day — را می‌پذیرد و داده‌های JSON را برمی‌گرداند. ما یک درخواست GET به آدرس URL ارسال می‌کنیم و sign و day را به‌عنوان پارامترهای جست‌وجو (query parameters) پاس می‌دهیم.

اگر تابع را آزمایش کنید، خروجی مشابه زیر دریافت خواهید کرد:

json{
   "data":{
      "date": "Dec 15, 2022",
      "horoscope_data": "Lie low during the day and try not to get caught up in the frivolous verbiage that dominates the waking hours. After sundown, feel free to speak your mind. You may notice that there is a sober tone and restrictive sensation today that leaves you feeling like you will never be able to break free from your current situation. Don't get caught in this negative mindset."
   },
   "status": 200,
   "success": true
}
نکته: می‌توانید در این آموزش دربارهٔ کتابخانهٔ requests در پایتون بیشتر کاوش کنید.

نحوهٔ افزودن یک مدیریت‌کنندهٔ پیام

حالا که تابعی داریم که داده‌های طالع‌بینی را برمی‌گرداند، بیایید در ربات خود یک مدیریت‌کنندهٔ پیام ایجاد کنیم که علامت زودیاک کاربر را می‌پرسد:

py@bot.message_handler(commands=['horoscope'])
def sign_handler(message):
    text = "What's your zodiac sign?\nChoose one: *Aries*, *Taurus*, *Gemini*, *Cancer,* *Leo*, *Virgo*, *Libra*, *Scorpio*, *Sagittarius*, *Capricorn*, *Aquarius*, and *Pisces*."
    sent_msg = bot.send_message(message.chat.id, text, parse_mode="Markdown")
    bot.register_next_step_handler(sent_msg, day_handler)

تابع بالا کمی با توابع دیگری که قبلاً تعریف کردیم متفاوت است. عملکرد طالع‌بینی ربات با دستور /horoscope فراخوانی می‌شود. ما یک پیام متنی به کاربر ارسال می‌کنیم، اما توجه کنید که هنگام ارسال پیام، parse_mode را روی Markdown تنظیم کرده‌ایم.

از آنجا که از زنجیره‌سازی پیام استفاده می‌کنیم، از متد register_next_step_handler() استفاده کردیم. این متد دو پارامتر می‌پذیرد: پیامی که توسط کاربر ارسال شده و تابع بازخوانی (callback function) که باید پس از پیام فراخوانی شود. بنابراین، متغیر sent_msg و یک تابع جدید day_handler که در ادامه تعریف خواهیم کرد را پاس می‌دهیم.

بیایید تابع day_handler() را که پیام را می‌پذیرد تعریف کنیم:

pydef day_handler(message):
    sign = message.text
    text = "What day do you want to know?\nChoose one: *TODAY*, *TOMORROW*, *YESTERDAY*, or a date in format YYYY-MM-DD."
    sent_msg = bot.send_message(
        message.chat.id, text, parse_mode="Markdown")
    bot.register_next_step_handler(
        sent_msg, fetch_horoscope, sign.capitalize())

علامت زودیاک را از ویژگی message.text دریافت می‌کنیم. مشابه تابع قبلی، روزی را نیز می‌پرسد که می‌خواهید طالع‌بینی آن را بدانید.

در پایان، از همان متد register_next_step_handler() استفاده می‌کنیم و sent_msg، تابع بازخوانی fetch_horoscope و sign را پاس می‌دهیم.

حالا بیایید تابع fetch_horoscope() را تعریف کنیم که پیام و علامت را می‌پذیرد:

pydef fetch_horoscope(message, sign):
    day = message.text
    horoscope = get_daily_horoscope(sign, day)
    data = horoscope["data"]
    horoscope_message = f'*Horoscope:* {data["horoscope_data"]}\\n*Sign:* {sign}\\n*Day:* {data["date"]}'
    bot.send_message(message.chat.id, "Here's your horoscope!")
    bot.send_message(message.chat.id, horoscope_message, parse_mode="Markdown")

این تابع پایانی است که در آن علامت را از پارامتر تابع و روز را از ویژگی message.text دریافت می‌کنیم.

سپس با استفاده از تابع get_daily_horoscope() طالع‌بینی را دریافت می‌کنیم و پیام خود را می‌سازیم. در پایان، پیام را با داده‌های طالع‌بینی ارسال می‌کنیم.
