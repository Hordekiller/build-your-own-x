چرا Swift برای مفسر Lisp؟

Lisp یکی از ساده‌ترین زبان‌ها برای ساخت مفسر است (سینتکس آن تقریباً فقط پرانتز و تابع است) و Swift با enumهای تودرتو و closure، ابزار مفیدی برای مدل‌سازی انواع دادهٔ تابعی فراهم می‌کند. این ترکیب، آموزش را هم برای آشنایان به مفسرها و هم برای علاقه‌مندان به Swift جذاب می‌کند.

مفسر ساخته‌شده سه مرحلهٔ کلاسیک دارد: توکن‌کننده، پارسر و ارزیابی‌کننده — و در نهایت یک REPL که می‌توانید در ترمینال با آن کار کنید.

مدل‌سازی LispVal با enum

مهم‌ترین تصمیم معماری، تعریف نوع دادهٔ همهٔ مقادیر Lisp است. با enum Swift این کار بسیار طبیعی انجام می‌شود:

Swift// همهٔ مقادیر زبان: عدد، نام نماد، لیست، تابع
enum LispVal {
    case atom(String)
    case number(Int)
    case string(String)
    case list([LispVal])
    case function(String, ([LispVal]) throws -> LispVal)
}

با این تعریف، یک لیست خودش حاوی LispValهای دیگر است و تابع به‌صورت یک ساختار قابل‌ترکیب مدل می‌شود. همهٔ الگوریتم‌های بعدی (پارسر و evaluator) بر همین پایه بنا می‌شوند.

توکن‌کننده و پارسر

پارسر با خواندن کاراکتر به کاراکتر کار می‌کند و با رسیدن به `(` شروع به ساخت یک لیست می‌کند. به‌طور خاص، بازگشت‌گر برای مدیریت پرانتزهای تودرتو به‌کار می‌رود:

Swiftfunc parseList(_ chars: [Character], _ pos: Int) throws -> (LispVal, Int) {
    var result: [LispVal] = []
    var i = pos
    while i < chars.count {
        let c = chars[i]
        if c == ")" { return (LispVal.list(result), i + 1) }
        if c == "(" {
            let (list, next) = try parseList(chars, i + 1)
            result.append(list)
            i = next
        } else {
            let (v, next) = try parseAtom(chars, i)
            result.append(v)
            i = next
        }
    }
    throw LispError.unexpectedEnd
}

// تبدیل یک علامت به عدد یا نماد
func parseAtom(_ chars: [Character], _ pos: Int) throws -> (LispVal, Int) {
    var s = ""
    var i = pos
    while i < chars.count, !"() ".contains(chars[i]) {
        s.append(chars[i]); i += 1
    }
    if let n = Int(s) { return (LispVal.number(n), i) }
    return (LispVal.atom(s), i)
}

این پارسر ساده، تمام Lisp پایه (اعداد، نمادها و لیست‌های عمیق) را بدون خطا می‌خواند.

ارزیابی و closure

ارزیاب با الگوگرفتن روی LispVal کار می‌کند: اگر `atom` بود، تابع اولیه‌ی تعریف‌شده را اجرا می‌کند؛ اگر `list` بود، عنصر اول را به‌عنوان تابع و بقیه را آرگومان ارزیابی می‌کند. تابع‌ها به‌عنوان closure نگهداری می‌شوند تا بتوانند به متغیرهای محیط‌شان دسترسی داشته باشند.

در پایان، آموزش solutionهای مختلف از جمله تعریف `defun` (توابع با نام)، عملگرهای حسابی و حتی بازگشت (fibonacci) را نشان می‌دهد — همهٔ این‌ها از همان سه ساختمان اصلی ساخته شده‌اند.
