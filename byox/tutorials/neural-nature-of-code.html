۱. دربارهٔ این مجموعه

در طول کتاب و مجموعهٔ ویدیویی Nature of Code، شیفمن پدیده‌های طبیعی را با کد شبیه‌سازی می‌کند؛ فصل دهم به شبکه‌های عصبی می‌رسد: مغز به‌عنوان یک «الگوریتم طبیعی» و شبکه‌های عصبی مصنوعی به‌عنوان الهام‌گرفته از آن. رویکرد او آموزشی و تصویری است: هر مفهوم (نورون، پرسپترون، لایه، آموزش) با اسکچ‌های بصری p5.js نشان داده می‌شود تا «مکانیک» شبکه دیده شود، نه فقط فرمول‌ها. برای بخشی از مطالب، کتاب Make Your Own Neural Network از تریک رشید مرجع شیفمن بوده است.

JavaScript// پرسپترون ساده در p5.js: مجموع وزن‌دار + فعال‌سازی پله‌ای
function guess(inputs) {
  let sum = 0;
  for (let i = 0; i < inputs.length; i++) {
    sum += inputs[i] * this.weights[i];   // جمع وزن‌دار ورودی‌ها
  }
  return sum > 0 ? 1 : -1;                // خروجی پله‌ای
}

۲. مسیر ویدیوها

  • مقدمه: نورون چیست، شبکهٔ عصبی چرا «طبیعی» است، و مروری بر فصل.
  • پرسپترون: ساده‌ترین شبکه — یک نورون با چند ورودی که جمع وزن‌دار را از فعال‌سازی می‌گذراند؛ و محدودیت‌های آن (XOR قابل حل نیست).
  • پرسپترون چندلایه: چیدن پرسپترون‌ها کنار هم و قدرت بیان بیشتر.
  • یادگیری: تنظیم وزن‌ها با خطا، و ایدهٔ backpropagation و گرادیان نزولی به‌صورت شهودی.
  • کاربردها: عامل‌های «هوشمند» که از تجربه یاد می‌گیرند و تعامل پرسپترون‌ها با شبیه‌سازی‌های فصل‌های قبل (مثل حرکت و نیرو).

۳. چرا تماشای این مجموعه مفید است؟

  • شهود پیش از فرمول: می‌بینید که وزن‌ها چطور شکل خروجی را تغییر می‌دهند، قبل از اینکه فرمول‌ها را حفظ کنید.
  • کد کم و زنده: مثال‌ها در مرورگر (p5.js Web Editor) اجرا می‌شوند؛ می‌توانید همان لحظه دستکاری‌شان کنید.
  • پل بین هنر و ML: برای کسانی که می‌خواهند شبکه را در پروژه‌های خلاقانه (حرکت، تعامل، طراحی) به کار بگیرند.
  • پایهٔ قوی برای ادامه: کتابِ کامل‌تر Nature of Code شامل فصل‌های مجزا برای شبکه و «تکامل عصبی» (neuroevolution) است.
نکته: این یک دورهٔ ویدیویی است و محتوای آن اینجا میزبانی نمی‌شود؛ لینک اصلی پلی‌لیست را از دکمهٔ بالا دنبال کنید. همهٔ مثال‌ها با p5.js (جاوااسکریپت) نوشته شده‌اند و کدشان در سایت natureofcode.com و کانال The Coding Train در دسترس است.
کپیرایت: دورهٔ ویدیویی «Neural Networks — The Nature of Code» اثر دنیل شیفمن (Daniel Shiffman) است و در کانال The Coding Train منتشر شده. این صفحه فقط معرفی فارسی آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
