فرمت INI

INI ساده‌ترین فرمت پیکربندی متنی است: بخش‌ها با `[نام]` جدا می‌شوند و زیر هر بخش زوج‌های `کلید=مقدار` می‌آیند. کامنت‌ها با `;` یا `#` شروع می‌شوند. هنوز برای ابزارهای کوچک همه‌جا استفاده می‌شود — از php.ini تا پیکربندی‌های سیستمی:

INI[server]
host = 0.0.0.0
port = 8080

[database]
name = byox
user = admin
; این خط کامنت است
pass = secret123

راه‌اندازی پارسر

پارسر خط‌به‌خط کار می‌کند: خطوط خالی و کامنت را رد می‌کند، `[x]` را به‌عنوان بخش جدید ثبت می‌کند و `کلید=مقدار` را به بخش جاری اضافه می‌کند. حالت جاری «بخش» باید بین خطوط حفظ شود:

Nimimport strutils, tables

type IniFile = Table[string, Table[string, string]]

proc parseIni(content: string): IniFile =
  var
    currentSection = ""         # بخش جاری
    section = initTable[string, string]()

  for line in content.splitLines():
    let trimmed = line.strip()

    # رد کردن خالی و کامنت
    if trimmed.len == 0 or trimmed[0] in {';', '#'}: continue

    if trimmed[0] == '[':       # شروع بخش جدید
      if currentSection != "":
        result[currentSection] = section
      currentSection = trimmed[1..^2]
      section = initTable[string, string]()
    else:                       # کلید=مقدار
      let parts = trimmed.split("=", 1)
      let key = parts[0].strip()
      let value = (if parts.len > 1: parts[1].strip() else: "")
      section[key] = value

  if currentSection != "":
    result[currentSection] = section

توجه: `split("=", 1)` یعنی فقط روی اولین `=` شکسته شود — این برای مقادیری مثل URL که `=` دارند ضروری است.

استفادهٔ پایه

Nimlet config = parseIni(readFile("app.ini"))
echo config["server"]["port"]       # 8080
echo config["database"]["name"]     # byox

# دسترسی امن در نبودِ بخش/کلید:
echo config.getOrDefault("missing", initTable[string, string]())

جداول تو در تو در Nim همان دیکشنری هستند، پس ارسال پارامترِ پیش‌فرض `getOrDefault` باید از نوع `Table[string,string]` باشد؛ این همان ساختاری است که `parseIni` برمی‌گرداند.

گام‌های بعدی

پارسرهای واقعی فراتر از این نسخهٔ پایه می‌روند: پشتیبانی از `:` به‌جای `=`، حذف کوتیشن‌ها از مقدارها، پشتیبانی از مقادیر چندخطی، و نگاشت خودکار به انواع (int، bool). این موارد با همان ساختار خط‌به‌خط فعلی قابل افزودن هستند — هر کدام فقط یک قانون تجزیهٔ دیگر روی خط جاری است.

کپیرایت: احمد منصور (xmonader). این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
