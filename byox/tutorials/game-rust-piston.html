ماجراجویی‌ها در Rust — ساخت یک بازی دو‌بعدی پایه با Piston

⚙ زبان: Rust ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور مقالهٔ «Adventures in Rust — A Basic 2D Game» از آدام هوئین (Adam Huynh) در وبلاگ a5huynh.github.io است — ساخت یک بازی دو‌بعدی الهام‌گرفته از Defender با زبان Rust و کتابخانهٔ Piston.
↗ مشاهده منبع اصلی

۱. دربارهٔ آموزش

این مقاله یکی از اولین «بازی‌سازی با Rust»های معروف است: با Piston (مجموعه‌ای از کرت‌ها برای پنجره، ورودی و رندر) یک بازی سادهٔ دوبعدی (الهام‌گرفته از Defender — هواپیمای افقی شوتر) ساخته می‌شود. تمرکز مقاله روی معماری ماژولار است: جدا کردن حلقهٔ اصلی، رندر و منطق بازی در فایل‌های مختلف (main.rs و lib.rs).

نکته: پیش‌نیاز: آشنایی مقدماتی با Rust (مدیریت پکیج با Cargo) کافی است؛ مفاهیم Piston در طول مقاله توضیح داده می‌شود.

۲. ساختار پروژه

textsrc/
├── main.rs   # نقطهٔ ورود: پنجره، حلقهٔ رویداد
└── lib.rs    # منطق بازی: update و render و موجودیت‌ها
Cargo.toml

در Cargo.toml کرت‌های piston_window و graphics و… به‌عنوان وابستگی افزوده می‌شوند و با یک cargo run بازی بالا می‌آید.

۳. نمونهٔ کد

rust// main.rs — پنجره و حلقهٔ main
extern crate piston_window;
extern crate adventures;

use piston_window::*;
use adventures::render::{Render, draw};
use adventures::update::{Update, update};
use adventures::Player;

fn main() {
    let mut window: PistonWindow =
        WindowSettings::new("ماجراجویی‌ها در Rust", [640, 480])
            .exit_on_esc(true)
            .build()
            .unwrap();

    let mut player = Player::new(&mut window);

    while let Some(event) = window.next() {
        // به‌روزرسانی منطق با رویدادهای ورودی
        update(&mut player, &event);
        // رندر با رویدادهای رسم
        window.draw_2d(&event, |c, g| {
            clear([0.0, 0.0, 0.0, 1.0], g);
            draw(&player, &c, g);
        });
    }
}

منطق بازی در lib.rs به‌صورت ساختارها و traitهای Update/Render جدا می‌شود تا کد تمیز بماند.

۴. جمع‌بندی

  • یک مسیر عملی برای شروع بازی‌سازی با Rust (بدون موتور سنگین).
  • معماری ماژولار: update/render جدا — همان الگویی که موتورها استفاده می‌کنند.
  • مقاله چالش‌های واقعی (مالکیت/borrow checker در بازی) را هم نشان می‌دهد.
