چرا WebAssembly نقطهٔ عالی برای کامپایلر است؟

WebAssembly یک قالب باینری با هدف اجرای سریع در مرورگر است. مزیت آن برای یادگیری کامپایلر این است که خروجی نهایی شما یک فایل `.wasm` قابل‌اجرا در مرورگر خواهد بود — یعنی بلافاصله و بدون واسطه می‌توانید ببینید که کد شما درست کار می‌کند یا نه.

این آموزش با یک زبان مینی سفارشی شروع می‌کند و با سه مرحلهٔ اساسی پیش می‌رود: lexer برای تشخیص توکن، parser برای ساخت درخت نحو و code generator برای تولید بایت‌کد wasm.

ساختار زبان ورودی

زبان مورد نظر سینتکسی شبیه به جاوااسکریپت دارد: اعداد صحیح، متغیرهای محلی، دستور return و تابع main. ساده‌ترین نقطهٔ شروع، تولید یک تابع است که با تعداد مشخصی آرگومان ورودی کار می‌کند و نتیجه را با `return` برمی‌گرداند.

lexer و parser

بخش‌های ابتدایی به‌صورت کلاسیک هستند: توکن‌های `number`، `identifier`، عملگرها و کلیدواژه‌ها. در ادامه، parser با یک تابع recursive descent روی AST می‌سازد:

TypeScript// تجزیهٔ عبارت: عدد، متغیر یا فراخوانی تابع
function parseExpression(): AstNode {
  const token = nextToken();
  if (token.type === "number") {
    return { kind: "number", value: Number(token.value) };
  }
  if (token.type === "identifier") {
    const next = peek();
    if (next.type === "lparen") {          // فراخوانی تابع
      nextToken();
      const args: AstNode[] = [];
      while (peek().type !== "rparen") {
        args.push(parseExpression());
        if (peek().type === "comma") nextToken();
      }
      nextToken();                          // بستن پرانتز
      return { kind: "call", name: token.value, args };
    }
    return { kind: "var", name: token.value };
  }
  throw new Error(`توکن غیرمنتظره: ${token.value}`);
}

این parser ساده، ساختارهای متداخل مثل `main(add(1, 2))` را درست تجزیه می‌کند.

codegen به بایت‌کد wasm

بخش جذاب، ترجمهٔ AST به دستورهای باینری بود: هر گره به یک سری `opcode` و `leb128` تبدیل می‌شود. به‌طور مثال، جمع دو عدد یک دستور `i32.add` و یک تابع، یک type section و function body خواهد داشت:

TypeScript// تولید بایت‌کد برای تابع main
function emitFunction(name: string, params: number[], body: AstNode): Uint8Array {
  const bytes: number[] = [];

  // بخش function type را ثبت می‌کند
  const typeIdx = encodeL128(params.filter(p => p === i32).length);

  // body: بدنهٔ عبارت return
  bytes.push(0x0b);          // end of expression block
  emitExpression(body);      // دستورها به bytes اضافه می‌شوند

  return new Uint8Array(bytes);
}

اینجا دید می‌کنید که بخش‌های محتلف (header، type و code) هرکدام با یک بایت مودیولار ۰x و شناسه ثبت می‌شوند.

اجرا و تست

در پایان، لودر itify به‌کمک `WebAssembly.instantiate`، بایت‌کد را در مرورگر اجرا و نتیجهٔ تابع را چاپ می‌کند. این چرخه — ویرایش، کامپایل، اجرا — بازخورد فوری می‌دهد و یادگیری را واقعاً به‌دست‌یافتنی می‌کند.

جمع‌بندی

این آموزش یک شروع عالی برای ورود به دنیای کامپایلرهای زبان‌های مرورگاهی است. اگر بعد از آن به دنبال پروژهٔ بزرگ‌تری هستید، ساخت یک frontend برای زبانی با تایپ‌ها یا حلقه‌ها منطق بعدی است.
