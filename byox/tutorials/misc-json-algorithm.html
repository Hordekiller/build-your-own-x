الگوریتم رمزگشایی JSON

⚙ زبان: Python ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور «json-algorithm» از چری است که یک رمزگشای JSON را از صفر در پایتون با «الگوریتم» ساده و شفاف می‌سازد.
↗ مشاهده منبع اصلی

JSON چه شکلی است؟

JSON زبانی کوچک با ۸ نوع مقدار: null، true، false، عدد، رشته (با escape مثل `\"` و `\n`)، آرایه `[...]`، شیء `{"k": v}` و ترکیب‌های تو در تو. رمزگشایی یعنی: متن را بخوان و به ساختار دادهٔ زبان مقصد تبدیل کن.

الگوریتم اصلی

ایدهٔ متمرکز این پیاده‌سازی: یک تابع `decoder` که بر حسب نویسهٔ بعدی، فرم مناسب را انتخاب می‌کند — حالت Kind. کل منطق در تابعی تکی و بازگشتی می‌نشیند:

Pythondef decode(json_string):
    """رمزگشای ۸۰ خطی JSON از چری"""
    pos = 0
    n = len(json_string)

    def read_ws():
        nonlocal pos
        while pos < n and json_string[pos] in ' \t\n\r':
            pos += 1

    def read_string():
        nonlocal pos
        pos += 1                       # رد کردن "
        out = []
        while json_string[pos] != '"':
            c = json_string[pos]
            if c == '\\':              # escape
                pos += 1
                esc = json_string[pos]
                out.append({'n': '\n', 't': '\t', '"': '"'}.get(esc, esc))
            else:
                out.append(c)
            pos += 1
        pos += 1                       # رد کردن " پایانی
        return ''.join(out)

    # read_number، read_array و read_object در ادامهٔ همین تابع تعریف می‌شوند

    def read_value():
        nonlocal pos
        read_ws()
        c = json_string[pos]
        if c == '"': return read_string()
        if c == '[': return read_array()
        if c == '{': return read_object()
        if c in '0123456789-': return read_number()
        if json_string.startswith('true', pos): pos += 4; return True
        if json_string.startswith('false', pos): pos += 5; return False
        if json_string.startswith('null', pos): pos += 4; return None
        raise ValueError(f'JSON نامعتبر: {c} در {pos}')

    return read_value()

الگوی «یک نویسه را نگاه کن، ادعای نامعتبری‌بودن را کوتاه کن» (single-dispatch) بهترین راه برای رمزگشایی دستی است: رشته، آرایه و شیء هر کدام تابع خودشان را دارند و بازگشتی به هم می‌پیوندند.

عددها و ساختارها

Python    def read_number():
        nonlocal pos
        start = pos
        while pos < n and json_string[pos] in '0123456789.eE+-':
            pos += 1
        text = json_string[start:pos]       # برش عدد خوانده‌شده
        if '.' in text or 'e' in text or 'E' in text:
            return float(text)              # عدد اعشاری
        return int(text)                    # عدد صحیح

    def read_array():
        nonlocal pos
        pos += 1                        # رد کردن [
        out = []
        read_ws()
        if json_string[pos] == ']':     # آرایهٔ خالی
            pos += 1; return out
        while True:
            out.append(read_value())
            read_ws()
            if json_string[pos] == ',': pos += 1
            elif json_string[pos] == ']':
                pos += 1; return out

همین الگو برای آرایه، برای object هم با دیکشنری تکرار می‌شود. با این ۸۰ خط، خودتان JSON.parse را دارید — همانی که مرورگرها هر روز صدها بار اجرا می‌کنند.

جمع‌بندی

بعد از این‌کار، رمزگشای هر فرمت دیگری (YAML، TOML، XML) فقط یک حالت اضافه و چند قانون escape است. درک چنین الگوریتم کوچکی، پایه‌ای است برای شناختن «چرا فرمت‌ها این‌طور طراحی می‌شوند».
