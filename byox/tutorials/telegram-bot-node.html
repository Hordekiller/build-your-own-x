ساخت (و استقرار) یک ربات تلگرام تعاملی در Node.js

⚙ زبان: Node.js 📁 دسته: ربات ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمه فارسی مقاله «Making (and deploying) an Interactive Telegram Bot in Node.js» نوشته «سوهام کامانی (Soham Kamani)» است. نسخه کامل و به‌روز را از سایت اصلی بخوانید.
↗ مشاهده منبع اصلی

مقدمه

خلاصه: این آموزش شما را با گام‌های ساده و سرراست، از صفر تا راه‌اندازی یک ربات تلگرام (Telegram Bot) پاسخگو پیش می‌برد.

من زمان قابل توجهی صرف کردم تا بفهمم چطور می‌شود یک ربات تلگرام کاربردی ساخت. مسلماً معرفی رسمی تلگرام خوب است؛ اما چیزهای زیادی دربارهٔ اینکه ربات‌ها چیستند و چند دستورالعمل پراکنده‌وار دربارهٔ API می‌گوید، بدون اینکه ساختار کافی برای یک مبتدی فراهم کند تا سریع راه بیفتد.

بنابراین، این‌جا روش ساخت یک ربات تلگرام پاسخگو در Node.js را با کمترین دردسر می‌بینید.

نکته: اگر می‌خواهید ساخت ربات تلگرام با زبان Go را یاد بگیرید، می‌توانید پست دیگر من را بخوانید.

ربات خود را بسازید

برای این مرحله نیازی به نوشتن هیچ کدی نیست؛ در واقع حتی به کامپیوتر هم نیاز ندارید! به اپلیکیشن تلگرام روی گوشی‌تان بروید و…

  1. ربات تلگرامی «botfather» را جست‌وجو کنید (همان‌که در ایجاد و مدیریت ربات شما را یاری می‌کند).
  2. /help را تایپ کنید تا همهٔ فرمان‌هایی را که botfather می‌تواند انجام دهد ببینید.
  3. روی /newbot کلیک کنید یا آن را تایپ کنید تا یک ربات جدید بسازید.

    دستورالعمل‌ها را دنبال کنید و یک نام جدید برای ربات خود بگذارید. اگر ربات را فقط برای آزمایش می‌سازید، بهتر است در نام کاربری (username) آن، نام خودتان را هم بیاورید؛ چون نام کاربری باید یکتا باشد. البته نام نمایشی (screen name) آن می‌تواند هرچه دوست دارید باشد. من «Marco Polo Bot» را به‌عنوان نام نمایشی و «my_marco_polo_bot» را به‌عنوان نام کاربری انتخاب کرده‌ام.
  4. تبریک! اولین ربات خود را ساخته‌اید. باید یک توکن API (API token) جدید برای آن تولید شده باشد (برای نمونه، در تصویر قبلی می‌توانید توکن تازه‌تولیدشدهٔ من را ببینید: 777845702:AAFdPS_taJ3pTecEFv2jXkmbQfeOqVZGER). حالا می‌توانید ربات تازه‌ساختهٔ خود را در تلگرام جست‌وجو کنید:
  5. بروید و شروع به گفت‌وگو با ربات خود کنید!

    خب، کاملاً ناامیدکننده است! ربات ما ظاهراً احمق است؛ به این معنا که نمی‌تواند واقعاً پاسخ بدهد یا چیزی برگرداند. بیایید با ساختن یک سرور ربات که در پس‌زمینه (back end) اجرا می‌شود، این مشکل را حل کنیم.

سرور ربات خود را راه‌اندازی کنید

هر بار که به یک ربات پیام می‌دهید، پیام شما در قالب یک فراخوانی API (API call) به یک سرور ارسال می‌شود. این سرور همان چیزی است که همهٔ پیام‌های ارسالی شما به ربات را پردازش و به آن‌ها پاسخ می‌دهد.

برای دریافت به‌روزرسانی‌ها (updates) هر زمان که کسی به ربات ما پیام می‌فرستد، دو راه در پیش داریم:

  1. پولینگ طولانی (Long polling): به‌صورت دوره‌ای برای یافتن پیام‌های احتمالی جست‌وجو می‌کند. توصیه نمی‌شود.
  2. وبهوک (Webhook): هر بار که ربات پیامی دریافت می‌کند، API صدا زده می‌شود. بسیار سریع‌تر و پاسخگوتر.

در این آموزش از وبهوک استفاده می‌کنیم. هر وبهوک با یک شیء به‌روزرسانی (update object) صدا زده می‌شود. برویم سرورمان را برای مدیریت این به‌روزرسانی بسازیم.

سرور خود را با نود.جی‌اس (Node.js) می‌سازیم؛ اما می‌توانید از هر آنچه برای ساخت سرور مناسب شماست استفاده کنید. پس از نصب node و npm:

ابتدا پروژه خود را راه‌اندازی (initialize) کنید:

shell## ساخت یک پوشه جدید و ورود به آن
mkdir my-telegram-bot
cd my-telegram-bot

## راه‌اندازی پروژه npm
npm init

پس از دنبال کردن دستورالعمل‌ها، به یک فایل package.json خواهید رسید.

سپس با اجرای دستور زیر، وابستگی‌های خود را نصب کنید:

shellnpm install --save express axios body-parser
  • express سرور اپلیکیشن ماست
  • axios یک کلاینت HTTP است
  • body-parser به ما کمک می‌کند بدنهٔ پاسخ (response body) دریافت‌شده از هر درخواست را تجزیه کنیم

یک فایل جدید به نام index.js بسازید:

jsvar express = require("express")
var app = express()
var bodyParser = require("body-parser")
const axios = require("axios")

app.use(bodyParser.json()) // برای تجزیه application/json
app.use(
	bodyParser.urlencoded({
		extended: true,
	})
) // برای تجزیه application/x-www-form-urlencoded

//این مسیری است که API صدا خواهد زد
app.post("/new-message", function(req, res) {
	const { message } = req.body

	//هر پیام شامل "text" و یک شیء "chat" است که "id" آن، شناسه چت است

	if (!message || message.text.toLowerCase().indexOf("marco") < 0) {
		// اگر پیامی وجود نداشته باشد، یا پیام ما کلمه marco را نداشته باشد،
		// هیچ کاری نکن و یک پاسخ خالی برگردان
		return res.end()
	}

	// اگر به اینجا رسیده باشیم، یعنی پیامی حاوی کلمه "marco" دریافت کرده‌ایم.
	// با صدا زدن API ربات تلگرام و پاسخ دادن به chat_id مناسب با کلمه "Polo!!" پاسخ بده
	// به یاد داشته باشید به جای توکن زیر، از توکن API خودتان استفاده کنید
	// "https://api.telegram.org/bot<your_api_token>/sendMessage"
	axios
		.post(
			"https://api.telegram.org/bot777845702:AAFdPS_taJ3pTecEFv2jXkmbQfeOqVZGER/sendMessage",
			{
				chat_id: message.chat.id,
				text: "Polo!!",
			}
		)
		.then((response) => {
			// اگر پیام با موفقیت ارسال شد به اینجا می‌رسیم
			console.log("Message posted")
			res.end("ok")
		})
		.catch((err) => {
			// ...و اگر ارسال نشد به اینجا
			console.log("Error :", err)
			res.end("Error :" + err)
		})
})

// در نهایت، سرور خود را راه‌اندازی می‌کنیم
app.listen(3000, function() {
	console.log("Telegram app listening on port 3000!")
})

می‌توانید این سرور را روی ماشین محلی خود با اجرای node index.js اجرا کنید.

اگر همه‌چیز خوب پیش برود، باید پیام «Telegram app listening on port 3000!» را روی کنسول خود ببینید.

اما این کافی نیست. اگر ربات روی ماشین محلی شما اجرا شود، نمی‌تواند API را صدا بزند؛ به یک نام دامنهٔ عمومی (public domain name) نیاز دارد. یعنی باید اپلیکیشن خود را استقرار (deploy) دهیم.

سرویس خود را مستقر کنید

می‌توانید سرور خود را به هر شکلی که می‌خواهید مستقر کنید؛ اما به‌نظر من استفاده از سرویسی به نام now بسیار سریع و آسان است.

now را روی سیستم خود نصب کنید:

shellnpm install -g now

یک اسکریپت شروع (start script) به فایل package.json خود اضافه کنید.

فایل package.json اصلی من این‌گونه است:

json{
  "name": "telegram-bot",
  "version": "1.0.0",
  "description": "",
  "main": "index.js",
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1"
  },
  "author": "Soham Kamani <soham@sohamkamani.com> (http://sohamkamani.com)",
  "license": "ISC"
}

یک اسکریپت شروع اضافه کنید تا به این شکل درآید:

json{
  "name": "telegram-bot",
  "version": "1.0.0",
  "description": "",
  "main": "index.js",
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1",
    "start" : "node index.js"
  },
  "author": "Soham Kamani <soham@sohamkamani.com> (http://sohamkamani.com)",
  "license": "ISC"
}

پس از افزودن اسکریپت، دستور زیر را اجرا کنید:

shellnow

(به یاد داشته باشید آن را در ریشهٔ پوشهٔ پروژه، یعنی جایی که فایل package.json قرار دارد، اجرا کنید.)

اگر اولین بار است که از «now» استفاده می‌کنید، چند دستورالعمل برای ورود به حساب (signing in) خواهید دید؛ اما پس از آن باید چیزی شبیه این ببینید:

عالی! یعنی سرور شما روی https://my-telegram-bot-tanvxponxj.now.sh مستقر شده است (یا هر لینکی که شما می‌بینید) و API شما روی https://my-telegram-bot-tanvxponxj.now.sh/new-message در دسترس خواهد بود (همان‌طور که در index.js تعریف شد).

حالا فقط باید به تلگرام اطلاع دهیم که ربات ما هر وقت پیامی دریافت کرد، باید با این آدرس صحبت کند. این کار را از طریق API تلگرام انجام می‌دهیم. این را در ترمینال خود وارد کنید:

shellcurl -F "url=https://my-telegram-bot-tanvxponxj.now.sh/new-message"  https://api.telegram.org/bot<your_api_token>/setWebhook

…و تقریباً کار تمام است! با ربات تازه‌ساختهٔ خود گفت‌وگو کنید و ببینید چه اتفاقی می‌افتد!
