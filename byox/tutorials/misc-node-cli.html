یک CLI واقعی چه شکلی است؟

یک ابزار خط فرمان حرفه‌ای: آرگومان‌ها و فلگ‌ها را می‌فهمد، خروجی رنگی و مرتب دارد، با کاربر گفت‌وگو می‌کند (مثل درخواست تایید)، سوال‌های تعاملی دارد و در npm قابل نصب است. نمونهٔ این آموزش: ابزاری که آمار گیت شما را چاپ می‌کند.

اسکلت پروژه

در `package.json` باید `bin` را تعریف کنید تا npm یک دستور بی‌واسطه از اسکریپت شما بسازد. و در ابتدای فایل، مسیر shebang برای اجرای مستقیم لازم است:

JSON{
  "name": "git-stats-cli",
  "bin": {
    "git-stats": "./index.js"
  },
  "dependencies": {
    "chalk": "^2.0.0",
    "inquirer": "^5.0.0",
    "simple-git": "^1.0.0"
  }
}
JavaScript#!/usr/bin/env node
'use strict';
const chalk = require('chalk');
const inquirer = require('inquirer');

async function run() {
  const { repo } = await inquirer.prompt([{
    type: 'input',
    name: 'repo',
    message: 'پوشهٔ پروژه؟',
    default: '.'
  }]);

  const stats = await analyzeGit(repo);
  console.log(chalk.green.bold('کامیت‌ها:'), stats.total);
  console.log(chalk.cyan('نویسندهٔ فعال:'), stats.topAuthor);
}

`chalk` رنگ را مدیریت می‌کند و `inquirer` سوال‌های تعاملی را — دو ستون اصلی هر CLI مدرن.

پردازش آرگومان‌ها

کلاینت‌های واقعی فلگ می‌پذیرند (مثل `--json` یا `-r`). ساده‌ترین روش بدون کتابخانهٔ جدا: خواندن `process.argv` و جست‌وجوی الگوهای شناخته‌شده:

JavaScriptfunction parseFlags(argv) {
  const flags = { json: false, repo: '.' };
  for (let i = 2; i < argv.length; i++) {
    switch (argv[i]) {
      case '--json': flags.json = true; break;
      case '-r':
      case '--repo': flags.repo = argv[++i]; break;
      case '--help':
        console.log('استفاده: git-stats [-r repo] [--json]');
        process.exit(0);
    }
  }
  return flags;
}

برای CLIهای بزرگ‌تر کتابخانه‌هایی مثل commander یا yargs وجود دارند، ولی فهمیدن این حلقهٔ دستی به شما می‌فهماند که آن‌ها چه می‌کنند.

انتشار در npm

با اضافه‌کردن `"bin"`، کافی است `npm publish` بزنید تا ابزار شما روی هر سیستم با `npx git-stats` یا `npm i -g` در دسترس باشد. تجربهٔ ساخت و انتشار یک ابزار، خودش نصف آموزش برنامه‌نویسی دیگه‌ست.
