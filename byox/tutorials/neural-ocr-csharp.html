تشخیص نوری حروف (OCR) با شبکه عصبی در سی‌شارپ

⚙ زبان: C# 🧠 AForge.NET ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور مقالهٔ «Neural Network OCR» از اندرو کیریلوف (Andrew Kirillov) در CodeProject است که با استفاده از شبکهٔ عصبی انتشار بازگشتی (backpropagation)، حروف دست‌نویس و چاپی را تشخیص می‌دهد.
↗ مشاهده منبع اصلی

۱. مقدمه: چرا شبکه عصبی برای OCR؟

تشخیص نوری حروف (OCR) یعنی تبدیل تصویر متن به متن قابل ویرایش. روش کلاسیک مقایسهٔ الگو (template matching) در برابر تغییرات فونت، اندازه و چرخش حروف شکننده است. مقالهٔ کیریلوف به‌جای آن از یک شبکهٔ عصبی چندلایه با یادگیری انتشار بازگشتی (backpropagation) استفاده می‌کند: شبکه روی نمونه‌های حروف آموزش می‌بیند و سپس حروف نادیده را تشخیص می‌دهد. پیاده‌سازی در C# و با کتابخانهٔ متن‌باز AForge.NET انجام شده و برای آموزش/اجرا نیازی به هیچ کتابخانهٔ خارجی ندارد.

۲. معماری شبکه: ورودی، لایه پنهان و خروجی

ایدهٔ اصلی: هر تصویر حرف به یک بردار عددی تبدیل می‌شود و شبکه باید آن بردار را به یکی از حروف الفبا نگاشت کند. برای یک حرف با تصویر بزرگ‌نمایی‌شدهٔ ۱۲×۱۲ پیکسل، ورودی ۱۴۴ نورون دارد. خروجی شبکه نیز به‌اندازهٔ تعداد حروف الفباست؛ هر نورون خروجی نمایندهٔ یک حرف است و پیش‌بینی شبکه، نوری‌نی است که بیشترین مقدار را دارد.

csharp// تعریف یک شبکهٔ عصبی: ورودی ۱۴۴ نورون، لایهٔ پنهان ۵۰ نورون، خروجی برابر تعداد حروف
NeuralNetwork network = new ActivationNetwork(
    new SigmoidFunction(2),     // تابع فعال‌سازی سیگموئید
    144,                        // تعداد نورون‌های ورودی (پیکسل‌های تصویر)
    50,                         // لایهٔ پنهان
    alphabetSize);              // لایهٔ خروجی (تعداد حروف)

انتخاب تعداد نورون‌های لایهٔ پنهان یک تنظیم تجربی است: خیلی کم = ناتوانی در یادگیری الگوهای پیچیده، خیلی زیاد = خطر بیش‌برازش (overfitting) و آموزش کندتر.

۳. ساخت نمونه‌های آموزشی

قلب آموزش، داده است. کیریلوف دو منبع نمونه دارد: حروف دست‌نویس (کاربر با ماوس در یک ناحیهٔ ۴۸×۴۸ رسم می‌کند) و حروف چاپی که از فونت‌های ویندوز با GDI+ رندر می‌شوند: Arial، Courier New، Tahoma، Times New Roman و Verdana. هر حرف با چندین اندازه و حالت (ضخیم/کج) رندر می‌شود تا شبکه تنوع را بیاموزد.

csharp// رندر یک حرف چاپی از فونت و تبدیل آن به بردار ورودی شبکه
Bitmap bitmap = DrawChar(letter, font, size);
double[] input = ImageToVector(bitmap);   // سطح خاکستری هر پیکسل، نرمال‌شده بین ۰ و ۱
double[] output = new double[alphabetSize]; // بردار خروجی «یک-داغ»
output[letterIndex] = 1;
نکته: برای حروف دست‌نویس، تصویر ابتدا به‌شکل گرید شبکه‌ای (۱۲×۱۲) زیرنمونه‌گیری می‌شود؛ این هم ابعاد ورودی را کوچک می‌کند و هم تا حدی نسبت به جابه‌جایی جزئی حساسیت‌زدایی می‌کند.

۴. آموزش با انتشار بازگشتی

آموزش با الگوریتم backpropagation انجام می‌شود: شبکه خروجی را پیش‌بینی می‌کند، خطای پیش‌بینی محاسبه می‌شود و این خطا از لایهٔ خروجی به‌سوی لایه‌های قبلی «پخش» می‌شود تا وزن‌ها در جهت کاهش خطا اصلاح شوند. در AForge این کار با کلاس BackPropagationLearning انجام می‌شود:

csharp// ساخت یادگیرندهٔ انتشار بازگشتی روی شبکه
BackPropagationLearning teacher = new BackPropagationLearning(network);
teacher.LearningRate = 0.1;   // نرخ یادگیری
teacher.Momentum = 0.9;       // مومنتوم برای فرار از نوسان‌ها

// حلقهٔ آموزش: ارائهٔ همهٔ نمونه‌ها، ده‌ها بار تکرار (epoch)
for (int epoch = 0; epoch < 100; epoch++)
{
    for (int sample = 0; sample < samples.Length; sample++)
    {
        teacher.Run(samples[sample].Input, samples[sample].Output);
    }
}

نرخ یادگیری و مومنتوم پارامترهای حیاتی‌اند: نرخ یادگیری بالا، آموزش را سریع اما ناپایدار می‌کند؛ مومنتوم به وزن‌ها «اینرسی» می‌دهد تا از کمینه‌های محلی گذر کنند.

۵. تشخیص (recognition)

بعد از آموزش، برای هر تصویر ورودی شبکه یک بردار خروجی می‌دهد؛ حرف پیش‌بینی‌شده شاخص بزرگ‌ترین مقدار بردار است. نکتهٔ مهم مقاله: می‌توان کیفیت پیش‌بینی را با اختلاف بین دو خروجی بزرگ سنجید — اگر شبکه بین دو حرف مردد باشد، بهتر است به‌جای اشتباه، «ناشناخته» اعلام کند.

csharp// اجرای شبکه روی یک تصویر و یافتن حرف برنده
network.Compute(ImageToVector(bitmap));

int best = 0, second = 1;
if (network.Output[1] > network.Output[0]) { best = 1; second = 0; }
for (int i = 2; i < network.Output.Length; i++)
{
    if (network.Output[i] > network.Output[best])
    {
        second = best;
        best = i;
    }
    else if (network.Output[i] > network.Output[second])
    {
        second = i;
    }
}

double diff = network.Output[best] - network.Output[second];
char recognized = (diff > Threshold) ? (char)('A' + best) : '?';

۶. نتایج و محدودیت‌ها

  • حروف چاپی با چند فونت به‌خوبی تشخیص داده می‌شوند، اما هرچه فونت تزئینی‌تر باشد، شبکه به نمونه‌های آموزشی بیشتری نیاز دارد.
  • دست‌نویس سخت‌تر است؛ تنوع دست هر شخص بزرگ است، پس نمونهٔ دست‌نویس بیشتر یعنی دقت بیشتر.
  • شبکه به هم‌اندازه‌سازی ورودی حساس است؛ تصاویر باید پیش از ورود استاندارد شوند.
  • با همان ایده می‌توان به‌جای حروف، ارقام، نمادها یا هر کلاس تصویری دیگری یاد گرفت.
