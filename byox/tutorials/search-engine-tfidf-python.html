یافتن کلمات مهم در متن با TF-IDF

⚙ زبان: Python ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی مقالهٔ «Finding Important Words in Text Using TF-IDF» اثر استیون لوریا (Steven Loria) در وبلاگ شخصی او (منتشرشده: ۲۰۱۵) است. نسخه کامل و به‌روز را از سایت اصلی بخوانید.
↗ مشاهده منبع اصلی

۱. چرا TF-IDF؟

وقتی متنی دارید و می‌خواهید بفهمید «این متن دربارهٔ چیست»، شمارشِ سادهٔ کلمات کافی نیست: واژه‌های پرتکرار مثل «the» و «and» در صدر قرار می‌گیرند ولی هیچ اطلاعاتی نمی‌دهند. TF-IDF (فراوانی واژه در سند × عکس فراوانی سند) راهی است برای سنجشِ «مهم‌بودن» یک واژه در سند نسبت به مجموعه‌ای از اسناد: واژه‌ای که در یک سند زیاد می‌آید اما در بقیهٔ اسناد کم‌یاب است، نشانهٔ موضوعِ همان سند است. استیون لوریا در این آموزش پست کوتاه، این معیار را در ~۱۴ خط پایتون پیاده می‌کند و روی چند مثال واقعی نشانش می‌دهد.

۲. تعریف‌ها: tf و idf

  • TF (Term Frequency): تعداد دفعاتی که واژه در سند آمده. گاهی نرمال می‌شود اما در این پیاده‌سازی ساده، همان تعدادِ خام است.
  • IDF (Inverse Document Frequency): معکوسِ «چند درصدِ کل اسناد این واژه را دارند». لگاریتمِ معکوسِ نسبتِ اسنادِ دارای واژه به کل اسناد؛ واژه‌ای که در همهٔ اسناد هست → idf≈0، واژه‌ای که کمیاب است → idf بزرگ.
  • TF-IDF: حاصل‌ضرب این دو — عددی که هم تکرارِ واژه در سند و هم کمیابیِ آن در مجموعهٔ اسناد را در خود دارد.
pythonfrom math import log
from collections import Counter

def tf(word, doc):
    """فراوانی واژه در سند = تعدادِ دفعاتِ حضور تقسیم بر تعداد کل واژه‌ها"""
    counts = Counter(doc.split())
    return counts[word] / len(doc.split())

def idf(word, docs):
    """عکسِ فراوانی سند: لگاریتمِ (کل اسناد / اسنادِ دارای واژه) — ساده و بدون smoothing"""
    n_docs_with = sum(1 for d in docs if word in d.split())
    if n_docs_with == 0:
        return 0.0
    return log(len(docs) / n_docs_with)

def tfidf(word, doc, docs):
    """امتیاز نهایی: تکرار در سند × کمیابی در کل مجموعه"""
    return tf(word, doc) * idf(word, docs)

تابع idf در مقاله یک پارامتر اختیاری default دارد (عدد اولیهٔ log که می‌توانید به دلخواه تنظیم کنید) تا وقتی واژه‌ای در هیچ سندی نیست، رفتار مشخصی داشته باشد.

۳. پیاده‌سازی کامل و مثال

مقاله با TextBlob 0.6.1 (کتابخانهٔ پردازش متن پایتون) یک مجموعهٔ دمو می‌سازد: چند سند کوتاه که هرکدام موضوعی دارند (مثلاً یکی دربارهٔ بیت‌کوین، یکی دربارهٔ شیمی/کتابی‌خوانی و…) و بعد امتیاز TF-IDFِ همهٔ واژه‌ها را حساب و مرتب می‌کند تا «کلمات مهمِ» هر سند مشخص شود. کد کامل به‌صورت گام‌به‌گام:

pythonimport math
import numpy as np
from textblob import TextBlob
from collections import Counter

# ۱) ساخت مجموعه‌ای از اسناد متنی (متن‌های آموزشی برای هر موضوع)
doc1 = "The bitcoin blockchain is a distributed ledger that records every transaction..."
doc2 = "Chemistry is the scientific study of the properties and behavior of matter..."
doc3 = "Reading books helps you learn new things and improves your vocabulary..."
docs = [doc1, doc2, doc3]

# ۲) از طریق TextBlob به کلمات نرمال‌شده (stem/لمسی‌نشده) برسیم
def get_tokens(doc):
    blob = TextBlob(doc)
    return [token.singularize().lower() for token in blob.words]

tokenized = [get_tokens(d) for d in docs]

# ۳) TF-IDF هر واژه برای هر سند
def tf_idf(word, doc_index):
    tokens = tokenized[doc_index]
    tf = tokens.count(word) / float(len(tokens))
    n_docs_with = sum(1 for t in tokenized if word in t)
    idf = math.log(len(docs) / float(n_docs_with))
    return tf * idf

# ۴) کلمات مهمِ هر سند: امتیازدهی و مرتب‌سازی نزولی
for i, tokens in enumerate(tokenized):
    uniques = Counter(tokens)
    ranked = sorted(uniques, key=lambda w: tf_idf(w, i), reverse=True)
    print("مهم‌ترین کلمات سند", i + 1, ":", ranked[:5])
منظور از کد بالا: نکتهٔ آموزشی، صرفاً محاسبهٔ ریاضی نیست؛ ترکیب است: نرمال‌سازی واژه‌ها با TextBlob (مفردسازی و کوچک‌کردن)، شمارش، محاسبهٔ tf و idf، و در نهایت «مرتب‌سازی واژه‌های هر سند بر اساس امتیاز TF-IDF» برای یافتن نماینده‌های موضوع. خروجیِ مثال مقاله دقیقاً نشان می‌دهد که کلمات «بلاکچین»، «شیمی» و «کتاب» در سند خودشان بالاترین امتیاز را می‌گیرند.

۴. چرا این مهم است؟

  • استخراج موضوع/کلمات کلیدی: سریع‌ترین راهِ فهمیدنِ «یک دسته متن دربارهٔ چیست» بدون خواندن کامل.
  • زیربنای جست‌وجو: TF-IDF قلبِ بسیاری از موتورهای جست‌وجوی کلاسیک است (در آموزش‌های «فضای برداری» و «جست‌وجو با Redis» همین مجموعه هم دیده‌اید).
  • وزن‌دهی در متن‌کاوی: قبل از الگوریتم‌های پیچیدهٔ ML، تبدیل سند به بردارِ TF-IDF اغلب کافی و مؤثر است.

۵. جمع‌بندی

در کمتر از بیست خط کد یاد گرفتید متنی را به «امتیاز اهمیتِ واژه‌ها» تبدیل کنید — ابزاری که در جست‌وجو، خلاصه‌سازی و طبقه‌بندی متن کاربرد دارد. قدم بعدی پیشنهادی: ترکیب همین امتیازها با «فضای برداری» و «بازخورد کاربر» برای ساختن موتور جست‌وجوی واقعی.
