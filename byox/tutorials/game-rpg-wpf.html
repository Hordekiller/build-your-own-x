۱. دربارهٔ دوره

این سری آموزشی یک بازی کامل RPG با رابط گرافیکی می‌سازد: حرکت در دنیای دوعددی، نبرد نوبتی، آیتم‌ها، کوئست‌ها و اتاق‌های تجارت. تفاوت این دوره با «RPG ساده»: رابط کاربری واقعی با WPF/XAML دارد و معماری بهتری (لایه‌بندی و قواعد طراحی) معرفی می‌کند. برای ورود به دوره، پیش‌نیاز مبانی C# (از دورهٔ قبلی) است.

نکته: از درس «۰۳٫۱ ساخت Solution» و «۰۴٫۲ ساخت کلاس World با ایجاد اشیای Location» به بعد، ساختار پروژه به‌صورت کامل توضیح داده می‌شود.

۲. ساختار معماری

دوره یک معماری لایه‌ای را معرفی می‌کند که در آن، دنیای بازی کاملاً مستقل از رابط کاربری است:

textSimpleRPG/                  # Solution
├── SimpleRPG/               # پروژهٔ اصلی WPF
│   ├── MainWindow.xaml      # رابط کاربری
│   └── ViewModels/          # لایهٔ اتصال داده به UI
├── SimpleRPG.Engine/        # موتور بازی (بدون وابستگی به UI)
│   ├── World.cs             # مکان‌ها و ارتباطات
│   ├── GameItems.cs         # آیتم‌ها
│   ├── Quest.cs             # کوئست‌ها
│   └── Monster.cs           # هیولاها
└── SimpleRPG.Core/          # کتابخانهٔ مشترک (گزینه‌ها، الوار)

۳. نمونهٔ کد: کلاس World و Location

csharp// کلاس Location — یک مکان روی نقشهٔ بازی
public class Location
{
    public int X { get; set; }
    public int Y { get; set; }
    public string Name { get; set; }
    public string Description { get; set; }

    public Location North { get; set; }
    public Location East  { get; set; }
    public Location South { get; set; }
    public Location West  { get; set; }

    // اشیای موجود در این مکان
    public Item ItemAvailableHere { get; set; }
    public Quest QuestAvailableHere { get; set; }
    public Monster MonsterLivingHere { get; set; }
}

// World: فهرست مکان‌ها و ساخت نقشه
public static class World
{
    public static readonly List<Location> Locations = new List<Location>();

    // سازندهٔ استاتیک: تعریف مکان‌ها و اتصال آن‌ها
    static World()
    {
        Location home = new Location { X = 0, Y = -1, Name = "خانه", ... };
        Location farm = new Location { X = 0, Y = 0, Name = "مزرعه قدیمی", ... };
        farm.North = home;
        home.South = farm;
        Locations.Add(home);
        Locations.Add(farm);
        // ...
    }

    public static Location LocationAt(int x, int y)
        => Locations.FirstOrDefault(l => l.X == x && l.Y == y);
}
