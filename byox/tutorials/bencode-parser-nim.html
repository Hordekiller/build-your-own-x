نوشتن یک Bencode Parser

چه چیزی انتظار دارید؟

nim-bencode کتابخانه‌ای برای رمزگذاری (encode) و رمزگشایی (decode) فایل‌های تورنت با قالب Bencode است.

در این آموزش یک انکودر و یک دیکودر کامل برای قالب بنکد می‌سازیم. ابتدا یک نمونه استفاده از این کتابخانه را ببینید:

nimimport bencode, tables, strformat

let encoder = newEncoder()
let decoder = newDecoder()

let btListSample1 = @[BencodeType(kind:btInt, i:1), BencodeType(kind:btString, s:"hi") ]
var btDictSample1 = initOrderedTable[BencodeType, BencodeType]()
btDictSample1[BencodeType(kind:btString, s:"name")] = BencodeType(kind:btString, s:"dmdm")
btDictSample1[BencodeType(kind:btString, s:"lang")] = BencodeType(kind:btString, s:"nim")
btDictSample1[BencodeType(kind:btString, s:"age")] = BencodeType(kind:btInt, i:50)
btDictSample1[BencodeType(kind:btString, s:"alist")] = BencodeType(kind:btList, l:btListSample1)

var testObjects = initOrderedTable[BencodeType, string]()
testObjects[BencodeType(kind: btString, s:"hello")] = "5:hello"
testObjects[BencodeType(kind: btString, s:"yes")] = "3:yes"
testObjects[BencodeType(kind: btInt, i:55)] = "i55e"

testObjects[BencodeType(kind: btInt, i:12345)] = "i12345e"
testObjects[BencodeType(kind: btList, l:btListSample1)] = "li1e2:hie"
testObjects[BencodeType(kind:btDict, d:btDictSample1)] = "d4:name4:dmdm4:lang3:nim3:agei50e5:alistli1e2:hiee"


for k, v in testObjects.pairs():
    echo $k & " => " & $v
    doAssert(encoder.encodeObject(k) == v)
    doAssert(decoder.decodeObject(v) == k)

در این کد، تعدادی شیء بنکد (لیست، دیکشنری، عدد و رشته) ساخته می‌شود و سپس با doAssert بررسی می‌شود که خروجی انکودر دقیقاً با رشته‌های بنکدِ انتظاری (مثل i55e یا li1e2:hie) برابر است و دیکودر هم همان شیء اصلی را بازسازی می‌کند.

پیاده‌سازی

طبق قالب بنکد، این نوع داده‌ها را داریم:

  • رشته‌ها — با طول رشته، سپس یک دونقطه و سپس خود رشته رمزگذاری می‌شوند: length:string؛ مثلاً yes به صورت 3:yes رمزگذاری می‌شود.
  • اعداد صحیح — بین حروف i و e رمزگذاری می‌شوند؛ مثلاً 59 به صورت i59e.
  • لیست‌ها — می‌توانند هر کدام از انواع بنکد را داشته باشند و با حروف l و e رمزگذاری می‌شوند؛ مثلاً لیست اعداد 1 و 2 به صورت li1ei2e یا برای خوانایی بیشتر با فاصله: l i1e i2e e.
  • دیکشنری‌ها — نگاشت‌هایی از رشته به هر نوع هستند و بین حروف d و e رمزگذاری می‌شوند؛ مثلاً name => hi و num => 3 به صورت d4:name2:hi3:numi3ee یا با فاصله: d 4:name 2:hi 3:num i3e e رمزگذاری می‌شوند.

ایمپورت‌ها

nimimport strformat, tables, json, strutils, hashes

چون قرار است زیاد با رشته‌ها و جدول‌ها (جدول‌های مرتب) سر و کار داشته باشیم، این ماژول‌ها را ایمپورت می‌کنیم.

انواع (Types)

همان‌طور که درباره انواع داده بنکد گفتیم، می‌توانیم یک enum برای نمایش این انواع تعریف کنیم:

nimtype 
    BencodeKind* = enum
        btString, btInt, btList, btDict

حالا نوع اصلی یعنی BencodeType را به‌صورت یک «شیء متغیر» (variant object) تعریف می‌کنیم که در زبان‌های دیگر به آن «کلاس‌های case» می‌گویند؛ همراه با دو کلاس ساده Encoder و Decoder:

nim    BencodeType* = ref object
        case kind*: BencodeKind 
        of BencodeKind.btString: s* : string 
        of BencodeKind.btInt: i*    : int
        of BencodeKind.btList: l*   : seq[BencodeType]
        of BencodeKind.btDict: d*  : OrderedTable[BencodeType, BencodeType]

    Encoder* = ref object
    Decoder* = ref object
  • Encoder — یک کلاس ساده برای نمایش عملیات رمزگذاری.
  • Decoder — یک کلاس ساده برای نمایش عملیات رمزگشایی.
  • برای BencodeType از شیء متغیر (در زبان‌های دیگر: case classes) استفاده می‌کنیم. جالب است بدانید که ماژول json نیم هم دقیقاً از همین تکنیک استفاده می‌کند.

پس می‌توانیم این‌طور از آن استفاده کنیم:

nimBencodeType(kind: btString, s:"hello")
BencodeType(kind: btInt, i:55)
let btListSample1 = @[BencodeType(kind:btInt, i:1), BencodeType(kind:btString, s:"hi") ]
BencodeType(kind: btList, l:btListSample1)

قانون کلی این «کلاس‌های case» این است که یک kind تعریف‌شده در enum دارید و با یک سازنده، شیء را می‌سازید. اگر از هسکل (Haskell) یا زبان مشابهی به نیم آمده باشید، این تعریف معادل Haskell زیر است:

haskelldata BValue = BInt Integer
            | BStr B.ByteString
            | BList [BValue]
            | BDict (M.Map BValue BValue)
            deriving (Show, Eq, Ord)

لطفاً توجه داشته باشید: اگر نوع متغیر خودتان را تعریف می‌کنید، باید پروسیجرهای hash و == را نیز تعریف کنید تا بتوانید مقادیر را مقایسه یا هش کنید.

nimproc hash*(obj: BencodeType): Hash = 
    case obj.kind
    of btString : !$(hash(obj.s))
    of btInt : !$(hash(obj.i))
    of btList: !$(hash(obj.l))
    of btDict: 
        var h = 0
        for k, v in obj.d.pairs:
            h = h !& hash(k) !& hash(v)
        !$(h)
  • پروسیجر hash یک Hash برمی‌گرداند و بسته به kind، هش شیء ذخیره‌شده درون آن (رشته، عدد صحیح یا لیست) را برمی‌گرداند یا در صورت لزوم یک هش جدید محاسبه می‌کند.
  • !& را مانند «ادغام دو هش در هم» در نظر بگیرید.
  • !$ برای نهایی‌کردنِ شیء Hash به کار می‌رود.

حالا عملگر برابری را روی BencodeType تعریف می‌کنیم تا مشخص کنیم دو مقدار چه زمانی برابرند — با تعریف پروسیجر برای عملگر ==:

nimproc `==`* (a, b: BencodeType): bool =
    ## بررسی تساوی دو گره
    if a.isNil:
        if b.isNil: return true
        return false
    elif b.isNil or a.kind != b.kind:
        return false
    else:
        case a.kind
        of btString:
            result = a.s == b.s
        of btInt:
            result = a.i == b.i
        of btList:
            result = a.l == b.l
        of btDict:
            if a.d.len != b.d.len: return false
            for key, val in a.d:
                if not b.d.hasKey(key): return false
                if b.d[key] != val: return false
            result = true

و در نهایت یک پروسیجر ساده toString با استفاده از عملگر $ تعریف می‌کنیم:

nimproc `$`* (a: BencodeType): string = 
    case a.kind
    of btString:  fmt("<Bencode {a.s}>")
    of btInt: fmt("<Bencode {a.i}>")
    of btList: fmt("<Bencode {a.l}>")
    of btDict: fmt("<Bencode {a.d}")

رمزگذاری (Encoding)

nimproc encode(this: Encoder,  obj: BencodeType) : string

یک اعلانِ پیشاپیش (forward declaration) برای encode اضافه می‌کنیم؛ چون برای رمزگذاری یک لیست ممکن است مجبور باشیم مقادیر دیگری مثل string یا حتی خود list را رمزگذاری کنیم، بنابراین در صورت نیاز encode را به‌صورت بازگشتی صدا می‌زنیم — در صورت تمایل می‌توانید به بخش بعدی بروید.

nimproc encode_s(this: Encoder, s: string) : string=
    # TODO: بررسی طول
    return $s.len & ":" & s

برای رمزگذاری یک رشته گفتیم که آن را با طولش + : + خود رشته رمزگذاری می‌کنیم.

nimproc encode_i(this: Encoder, i: int) : string=
    # TODO: بررسی طول
    return fmt("i{i}e")

برای رمزگذاری یک عدد صحیح آن را بین حروف i و e قرار می‌دهیم.

nimproc encode_l(this: Encoder, l: seq[BencodeType]): string =
    var encoded = "l"
    for el in l:
        encoded &= this.encode(el)
    encoded &= "e"
    return encoded
  • برای رمزگذاری یک لیست از عناصر نوع BencodeType، مقادیر رمزگذاری‌شده‌شان را بین حروف l و e قرار می‌دهیم.
  • به صدای this.encode دقت کنید؛ به همین دلیل به اعلان پیشاپیش (forward declaration) نیاز داشتیم.
nimproc encode_d(this: Encoder, d: OrderedTable[BencodeType, BencodeType]): string =
    var encoded = "d"
    for k, v in d.pairs():
        assert k.kind == BencodeKind.btString
        encoded &= this.encode(k) & this.encode(v)

    encoded &= "e"
    return encoded
  • برای رمزگذاری یک دیکشنری، مقدار رمزگذاری‌شده زوج‌های کلید/مقدار را بین d و e قرار می‌دهیم.
  • به صدا‌زدن بازگشتی this.encode برای کلیدها و مقادیر دقت کنید.
  • به جمله شرط (assert) دقت کنید: طبق مشخصات Bencode، نوع کلیدها باید حتماً btString باشد.
nimproc encode(this: Encoder,  obj: BencodeType) :  string =
    case obj.kind
    of BencodeKind.btString:  result =this.encode_s(obj.s)
    of BencodeKind.btInt :  result = this.encode_i(obj.i)
    of BencodeKind.btList : result = this.encode_l(obj.l)
    of BencodeKind.btDict : result = this.encode_d(obj.d)

یک پروکسی ساده برای رمزگذاری شیء obj از نوع BencodeType.

رمزگشایی (Decoding)

nimproc decode(this: Decoder,  source: string) : (BencodeType, int)

اعلان پیشاپیش برای decode؛ همان دلیلی که برای encode داشتیم.

nimproc decode_s(this: Decoder, s: string) : (BencodeType, int) =
    let lengthpart = s.split(":")[0]
    let sizelength = lengthpart.len
    let strlen = parseInt(lengthpart)
    return (BencodeType(kind:btString, s: s[sizelength+1..strlen+1]), sizelength+1+strlen)

پس از رمزگشایی یک رشته، یک BencodeType می‌سازیم — این عملیاتِ معکوسِ encode_s است. به‌طور خلاصه: به اندازه strlen کاراکتر بعد از دونقطه را می‌خوانیم و از روی آن یک BencodeType از نوع btString می‌سازیم.

nimproc decode_i(this: Decoder, s: string) : (BencodeType, int) =
    let epos = s.find('e')
    let i = parseInt(s[1..<epos])
    return (BencodeType(kind:btInt, i:i), epos+1)

عدد بین حروف i و e را استخراج می‌کنیم و از روی آن یک BencodeType از نوع btInt می‌سازیم.

nimproc decode_l(this: Decoder, s: string): (BencodeType, int) =
    # عناصر بین l و e هستند
    var els = newSeq[BencodeType]()
    var curchar = s[1]
    var idx = 1
    while idx < s.len:
        curchar = s[idx]
        if curchar == 'e':
            idx += 1
            break
    
        let pair = this.decode(s[idx..<s.len])
        let obj = pair[0]
        let nextobjpos = pair[1] 
        els.add(obj)
        idx += nextobjpos
    return (BencodeType(kind:btList, l:els), idx)

رمزگشایی لیست کمی پیچیده است:

  • عناصر آن بین حروف l و e قرار دارند.
  • بنابراین از اولین حرف «بعد از» l شروع به رمزگشایی اشیاء می‌کنیم تا به e پایانی برسیم. مثلاً:
textli1ei2ee

به این صورت تجزیه می‌شود:

textli120ei492ee
 $   $
  • شیء i120e مصرف می‌شود و مکان‌نما (cursor) به ابتدای شیء دوم یعنی i492e منتقل می‌شود.
  • بعد از مصرف همه اشیاء، حرف پایانی e را هم مصرف می‌کنیم و تمام می‌شویم.
  • به همین دلیل است که همه پروسیجرهای decode یک مقدار int هم برمی‌گردانند تا بدانیم چند کاراکتر باید رد شویم.
nimproc decode_d(this: Decoder, s: string): (BencodeType, int) =
    var d = initOrderedTable[BencodeType, BencodeType]()
    var curchar = s[1]
    var idx = 1
    var readingKey = true
    var curKey: BencodeType
    while idx < s.len:
        curchar = s[idx]
        if curchar == 'e':
            break
        let pair = this.decode(s[idx..<s.len])
        let obj = pair[0]
        let nextobjpos = pair[1]
        if readingKey == true:
            curKey = obj
            readingKey = false
        else:
            d[curKey] = obj
            readingKey = true
        idx += nextobjpos
    return (BencodeType(kind:btDict, d: d), idx)
  • همان تکنیک بالا.
  • به‌طور خلاصه: یک شیء می‌خوانیم؛ اگر کلید جاری نداشته باشیم، آن را به‌عنوان کلید جاری قرار می‌دهیم.
  • اگر کلید جاری داشته باشیم، شیء خوانده‌شده مقدار (value) است؛ پس کلید جاری را به آن مقدار نسبت می‌دهیم و حالت را دوباره به readingKey برمی‌گردانیم.
nimproc decode(this: Decoder,  source: string) : (BencodeType, int) =
    var curchar = source[0]
    var idx = 0
    while idx < source.len:
        curchar = source[idx]
        case curchar
        of 'i':
            let pair = this.decode_i(source[idx..source.len])
            let obj = pair[0]
            let nextobjpos = pair[1] 
            idx += nextobjpos
            return (obj, idx)
        of 'l':
            let pair = this.decode_l(source[idx..source.len])
            let obj = pair[0]
            let nextobjpos = pair[1] 
            idx += nextobjpos
            return (obj, idx)
        of 'd':
            let pair = this.decode_d(source[idx..source.len])
            let obj = pair[0]
            let nextobjpos = pair[1] 
            idx += nextobjpos
            return (obj, idx)
        else: 
            let pair = this.decode_s(source[idx..source.len])
            let obj = pair[0]
            let nextobjpos = pair[1] 
            idx += nextobjpos
            return (obj, idx)

رمزگشایی بر اساس حرف اولِ شیء رمزگذاری‌شده شروع می‌شود: i برای عدد صحیح، l برای لیست، d برای دیکشنری؛ در غیر این صورت سعی می‌کند یک رشته را تجزیه کند.

سازنده‌ها و API عمومی

پروسیجرهای سازنده ساده برای newEncoder و newDecoder:

nimproc newEncoder*(): Encoder =
    new Encoder

proc newDecoder*(): Decoder = 
    new Decoder
nimproc encodeObject*(this: Encoder, obj: BencodeType) : string =
    return this.encode(obj)

encodeObject فراخوانی را به پروسیجر encode ارجاع می‌دهد.

nimproc decodeObject*(this: Decoder, source:string) : BencodeType =
    let p = this.decode(source)
    return p[0]

decodeObject یک API دوستانه‌تر ارائه می‌دهد و به جای جفت BencodeType و «چند کاراکتر باید خوانده شود»، فقط همان BencodeType را از decode برمی‌گرداند.
