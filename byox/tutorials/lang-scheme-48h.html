آشنایی با کتاب

این آموزش که از سال ۲۰۰۷ روی ویکی‌بوک در حال رشد است، با دو هدف نوشته شده: آموزش Haskell به شکل عملی و ساخت یک مفسر Scheme کامل. در طول مسیر، با مفاهیم Haskell (Function Composition، Functor/Monad، Parsec و …) و مفاهیم کامپایلر (نمایش داده، محیط، ارزیابی) آشنا می‌شوید.

ساختار سفر

کتاب در ۷ فصل پیش می‌رود: (۱) نمایش و ارزیابی ساده (اعداد، اتم‌ها)؛ (۲) پارسینگ با Parsec (تعریف LispVal و گرامر)؛ (۳) ارزیابی و مدیریت خطا (Either/Error)؛ (۴) افزودن نوع‌های داده (لیست‌ها، بولی، رشته) و توابع؛ (۵) متغیرها و محیط (با State monad، کلیدواژهٔ define و set!)؛ (۶) توابع به‌عنوان مقدار (lambda) و توابع با آرگومان؛ (۷) IO واقعی و توابع پایه (readFile، writeFile).

نمونهٔ کد: نوع داده و ارزیابی

Haskell-- نمایش مقادیر نطق‌پذیر
data LispVal = Atom String
             | List [LispVal]
             | DottedList [LispVal] LispVal
             | Number Integer
             | String String
             | Bool Bool

-- قلب مفسر: ارزیابی در محیط
eval :: Env -> LispVal -> IOThrowsError LispVal
eval env val@(String _) = return val
eval env val@(Number _) = return val
eval env val@(Bool _)   = return val

eval env (List [Atom "quote", val]) = return val

eval env (List [Atom "if", cond, t, f]) = do
  result <- eval env cond
  case result of
    Bool False -> eval env f
    _          -> eval env t

eval env (List (Atom func : args)) = do
  funcVal <- eval env (Atom func)
  argVals <- mapM (eval env) args
  apply funcVal argVals

همهٔ جزئیات مهم interpret‌ر — از quote تا فراخوانی تابع — در همین چند سطر دیده می‌شود.

نکته‌ها و درس‌ها

در فصول میانی، با خطاهای رایج مفسرنویسان آشنا می‌شوید (خطای show و نمایش اشتباه) و یاد می‌گیرید که چطور MonadError و State را ترکیب کنید. در فصل آخر، مفسر قابلیت خواندن پرایم‌ها و توابع پایهٔ IO را پیدا می‌کند و می‌توانید اسکریپت‌های Scheme واقعی را اجرا کنید.
