موتورهای فیزیک چگونه کار می‌کنند

⚙ زبان: JavaScript ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمه فارسی مقاله «How Physics Engines Work» از Burak Kanber (سایت Build New Games، ۲۰۱۲) است — یک مقدمه کاربردی و سرراست با جاوااسکریپت: گرانش، انتگرال‌گیری، برخورد با زمین و پرش توپ در چند ده خط کد.

۱. فیزیک در بازی چگونه کار می‌کند؟

روش‌های متعددی برای «فیزیک» در بازی وجود دارد، از ساده‌ترین تا پیچیده‌ترین. یکی از ساده‌ترین و مؤثرترین روش‌ها این است: به‌جای اینکه در هر فریم، جا‌به‌جایی جسم را مستقیم تعیین کنید، به جسم یک شتاب (مثلاً گرانش) بدهید و بگذارید سرعت و مکان آن هر فریم از روی شتاب محاسبه شود. دنیای فیزیکی این‌گونه «خودش» رفتار طبیعی پیدا می‌کند.

پس به‌جای این کد:

javascript// رویکرد غیرفیزیکی: ما مکان را مستقیم تعیین می‌کنیم
ball.y += 10; // توپ با سرعت ثابت سقوط می‌کند!

این کد را می‌نویسیم:

javascript// رویکرد فیزیکی: فقط نیروها را اعمال می‌کنیم
ball.velocityY += GRAVITY * dt;   // سرعت با شتاب تغییر می‌کند
ball.y += ball.velocityY * dt;    // مکان با سرعت تغییر می‌کند

۲. گرانش و «حلقه فیزیک»

موتور فیزیک اغلب همراه با حلقه رندر از requestAnimationFrame کار می‌کند. در هر فریم: سرعت را با گرانش به‌روز کنیم، مکان را با سرعت به‌روز کنیم و سپس برخوردها را بررسی کنیم. این روش «انتگرال‌گیری اویلر» نام دارد و به‌رغم سادگی برای بیشتر بازی‌ها کافی است:

javascriptfunction update(dt) {
    // گرانش به سمت پایین
    ball.velocityY += GRAVITY * dt;

    // جابه‌جایی
    ball.y += ball.velocityY * dt;
    ball.x += ball.velocityX * dt;

    // برخورد با زمین
    if (ball.y + ball.radius > floorY) {
        ball.y = floorY - ball.radius;
        ball.velocityY = -ball.velocityY * RESTITUTION;
    }
}

RESTITUTION ضریب بازگشت است: مقدار ۰٫۷ یعنی توپ در هر برخورد ۳۰ درصد انرژی خود را از دست می‌دهد — درست مثل توپ واقعی.

۳. رندر و چرخه فریم

حلقه اصلی با requestAnimationFrame ساخته می‌شود و بین به‌روزرسانی فیزیک و رسم، تفکیک می‌کند:

javascriptfunction loop(now) {
    var dt = (now - lastTime) / 1000; // اختلاف زمان به ثانیه
    lastTime = now;

    update(dt); // منطق فیزیک
    draw();     // رسم روی canvas

    requestAnimationFrame(loop);
}
requestAnimationFrame(loop);
نکته: در بازی‌های جدی‌تر از گام زمانی ثابت (fixed timestep) استفاده می‌شود تا رفتار فیزیک روی فریم‌ریت‌های مختلف یکسان بماند.

۴. اصطکاک و مقاومت

یک ترفند ساده و قدرتمند: ضرب سرعت در یک عدد کمی کمتر از ۱ در هر فریم، هم «مقاومت هوا» می‌سازد و هم از مرزهای عددی جلوگیری می‌کند:

javascript// مقاومت: هر فریم کمی از سرعت کم می‌شود
ball.velocityX *= 0.98;
ball.velocityY *= 0.98;

همین الگو با ضریب‌های متفاوت روی محورها، «اصطکاک زمین در برابر اصطکاک هوا» را شبیه‌سازی می‌کند.

۵. جمع‌بندی

مقاله با همین اصول ساده — شتاب، انتگرال‌گیری عددی و برخورد با سطح — یک دنیای کوچک با توپ‌های جهنده می‌سازد و نشان می‌دهد شروع کار با موتور فیزیک بسیار آسان‌تر از آن است که فکر می‌کنید. بعد از این پایه، سراغ مباحث واقعی‌تر بروید: برخورد بین اجسام، چرخش، و حل‌کننده ایمپالس (اینجا در همین مجموعه مقاله‌های دیگر Build New Games مثل مقاله «فاز گسترده تشخیص برخورد» وجود دارد).

کپیرایت: مقاله «How Physics Engines Work» اثر بوراک کانبر (Burak Kanber) و متعلق به سایت Build New Games است. این صفحه فقط ترجمه فارسی آن است و تمام حقوق محتوا و کدها متعلق به نویسنده اصلی است. برای مشاهده اصل مطلب به سایت اصلی مراجعه کنید.
