دربارهٔ ویدیو

این ویدیوی بلند و آموزشی، روند کامل ساخت یک کامپایلر را نشان می‌دهد: از تعریف زبان ورودی ساده تا تولید کد اجرایی. دیدن ویدیو برای شروع، دیدن خروجی کامپایلر روی کد خود شما و مرور اشتباه‌های رایج، تجربه‌ای بسیار ارزشمند است.

▶ تماشای ویدیو

آنچه در ویدیو می‌سازید

وسط مسیر، درک شما از سه مفهوم اصلی روشن می‌شود: lexer (تبدیل متن به token)، parser (تبدیل tokenها به درخت نحو) و code generator (تبدیل درخت به کد اسمبلی/ماشین). تفاوت این آموزش با آموزش‌های متنی، دیدن «حل کردن خطاهای لحظه‌ای» است.

نمونه‌ای از ساختار توکن

اگر با مفاهیم اصلی آشنا نیستید، این بخش به‌عنوان پیش‌زمینه است؛ ساختار توکن معمولاً این‌گونه است:

C++enum TokenType {
  TOK_NUMBER,   // عدد
  TOK_IDENT,    // شناسه (متغیر)
  TOK_PLUS,     // +
  TOK_STAR,     // *
  TOK_LPAREN,   // (
  TOK_RPAREN,   // )
  TOK_EOF
};

struct Token {
  TokenType type;
  std::string text;   // متن خام توکن
  long double value;  // اگر عدد بود
};

نکته‌های کلیدی که از ویدیو می‌گیرید

۱) ساده شروع کنید: اول یک زبان با اعداد و چهار عمل؛ ۲) به‌تدریج شرط‌ها و حلقه‌ها را اضافه کنید؛ ۳) همیشه خروجی اسمبلی را با gcc یا clang تست کنید؛ ۴) هر بار یک قابلیت اضافه کنید تا اشکال‌یابی ساده بماند.

جمع‌بندی

برای یادگیری بصری، کمترین هزینهٔ ورودی و بیشترین بینش: این ویدیو شما را از «کامپایلر چیست؟» به «می‌توانم خودم بسازم» می‌رساند. پس از آن، برای عمق بیشتر به سری‌های متنی مثل acwj بروید.

کپیرایت: سازندهٔ ویدیو. این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
