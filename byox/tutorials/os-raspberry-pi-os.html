raspberry-pi-os — سیستم‌عامل لینوکس‌گونه روی Raspberry Pi 3

⚙ زبان: C + Assembly (AArch64) 🍓 Raspberry Pi 3 ✅ ترجمه شده 🔗 منبع اصلی
منبع اصلی: این صفحه ترجمهٔ فارسی و مرور پروژهٔ raspberry-pi-os از سرگئی ماتیوکویچ (Sergey Matyukevich) است که یک سیستم‌عامل چندوظیفه‌ای و «لینوکس‌گونه» را در ۶ درس برای Raspberry Pi 3 (معماری AArch64) می‌سازد — با مقایسهٔ هر مرحله با لینوکس واقعی.
↗ مشاهده منبع اصلی

۱. دربارهٔ پروژه

این مخزن در ۶ درس، یک سیستم‌عامل نسبتاً کامل برای Raspberry Pi 3 می‌سازد که در پایان قادر است چندین فرایند کاربر را هم‌زمان اجرا کند و بین آنها جابه‌جا شود — درست مثل لینوکس مینیاتوری. ویژگی متمایز این دوره: بعد از هر درس، یک فصل مقایسه وجود دارد که نشان می‌دهد لینوکس واقعی همان کار را چگونه انجام می‌دهد. پشتیبانی از QEMU هم وجود دارد که توسعه بدون سخت‌افزار را ممکن می‌کند.

۲. شش درس

  • درس ۱ — آماده‌سازی کرنل: ساختار بوت، تنظیم آدرس‌ها، پشته و اولین کد C؛ روشن کردن UART برای خروجی سریال.
  • درس ۲ — آماده‌سازی پردازنده: مدیریت پردازنده، جدول Exception Levelها و حالت‌های اجرا (EL1/EL0 در AArch64).
  • درس ۳ — وقفه‌ها: IRQ و کنترل‌کنندهٔ وقفه؛ پیاده‌سازی زمان‌سنج و ورودی صفحه‌کلید با وقفه.
  • درس ۴ — زمان‌بند (Scheduler): تعریف فرایندها، بلوک کنترل فرایند (PCB) و جابه‌جایی بین فرایندها.
  • درس ۵ — فرایندهای کاربر: حالت کاربر (EL0)، فراخوان‌های سیستم (syscall) و اجرای برنامه‌های کاربری.
  • درس ۶ — حافظهٔ مجازی: MMU، جداول صفحه و ترجمهٔ آدرس مجازی به فیزیکی.

۳. نمونهٔ کد: بوت و اولین پیام (درس ۱)

اولین قدم، اسمبلی بوت است که پشته را تنظیم می‌کند و کنترل را به C می‌سپارد — و سپس راه‌اندازی UART برای چاپ «Hello World»:

arm// kernel.c (درس ۱) — راه‌اندازی UART و چاپ پیام
#include "uart.h"

void kernel_main(void) {
    uart_init();               // راه‌اندازی پورت سریال
    uart_send_string("Hello, world!\n");

    while (1) {
        // یک کاراکتر بخوان و برگردان (پژواک)
        uart_send(uart_recv());
    }
}

مشاهدهٔ خروجی: تصویر کرنل (kernel8.img) را روی کارت SD بگذارید و به پورت سریال وصل شوید، یا در QEMU با -kernel kernel8.img اجرا کنید تا متن را روی کنسول ببینید.

۴. تفاوت این دوره با دیگران

  • معماری مدرن: AArch64 (۶۴ بیتی) به‌جای x86 قدیمی — دیدی متفاوت به وقفه‌ها و حافظه می‌دهد.
  • مقایسه با لینوکس: هر مفهوم با اجرای واقعی در لینوکس مقایسه می‌شود؛ پیوند آموزش و واقعیت.
  • مسیر کامل: از بوت تا فرایندهای کاربر و حافظهٔ مجازی — تقریباً همهٔ اجزای یک سیستم‌عامل کوچک.
  • پشتیبانی QEMU: اگر برد ندارید، همه‌چیز شبیه‌سازی می‌شود.
نکتهٔ تکمیلی: این پروژه تکمیل‌کنندهٔ طبیعی Baking Pi است: بعد از یادگیری ARM از پایه در Baking Pi، این دوره همان زبان را برای ساخت یک سیستم‌عامل کامل‌تر به کار می‌گیرد.
