۱. دربارهٔ دوره

این دورهٔ چندساعته (منتشرشده توسط freeCodeCamp) یک موتور بازی دو‌بعدی را از صفر در جاوا می‌سازد و سپس با همان موتور یک بازی کامل شبیه Super Mario (کلون) توسعه می‌دهد. در پایان، بازی شما در قالب یک بستهٔ jar قابل اجرا بسته‌بندی می‌شود — یعنی یک بازی واقعی که می‌توانید روی هر سیستمی اجرا کنید.

نکته: این دوره برای مبتدیان طراحی شده: حتی نصب JDK و راه‌اندازی محیط هم در ابتدای ویدیو آموزش داده می‌شود.

۲. ویدیو را تماشا کنید

این آموزش ویدیویی است و محتوای آن در این صفحه میزبانی نمی‌شود؛ از لینک زیر مستقیم به یوتیوب بروید:

▶ تماشای دورهٔ «Code a 2D Game Engine using Java»

۳. محتوای دوره

  • ساخت پنجرهٔ بازی و حلقهٔ اصلی (Game Loop) با Java Swing/AWT
  • سیستم GameObject: موجودیت‌های قابل رندر با موقعیت و اندازه
  • فیزیک پایه: گرانش، سرعت و برخورد با پلتفرم‌ها
  • انیمیشن اسپرایت: کنترل فریم‌ها برای راه‌رفتن و پرش
  • دوربین و صحنه: حرکت بین سطوح و اسکرول
  • ادیتور سطح: ساخت و طراحی مراحل با ابزار ساخته‌شده در دوره
  • بسته‌بندی نهایی با jar

// حلقهٔ اصلی بازی: ۶۰ فریم در ثانیه
public class GameWindow implements Runnable {
    public void run() {
        while (running) {
