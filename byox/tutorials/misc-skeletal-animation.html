بارگذاری و رندر انیمیشن‌های سه‌بعدی اسکلتی از صفر در C# و GLSL

انیمیشن اسکلتی چیست؟

وقتی یک شخصیت سه‌بعدی راه می‌رود، کل مدل جابه‌جا نمی‌شود؛ بلکه یک اسکلت (سلسله‌مراتب استخوان‌ها) درون آن حرکت می‌کند و هر رأس mod به‌وسیلهٔ ماتریس استخوان‌های مجاورش جابه‌جا می‌شود. این روش «skeletal animation» یا «skinning» نام دارد.

در این آموزش، همهٔ بخش‌ها از صفر ساخته می‌شود: ساختار skeleton، بارگذاری animation (با فرمت gLTF ساده‌شده) و shader که ماتریس‌های استخوان را اعمال می‌کند.

ریاضیات: ماتریس استخوان

قلب کار، محاسبهٔ «ماتریس نهایی» برای هر استخوان است: `global = parent * local`. این ماتریس‌ها به شیدر فرستاده می‌شوند و در آن‌جا برای هر رأس به‌صورت وزنی (weight) ترکیب می‌شوند:

C#// محاسبهٔ ماتریس‌های جهانی استخوان‌ها با پیمایش درخت
void ComputeBoneMatrices(Bone[] bones, int parentIndex,
                         Matrix4 parentMatrix) {
    for (int i = 0; i < bones.Length; i++) {
        if (bones[i].parent != parentIndex) continue;

        // ماتریس جهانی = ماتریس والد × ماتریس محلی
        Matrix4 local = bones[i].localTransform;
        Matrix4 global = local * parentMatrix;

        // ماتریس نهایی برای رندر (inverse bind × global)
        boneMatrices[i] = bones[i].inverseBindMatrix
                          .Multiply(global);
        ComputeBoneMatrices(bones, i, global);
    }
}

متغیر `inverseBindMatrix` رأس را از «فضای مدل» به «فضای استخوان» می‌برد تا فقط حرکت استخوان به آن اعمال شود.

شیدر و vertex skinning

هر رأس، چند شاخص استخوان و چند وزن دارد (مثلاً ۴). شیدر باید ماتریس‌های متناظر را جمع کند:

GLSL// ورودی‌های رأس: موقعیت، وزن‌ها و شاخص استخوان
layout(location = 0) in vec3 aPosition;
layout(location = 3) in vec4 aWeights;
layout(location = 4) in ivec4 aBoneIndices;

uniform mat4 uBoneMatrices[24];
uniform mat4 uModelViewProjection;

void main() {
    // ترکیب ماتریس استخوان‌ها با وزن‌ها
    mat4 skin =
        uBoneMatrices[aBoneIndices.x] * aWeights.x +
        uBoneMatrices[aBoneIndices.y] * aWeights.y +
        uBoneMatrices[aBoneIndices.z] * aWeights.z +
        uBoneMatrices[aBoneIndices.w] * aWeights.w;

    vec4 worldPos = skin * vec4(aPosition, 1.0);
    gl_Position = uModelViewProjection * worldPos;
}

این شیدر است که حرکت اسکلتی را به گرافیک تبدیل می‌کند؛ بدون آن، انیمیشن فقط روی کاغذ می‌ماند.

بارگذاری فرمت و پخش انیمیشن

بخش بارگذاری، نمونه‌ها (keyframes) را می‌خواند و بین position/rotation درون‌یابی می‌کند. برای سادگی، از چارگشتی‌ها (quaternion) برای دوران استفاده می‌شود تا از «گیمبال لاک» جلوگیری شود.

در پایان، یک loop سادهٔ animation player دارید که ماتریس‌ها را با dt آپدیت می‌کند و شخصیت را راه می‌برد یا می‌دود.

جمع‌بندی

این آموزش تمام ریاضیات پشت «شخصیت‌های متحرک» را آشکار می‌کند: سلسله‌مراتب ماتریس، inverse bind و رندر وزنی. بعد از اتمام، فرمت‌های تجاری (FBX، glTF) برایتان جعبهٔ شفاف می‌شوند.
