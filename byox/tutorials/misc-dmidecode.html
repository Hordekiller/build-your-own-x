dmidecode چیست؟

ابزار `dmidecode` اطلاعات سخت‌افزار سیستم را از جداول SMBIOS/DMI می‌خواند: سازندهٔ مادربرد، نسخهٔ BIOS، نوع حافظه، شمارهٔ سریال و... این داده‌ها روی خروجی استاندارد به‌صورت متن ساخت‌یافته چاپ می‌شوند و معمولاً برای اتوماسیون سرورها (مانیتورینگ، inventory) باید تجزیه شوند.

ساختار خروجی

خروجی dmidecode به شکل «بخش‌ها» است: هر بخش با نوع (Type) و Handle شروع می‌شود و سپس فیلدها با تورفتگی می‌آیند؛ دستهٔ اطلاعات مانند BIOS، System و Baseboard:

Nim# خروجی نمونه:
# Handle 0x0000, DMI type 0, 24 bytes
# BIOS Information
#     Vendor: American Megatrends Inc.
#     Version: 5.19
#     Release Date: 08/10/2023
# Handle 0x0001, DMI type 1, 27 bytes
# System Information
#     Manufacturer: LENOVO
#     Product Name: ThinkPad T14

الگوی نقطهٔ شروع هر بخش: خطی که با `Handle` شروع می‌شود و نوع DMI و اندازه را می‌گوید، و خط بعدی نام دسته.

پارسر در Nim

پارسر خط‌به‌خط می‌خواند؛ وقتی خط `Handle` دید، بخش جدیدی را شروع می‌کند و فیلدهای تورفتاده را به آن می‌چسباند:

Nimimport strutils, tables, sequtils

type
  DmiRecord = object
    dmiType: int
    name: string
    fields: Table[string, string]

proc parseDMI(content: string): seq[DmiRecord] =
  var
    current: DmiRecord
    inRecord = false

  for line in content.splitLines():
    if line.startsWith("Handle"):
      if inRecord: result.add(current)
      # استخراج نوع از: Handle 0x0001, DMI type 1, 27 bytes
      let m = line.findAll("\d+")
      current = DmiRecord(
        dmiType: parseInt(m[1]),
        name: "", fields: initTable[string, string]()
      )
      inRecord = true
    elif line.startsWith("    ") and inRecord:
      let parts = line.strip().split(":", 1)
      if parts.len == 2:
        current.fields[parts[0]] = parts[1].strip()
    elif inRecord and not line.startsWith(" "):
      current.name = line.strip()

  if inRecord: result.add(current)

نکتهٔ ظریف: فیلدها ۴ فضای تورفتگی دارند، ولی نام بخش بدون تورفتگی است؛ همین دو قانون کافی است کل خروجی را ساختارمند کنیم.

به سمت ابزار واقعی

وقتی داده ساختارمند شد، می‌توانید سریال‌های سرور را جمع کنید، MAC کارت‌های شبکه را از بخشهای نوع 41 (Onboard Device) بخوانید یا خروجی JSON بسازید. `dmidecode` بیش از ۴۰ نوع DMI دارد؛ همین آموزش پایهٔ خواندن همهٔ آن‌هاست.
