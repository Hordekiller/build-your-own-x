MQTT و نقش بروکر

MQTT یک پروتکل پیام‌رسانی سبک برای IoT است که بر پایهٔ مدل publish/subscribe کار می‌کند. در این مدل، دستگاه‌ها (clients) به موضوعاتی (topics) مشترک می‌شوند و بروکر وظیفه دارد پیام‌های منتشرشده را به مشترکین درست برساند. بروکر «قلب» سیستم است: بدون آن هیچ پیامی جابه‌جا نمی‌شود.

پیاده‌سازی بروکر به شما یاد می‌دهد که پروتکل باینری را بفهمید: هر پیام MQTT یک fixed header با یک byte از نوع و علامت، و به‌دنبالش باقی‌ماندهٔ بدنه با طول Variable-Length (۲ بایت LSB).

ارسال و دریافت: ساختار پروتکل

اولین گام، تعریف ساختار header و پارس آن است. برای مثال، پیام CONNECT شامل `protocol level` و `client id` است، و پیام SUBSCRIBE باید `packet identifier` و topic-filter را حمل کند:

Ctypedef struct {
    uint8_t type: 4;      // نوع پیام (1=CONNECT, 3=PUBLISH, ...)
    uint8_t flags: 4;
    uint8_t remaining_len; // طول Variable Byte Integer
} mqtt_fixed_header;

// یک تابع ساده برای ساخت پیام PUBLISH
int build_publish(uint8_t* buf, const char* topic,
                  const char* payload, int payload_len) {
    int off = 0;
    buf[off++] = 0x30;                    // PUBLISH QOS0
    int rem = 2 + strlen(topic) + payload_len;
    buf[off++] = (uint8_t)rem;
    buf[off++] = (strlen(topic) >> 8) & 0xff;
    buf[off++] = strlen(topic) & 0xff;
    memcpy(buf + off, topic, strlen(topic));
    off += strlen(topic);
    memcpy(buf + off, payload, payload_len);
    off += payload_len;
    return off;
}

این بافر، خروجی کاملی از یک پیام publish است که می‌توان آن را روی socket ارسال کرد.

مدیریت اشتراک‌ها

قلب بروکر، ساختار داده‌ای است که «topic → list of clients» را نگه می‌دارد. وقتی پیامی منتشر می‌شود، باید آن را به همهٔ مشترکین آن topic (یا wildcardها) ارسال کنیم. این کار با یک تری/هش‌مپ و چند رشتهٔ همزمان انجام می‌شود.

چالش‌های مهم: همزمانی (یک پیام چند کلاینت را می‌گیرد)، قطعی شدن QoS، و رفتار با clientهای بدون پاسخی (keep-alive). برای شروع، پیاده‌سازی تک‌نخی و سپس افزودن pthread کافی است.

جمع‌بندی

ساخت بروکر MQTT یک پروژهٔ واقعی و لذت‌بخش است: پروتکل پیام‌رسانی، شبکه و همزمانی را در کنار هم درگیر می‌کند. بعد از این پروژه، با مفاهیم pub/sub و نحوهٔ کار بروکرهای تجاری (مثل Mosquitto) عمیقاً آشنا می‌شوید.
