۲. نورون: جمع وزن‌دار و فعال‌سازی

هر نورون ورودی‌ها را با وزن‌ها ضرب و جمع می‌کند، بایاس اضافه می‌کند و نتیجه را از تابع فعال‌سازی می‌گذراند. در این مقاله خروجی خطی است (بدون فعال‌سازی در لایهٔ آخر) چون مسئله رگرسیون است. وزن اولیه تصادفی است — یادگیری یعنی یافتن وزن‌های درست:

python# محاسبه‌ی خروجی یک نورون: Σ(ورودی × وزن) + بایاس
def output(self, inputs):
    total = np.dot(self.weights, inputs) + self.bias
    return total   # بدون فعال‌سازی (رگرسیون)

۳. تابع هزینه: میانگین مربعات خطا (MSE)

کیفیت پیش‌بینی با MSE سنجیده می‌شود: میانگین مجذور اختلاف پیش‌بینی‌ها و مقادیر واقعی. هدف آموزش، کمینه‌کردن این عدد است. گرادیان MSE نسبت به خروجی ساده است: 2×(خروجی − واقعی) / تعداد نمونه‌ها — همین سادگی، همگرایی آموزش را شفاف می‌کند.

python# تابع هزینه‌ی میانگین مربعات خطا
def mse_loss(predictions, targets):
    return np.mean((predictions - targets) ** 2)
