جدول هش چیست و چرا مهم است؟

جدول هش (hash table) ساختاری است که با استفاده از یک تابع هش، کلید را به یک ایندکس در آرایه می‌نگارد؛ بهاین‌ترتیب جست‌وجو، افزودن و حذف در حالت متوسط O(1) می‌شود. تقریباً همه‌چیز — از دیکشنری‌های پایتون تا کش مرورگر — روی همین ساختار بنا شده‌اند.

ساختن یک جدول هش در C به شما یاد می‌دهد که حافظه را مدیریت کنید و دربارهٔ برخورد (collision) و بزرگ‌شدن جدول تصمیم بگیرید؛ چیزهایی که در زبان‌های سطح بالا پنهان‌اند.

ساختارهای پایه و توابع هش

اولین گام، تعریف ساختارهای `ht_item` (عنصر شامل کلید و مقدار) و `ht_hash_table` (آرایهٔ عناصر و اندازه). تابع هش، رشته را به یک عدد بزرگ و then modulo تبدیل می‌کند:

C#include <stdlib.h>
#include <string.h>

typedef struct {
    char* key;
    char* value;
} ht_item;

// تابع هش ساده: جمع وزنی کاراکترها
static int hash(const char* s, const int a, const int m) {
    long hash = 0;
    const int len = strlen(s);
    for (int i = 0; i < len; i++) {
        hash = (hash * a + s[i]) % m;
    }
    return hash;
}

این تابع را می‌توان با تنظیم `a` (که نخست‌وزن است) و `m` (اندازهٔ جدول) بهینه کرد تا توزیع یکنواخت‌تری داشته باشیم.

مدیریت برخورد با زنجیره‌سازی

وقتی دو کلید به یک ایندکس می‌رسند، «برخورد» رخ داده است. ساده‌ترین راه، زنجیره‌سازی است: هر خانهٔ جدول، یک لیست پیوندی از عناصر است. راه دیگر، «گشویی باز» (open addressing) است که در آن عنصر به خانهٔ بعدی خالی منتقل می‌شود.

در این آموزش از گشویی باز استفاده می‌شود؛ یعنی هنگام جست‌وجو اگر خانه اشغال بود، با پرش منظم ادامه می‌دهیم تا خانهٔ خالی پیدا شود.

درج و بازیابی

تابع‌های `ht_insert` و `ht_search` هستهٔ جدول را می‌سازند:

C// درج یک جفت کلید/مقدار
void ht_insert(ht_hash_table* ht, const char* key, const char* value) {
    ht_item* item = ht_new_item(key, value);
    int index = hash(key, ht->base_size, ht->size);
    ht_item* cur = ht->items[index];

    // گشویی باز: خانهٔ خالی یا خانه با همان کلید را پیدا کن
    int i = index;
    while (cur != NULL) {
        if (cur != &DELETED_ITEM) {
            if (strcmp(cur->key, key) == 0) {
                free(cur->value);
                cur->value = item->value;
                free(item);
                return;
            }
        }
        i = (i + 1) % ht->size;
        cur = ht->items[i];
    }
    ht->items[i] = item;
    ht->count++;
    // وقتی پر شد، بزرگش کن
    if (ht->count == ht->size) ht_resize_up(ht);
}

در این کد، خانهٔ حذف‌شده با نشانگر اختصاصی `DELETED_ITEM` مشخص می‌شود تا زنجیرهٔ گشویی قطع نشود؛ و وقتی جدول پر شد، `ht_resize_up` اندازه را دو برابر می‌کند.

جمع‌بندی

این آموزش با تکیه بر تست و گام‌های کوچک، جدول هش را در C کامل می‌کند. بعد از اتمام، به عمق مفاهیمی مثل «برخورد»، «بزرگ‌شدن جدول» و «مدیریت حافظه» مسلط می‌شوید و می‌توانید رفتار ساختار در زبان‌های دیگر را هم راحت‌تر بفهمید.
