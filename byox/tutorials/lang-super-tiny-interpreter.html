The Super Tiny Interpreter — مفسر فوق‌کوچک (رفیق کامپایلر فوق‌کوچک)

منبع اصلی: این صفحه ترجمهٔ فارسی و مرور «Super Tiny Interpreter» نوشتهٔ کیان ژانگ است — مفسری که AST کامپایلر فوق‌کوچک را مستقیم اجرا می‌کند.
↗ مشاهده منبع اصلی

مکمل طبیعی کامپایلر فوق‌کوچک

در «کامپایلر فوق‌کوچک» یاد گرفتیم که AST را به کد C تبدیل کنیم؛ اما گزینهٔ دیگر این است که به‌جای تولید کد، همان AST را بگیریم و مستقیم «ارزیابی» کنیم — این یعنی یک مفسر. این پروژه دقیقاً همین کار را انجام می‌دهد و در نتیجه، مقایسهٔ «کامپایل» در برابر «تفسیر» را ملموس می‌کند.

ساختار

مانند نسخهٔ کامپایلر، کد در چند بخش مرتب است: tokenizer و parser (همان ورودی Lisp-like)، سپس یک evaluator که با پیمایش AST و یک جدول محیط متغیرها را نگه می‌دارد. قلب مفسر تابع interpret است:

JavaScriptfunction interpret(ast, env = {}) {
  const node = ast;

  switch (node.type) {
    case 'NumberLiteral':
      return Number(node.value);

    case 'CallExpression': {
      // هر آرگومان را ارزیابی کن
      const args = node.arguments.map(arg => interpret(arg, env));

      // تابع را از محیط پیدا کن (مثلاً add یا subtract)
      const func = env[node.callee];
      if (typeof func !== 'function')
        throw new Error(`تابع ${node.callee} تعریف نشده است`);

      return func.apply(null, args);
    }
    default:
      throw new Error(`گرهٔ نامشخص: ${node.type}`);
  }
}

// محیط اولیه: توابع پایه
const env = {
  add: (a, b) => a + b,
  subtract: (a, b) => a - b,
};

const ast = parse(tokenize('(add 2 (subtract 4 2))'));
console.log(interpret(ast, env)); // 4

چرا مقایسهٔ این دو مهم است؟

بین دو پروژه تفاوت ظریفی هست: کامپایلر خروجی «کد» می‌دهد (خودش اجرا نمی‌کند)، مفسر خروجی «مقدار» می‌دهد (خودش اجرا می‌کند). مفهوم «هزینهٔ اجرا» و «هزینهٔ کامپایل» را می‌فهمید — در دنیای واقعی، JIT (اجرای درحال‌کامپایل) ترکیبی از هر دو است.

نکتهٔ آموزشی

اگر می‌خواهید محیط را گسترش دهید (متغیرها، if، lambda)، این بهترین نقطهٔ شروع است: کد کوتاه است و می‌توانید interpret را برای هر گرهٔ جدید توسعه‌دهید. همین الگو — جدول symbol ها و ارزیابی بازگشتی — در مفسرهای واقعی (مثل jlox) به مقیاس بزرگ اجرا می‌شود.

کپیرایت: کیان ژانگ (Keyan Zhang). این صفحه فقط ترجمهٔ فارسی و مرور آن است و تمام حقوق محتوا، تصاویر و کدها متعلق به نویسندهٔ اصلی است. برای مشاهدهٔ اصل مطلب به سایت اصلی مراجعه کنید.
